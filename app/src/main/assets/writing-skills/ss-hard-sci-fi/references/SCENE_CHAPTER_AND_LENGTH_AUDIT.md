# 场景、章节与自然篇幅审计

## 目录

- 场景合同与科学说明
- 视角、冲突和悲剧
- 章节审计
- 自然篇幅与密度审计
- 扩写和删减判断

## 使用场景

在写作、续写、润色章节，或判断故事能否自然支撑目标字数时使用。

## 一、场景合同

进入正文前回答：

```text
视角人物：
此刻想得到什么：
谁或什么在阻止：
人物拥有和缺失的信息：
场景中的具体物理任务：
必须作出的选择：
选择的即时成本：
退出时局势、关系或认知改变了什么：
哪些感官细节只有这个环境才会出现：
```

若人物没有欲望、阻力和退出变化，场景可能只是说明材料。

## 二、科学说明进入场景的方式

优先通过以下载体呈现：

- 故障诊断与维修顺序
- 医疗知情同意和副作用
- 能源、空气、时间或算力配给
- 事故调查和责任争议
- 训练、认证和技能失误
- 法庭、听证、谈判与保险定价
- 不同专业人员对同一数据的分歧
- 普通用户误用设备后的后果

解释到足以理解人物选择即可。不要为展示研究成果而暂停情节。

## 三、视角纪律

- 只写视角人物能够感知、回忆、推断或误解的内容。
- 专家会省略基础步骤，却注意异常；外行会注意表面现象，却可能使用错误术语。
- 不同人物对同一技术应有不同的身体经验、经济成本和道德语言。
- 不要让作者结论伪装成所有人物同时拥有的常识。

## 四、冲突与悲剧

冲突不必每次表现为暴力，但必须存在无法靠补充一句信息立刻消失的欲望、利益或价值矛盾。

允许人物受伤、犯罪、死亡或失败，同时检查：

- 事件是否源于此前选择与条件，而非随机惩罚
- 暴力是否改变资源、责任、关系或叙事
- 受害者是否拥有超越“促使主角成长”的人物价值
- 幸存者是否承担哀悼、调查、赔偿、羞耻、替班或政治利用
- 平静章节是否给损失留下回声

不要为了证明作品“成熟”而机械增加死亡，也不要为了所谓人文关怀替所有主要人物取消代价。

## 五、章节审计

完成一章后检查：

| 项目 | 问题 |
|---|---|
| 功能 | 删除本章会失去什么不可替代的变化？ |
| 人物 | 视角人物主动做了什么？ |
| 科学 | 技术的能力和限制是否同时可见？ |
| 关系 | 人与人之间的距离是否发生变化？ |
| 后果 | 前文决定是否在本章产生具体账单？ |
| 节奏 | 说明、行动、情感和感官是否失衡？ |
| 连续性 | 时间、地点、知识、伤势和资源是否一致？ |
| 退出 | 最后一段是否建立了新的压力、理解或余味？ |

连续两章只推进同一种功能时，考虑合并或改变视角与尺度。

## 六、自然篇幅法

先估算故事单位，再估算字数：

1. 列出卷级不可逆变化。
2. 为每卷列出人物选择、关系转折、公共事件和后果章节。
3. 判断每章需要一个完整场景、多个短场景还是跨时段蒙太奇。
4. 根据已有正文的真实平均章长估算区间，不预设所有章节等长。
5. 设置三个弹性指标：
   - **自然目标区间**：现有结构在充分展开时最可能形成的篇幅。
   - **下限检查线**：低于此值时检查人物、关系、日常与后果是否被压缩。
   - **弹性上限**：只有内容自然生长时才允许接近，不作为必须完成的指标。

不要把下限当作交稿数字，也不要用无关支线追逐上限。

## 七、密度审计

从章纲中分别统计或抽样：

- 制度、战争、调查和重大事件章节
- 科学、工程、故障和发现章节
- 人物选择与成长章节
- 关系、家庭、照护和亲密章节
- 工作、消费、娱乐和普通生活章节
- 决策后果、哀悼、维修和责任章节

若前两类远高于其余类别，作品可能“设定很厚、人物很薄”。优先增加会改变关系和后果的场景，不要增加更多百科设定。

## 八、扩写与删减判断

值得扩写：

- 关键选择缺乏足够的私人代价
- 人物立场变化没有经历可见过程
- 制度成果突然出现，缺少失败、谈判和执行
- 死亡或灾难没有后续生活影响
- 技术只在说明中存在，没有进入身体与工作

应该删减或合并：

- 同一科学原理被多次完整解释
- 不同人物重复表达相同主题结论
- 支线既不改变人物，也不改变主线条件
- 连续危机只升级规模，没有新增选择
- 日常场景没有关系变化，只为展示未来用品

长篇的充实感来自累积与回响，不来自单位字数内塞入更多名词。
