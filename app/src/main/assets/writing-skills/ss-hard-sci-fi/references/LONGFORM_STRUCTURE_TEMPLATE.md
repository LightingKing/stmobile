# 中长篇与多卷本结构模板

## 目录

- 全书脊柱与结构选择
- 故事线和卷级合同
- 章节台账与冲突升级
- 伏笔谜团
- 结构压力测试

## 使用场景

在设计十万字以上总纲、多卷结构、故事线、视角汇流、章纲、伏笔或重构节奏时使用。

## 一、先定义全书脊柱

```text
核心“如果”：
主题问题：
开篇世界仍相信什么：
结尾世界再也无法相信什么：
主轴人物最初如何逃避选择：
最终必须承担什么责任：
全书不可逆的制度或文明变化：
结局解决什么、保留什么：
```

全书脊柱不是事件摘要，而是“人物与世界共同发生了何种不可逆变化”。

## 二、选择结构，不默认三幕式

- **多幕结构**：适合连续升级的单一主危机。
- **多卷结构**：适合时间跨度大、制度阶段清晰、每卷有局部闭合的作品。
- **群像汇流结构**：适合多地、多阶层和信息不对称，先独立后交叉。
- **编年结构**：适合跨数十年或数代人的技术与社会演变。
- **谜团结构**：适合证据真假、人工智能意图或外源信号等认知冲突。
- **混合结构**：可以让卷级采用阶段结构、全书采用群像汇流，不必只选一种。

选择能够承载主题和时间尺度的结构，不为套公式增加转折。

## 三、故事线台账

至少区分：

| 故事线 | 起始问题 | 推进主体 | 独立高潮 | 与其他线的依赖 | 最终回收 |
|---|---|---|---|---|---|
| 科学与工程 |  |  |  |  |  |
| 政治与制度 |  |  |  |  |  |
| 经济与阶层 |  |  |  |  |  |
| 人物成长 |  |  |  |  |  |
| 关系与家庭 |  |  |  |  |  |
| 谜团与证据 |  |  |  |  |  |
| 日常生活 |  |  |  |  |  |

并非每部作品都需要全部故事线，但长篇不能只剩连续发生的公共事件。

## 四、卷级合同

每卷填写：

```text
卷名与时间范围：
主视角及占比倾向：
开卷时的稳定状态：
本卷向读者承诺的问题：
主要欲望冲突：
工程或制度限制：
中段不可逆变化：
本卷高潮中的选择：
人物付出的代价：
局部闭合：
留给下一卷的新条件：
新增伏笔与本卷回收：
```

每卷应改变下一卷的边界条件。若删除一卷不影响后续，它可能只是放大的支线。

## 五、章节台账

| 章 | 视角 | 时间地点 | 眼前欲望 | 阻力与信息差 | 关键选择 | 退出状态 | 推进故事线 | 伏笔状态 |
|---|---|---|---|---|---|---|---|---|

章节至少完成以下一项，关键章节完成两项以上：

- 改变局势
- 改变关系
- 改变人物对事实的理解
- 展示此前决定的具体代价
- 建立后续必然回收的承诺

只有解释世界、重复情绪或搬运角色的章节应合并、重写或删除。

## 六、升级尺度

让冲突从不同维度升级，而不只是增加爆炸规模：

1. 个人工作和身体风险
2. 亲密关系与职业责任冲突
3. 组织资源和法律身份冲突
4. 城市或生态系统的公共风险
5. 行星间合法性、战争或文明路径冲突

大型危机之后安排调查、维修、哀悼、宣传、赔偿、权力重组和私人关系变化。后果本身就是下一阶段的情节。

## 七、伏笔与谜团

为每个重要伏笔记录：

```text
表层信息：
首次出现：
谁看见、谁误解、谁隐瞒：
可检验的替代解释：
中途强化或反证：
计划回收位置：
回收后改变什么选择：
若最终保持开放，读者仍能确认什么：
```

不要只用“作者暂不告诉读者”制造悬念。让人物确实受限于证据、距离、权限、记忆或立场。

## 八、结构压力测试

- 主轴人物缺席一段时间后，世界是否仍在运动？
- 每位次主角是否拥有独立高潮，而不只是协助主角？
- 技术突破是否过早解决了后续全部问题？
- 同一种冲突是否只换地点重复？
- 每卷是否都出现新的选择，而非只有更大的灾难？
- 伏笔回收是否改变人物行为，而非只证明作者聪明？
- 结局的制度成果是否由此前谈判、失败和牺牲逐步获得？
