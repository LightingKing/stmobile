# 世界观因果推演模板

## 目录

- 世界契约与六段因果链
- 历史时间线与权力组织
- 富足之后的稀缺
- 身份分类与日常生活
- 矛盾审查

## 使用场景

在构建或审查未来历史、政治、经济、组织、法律、身份、生态和日常生活时使用。

## 一、世界契约

```text
故事时间与跨度：
主要空间尺度：
与现实分叉的关键年份：
一至三个核心技术变化：
没有发生的常见科幻奇迹：
世界表面上的承诺：
世界实际稀缺的事物：
普通人的一天发生了什么变化：
```

控制核心突破数量。每增加一个突破，都要推演它与已有技术、制度和价格的相互作用。

## 二、六段因果链

对每项重大技术填写：

| 环节 | 问题 |
|---|---|
| 能力 | 它让谁第一次能做什么？ |
| 成本 | 什么变便宜，什么仍昂贵，新增了什么隐性成本？ |
| 所有权 | 谁拥有设备、数据、燃料、专利、算力或航线？ |
| 制度 | 法律、税收、福利、军队、公司和家庭如何调整？ |
| 日常 | 工作、教育、婚育、医疗、娱乐、犯罪和死亡如何变化？ |
| 冲突 | 谁受益、谁承担风险、谁被排除、谁组织反抗？ |

若因果链跳过中间环节，不要直接声称某项技术必然导致某种政治结果。

## 三、历史时间线

每个节点同时记录“能力”和“后果”：

| 年份 | 事件 | 当时可用能力 | 直接赢家与输家 | 五年后的意外后果 | 正文中的证据 |
|---|---|---|---|---|---|

避免让所有关键突破集中在开篇前一年。给科研、基础设施、普及、监管和代际文化变化留出时间。

## 四、权力与组织

为重要组织记录：

```text
正式目标：
实际生存需求：
合法性来源：
掌握的稀缺资源：
无法控制的依赖：
内部派系：
公开手段：
隐秘手段：
不可接受的失败：
愿意牺牲的人：
与其他组织的交换关系：
```

不要把组织写成单一人格。让制度惯性、派系、基层执行者和正式文件彼此产生摩擦。

## 五、富足之后的稀缺

当能源和自动生产降低基本生活成本时，继续追踪：

- 安全住房和有利地理位置
- 可靠算力、低延迟网络与模型权限
- 高阶医疗、寿命工程和真实人体服务
- 教育中的人类注意力、信誉和社会网络
- 有意义的工作、公共发言权和风险决定权
- 私密空间、未被预测的时间和不被优化的人生
- 稀缺体验、身份象征、原创文化和亲密关系

区分“活得下去”“活得体面”“能够实现自我”和“能够决定他人命运”。

## 六、身份与分类

为人类、改造人、共智者、克隆体、数字代理、普通机器人和人格型合成主体建立互斥或明确重叠的定义。至少记录：

- 生物或机械载体
- 认知增强来源
- 是否具有连续记忆和自主目标
- 生殖、复制、备份与继承方式
- 医疗、维修和死亡的法律定义
- 劳动身份、财产权和政治代表权
- 群体内部差异及其自称、他称和蔑称

不要让一个术语在不同文件中同时指向生物增强者和具身机器人。

## 七、日常生活取样

每个主要社会至少设计以下场景：

1. 一个普通工作日
2. 一次医疗或维修
3. 一顿饭及其供应链
4. 一次教育、考试或技能认证
5. 一次恋爱、婚育或监护冲突
6. 一次行政手续或法律争议
7. 一次娱乐、宗教或纪念活动
8. 一场事故、犯罪或葬礼

如果世界观只能在峰会和实验室中成立，它还不足以支撑长篇。

## 八、矛盾审查

- 宣称物资富足，却没有解释土地、医疗和机会为何仍稀缺
- 宣称完全自治，却依赖对手提供无法替代的关键部件
- 宣称人工智能接管劳动，却没有重新设计收入、身份和消费
- 宣称群体获得平权，却没有展示登记、责任、保险和继承变化
- 宣称技术普及，却只让重要角色使用
- 宣称国际组织统一行动，却没有内部国家、派系和执行落差

发现矛盾时优先把它发展为冲突；只有破坏核心逻辑时才直接消除。
