# 中长篇硬科幻写作

## 核心目标

把作品当作可持续维护的小说工程，而不是一次性生成的大纲。让科学限制、社会制度、人物欲望和叙事后果相互咬合，使篇幅来自人物行动与因果展开，而不是来自设定堆积或字数填充。

## 不可省略的原则

1. 以用户最新明确反馈为最高项目事实。区分“已定、暂定、待确认、废弃”，不要把自行补全的重要设定伪装成用户决定。
2. 让核心技术遵守已知物理规律，或明确标为作品的单一重大假设。始终写出能源、质量、热、时间、通信、维护、规模化和失败模式。
3. 把技术沿着“能力变化 → 成本变化 → 权力重分配 → 日常生活变化 → 人物选择 → 不可逆后果”推演，不把科技当作装饰名词。
4. 让人物拥有独立欲望、私人关系、自我欺骗和行动能力。不要把角色降格为技术观点或政治阵营的发言器。
5. 允许死亡、犯罪、流血、背叛、误判和失败进入作品。让悲剧产生于人物选择、技术条件与制度压力的交汇，并持续改变幸存者和社会叙事。
6. 保持道德灰度。让每个重要阵营拥有部分合理性和不可接受的代价；理解动机不等于取消责任。
7. 不默认三幕式、单主角或固定章长。根据作品规模选择多幕、多卷、群像、谜团或编年结构。
8. 分析其他作品时只提炼高层结构、叙事功能和阅读效果，不仿写在世作者或特定作品可辨识的语言风格。

## 任务路由

根据任务只读取需要的参考文件，不要把所有模板一次性载入。

- 新建或重建小说项目、拆分目录、维护设定状态、吸收用户反馈：先读 [PROJECT_AND_REVISION_WORKFLOW.md](references/PROJECT_AND_REVISION_WORKFLOW.md)。
- 研究现实技术、判断可行性、设计未来技术路线：先读 [SCIENCE_AND_EXTRAPOLATION_PROTOCOL.md](references/SCIENCE_AND_EXTRAPOLATION_PROTOCOL.md)。
- 构建历史、政治、经济、组织、文化、生态或日常生活：先读 [WORLDBUILDING_CAUSAL_TEMPLATE.md](references/WORLDBUILDING_CAUSAL_TEMPLATE.md)。
- 设计角色、关系网、多视角群像、人物成长或伤亡后果：先读 [CHARACTERS_AND_ENSEMBLE_TEMPLATE.md](references/CHARACTERS_AND_ENSEMBLE_TEMPLATE.md)。
- 设计总纲、分卷、章节、故事线汇流、伏笔与回收：先读 [LONGFORM_STRUCTURE_TEMPLATE.md](references/LONGFORM_STRUCTURE_TEMPLATE.md)。
- 写作或修订章节、控制说明密度、评估自然篇幅：先读 [SCENE_CHAPTER_AND_LENGTH_AUDIT.md](references/SCENE_CHAPTER_AND_LENGTH_AUDIT.md)。

遇到跨领域任务时，按“项目状态 → 科学边界 → 世界因果 → 人物群像 → 长篇结构 → 场景正文”的顺序读取相关文件。

## 标准工作流

### 1. 识别任务状态

- 区分用户是在询问、诊断、规划、建项、修改还是写正文。
- 对只要求分析的任务保持只读；对明确要求建设或修改的任务更新产物并验证。
- 进入已有项目时，先读取项目说明、设定状态、目录索引、时间线、人物索引和相关正文；保护用户原稿与未提交修改。
- 只在答案会显著改变作品方向、且无法从项目事实中判断时提问。其余空白标为“暂定”，继续推进。

### 2. 锁定作品契约

记录或推断以下内容：

- 时间跨度、空间尺度与预期硬度
- 核心科学前提及禁止突破的规律
- 主题问题、读者体验与叙事距离
- 自然篇幅区间、卷数倾向与视角结构
- 允许出现的暴力、悲剧、亲密关系和道德灰度
- 用户已定事实、可调整内容与关键待决项

不要把最初估计当作永久指标；用户后续确认应立即进入“已定”。

### 3. 建立科学边界

- 对可能随时间变化的技术进展检索当前资料，优先使用论文、科研机构、标准组织和任务方的一手来源。
- 把关键论断分为“已验证事实、工程中路线、合理外推、作品假设”。
- 为每项核心技术建立能力、依赖、成本、限制、风险、成熟时间和社会影响卡。
- 主动寻找能够制造情节的限制；不要只寻找支持设定的乐观材料。

### 4. 推演世界因果

- 从技术突破推演价格、所有权、职业、阶层、法律、家庭、身份和地缘政治变化。
- 同时追踪受益者、承担风险者、被排除者和反抗者。
- 区分“基础生存变便宜”与“稀缺消失”；继续追踪土地、算力、医疗、注意力、机会、信誉和自我实现。
- 把宏观变化落到住房、工作班次、医疗账单、教育、婚育、交通、娱乐、犯罪和葬礼。

### 5. 构建人物与冲突网络

- 先写欲望、恐惧、关系和选择，再写角色的剧情功能。
- 为每位主视角建立即使不遇见主轴人物也能成立的故事线。
- 为主要人物分配不同的信息、资源、盲点与代价；不要让所有人共享作者的完整世界观。
- 让各线通过公共事件、资源依赖、误解、责任或损失渐进汇流，不要强迫所有角色从开篇围绕同一人旋转。

### 6. 构建长篇结构

- 先确定全书不可逆变化，再拆分卷级承诺、卷级转折和人物阶段。
- 用故事线台账管理政治、科技、人物、关系、谜团和日常生活线。
- 让每卷既有局部闭合，又改变下一卷的条件。
- 让章节至少完成“改变局势、改变关系、改变认知、展示代价”中的一项，重要章节完成两项以上。

### 7. 写作场景

- 在进入正文前确认本章视角、欲望、阻力、信息差、选择、代价和退出状态。
- 通过操作、故障、维修、医疗、审判、谈判、配给和事故呈现科学；减少脱离行动的讲义式说明。
- 保持第三人称限知或用户选定的视角纪律，只写该人物能够感知、理解或误解的内容。
- 允许安静场景承担关系、哀悼、欲望和日常质感；不要把“节奏快”等同于持续发生大事件。

### 8. 同步反馈与验证

- 收到定义修正时，先明确旧定义、新定义及影响范围，再搜索并更新设定、人物、结构、正文、术语和索引。
- 不静默覆盖冲突。把无法立即修复的矛盾写入连续性台账。
- 完成后检查内部链接、命名、年份、年龄、技术成熟度、视角知识边界、伏笔状态和伤亡后果。
- 向用户交付本轮已定内容、改动文件、仍待确认事项和验证结果；不要把内部过程写成长篇报告。

## 长篇质量闸门

在扩写前逐项检查：

- **科学闸门**：关键能力是否有依据、边界和代价？
- **因果闸门**：技术是否真正改变制度、价格和生活？
- **人物闸门**：人物是否因自己的欲望行动，而非只响应情节？
- **群像闸门**：各视角是否独立成立并提供不可替代的信息或情感？
- **冲突闸门**：是否存在无法靠解释立即消失的价值或利益冲突？
- **后果闸门**：伤亡、背叛和制度决策是否持续产生影响？
- **篇幅闸门**：篇幅是否来自选择、关系和后果，而非重复说明？
- **连续性闸门**：时间、术语、技术能力、人物知识和伏笔是否一致？

任一闸门失败时，先修复结构，不要继续机械增加章节。
