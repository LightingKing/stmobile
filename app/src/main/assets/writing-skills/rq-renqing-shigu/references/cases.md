# 真实案例库

下面这些案例都来自联网搜索到的真实网页，用来校准 `人情世故.skill` 的判断和输出风格。

## 案例 1：深夜工作群“已读未回”

- 日期：2024-12-04
- 来源：澎湃新闻转载上游新闻
- 链接：https://m.thepaper.cn/newsDetail_forward_29547749

### 发生了什么

某企业负责人在晚上 10:05 于工作群发出“全面停止调休”的消息并 `@所有人`，因无人回复，凌晨 2:10 再次发言并表示“不回复的一律按照旷工处理”。

### 这个案例说明什么

- 在中国职场语境里，很多领导深夜发通知，第一诉求不是讨论，而是“有人接收”
- 回复过多会把夜间对话继续拉长
- 完全不回又容易被解释为“态度问题”

### Skill 应学到什么

- 通知类消息先短回执
- 只确认接收，不展开
- 给自己留到白天再处理的空间

## 案例 2：熟人介绍相亲，怎么拒绝才不伤长辈

- 来源：V2EX《怎么应对相亲》
- 链接：https://fast.v2ex.com/t/163738

### 发生了什么

发帖人被家中长辈和熟人反复推动相亲，不想去，又担心伤害 70 多岁长辈的感情和面子。

### 这个案例说明什么

- 这类场景的压力常常不来自相亲对象，而来自介绍人和家庭网络
- 直接评价对方不好，容易让介绍人觉得自己“好心办坏事”
- 真正高情商的拒绝，是把原因落在自己的节奏和状态上

### Skill 应学到什么

- 先谢介绍人费心
- 不评价对方
- 把责任揽到自己的阶段和状态
- 帮介绍人保住“这次不是白忙，是时机不对”

## 案例 3：和领导思路不一致，被拉会批斗

- 来源：V2EX《领导专门拉了个会批斗了我一番。大伙帮忙看下，我的设计思路很离谱么》
- 链接：https://v2ex.com/t/902902

### 发生了什么

发帖人写了一份设计文档，但没有提前征求上级意见，最终和领导方向不一致，被领导专门开会批评。

### 这个案例说明什么

- 中国职场里，公开分歧往往不只是技术分歧，也是角色秩序问题
- 很多领导更在意“你有没有先对齐我”，而不仅是方案本身
- 会上正面顶撞，容易把专业讨论变成立场冲突

### Skill 应学到什么

- 反对意见先对齐目标
- 不上来否定
- 把“你错了”改成“我补一个执行风险 / 备选方案”

## 案例 4：同事出差吃饭，AA 还是轮请

- 来源：V2EX《北方同事之间吃饭是 AA 还是轮请制》
- 链接：https://v2ex.com/t/1151528

### 发生了什么

出差同事一起吃了三顿饭，付款规则没有提前说清，一位同事连续垫付，事后才发现不同人对“AA”“轮请”“地主之谊”理解完全不同，导致尴尬和不满。

### 这个案例说明什么

- 规则不透明时，最容易出现“我以为”和“你以为”
- 钱不一定多，但体感会非常伤关系
- 事后追讨最怕语气像翻旧账

### Skill 应学到什么

- 金钱规则尽量前置
- 事后要钱改成“顺手对一下”
- 给对方一个文化差异或习惯差异的缓冲解释

## 案例 5：专注做事时，不回别人是不是情商低

- 来源：V2EX《专注做事时不回复任何外部请求是情商低吗？》
- 链接：https://www.v2ex.com/t/579358

### 发生了什么

发帖人专注做事时经常不回应他人的呼叫和请求，认为自己不是故意不礼貌，但同事会觉得协作体验差。

### 这个案例说明什么

- 在协作环境里，“完全不回”常被理解为不尊重，而不只是忙
- 立刻接单会破坏专注
- 更优解是“快速确认 + 延后处理”

### Skill 应学到什么

- 给一个简短响应
- 明确回复时间
- 对紧急事项开放绿色通道

## 备注

这些案例不是为了证明“人情世故万能”，而是为了限制 skill 的幻觉：

- 它必须处理真实世界的关系复杂度
- 它不能只会写漂亮鸡汤
- 它要在体面和边界之间找到更稳的平衡
