# 万能句式模板库

本文档包含6大类36个可直接套用的万能句式模板，支持动态替换关键词。

---

## 使用说明

### 句式结构

```
【句式编号】句式名称
使用场景：...
句式模板：... [关键词] ...
示例：...
```

### 关键词说明

- `[事项]`：具体的工作、任务、项目名称
- `[原因]`：具体的原因说明
- `[方案]`：解决方案或改进措施
- `[时间]`：具体的时间节点
- `[人物]`：具体的人员或部门
- `[成果]`：具体的成果或数据

## 一、表态类句式（T01-T06）

### T01 接受任务表态

**使用场景：** 领导布置任务、会议布置工作

**句式模板：**
```
收到，我会认真落实[事项]，进展情况及时[汇报/同步]。
```

**示例：**
> "收到，我会认真落实这个项目，进展情况及时汇报。"
> "收到，我会认真落实领导的要求，进展情况及时同步给各位。"

**变体（互联网风格）：**
> "收到，我理解的目标是[目标]，预计[时间]交付，中间会同步进展。"

**变体（体制内风格）：**
> "收到，我会立即贯彻落实，进展情况及时向领导汇报。"

---

### T02 支持赞同表态

**使用场景：** 会议表态、同意某项建议

**句式模板：**
```
我完全认同/支持[事项]，后续会[行动]。
```

**示例：**
> "我完全认同领导的分析，后续会认真落实。"
> "我支持这个方案，后续会全力配合推进。"

**变体（会议发言）：**
> "领导的意见我完全赞同。在此基础上，我补充一点：[补充内容]。"

---

### T03 承担责任表态

**使用场景：** 接手项目、承担工作

**句式模板：**
```
[事项]我来牵头负责，过程中如有问题及时[汇报/请示]。
```

**示例：**
> "这个项目我来牵头负责，过程中如有问题及时汇报。"
> "这项工作我来负责，过程中如有需要协调的地方及时请示。"

**变体（团队协作）：**
> "[事项]我来主责，XX同事配合支持，确保顺利推进。"

---

### T04 改进承诺表态

**使用场景：** 接受批评、复盘改进

**句式模板：**
```
我会认真总结[事项]，吸取教训，确保不再发生类似问题。
```

**示例：**
> "我会认真总结这次失误，吸取教训，确保不再发生类似问题。"
> "我会认真反思，引以为戒，后续工作中一定注意。"

**变体（互联网风格）：**
> "我会复盘这次的问题，沉淀经验，后续迭代改进。"

---

### T05 配合支持表态

**使用场景：** 跨部门协作、支持他人工作

**句式模板：**
```
我们会全力配合[事项]，确保[目标]。
```

**示例：**
> "我们会全力配合这个项目，确保按时完成。"
> "我们会全力配合XX部门的工作，确保顺利推进。"

**变体（明确边界）：**
> "在[具体范围]内，我们会全力配合。"

---

### T06 延缓表态

**使用场景：** 需要时间考虑、不确定事项

**句式模板：**
```
这个问题我需要[研究/核实/请示]一下，[会后/明天]给您答复。
```

**示例：**
> "这个问题我需要研究一下，会后给您答复。"
> "这个情况我需要核实一下，明天给您回复。"
> "这个事项我需要请示领导，确认后再汇报。"

## 二、拒绝类句式（T07-T12）

### T07 委婉拒绝

**使用场景：** 拒绝不合理请求、帮忙请求

**句式模板：**
```
这事我确实想帮忙，但目前[困难]，要不[替代方案]？
```

**示例：**
> "这事我确实想帮忙，但目前手头有急活走不开，要不等我忙完这段？"
> "这事我确实想帮忙，但这周已经排满了，要不你看看其他同事？"

---

### T08 推活话术

**使用场景：** 被安排不合理工作

**句式模板：**
```
这个工作[原因]，建议由[人物]牵头，我们可以配合支持。
```

**示例：**
> "这个工作专业性较强，建议由XX部门牵头，我们可以配合支持。"
> "这个工作涉及XX领域，建议由XX同事负责更合适，我们可以配合。"

**变体（程序理由）：**
> "这个工作按程序需要XX部门会签，要不先走一下流程？"

---

### T09 推责任话术

**使用场景：** 被问及不属于自己的责任

**句式模板：**
```
这个问题涉及[范围]，可能需要[人物]来回答更合适。
```

**示例：**
> "这个问题涉及XX领域，可能需要XX部门来回答更合适。"
> "这个情况我了解不够全面，可能需要XX来解释更清楚。"

---

### T10 推邀约话术

**使用场景：** 拒绝饭局、活动邀约

**句式模板：**
```
谢谢邀请，这次确实不太方便，下次一定[约/补上]。
```

**示例：**
> "谢谢邀请，这次确实不太方便，下次一定约！"
> "谢谢邀请，那天已经有安排了，下次我请大家补上！"

**变体（身体原因）：**
> "谢谢邀请，最近身体不太舒服，这次先不去了，下次一定。"

---

### T11 能力不足推辞

**使用场景：** 不擅长的工作、超出能力范围

**句式模板：**
```
这个工作我可能不太擅长，担心做不好耽误事，要不找[人物]？
```

**示例：**
> "这个工作我可能不太擅长，担心做不好耽误事，要不找XX？"
> "XX领域确实不是我的强项，怕影响质量，建议由XX来负责。"

---

### T12 优先级冲突推辞

**使用场景：** 手头有其他工作无法兼顾

**句式模板：**
```
目前手头有[事项]在推进，这个可能需要协调一下优先级，您看我先做哪个？
```

**示例：**
> "目前手头有XX项目在推进，这个可能需要协调一下优先级，您看我先做哪个？"
> "这周排期已满，建议排到下周，或者看看有没有其他同事可以支援？"

## 三、澄清类句式（T13-T18）

### T13 澄清事实

**使用场景：** 需要说明真实情况

**句式模板：**
```
关于这个问题，情况是[事实]，依据是[证据]。
```

**示例：**
> "关于这个问题，情况是我们已经完成了XX，依据是项目进度表。"
> "关于这个事项，实际情况是XX，有邮件记录可以查证。"

---

### T14 澄清分工

**使用场景：** 责任边界不清

**句式模板：**
```
关于[事项]，我理解的分工是：我负责[部分]，[人物]负责[部分]。建议我们确认一下边界。
```

**示例：**
> "关于这个项目，我理解的分工是：我负责XX部分，XX负责XX部分。建议我们确认一下边界。"
> "为确保顺利推进，建议我们明确一下各自的责任范围。"

---

### T15 澄清立场

**使用场景：** 表明个人看法，留有余地

**句式模板：**
```
我个人的看法是[观点]，但还需要[综合考虑/请示领导]。
```

**示例：**
> "我个人的看法是这个方案可行，但还需要综合考虑其他因素。"
> "我个人倾向于XX方向，但具体还需要请示领导。"

---

### T16 澄清误解

**使用场景：** 被误解需要解释

**句式模板：**
```
可能是沟通有误解，我的本意是[真实意图]。
```

**示例：**
> "可能是沟通有误解，我的本意是希望大家能提前沟通。"
> "可能是我表达不够清晰，我想说的是XX。"

---

### T17 澄清进度

**使用场景：** 说明工作进展

**句式模板：**
```
关于[事项]，目前的进展是[状态]，预计[时间]完成。
```

**示例：**
> "关于这个项目，目前的进展是已完成80%，预计本周五完成。"
> "目前整体进度正常，预计下周可以交付。"

---

### T18 澄清困难

**使用场景：** 说明遇到的挑战

**句式模板：**
```
在推进[事项]过程中，遇到了[困难]，原因是[原因]，建议[方案]。
```

**示例：**
> "在推进项目过程中，遇到了资源不足的问题，原因是预算有限，建议协调增派人手。"
> "XX环节遇到了一些挑战，主要是XX原因，建议XX方案解决。"

---

## 四、延缓类句式（T19-T24）

### T19 延缓表态

**使用场景：** 需要时间考虑

**句式模板：**
```
这个问题我需要[研究/考虑]一下，[时间点]给您答复。
```

**示例：**
> "这个问题我需要研究一下，明天给您答复。"
> "这个建议很好，我需要考虑一下，会后给您回复。"

---

### T20 延缓决策

**使用场景：** 不急于做决定

**句式模板：**
```
这个建议很好，我再和[人物/团队]讨论一下，确保考虑周全。
```

**示例：**
> "这个建议很好，我再和团队讨论一下，确保考虑周全。"
> "这个方案值得讨论，我先和XX对齐一下意见。"

---

### T21 延缓回应

**使用场景：** 需要了解情况

**句式模板：**
```
这事涉及的面比较广，我需要[了解情况/调研]，确认后再回复您。
```

**示例：**
> "这事涉及的面比较广，我需要了解情况，确认后再回复您。"
> "这个问题需要调研一下，我整理好后再汇报。"

---

### T22 延缓执行

**使用场景：** 需要协调资源

**句式模板：**
```
目前[困难]，这个可能需要协调一下[资源/优先级]，您看[方案]？
```

**示例：**
> "目前手头有急活，这个可能需要协调一下优先级，您看我先做哪个？"
> "目前资源紧张，可能需要协调一下人力，您看是否可以增派支持？"

---

### T23 延缓讨论

**使用场景：** 需要更多时间讨论

**句式模板：**
```
这个问题比较复杂，要不我们[会后/改天]专门讨论？
```

**示例：**
> "这个问题比较复杂，要不我们会后专门讨论？"
> "这个话题值得深入讨论，要不改天专门安排一个会议？"

---

### T24 延缓承诺

**使用场景：** 不急于承诺

**句式模板：**
```
这事我需要[评估/确认]，目前不便承诺，请您理解。
```

**示例：**
> "这事我需要评估一下，目前不便承诺，请您理解。"
> "这个需要确认一下资源情况，暂时不能保证，请您理解。"

## 五、肯定类句式（T25-T30）

### T25 肯定领导

**使用场景：** 表达对领导的认同

**句式模板：**
```
领导的分析/决策很全面，我完全认同，后续会[行动]。
```

**示例：**
> "领导的分析很全面，我完全认同，后续会认真落实。"
> "领导的决策站位高，我完全赞同，会后立即推进。"

---

### T26 肯定同事

**使用场景：** 肯定同事的建议或工作

**句式模板：**
```
[人物]的建议很好，在此基础上我补充一点：[补充内容]。
```

**示例：**
> "XX的建议很好，在此基础上我补充一点：XX方面还需要注意。"
> "XX说得有道理，我想补充的是..."

---

### T27 肯定下属

**使用场景：** 表扬下属的工作

**句式模板：**
```
你最近在[方面]做得不错，继续保持，有需要支持的地方随时说。
```

**示例：**
> "你最近在XX方面做得不错，继续保持，有需要支持的地方随时说。"
> "这次项目你表现很好，继续加油，后续会给你更多机会。"

---

### T28 肯定方案

**使用场景：** 认同某个方案

**句式模板：**
```
这个方案整体可行，有几个细节可以再优化：[优化建议]。
```

**示例：**
> "这个方案整体可行，有几个细节可以再优化：XX部分可以调整一下。"
> "方案思路很好，执行层面我有几点建议..."

---

### T29 肯定成果

**使用场景：** 肯定工作成果

**句式模板：**

```
这次[事项]做得很好，特别是[亮点]，感谢大家的努力。
```

**示例：**
> "这次项目做得很好，特别是XX部分很有亮点，感谢大家的努力。"
> "成果超出预期，感谢团队的配合和付出。"

---

### T30 肯定价值

**使用场景：** 肯定某项工作的意义

**句式模板：**
```
这个[事项]很重要，对[目标]有很大价值，值得我们投入。
```

**示例：**
> "这个项目很重要，对公司战略有很大价值，值得我们投入。"
> "这项工作意义重大，希望团队重视。"

## 六、补救类句式（T31-T36）

### T31 失误补救

**使用场景：** 工作失误需要补救

**句式模板：**
```
这个问题确实是我的责任，我已经[补救措施]，确保影响降到最低。
```

**示例：**
> "这个问题确实是我的责任，我已经采取了补救措施，确保影响降到最低。"
> "这个失误我承担，目前正在处理，预计今天可以解决。"

---

### T32 误会补救

**使用场景：** 表达不当造成误会

**句式模板：**
```
可能是我的表达不够清晰，让我再解释一下：[真实意图]。
```

**示例：**
> "可能是我的表达不够清晰，让我再解释一下：我的本意是XX。"
> "刚才可能说得不够清楚，我想表达的是..."

---

### T33 延期补救

**使用场景：** 项目延期需要说明

**句式模板：**
```
延期原因是[原因]，我会加快进度，预计[时间]完成，会及时同步进展。
```

**示例：**
> "延期原因是资源不足，我会加快进度，预计周五完成，会及时同步进展。"
> "进度有所滞后，主要是XX原因，正在加班赶工，预计下周可以追上。"

---

### T34 质量补救

**使用场景：** 质量问题需要改进

**句式模板：**
```
这个问题我已经发现了，正在[改进措施]，预计[时间]解决。
```

**示例：**
> "这个问题我已经发现了，正在优化，预计本周可以解决。"
> "质量确实有提升空间，我们正在改进，后续会有明显改善。"

---

### T35 关系补救

**使用场景：** 人际关系出现问题

**句式模板：**
```
关于之前的事，我想[道歉/澄清]，希望不影响我们的合作关系。
```

**示例：**
> "关于之前的事，我想道个歉，希望不影响我们的合作关系。"
> "之前的误会我想澄清一下，希望我们能继续保持良好的合作。"

---

### T36 形象补救

**使用场景：** 影响职业形象需要挽回

**句式模板：**
```
这次的表现确实不够理想，我会[改进措施]，请您继续观察/支持。
```

**示例：**
> "这次的表现确实不够理想，我会加强学习，请您继续观察。"
> "这次让大家失望了，我会努力改进，用行动证明。"

## 组合使用示例

### 示例1：领导批评

```
T04（改进承诺） + T31（失误补救）
= "我会认真总结这次失误，吸取教训。这个问题确实是我的责任，我已经采取了补救措施，确保影响降到最低。"
```

### 示例2：同事求助

```
T07（委婉拒绝） + T08（推活话术）
= "这事我确实想帮忙，但目前手头有急活走不开。这个工作专业性较强，建议找XX同事，他更擅长这个领域。"
```

### 示例3：汇报工作

```
T17（澄清进度） + T29（肯定成果）
= "关于这个项目，目前的进展是已完成80%。这次团队合作得很好，特别是XX部分很有亮点，感谢大家的努力。"
```

---

> 💡 **使用技巧：** 句式可以单独使用，也可以组合使用。根据具体场景灵活调整关键词，让表达更自然、更贴合实际情况。
