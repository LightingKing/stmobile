## S08：拒绝不合理求助

### 场景描述

同事频繁找你帮忙，有些请求不合理、超出职责或影响你的工作，需要拒绝但不得罪人。

### 错误示范

| 类型 | 错误话术 | 问题 |
|------|----------|------|
| 生硬 | "这不是我的工作" | 不近人情、得罪人 |
| 敷衍 | "我很忙，没空" | 敷衍、没给台阶 |
| 被动 | 默默帮忙，心里抱怨 | 委屈自己 |
| 推诿 | "你找别人吧" | 无担当、没给方案 |

### 高情商标准答案

#### 【委婉拒绝】

**稳妥型：**
> "这事我挺想帮忙的，不过手头确实有急活走不开，你看要不找找XX？或者等我忙完这段？"

**进阶型：**
> "这事我确实想帮忙，但目前这周已经排满了，要不你看看有没有其他同事可以支援？或者我帮你想想其他办法？"

#### 【给替代方案】

**稳妥型：**
> "这个我确实不擅长/不太方便，不过我可以帮你问问XX，或者提供一些资料，你看怎么样？"

**进阶型：**
> "这个事情专业性比较强，我可能不是最合适的人选。要不我帮你对接一下XX？他在这方面更有经验。"

#### 【设定边界】

**稳妥型：**
> "这事我帮一次没问题，但后续可能精力有限，建议还是走正式流程/找相关负责人更稳妥。"

**进阶型：**
> "这次我可以帮你应急，但长期来看，这个事情还是需要明确责任人的。要不我们一起梳理一下分工？"

#### 【用领导做挡箭牌】

**稳妥型：**
> "我也想帮忙，但我这边有领导交办的急事，实在抽不开身，不好意思啊。"

**进阶型：**
> "手头这个活领导盯得紧，实在没精力顾及其他。要不你看看能不能找领导协调一下优先级？"

### 底层逻辑

1. **先肯定对方**：表达帮忙意愿
2. **再陈述困难**：客观陈述，不带情绪
3. **不说"不行"**：说"确实有困难"
4. **给替代方案**：不让对方空手而归
5. **必要时用"领导交办"做挡箭牌**

### 万能句式

```
"这事我确实想帮忙，但目前手头有...走不开。要不看看有没有其他方案，或者等我忙完这段再说？"
```

### 适用环境差异

| 职场环境 | 话术调整 |
|----------|----------|
| 体制内 | 强调"领导交办""按规定" |
| 互联网 | 强调"排期""优先级" |
| 外企 | 强调"bandwidth""capacity" |
| 通用 | 强调"人情""关系维护" |

## S09：同事甩锅、推卸工作

### 场景描述

同事将本该他做的工作推给你，或在项目出现问题时甩锅给你。

### 错误示范

| 类型 | 错误话术 | 问题 |
|------|----------|------|
| 当场翻脸 | "这不是我的活" | 得罪人、不给面子 |
| 被动 | 默默接下，背后抱怨 | 委屈自己 |
| 告状 | 找领导告状 | 显得小心眼 |
| 以牙还牙 | 也甩锅回去 | 恶性循环 |

### 高情商标准答案

#### 【当面澄清（温和但坚定）】

**稳妥型：**
> "这块工作按分工应该是XX负责的吧？我这边可以配合，但主要责任可能还需要您这边来担。要不我们对齐一下分工？"

**进阶型：**
> "关于这个工作，我理解的分工是：我负责...，您负责...。为确保项目顺利推进，建议我们明确一下边界，避免遗漏或重复。"

#### 【书面确认】

**邮件/文档确认：**
> "关于XX工作，我理解的分工是：我负责...，XX负责...。为确保项目顺利推进，建议我们确认一下边界，如有调整请同步更新。"

**项目文档：**
> 在项目文档、Jira、钉钉等平台上明确记录分工，以备查证。

#### 【被甩锅时】

**稳妥型：**
> "这个结果确实不理想。回顾一下，当时的分工是...（拿出依据），我这边负责的是...，已完成。可能需要复盘一下沟通环节有没有信息不对称的地方。"

**进阶型：**
> "关于这个问题，我了解的情况是...。当时我们约定的分工是...（书面记录），我这边负责的部分已经按计划完成。建议我们一起复盘一下，看看哪个环节出了问题。"

#### 【找领导协调（最后手段）】

**稳妥型：**
> "领导，XX项目推进中，关于分工有些拿不准的地方，想请您帮忙协调确认一下，确保项目顺利推进。"

**进阶型：**
> "领导，XX项目在执行过程中，我们发现有一些分工边界不够清晰，影响了效率。想请帮忙协调明确一下，确保后续推进顺畅。"

### 底层逻辑

1. **温和但坚定地澄清边界**
2. **用事实和书面依据说话**
3. **给对方台阶，但也要保护自己**
4. **必要时走正式协调渠道**

### 万能句式

```
"关于XX工作，我理解的分工是...（依据）。为确保项目顺利推进，建议我们确认一下边界，您看可以吗？"
```

### 适用环境差异

| 职场环境 | 话术调整 |
|----------|----------|
| 互联网 | 用文档、Jira确认分工 |
| 体制内 | 用会议纪要、领导协调 |
| 外企 | 用邮件Chain确认 |
| 通用 | 先私下沟通，再正式协调 |

## S10：同事抱怨、负能量

### 场景描述

同事经常抱怨工作、领导、公司，拉着你吐槽负能量，需要应对但不被牵连。

### 错误示范

| 类型 | 错误话术 | 问题 |
|------|----------|------|
| 附和 | 跟着一起抱怨 | 被录音、被告状风险 |
| 制止 | "你别抱怨了" | 得罪人 |
| 参与吐槽 | 附和吐槽领导 | 职场大忌 |
| 转身就走 | 不近人情 | 关系恶化 |

### 高情商标准答案

#### 【转移话题】

**稳妥型：**
> "确实挺不容易的，话说回来，最近那个项目进展怎么样了？"

**进阶型：**
> "理解理解，确实挺难的。对了，刚才说的那个XX事情，后来怎么样了？"

#### 【共情但不表态】

**稳妥型：**
> "我理解你的感受，这事确实挺让人郁闷的。不过换个角度想，也许...（给正向引导）"

**进阶型：**
> "确实不容易，这种情况搁谁都会郁闷。不过既然已经这样了，要不想想有没有什么解决办法？"

#### 【给建议而非附和】

**稳妥型：**
> "这事确实让人头疼，要不你试试和XX沟通一下？或者找机会和领导反映反映？"

**进阶型：**
> "我理解你的难处。这个情况，要不你试着...（给具体建议）？或者找机会走正式渠道反馈一下？"

#### 【保持中立】

**稳妥型：**
> "这个情况我了解不多，不太好评价。不过我相信会有解决办法的。"

**进阶型：**
> "这事确实复杂，我了解的信息有限，可能不太好给意见。要不你找XX聊聊？他可能更了解情况。"

#### 【脱身话术】

**稳妥型：**
> "不好意思啊，我手头还有个急活，咱们改天再聊。"

**进阶型：**
> "理解理解，这事确实让人郁闷。不过我得先去处理个急事，咱们回头再聊。"

### 底层逻辑

1. **共情但不表态**：倾听但不附和
2. **不参与吐槽领导**：不留下把柄
3. **转移话题、给正向引导**
4. **必要时找借口脱身**

### 万能句式

```
"我理解你的感受，这事确实不容易。要不试试...（给建议）？或者换个角度想...（正向引导）。"
```

### 适用环境差异

| 职场环境 | 话术调整 |
|----------|----------|
| 体制内 | 尤其要小心被录音、被告状 |
| 互联网 | 保持职业，避免负能量扩散 |
| 外企 | 保持Professional，不参与八卦 |
| 通用 | 维护关系，但不参与吐槽 |

## S11：同事抢功、越界

### 场景描述

同事在汇报或公开场合抢你的功劳，或越界插手你负责的工作。

### 错误示范

| 类型 | 错误话术 | 问题 |
|------|----------|------|
| 当众对质 | "这是我的功劳" | 让场面尴尬 |
| 忍气吞声 | 默默忍受 | 委屈自己 |
| 告状 | 找领导告状 | 显得格局小 |
| 以牙还牙 | 也去抢他的功 | 恶性循环 |

### 高情商标准答案

#### 【当场补充（温和澄清）】

**稳妥型：**
> "XX补充得很好，我再补充一下细节：这个项目过程中，我们还做了...（强调你的贡献）。"

**进阶型：**
> "感谢XX的分享，我想补充一些关键细节：在...环节，我们遇到了...挑战，当时我负责的...部分...（展示你的贡献）。"

#### 【私下沟通】

**稳妥型：**
> "XX，关于那个项目汇报，我感觉我的贡献没有被充分体现，可能是我多心了，但想和你沟通一下，以后在汇报时能否我们一起对齐一下？"

**进阶型：**
> "XX，有个事想和你聊聊。上次汇报时，我感觉我负责的那部分没有被提到。不是要争功，就是希望以后能一起对齐一下，确保大家的贡献都被看到。"

#### 【用数据说话】

**在汇报时用具体数据、文档链接展示你的贡献：**
> "关于XX项目，我主要负责的部分是...（附链接/数据），成果是..."

**在项目文档中明确记录分工和贡献**

#### 【找领导沟通（必要时）】

**稳妥型：**
> "领导，关于XX项目，我主要负责了...（具体工作），成果是...。想向您汇报一下细节，确保信息同步。"

**进阶型：**
> "领导，关于XX项目，我想补充一些信息：我负责的部分是...，完成了...。可能汇报时没有充分展示，想和您同步一下。"

### 底层逻辑

1. **当场补充而非对质**：给对方面子
2. **私下沟通而非公开撕破脸**
3. **用数据、事实说话**：不空口争功
4. **必要时让领导知道你的贡献**

### 万能句式

```
"XX说得很好，我再补充一下：这个项目过程中，我主要负责了...（具体工作），成果是..."
```

### 适用环境差异

| 职场环境 | 话术调整 |
|----------|----------|
| 互联网 | 用文档、日志、代码提交记录说话 |
| 体制内 | 用会议纪要、书面材料证明 |
| 外企 | 用邮件Chain、项目报告 |
| 通用 | 私下沟通，不给对方难堪 |

## S12：协作冲突、意见不合

### 场景描述

与同事在项目方向、工作方式上意见不合，产生争执或僵局。

### 错误示范

| 类型 | 错误话术 | 问题 |
|------|----------|------|
| 固执己见 | 坚持己见，不妥协 | 不合作 |
| 情绪化 | 情绪化争吵 | 不专业 |
| 互相指责 | 指责对方 | 破坏关系 |
| 闷头自己做 | 不沟通，自己搞 | 不协作 |

### 高情商标准答案

#### 【表达异议】

**稳妥型：**
> "我理解你的考虑，从我的角度看，可能会有...的风险/问题。要不我们讨论一下，看看有没有折中方案？"

**进阶型：**
> "你的方案有道理，我从另一个角度补充一下：如果这样做，可能会有...的影响。要不我们一起看看有没有兼顾的方案？"

#### 【寻求共识】

**稳妥型：**
> "咱们的目标是一致的，都是想把项目做好。目前分歧点在...，要不我们各自梳理一下方案，再一起讨论？"

**进阶型：**
> "我们都在为项目好，只是方法不同。要不我们把各自的方案列出来，对比一下优劣，看看怎么组合最优？"

#### 【找第三方】

**稳妥型：**
> "这个问题我们各自有不同看法，要不找XX（领导/资深同事）一起讨论一下，听听第三方意见？"

**进阶型：**
> "我们在XX上有分歧，要不找个时间拉上XX一起讨论一下？有个第三方视角可能会更清晰。"

#### 【让步话术】

**稳妥型：**
> "既然你坚持这个方案，那我们可以先试试，过程中如果发现问题再调整。我会配合执行。"

**进阶型：**
> "这个方案我没有完全想清楚，既然你觉得可行，我们可以先试试看效果。如果遇到问题，我们再及时调整。"

### 底层逻辑

1. **对事不对人**：先表达理解再陈述观点
2. **寻找共识和折中方案**
3. **引入第三方**：避免僵局
4. **必要时让步但留有后路**

### 万能句式

```
"我理解你的考虑，从我的角度看可能有...的问题。要不我们一起讨论一下，看看有没有折中方案？"
```

### 适用环境差异

| 职场环境 | 话术调整 |
|----------|----------|
| 互联网 | 用数据、A/B测试验证 |
| 体制内 | 找领导协调、按指示执行 |
| 外企 | 用会议讨论、投票决策 |
| 通用 | 寻求共识，必要时让步 |
