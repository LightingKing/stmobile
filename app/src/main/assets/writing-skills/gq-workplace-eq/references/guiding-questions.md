# 用户引导问题模板

本文档定义各场景下的用户引导问题策略，确保追问精准、高效、不超过3轮。

---

## 一、引导核心原则

```
1. 先锁定场景，再锁定环境，最后补充细节
2. 每次最多问1-2个问题，优先问对话术影响最大的
3. 第3轮无论信息是否充足，必须给话术
4. 问题要像自然对话，不要像调查问卷
5. 如果用户跳过问题直接补充了其他信息，灵活调整
```

---

## 二、引导维度详解

### P0 必问维度

#### 职场环境

**为什么必须问：** 同一句话在体制内是得体，在外企是多余，在互联网是低效。

| 环境类型 | 话术风格差异示例（拒绝领导临时任务） |
|----------|--------------------------------------|
| 体制内 | "领导，目前手头有XX急活，这个工作可能需要协调一下优先级，您看我先做哪个？" |
| 互联网 | "收到，我理解这事比较急。目前排期已满，需要协调优先级，您看怎么排？" |
| 外企 | "I understand this is time-sensitive. Given my current bandwidth, could we discuss priorities?" |
| 通用 | "领导，这事我明白重要性。不过今晚确实有安排了，能否明天一早第一时间处理？" |

**引导话术：**
> - "你在什么类型的单位？体制内/国企、互联网大厂、外企、还是普通企业？"
> - "你是在体制内还是在企业？这很影响话术风格。"

**检测关键词（用户已提供则不需要问）：**
- 体制内：机关、事业单位、国企、编制、单位、局里、政府
- 互联网：大厂、互联网、创业公司、产品、开发、运营
- 外企：外企、跨国、英文、国外、MNC

---

### P1 高优维度

#### 1. 对方身份

**为什么重要：** 对直属领导可以坦诚沟通，对跨级领导需要更加谨慎。

| 对方身份 | 话术差异 |
|----------|----------|
| 直属领导 | 可以更直接、更坦诚 |
| 跨级领导 | 更谨慎、更多留白 |
| 平级同事 | 可以更平等、更随意 |
| 其他部门 | 需要更多客套、留证据 |
| 老同事/前辈 | 需要更多尊重 |
| 新同事 | 可以更直接 |

**引导话术：**
> - "是您的直属领导还是跨级领导？"
> - "对方是老同事还是新来的？"
> - "这个人是你们部门的还是其他部门的？"

#### 2. 沟通渠道

**为什么重要：** 当面需要控制语气和表情，微信需要文字斟酌，邮件需要正式格式。

| 渠道 | 特点 |
|------|------|
| 当面/一对一 | 需要语气、表情、肢体语言配合 |
| 当众/会议 | 需要控制情绪、给对方面子 |
| 微信/文字 | 需要斟酌措辞、避免误解 |
| 电话/语音 | 语气很重要、可以稍自由 |
| 邮件 | 需要正式格式、抄送得当 |

**引导话术：**
> - "是当面说、微信上、还是邮件里？"
> - "是一对一私聊，还是有其他人在场？"
> - "是在会议上还是私下沟通？"

#### 3. 公开程度

**为什么重要：** 公开场合犯错的影响是私下的10倍。

| 公开程度 | 风险等级 | 策略 |
|----------|----------|------|
| 一对一 | 低 | 可以更坦诚 |
| 小范围（2-3人） | 中 | 适度谨慎 |
| 部门会议 | 高 | 高度谨慎，先认领会后沟通 |
| 大会/全员 | 极高 | 简短表态，会后单独处理 |

**引导话术：**
> - "是一对一私聊，还是有其他人在场？"
> - "是在部门会上被点名，还是和领导单独沟通？"

---

### P2 补充维度

#### 你的职位层级

**引导话术：**
> - "你是基层员工还是带团队的管理者？"

**影响：** 管理者有更多筹码和回旋余地，基层员工需要更谨慎。

#### 对方性格

**引导话术：**
> - "对方平时是强势型的还是比较好说话？"

**影响：** 强势型需要更坚定的态度+更多证据，温和型可以更柔性。

#### 紧急程度

**引导话术：**
> - "是需要马上回复，还是可以准备一下？"

**影响：** 紧急情况需要用"万能句式"快速应对，非紧急可以精细打磨。

## 四、引导话术模板库

### 自然引导式（推荐）

> "为了给你更精准的建议，想补充两个小细节：\n1）你在什么类型的单位？\n2）是一对一沟通还是有其他人在场？"

> "我理解你的情况了。再问一个：这件事是在什么场合发生的？当面还是线上？"

### 选择题式（降低回答成本）

> "你是在 [体制内/国企]、[互联网大厂]、[外企]、还是[普通企业]？这个很影响话术风格。"

> "对方是 [直属领导]、[跨级领导]、还是[平级同事]？"

### 情境确认式

> "我理解你是 [场景复述] 的情况。是在什么场合发生的？当面、微信、还是邮件？"

> "听起来是 [具体场景]。对方平时是什么性格？强势型还是比较温和？"

### 安抚 + 引导式（用户可能焦虑）

> "别着急，这种情况有应对方法。为了给你最合适的建议，先确认一下：你是在什么类型的单位？"

> "这个情况虽然棘手，但处理好了反而能加分。能告诉我更多细节吗？比如是在什么场合发生的？"

### 第3轮兜底式

> "好的，基于目前的信息，我先给你一些通用的建议。如果后续你想补充更多细节（比如具体在什么类型的单位、什么场合），可以随时告诉我，我帮你调整得更精准。"

## 五、完整引导流程示例

### 示例A：典型引导流程

```
用户：我该怎么拒绝同事

第1轮（AI追问）：
为了给你更精准的建议，想确认两个小细节：
1. 你是在什么类型的单位？（体制内/互联网/外企/普通企业）
2. 是当面拒绝还是微信/文字上？

用户：我在国企，微信上
```
