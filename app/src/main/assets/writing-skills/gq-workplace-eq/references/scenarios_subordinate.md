## S13：批评但不打击

### 场景描述

下属工作出现问题需要批评指正，但要注意方式，避免打击积极性。

### 错误示范

| 类型 | 错误话术 | 问题 |
|------|----------|------|
| 当众批评 | 在会议上当众批评 | 让下属丢脸 |
| 人身攻击 | "你怎么这么笨" | 打击自尊 |
| 只指责 | 一味指责，不给建议 | 无建设性 |
| 翻旧账 | 把过去的问题都拿出来说 | 让人绝望 |

### 高情商标准答案

#### 【私下沟通】

**稳妥型：**
> "XX，关于这次工作，我想和你聊聊。整体来看...（先肯定），不过有个地方需要改进：...（具体问题）。我理解可能是...（给台阶），后续建议...（给建议）。你怎么看？"

**进阶型：**
> "XX，有个事想和你私下聊聊。你最近在...方面做得不错，但这次XX工作有个小问题。不是要批评你，是想帮你一起看看怎么改进。你觉得问题可能出在哪？"

#### 【三明治法】

**稳妥型：**
> "你最近在...方面做得不错（肯定）。不过这次XX工作有个小问题...（指出问题）。我相信你后续能做得更好，有需要支持的地方随时说（鼓励）。"

**进阶型：**
> "XX，先说个好的一面：这次...做得不错。然后有个点想和你一起看看：...方面还有提升空间。最后，我看好你的潜力，这个改进我相信你能做到。"

#### 【就事论事】

**稳妥型：**
> "这个问题出在...（具体事实），影响是...（后果）。我们一起复盘一下原因，后续怎么避免？"

**进阶型：**
> "XX，这个结果和预期有差距，具体是...。我们一起来复盘一下：问题可能出在哪个环节？后续如何改进？"

#### 【给改进机会】

**稳妥型：**
> "这个问题我们一起来看看怎么改进。你先想想方案，明天我们再讨论。"

**进阶型：**
> "XX，这次是个学习机会。你先自己复盘一下，看看问题在哪、怎么改进。有需要讨论的随时找我，我们一起想办法。"

### 底层逻辑

1. **私下批评，公开表扬**
2. **先肯定再指出问题，最后给鼓励**
3. **对事不对人**：就具体事实讨论
4. **给改进建议和机会**

### 万能句式

```
"XX，关于这次工作，整体不错（肯定）。不过有个地方需要注意：...（具体问题）。后续建议...（建议），我相信你能做得更好（鼓励）。"
```

### 适用环境差异

| 职场环境 | 话术调整 |
|----------|----------|
| 互联网 | 强调"成长思维""复盘改进" |
| 体制内 | 强调"严格要求""帮助成长" |
| 外企 | 强调"Constructive Feedback" |
| 通用 | 先肯定再指出问题，给鼓励 |

## S14：布置任务、激励

### 场景描述

向下属布置任务，需要清晰传达目标、激发动力，而非简单命令。

### 错误示范

| 类型 | 错误话术 | 问题 |
|------|----------|------|
| 简单命令 | "你去把XX做了" | 没有背景和目标 |
| 甩手 | "领导交代的，你看着办" | 不负责任 |
| 微观管理 | 事无巨细都要管 | 不信任、压抑 |
| 只布置不给资源 | 只给任务不给支持 | 设置失败 |

### 高情商标准答案

#### 【任务布置】

**稳妥型：**
> "XX，有个任务想交给你。背景是...，目标是...，期望的完成时间是...。过程中如果遇到困难随时和我说，我会给你支持。"

**进阶型：**
> "XX，有个新任务想让你负责。背景是这样的：...。目标是...。我想让你来负责的原因是...（为什么选他）。你有什么问题吗？"

#### 【赋予意义】

**稳妥型：**
> "这个任务比较重要，完成后对团队/公司会有...的价值。我觉得你很适合做这个，也相信你能做好。"

**进阶型：**
> "XX，这个项目对公司/团队的战略意义是...。你在这个领域有积累，我觉得你是最佳人选。做好了这个，对你的...（成长/发展）也很有帮助。"

#### 【明确支持】

**稳妥型：**
> "这个任务有一定挑战，需要的资源我会帮你协调。过程中有问题随时找我。"

**进阶型：**
> "XX，这个任务有挑战，但我相信你能搞定。需要的资源、协调，你随时说，我来帮你解决。你只需要专注把事情做好。"

#### 【给予自主权】

**稳妥型：**
> "目标是...，具体怎么做我交给你来发挥。有需要讨论的地方我们再一起商量。"

**进阶型：**
> "XX，目标是...，方向是...。具体怎么实现，我给你空间自己规划。有需要决策或者支持的地方，随时找我讨论。"

### 底层逻辑

1. **交代背景、目标、时间**：让下属理解意义
2. **表达信任和期待**：激发动力
3. **提供资源支持**：而非甩手不管
4. **给予自主权**：而非微观管理

### 万能句式

```
"XX，这个任务背景是...，目标是...，期望...时间完成。我觉得你很适合做，过程中有困难随时找我。"
```

### 适用环境差异

| 职场环境 | 话术调整 |
|----------|----------|
| 互联网 | 用OKR明确目标，强调成长 |
| 体制内 | 强调"组织安排""锻炼机会" |
| 外企 | 强调"Ownership""Impact" |
| 通用 | 清晰目标+信任支持 |

## S15：处理下属情绪问题

### 场景描述

下属因工作压力、人际关系等原因情绪低落，需要沟通疏导。

### 错误示范

| 类型 | 错误话术 | 问题 |
|------|----------|------|
| 忽视 | "工作就是这样的，克服一下" | 不关心、冷漠 |
| 指责 | "你情绪影响工作了" | 二次伤害 |
| 不理 | 忽视不理 | 缺乏关怀 |
| 过度干预 | 追问隐私细节 | 越界 |

### 高情商标准答案

#### 【表达关心】

**稳妥型：**
> "XX，最近看你状态不太好，是不是遇到什么困难了？方便聊聊吗？"

**进阶型：**
> "XX，我感觉你最近好像有些不在状态，是不是有什么事？作为你的主管，我想了解一下，看能不能帮上忙。"

#### 【倾听理解】

**稳妥型：**
> "我理解你的感受，这种情况确实让人压力大。你想说说具体情况吗？"

**进阶型：**
> "XX，我能理解这种感觉。你想聊聊具体是什么让你困扰吗？我这边听着。"（认真倾听，不打断、不评判）

#### 【提供支持】

**稳妥型：**
> "工作上如果有压力大的地方，可以和我沟通，我们一起看看怎么调整。也可以...（给建议：休假、调整分工等）"

**进阶型：**
> "XX，如果是工作上的压力，我们来一起看看怎么调整。如果是其他方面的问题，我能帮忙的一定帮。如果需要休假调整一下，也可以考虑。"

#### 【尊重边界】

**稳妥型：**
> "如果涉及个人隐私，我不过多打听。但如果有需要我支持的地方，随时说。"

**进阶型：**
> "XX，如果是个人私事，我不会多问。但作为主管，我想让你知道：如果有什么我能支持的，你随时告诉我。工作上的事我们可以一起调整。"

### 底层逻辑

1. **主动关心**：但不过度干预
2. **倾听理解**：给予情绪支持
3. **提供工作层面的帮助**
4. **尊重个人隐私和边界**

### 万能句式

```
"XX，最近看你状态不太好，是不是遇到什么困难？如果有需要我支持的地方，随时说。"
```

### 适用环境差异

| 职场环境 | 话术调整 |
|----------|----------|
| 互联网 | 关注心理健康，提供资源支持 |
| 体制内 | 强调组织关怀，工作生活平衡 |
| 外企 | 强调Well-being，提供EAP资源 |
| 通用 | 真诚关心，提供实际帮助 |

## 管理者沟通心法

### 表扬公式

```
具体行为 + 正向影响 + 表达感谢/期待
```

**示例：**
> "XX，你这次主动承担了XX任务（具体行为），帮团队解决了XX问题（正向影响），感谢你的担当，期待你继续成长（表达）。"

### 批评公式

```
肯定优点 + 具体问题 + 改进建议 + 表达信任
```

**示例：**
> "你最近在XX方面做得不错（肯定），但这次XX环节有个问题（具体问题），建议后续...（改进建议），我相信你能做得更好（信任）。"

### 激励公式

```
任务意义 + 个人匹配 + 成长价值 + 支持承诺
```

**示例：**
> "这个项目对团队很重要（意义），你的XX能力很适合（匹配），做好了对你的成长很有帮助（价值），过程中我会全力支持你（支持）。"
