# 盲盒手办 3D（blind box figure）—— 社交爆款风格深度指南

> 心智定位：2025–2026 社交媒体最火 AI 玩法（AI Action Figure）/ 实体感的收藏欲 / Q 版 3D。
> 首选模型：gpt-image-2（材质渲染与包装文字的双强）。

## 1. 美学 DNA

盲盒手办风格复刻的是潮玩产业的产品摄影：**Q 版比例的角色雕塑（大头 1:2 身/圆润造型）+玩具材质的真实感（哑光乙烯基/半光 PVC/陶瓷釉面）+产品摄影的灯光（影棚柔光/干净渐变背景/底座）**。它火的心理机制是「收藏欲的可视化」——把角色做成「可以拥有的实体」，比任何画风都更接近「这个角色属于我」的占有满足。

两种形态：**裸手办**（角色+底座的展示态——角色卡封面主用）与**盒装**（透明泡壳+包装设计——整活与彩蛋向，gpt-image 系的文字渲染让包装标语成为可能）。

## 2. 视觉要素解构

- **比例**：Q 版大头（头身比 1:1.5~1:2）、圆润的手脚、简化的手指。
- **材质**：哑光乙烯基（皮肤）/半光 PVC（服装）/亮面漆（眼睛头发的点睛）——材质混搭是手办质感的关键。
- **工艺感**：分模线的暗示/涂装的边界清晰/服装的立体褶皱雕塑感。
- **灯光**：影棚三点柔光、底部微反射（亚克力台面感）、无杂光。
- **背景**：浅色渐变（米白/浅粉/浅蓝）或主题色纯色——产品摄影的干净。
- **底座**：圆形/异形底座（角色主题化：云朵底座/书本底座）。

盒装变体附加：`透明泡壳包装+卡纸背板, 包装顶部大字「<系列名>」, 底部标语「<一句话>」（全大写英文渲染更稳）, 配件格里放[2-3件小配件], 轻微塑料反光`。

## 4. 构图变体

- **默认·单体展示**：45 度俯视微角+底座——标准产品照。
- **盒装**：正面平视泡壳包装——整活/系列卡的封面。
- **双人对盒**：两只手办面对面——双人卡的盲盒化（关系可视化为「一对」）。
- **场景微缩**：手办+微缩场景盒（diorama）——世界观卡的实体化。

## 6. 分类绑定

首选：整活喜剧/甜妹（Q 版彩蛋）/系统流（抽卡池的视觉隐喻！）/双人卡（对盒）/任何分类的「彩蛋第二封面」。
特别用法：**同角色的「正装封面+盲盒彩蛋」双图策略**——正装是氛围，盲盒是周边感（收藏心理的双击）。

## 7. 失败模式与修正

1. **真人比例化**（Q 版失效）→ 「大头小身约1:2、圆润简化的手脚」强调。
2. **塑料感假**（渲染过头像 CG 角色而非玩具）→ 「哑光乙烯基材质、涂装边界清晰、玩具摄影」。
3. **包装文字崩**（盒装的长文字乱码）→ 文字 ≤10 词、全大写、或放弃包装字改裸手办。
4. **背景抢戏**→ 「干净的浅色渐变背景、无杂物」。
5. **表情呆滞**（手办的「死鱼眼」）→ Q 版表情要夸张化（气鼓鼓/星星眼）。

## 8. 延伸风味

- **×古风**：汉服盲盒（国潮手办的既有市场语法）——古风卡的彩蛋首选。
- **×机甲**：Q 版机甲手办（可动关节的暗示）——赛博卡的玩具化。
- **×毛绒**：材质换「植绒质感」——治愈系的触觉升级版。
