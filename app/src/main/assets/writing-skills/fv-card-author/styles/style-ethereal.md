# 唯美幻想（ethereal fantasy）—— 仙气幻想风格深度指南

> 心智定位：WLOP 系审美的中文对应词「仙气」/ 幻想题材的情绪天花板 / 光的艺术。
> 首选模型：gpt-image-2。

## 1. 美学 DNA

唯美幻想的源流是 WLOP《鬼刀》确立的数字绘画范式：**电影级的体积光（光是画面的真正主角）+流体的长发（发丝如流水的物理感）+通透的皮肤渲染（次表面散射的冷光感）+梦幻粒子系统（光尘/花瓣/星屑的漂浮层）**。它与柔光厚涂的分界在「光的地位」——柔厚涂的光是氛围（服务人物），唯美幻想的光是叙事（人物在光里近乎溶解）。

角色卡场景的价值：仙侠/人外概念系/病弱美人这些「超越性」角色需要「不属于人间」的视觉证明——本风格的光学语法就是那个证明。

## 2. 视觉要素解构

- **光**：体积光（月光柱/逆光轮廓/透过纱衣的透光）+光粒子层（尘埃/萤光/星屑）。
- **发**：超长发的流体铺陈（发是画面的第二构图线）、发丝的高光如琴弦。
- **皮肤**：通透冷白、次表面散射感（耳缘/指尖的透光红）。
- **材质**：纱/绸/水/冰的透明系材质——透明度是本风格的材质关键词。
- **色彩**：深色基底（深蓝/墨黑）+冷光主导（月白/冰蓝）+一点暖或彩的点睛（朱砂痣/花瓣）。
- **构图**：人物置于光源与暗背景之间（三明治打光）、留出光的呼吸空间。
- **情绪**：出尘/悲悯/神性——「美到有距离」。

## 4. 构图变体

- **默认·月下抬眸**：三明治打光的标准帧（实测样张同款）。
- **水中悬浮**：发与衣的失重铺展——人外概念系（人鱼/水神）的原生构图。
- **羽落之瞬**：堕天使的下落定格+羽毛粒子——西超宗教线的封面。

## 6. 分类绑定

首选：仙侠师徒（女仙/上神）/人外概念系（神明/幽灵/AI 的圣光变体）/西方超自然（吸血鬼月夜/堕天使）/病弱美人（易碎感的光学化）/百合（唯美双人）。
换风格信号：需要烟火气 → 全线不适用（本风格排斥日常感——「不食人间烟火」是它的边界也是局限）。

## 7. 失败模式与修正

1. **光污染**（粒子糊满全画）→ 「光粒子稀疏克制，集中在人物周围」。
2. **脸被光吃掉**（过曝）→ 「脸部曝光正常清晰，光晕在轮廓」。
3. **网游 CG 化**（廉价特效感）→ 去掉魔法阵/技能特效类元素，「光是自然光源不是法术特效」。
4. **发丝糊化**（长发变绸带）→ 「发丝分缕可辨、如琴弦的高光」。
5. **甜美化漂移**（画成柔光厚涂）→ 「清冷出尘、有距离感的美」，冷光比例提高。
