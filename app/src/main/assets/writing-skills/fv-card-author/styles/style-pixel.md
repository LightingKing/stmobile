# 像素艺术（pixel art）—— 复古游戏风格深度指南

> 心智定位：游戏文化的乡愁载体 / 治愈系像素场景的独立审美 / 系统流的原生皮肤。
> 首选模型：gpt-image-2（像素栅格纪律最好）。

## 1. 美学 DNA

像素艺术的美学建立在「限制产生风格」上：**有限的分辨率（每个像素都是决策）+有限的色板（16–64 色的配色纪律）+锐利的边缘（无抗锯齿的像素栅格）**。当代像素艺术已脱离「复古模仿」进入独立审美（《八方旅人》的 HD-2D/像素治愈系插画的走红）——**大场景小人物+光影的现代化**（像素形态+当代打光）是 2020s 像素的主流语法。

角色卡场景的价值：系统流/世界卡/游戏题材的「界面即世界观」——像素封面直接声明「这是一张游戏感的卡」，且像素的抽象度天然规避了颜值内卷（不比脸，比氛围）。

## 2. 视觉要素解构

- **栅格**：清晰的像素边缘、无抗锯齿、像素大小一致（8/16/32-bit 的档位选择）。
- **色板**：有限色（声明 16/32/64 色）、同色系的阶梯过渡（dithering 点阵渐变可选）。
- **光影**：现代打光的像素化（光柱/霓虹反光/晨雾——像素形态渲染当代光）。
- **构图**：大场景小人物（人物 16–48px 高的抽象度）或像素半身像（精细档）。
- **动效暗示**：雨丝/飘雪/星闪的「可动感」静帧。
- **情绪**：治愈的孤独感（深夜便利店/末班车站台）或冒险的召唤（地牢门口/世界地图）。

## 3. 完整配方

```
精致像素画风格：32-bit像素艺术、有限色板（约32色）、清晰锐利的像素边缘、
无抗锯齿、复古游戏美学但构图现代。绘制新场景：
[场景：深夜便利店/雨夜站台/地牢入口/公会大厅], [人物：小尺寸像素角色在做[动作]],
[光影：暖黄灯光/霓虹反光/晨光的像素化渲染], [氛围元素：雨丝/飘雪/星星],
[情绪：治愈的深夜感/冒险前夜], 人物虽小但姿态生动,
画面一侧竖排白色像素字体标题「<卡名>」, 除标题外画面中不出现任何其他文字, 竖版9:16
```

像素半身像变体：`像素半身像构图, 人物占画面一半, 面部用像素级细节刻画（16x16 脸部网格感）, 背景简化`。

## 4. 构图变体

- **默认·场景流**：大场景小人物（实测样张的便利店同款）——氛围之王。
- **半身像**：RPG 对话框式的角色立绘——人设卡向。
- **横版关卡**：横切面的建筑内部（各楼层的小人各忙各的）——群像卡的像素化神构图。
- **世界地图**：俯视地图+图标化地标——世界卡的开屏。

## 5. 多模型适配

| 模型 | 表现 | 用法调整 |

| gpt-image-2 | 基准（栅格纪律最好+像素字标题可靠） | 原配方直用 |

## 6. 分类绑定

首选：系统流模拟器（原生皮肤）/世界卡无限流（地图感）/整活（游戏梗）/网恋电竞（游戏内世界）/异世界（RPG 语法）。
特别用法：**像素小剧场的第二封面**——正装封面之外的像素 Q 版彩蛋（角色的游戏化变身）。

## 7. 失败模式与修正

1. **伪像素**（放大后是模糊的「像素风滤镜」）→ 「清晰锐利的像素边缘、每个像素可辨」。
2. **色板爆炸**（渐变失控色数过多）→ 「有限色板约32色、同色系阶梯过渡」。
3. **人物比例崩**（像素小人的肢体错误）→ 缩小人物尺寸提高抽象度（16-24px 高最安全）。
4. **抗锯齿混入**（边缘发糊）→ 「无抗锯齿」置顶强调。
5. **标题非像素字**（书法字乱入）→ 本风格标题声明「像素字体」（全库唯一的标题字体例外）。

## 8. 延伸风味

- **×HD-2D**：像素人物+3D 景深与光晕（八方旅人式）——像素的豪华版。
- **×故障艺术**：像素+glitch 撕裂——赛博/恐怖题材的像素变体。
- **×水墨**（实验杂交）：水墨山水的像素化重绘——「像素国风」的猎奇流量点。
