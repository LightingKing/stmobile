# 多巴胺撞色（dopamine pop）—— 元气网感风格深度指南

> 心智定位：2026 中文社交的热词美学 / 高饱和的合法区之二 / 快乐的视觉化。
> 首选模型：seedream-5.0（撞色理解好+速度快）。

## 1. 美学 DNA

多巴胺风格是「dopamine dressing（多巴胺穿搭）」从时尚圈向视觉设计的扩散：**高饱和的糖果色系（玫红/柠檬黄/宝蓝/薄荷绿的大胆并置）+扁平化的叙事插画（干净色块/简化光影）+波普的装饰元素（圆点/几何/贴纸感）**。它的核心纪律是「撞色但有序」——色彩多而不乱的秘密是**色块的面积节奏**（一个主色统治 50%+两三个撞色分割剩余）与**白色的缓冲**（色与色之间的白边呼吸）。

与赛璐璐高饱和的分界：赛璐璐的饱和是「动画的天空色」（自然物的明快），多巴胺的饱和是「设计的糖果色」（人工色的直给快乐）。

## 2. 视觉要素解构

- **色彩**：糖果高饱和 3–4 色、一主多辅的面积节奏、白色缓冲边。
- **造型**：扁平化人物（简化的光影/粗轮廓线可选）、夸张的表情与手势（比耶/wink/大笑）。
- **装饰**：波普圆点/几何色块/贴纸元素（星星/爱心/闪电的符号库）。
- **服饰**：彩色墨镜/卫衣/发卡/彩袜——Z 世代衣橱的高彩单品。
- **构图**：居中直给（人物怼中间）/表情包式的裁切、背景是色块拼接。
- **情绪**：无条件的快乐/自信/「今天也超棒」。

```
多巴胺风格插画：高饱和撞色搭配（玫红/柠檬黄/宝蓝/薄荷绿）、扁平化叙事插画、
活力四射的青春能量、干净的色块与几何装饰元素。绘制新人物：
[年轻+元气身份——年龄用「大学生/年轻」等模糊词], [表情手势：灿烂大笑比耶/wink],
[服饰：高彩单品2-3件：彩色墨镜/卫衣/发卡], [色彩节奏：<主色>统治画面+<撞色2-3个>分割],
[背景：撞色几何色块+波普圆点], [装饰：星星/爱心贴纸元素点缀],
画面一侧竖排白色粗体标题「<卡名>」带小朱红印章,
除标题外画面中不出现任何其他文字, 竖版9:16
```

注意（seedream 实测坑）：prompt 里不要出现具体年龄数字（「20岁」会被渲染成画面文字）。

## 4. 构图变体

- **默认·居中直给**：怼脸的自信构图（实测样张同款）。
- **贴纸拼贴**：人物+散落的贴纸元素环绕——手帐感。
- **色块分屏**：画面纵切 2–3 个色块区、人物跨块——杂志封面感。

## 6. 分类绑定

首选：甜妹元气/整活喜剧/年下（活力线）/网恋电竞（欢乐日常线）/女性视角（职业体验的活力封面）。
换风格信号：治愈的「静」快乐 → 吉卜力；发疯文学的快乐 → 整活×表情包裁切。

## 7. 失败模式与修正

1. **彩虹爆炸**（色彩失序）→ 「一个主色统治画面+2-3撞色」的面积节奏声明。
2. **脏撞色**（互补色直怼产生浊色边）→ 「色块之间有白色缓冲边」。
3. **表情收着**（元气不足）→ 「表情夸张：大笑/wink/挑眉的表情包级生动」。
4. **年龄数字上屏**（seedream 特有）→ 年龄模糊词纪律。
5. **扁平失守**（画出厚涂光影）→ 「扁平化、简化光影、无渐变体积」。

## 8. 延伸风味

- **×孟菲斯**：加孟菲斯风的波浪线/网格装饰——设计感的升级版。
- **×运动**：撞色+动态奔跑帧+速度感色条——运动系人设（体育生年下）。
- **×发疯文学**：表情从「快乐」拧到「癫」（瞪眼/龇牙笑）——整活卡的多巴胺变体。
