# Q版二头身（chibi 2D）—— 软萌彩蛋风格深度指南

> 心智定位：表情包级的萌系语言 / 全分类通用的「第二封面」/ 贴纸美学。
> 首选模型：seedream-5.0（快+萌）；gpt-image-2（细节稳）。

## 1. 美学 DNA

Q 版（chibi/super deformed）是日系萌文化的比例学实验：**二头身的婴儿图式（大头+短躯干触发养育本能的硬件级可爱）+圆润的线条系统（一切尖角圆角化）+表情的夸张化补偿（身体简化后表情承担全部表演——嘟嘴/星星眼/气鼓鼓的漫画符号全开）**。与盲盒 3D 的分界：盲盒是「实体玩具的拟真」（材质感），chibi 2D 是「贴纸的平面萌」（水彩/平涂的轻盈）——一个想让你「拥有」，一个想让你「rua」。

角色卡场景的最大价值不是当主封面，是**关系的萌化注释**：正装封面的角色出 Q 版变体（角色的另一面/表情包/装饰贴纸），严肃人设的反差萌一击。

## 2. 视觉要素解构

- **比例**：二头身（1:1 到 1:1.5）、短手短脚、简化手指（馒头手）。
- **线条**：圆润闭合的轮廓、粗细均匀的软线。
- **上色**：水彩质感的柔和平涂/淡淡的腮红块。
- **描边**：贴纸式白描边（sticker 感的关键）。
- **表情**：夸张化的漫画表情（>_< / 星星眼 / 汗滴 / 气鼓鼓）——表情是 Q 版的演技。
- **道具**：迷你化的人设道具（小拂尘/小佩剑/小听诊器——道具也二头身化）。
- **背景**：奶油色纯底/圆点纹理/散落的小符号（星星/花瓣）。

## 4. 构图变体

- **默认·单体贴纸**：居中+白描边+环绕小元素（实测样张同款）。
- **表情包九宫**：同角色 9 表情的网格——角色的表情包资产（插图卡的差分素材）。
- **迷你剧场**：两只 Q 版的互动小剧（追逐/递东西）——双人卡的萌化注释。
- **大小同框**：正常比例角色+肩上的 Q 版小分身——「本我与萌我」的元构图。

## 6. 分类绑定

通用第二封面：任何分类的 Q 版彩蛋（严肃卡的反差萌资产）。
作为主封面的场景：整活喜剧/甜妹（萌系直球）/儿童全年龄向。
特别用法：**插图卡的表情差分**——Q 版九宫格是表情库的高性价比生产方案（一张图切九格）。

## 7. 失败模式与修正

1. **头身比漂移**（画成 4–5 头身的「少年」）→ 「严格二头身、头与身体等大」。
2. **表情平淡**（Q 版的死穴）→ 「表情夸张化：漫画符号级的生动」。
3. **线条带刺**（尖角出现）→ 「一切线条圆润化」。
4. **描边缺失**（贴纸感丢失）→ 「贴纸风格的白色描边」强调。
5. **道具正常比例**（道具没有 Q 化）→ 「道具迷你化圆润化」。

## 8. 延伸风味

- **×古风**：Q 版汉服+迷你发冠——国潮贴纸（古风卡的周边感彩蛋）。
- **×像素**：chibi 的像素化（16-bit 小人）——两个「小」美学的会师。
- **×毛绒**：上色换毛绒质感（fluffy）——玩偶化的触觉升级。
