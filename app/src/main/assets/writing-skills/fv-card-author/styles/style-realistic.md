# style-realistic · 写实摄影（真人质感立绘）

> v10 新增分支。来源：猫箱（MiniMax）真机竞品实测——其大流量女性角色卡（吴静/王雅萍/白玉泉级）立绘全部走**写实照片质感**路线，与韩系半写实「插画感」形成明确代差；本地 6081 卡普查中写实系占比约 6%，但在「都市/年上/职场/邻家」等现实系赛道的头部卡里占比过半。gpt-image-2 与 seedream-5.0 双模型实测全过（酒吧微醺 95s / 教室夕阳 65s）。

## 1. 美学 DNA

真实世界的一瞬间被专业摄影师抓拍下来——不是画，是**照片**。皮肤有真实的纹理毛孔与油脂光泽，光是物理正确的（逆光会真的在发丝边缘起亚光晕，霓虹会真的在虹膜上留反光点），景深是镜头光学的（f/1.8 大光圈的奶油虚化）。审美锚点是「氛围感人像摄影」：小红书摄影区的日系胶片人像、韩系咖啡馆写真、深夜酒吧氛围照。用户看到的心理暗示是**「这个人可能真的存在」**——现实系代入感的天花板，也是与二次元赛道切割最彻底的一支。

## 2. 视觉要素解构（杂交取词用）

- **质感句核**：写实摄影风格 / 真实照片质感 / 自然的皮肤纹理与光泽 / 专业人像摄影的景深 / 电影级调色
- **镜头语言**：85mm 人像镜头感 / 大光圈背景奶油虚化 / 浅景深锁定面部 / 抓拍感的不完美构图
- **光**：逆光轮廓光（夕阳/窗光在发丝上）/ 霓虹侧光（蓝紫冷光+暖肤色对撞）/ 室内钨丝暖光 / 阴天柔光箱般的均匀漫射
- **色**：电影 LUT 感——青橙对撞（都市夜）/ 低饱和牛奶色（日常清透）/ 暖褐怀旧（黄昏教室）
- **人**：真实的皮肤瑕疵感（不磨皮成塑料）/ 发丝乱一两缕才像抓拍 / 微表情（半笑/走神/微醺）比摆拍表情高级
- **环境叙事**：写实系的背景不能虚无——酒吧的酒瓶墙、教室的黑板粉笔字、便利店的暖柜，环境即人设第二层

## 3. 完整配方（gpt-image-2 / seedream 双路）

```
写实摄影风格的人像立绘：真实照片质感、自然的皮肤纹理与光泽、专业人像摄影的景深、电影级调色。
绘制：[年龄气质，如：30岁的成熟东亚美女 / 年轻的东亚女教师]在[场景+时间，如：深夜酒吧吧台 / 放学后的教室讲台边]，
[服饰具体单品与穿法，如：黑色蕾丝罩衫配紫色缎面吊带裙 / 米色针织衫配黑色半身裙]，
[手部动作+道具，如：手持一杯马天尼，红色美甲 / 抱着教案本]，
[表情与视线，如：微醺的慵懒眼神看向镜头侧前方 / 温柔中带一点疲惫的浅笑]，
[光源叙事，如：霓虹灯光在背景虚化成蓝紫色光斑 / 窗外夕阳的暖光在发丝上形成轮廓光]，
[环境虚化交代，如：烟雾质感的空气 / 黑板与课桌虚化在背景]，
构图为[半身像/七分身]、脸部清晰位于画面上三分之一处，
画面一侧竖排白色行草书法字标题「<角色名>」带小朱红印章，
除标题外画面中不出现任何其他文字，竖版9:16
```

要点：

- **「写实摄影/真实照片质感」必须是第一句**——放后面会被前面的「立绘/插画」词带偏成半写实。
- 年龄写气质词（成熟/年轻/大学生感），seedream 对具体数字有上屏倾向（「30岁」可能被印在画面里）。
- 微醺/疲惫/走神这类**非摆拍微表情**是写实系高级感的最大单项；「甜美微笑看镜头」立刻变影楼片。
- 环境必须具体到可闻气味的程度（酒吧的烟雾、教室的夕阳灰尘），写实系靠环境撑叙事。

## 4. 构图变体

- **封面规格**（默认）：半身/七分身，脸在上 1/3，斜对侧留白放书法标题+印章。
- **沉浸立绘规格**（聊天背景图用途）：人物整体上移、下半身画面 40% 留给暗调环境（浮层消息气泡可读）；不放书法标题（背景图不需要）；光源集中在上半，下半自然压暗。
- **抓拍规格**（朋友圈/私生活证据配图）：人物不看镜头、构图故意歪一点、带运动模糊边缘——「被偷拍的生活感」。

## 5. 多模型适配

- **nano-banana-2**（写实真人第一推荐，2026-07 Tuzi 渠道实测）：韩剧剧照级质感——皮肤真实带毛孔但不显老、光影层次电影级、构图叙事感强（20 张男女性向批量全过，人物美型且无一崩脸崩手）。~12s/张比 seedream 还快 3 倍，848x1264 直出。经 `api.tu-zi.com /v1/images/generations` 标准协议即可。中文标题未测（写实卡面走无字设计规避）。**nano-banana-pro** 同族更高清（1696x2528）但 90–270s/张且偶发超时，只给单张精品用。年龄词要写具体（「27 岁年轻」），否则职场/知性设定会往 40+ 老态跑。
- **seedream-5.0**（真人感批量备选）：皮肤水光、发丝逆光锐利、30s 出片、书法标题 2 字可靠。短板：脸型「大众网红模板」化、同批次撞脸明显、皮肤有轻微磨皮糊感——高级感上限低于 nano-banana-2（2026-07 20 卡批量被用户打回换模型的直接原因）。风险：会自作主张加品牌 logo/杂志刊头/条形码，prompt 加「服装无任何品牌标志」「画面绝不出现任何文字字母条形码水印」。**带印刷面的道具是重灾区**（2026-07-14 生产封面重制实测）：能量胶囊包装袋/饮料罐/屏幕界面都会被印满乱字，通用防字条款挡不住——要么换无印刷面道具（棒棒糖棍/吸管），要么显式写「不出现任何包装印刷字、任何屏幕界面字」并把屏幕写成「背对镜头只见光晕」。
- **gpt-image-2**（中文书法标题唯一全稳）：质感最厚，95–140s。自带胶片颗粒感（grain），追求猫箱式干净锐利网红感时不是最优；出图偏暗偏「剧照灰」。需要画中文字的封面仍然只能靠它。
- **wan2.7-image-pro**：纪实摄影脸——皮肤纹理真实到「素人感」，美型感弱。仅适合年代文/胶片怀旧/刻意素人化需求，主流网红感不选它。
- **MJ v7**（`--v 7 --style raw`）：顶级摄影感但不写中文，出无字底图再二次加工。仅在追求「摄影大片」上限时用。
- z-image-turbo 不适合（塑料感重），赛璐璐专用勿混；qwen-image-max 限流严重（429 频发）不作依赖。

## 6. 分类绑定

第一推荐：都市异能（现实皮）/ 职场年上 / 邻家青梅 / 恋综（综艺感抓拍）/ 年代文（做旧胶片味）/ 明星偶像。
可选：网恋奔现后线下篇、现代言情全谱系、以「怕生成二次元脸」为耻的男性向现实卡。
禁用：仙侠/西幻/兽人人外（写实人脸+幻想设定=恐怖谷）；校园未成年角色（写实质感撞红线，未成年题材一律走插画系）。

## 7. 失败模式与修正

- **影楼塑料脸**：磨皮过度、瞳孔无反光 → 加「自然的皮肤纹理」「真实抓拍感」，删掉一切「完美/精致」类词。
- **AI 手**：写实系手部畸变最扎眼 → 道具遮挡（持杯/抱书/插兜），或构图裁掉手。
- **年龄数字上屏**（seedream）：「30岁」被印进画面 → 用「成熟/轻熟/大学生气质」。nano-banana 系无此问题，反而**必须**写具体年龄数字（「27 岁年轻紧致的皮肤」）防止知性/职场设定画老。
- **画老 10 岁**（nano-banana 系）：教授/总裁/军官等气场设定会自动+年龄 → prompt 锁「XX 岁年轻的」+「年轻紧致白皙的皮肤,绝不显老」。
- **环境假**：背景虚化成色块没有物件 → 环境词写到具体物件（酒瓶墙/黑板板书/暖柜关东煮）。
- **标题吃进人物**：写实系背景暗部大，白色书法字要放「画面留白或纯暗部一侧」，与脸错开。

## 8. 延伸风味

- **胶片风**：加「富士胶片色调、颗粒感、日系胶片摄影」——低饱和牛奶色，青春疼痛文学赛道。
- **黑白人文**：加「黑白摄影、强对比、莱卡人文纪实感」——刑侦/民国/破碎感男主。
- **雨夜霓虹**：加「雨后街头、霓虹倒影在湿漉路面、玻璃上的雨滴虚化前景」——都市夜归人叙事。
- **韩剧剧照**：加「韩剧剧照质感、柔和暖光、浅景深过肩视角」——年上破镜赛道的「对手戏感」。

## 9. 服饰与角色魅力（猫箱星野对标 · 反「保守失分」）

> 2026-07 实测教训：写实卡默认给「安全保守」的服饰（职业装扣到顶、家居服宽大、外套裹严），
> 立绘干净但**缺记忆点和吸引力**——这是与猫箱（MiniMax）/星野头部女性角色卡立绘的最大差距之一。
> 猫箱星野的立绘服饰是「性感但过审」的应用商店尺度，不是暴露，而是**有设计、有风情、有记忆点**。

**服饰魅力三原则（成年角色）**：

1. **贴身剪裁显线条**：服饰跟随身材（腰线/肩颈/腿型/背线），而非宽大遮盖。宽松也要「露一处骨相」（松垮露肩、卷起小臂、开衩露腿），松弛感 ≠ 裹严实。
2. **关键部位点到为止**：性张力靠「露一处」而非「堆砌」——锁骨、肩线、后背、腰、小腿择一强调，其余克制。一张立绘一个视觉焦点。
3. **风格标签鲜明**：每个角色配一件「服饰记忆点」单品（缎面衬衫/丝质吊带/露肩针织/开衩长裙/改良制服），让立绘一眼可辨、可被记住。

**性张力尺度（成年角色 · nsfwLevel=0 上架卡的「擦边而过审」度）**：对标猫箱/星野实际在应用商店的立绘尺度，
**成年女性角色应当用足这个擦边尺度，别自我审查过头到丢失角色魅力**（2026-07 实测：默认给的服饰太保守被用户明确否掉）。
可用且鼓励的擦边单品：**黑色丝袜/包臀裙/高开衩/低领露锁骨与事业线/吊带/露肩/贴身勾勒腰臀与腿部曲线/短裙露腿**——
这些是 suggestive（性感撩人）内容，应用商店允许（猫箱星野常规款）。
**过审红线（越线即 explicit，不进 nsfwLevel=0 封面）**：不露点、不露内衣本体（内裤/文胸实物）、不裸露、
不做私处与胸部的特写强调、不做性行为或性暗示动作。即「性感撩人」可以、「色情裸露」不可以——
这条边界就是猫箱星野能上架而某些卡被下架的那条线。更高浓度走 `nsfwLevel` 分级与用户侧设置承接。

**红线（绝对，违反即 CSAM/法律风险 + 平台即拒）**：

- **未成年/校园学生角色的服饰绝不性化**——不做贴身显身材、不露肤堆砌、不物化，校服只做「青春清爽的时尚感」
  （改良制服/百褶裙/针织背心的干净版型，止于青春气质，绝不往身材与性暗示走）。此类角色一律走
  「明亮通透的青春写真」，服饰魅力=清爽与设计感，不是性张力。校园未成年题材本就建议插画系而非写实系（§6 禁用项）。
- 判断存疑（角色年龄接近成年边界）时，一律按未成年红线从严处理。
