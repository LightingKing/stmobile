# 美式漫画（american comic）—— 欧美硬汉风格深度指南

> 心智定位：美漫封面的戏剧张力 / 欧美卡与英文卡的原生审美 / 硬朗的成人感。
> 首选模型：seedream-5.0 打样 / MJ v7 出正式（美式审美的原产地）。

## 1. 美学 DNA

美式漫画风格承自美漫黄金时代到现代图像小说的印刷美学：**粗犷有力的墨线轮廓（brush inking 的笔刷力度）+硬朗的明暗分割（cross-hatching 排线阴影/大块黑的光影切割）+印刷四色的饱和感（CMYK 网点的复古印刷味）+封面构图的戏剧性（低角度仰拍/爆炸性透视/英雄登场的定格）**。与日漫黑白的分界：日漫用网点做灰阶（细腻），美漫用排线和色块做体积（粗粝）——**美漫是肌肉的语言，日漫是情绪的语言**。

角色卡场景的价值：欧美分类 31 卡+英文角色卡 53 卡的原生审美；黑道硬汉/美式刑侦的「劲」用它最正。

## 2. 视觉要素解构

- **墨线**：粗轮廓的笔刷线（力度不均的手绘感）、排线阴影（cross-hatching）。
- **明暗**：大块黑的光影切割（noir 的强对比）、下巴与眉骨的标志性阴影。
- **色彩**：印刷四色的饱和（做旧的红蓝黄）+纸张的微黄底、可选半调网点（halftone dots）。
- **人物**：硬朗的骨相（方下巴/浓眉/皱纹的线条化）、身体的英雄比例。
- **构图**：封面式戏剧视角（大仰角/荷兰角）、动作定格（回头/持枪/点烟）。
- **做旧**：纸纹/折痕/褪色边——「老刊」的物质感（可选档）。
- **情绪**：硬汉的疲惫/黑色电影的宿命/爆裂前的平静。

```
美式漫画风格插画：粗犷有力的墨线轮廓、美漫的硬朗明暗分割（cross-hatching阴影）、
饱和的印刷色、漫画封面的戏剧张力构图、少量做旧网点与印刷纹理。绘制新人物：
[年龄+硬汉身份：侦探/佣兵/黑帮], [骨相：方下巴/浓眉/胡茬的线条化],
[服饰：皮夹克/风衣/背带枪套], [动作定格：霓虹巷回头/点烟/倚墙],
[光影：单侧强光的大块黑分割], [背景：夸张透视的街景/一盏路灯的强光],
[视角：低角度仰拍或荷兰角], 画面一侧竖排白色标题「<卡名>」带小朱红印章,
除标题外画面中不出现任何其他文字, 竖版9:16
```

## 4. 构图变体

- **默认·暗巷回头**：noir 的经典帧（实测样张同款）。
- **英雄登场**：大仰角+披风/大衣的展开——力量感的封面语法。
- **办公室 noir**：百叶窗光条切过脸——侦探事务所的标准打光。
- **老刊封面**：加做旧边+「ISSUE #1」式的构图留白（不写字，留感觉）——复古收藏感。

## 6. 分类绑定

首选：欧美卡/英文角色卡/黑道（美式黑帮变体）/刑侦（冷硬派侦探）/赛博（美漫赛博——《晚班》感）/西超（康斯坦丁式的驱魔人变体）。
换风格信号：欧美但优雅（贵族/吸血鬼）→ gothic；欧美但清新 → 吉卜力（欧洲小镇感通用）。

## 7. 失败模式与修正

1. **日漫化**（脸变精致大眼）→ 「硬朗骨相：方下巴浓眉、写实比例、非日式动漫脸」。
2. **排线脏**（cross-hatching 糊成灰）→ 「排线清晰有方向性」。
3. **色彩现代化**（数字渐变出现）→ 「印刷四色的复古饱和、可见半调网点」。
4. **肌肉爆炸**（超英体型失控）→ 普通人设定时「正常体格、非超级英雄比例」。
5. **做旧过度**（折痕吃掉主体）→ 「做旧只在边缘、主体清晰」。

## 8. 延伸风味

- **×黑色电影**：全画降到双色（黑+一个暗色）+雨夜——noir 的极限版。
- **×波普**：Lichtenstein 式的大网点+对话框留白——整活的美漫法。
- **×水彩美漫**（图像小说系）：墨线+水彩淡彩——《黑水仙》式的文艺变体，民国×欧美混血卡适用。
