# 哥特厚涂（gothic ornate）—— 暗调华丽风格深度指南

> 心智定位：暗黑浪漫的视觉正装 / 西方超自然与病娇的母语 / 繁复细节美学。
> 首选模型：gpt-image-2 + ref-07。

## 1. 美学 DNA

哥特厚涂承自维多利亚哥特复兴与日系 Gothic Lolita 的双重血统：**暗调的基底（黑与深酒红/冷青的低明度世界）+繁复的手工细节（蕾丝层叠/缎带/铆钉/银饰的精工刻画）+古典的空间语汇（烛台/雕花家具/彩窗/鸟笼）**。它的张力公式是「华丽×死亡气息」——最盛大的美与最冷的调子共存，这正是吸血鬼/暗黑系角色的视觉人格。

与黑暗惊悚封面（美先于异+异常点 ≤1）的分界：哥特厚涂是「明牌的暗黑华丽」（用户一眼知道这是暗黑浪漫卡），惊悚封面是「伪装的正常」（细看才发凉）。

## 2. 视觉要素解构

- **色彩**：黑基底+一个宝石色（深酒红/祖母绿/宝蓝/紫）+银或金的金属点缀。
- **材质**：蕾丝的镂空层次/天鹅绒的哑光/绸缎的冷光/银饰的锐利反光。
- **光**：烛光（暖而摇曳）或月光（冷而静）单源打光、伦勃朗式的明暗分割。
- **空间**：古典家具/彩绘玻璃/鸟笼/挂镜/枯玫瑰——每个道具都带象征。
- **构图**：端坐/倚靠的静态构图（哥特是静的美学）、对称或框式构图（门框/椅背的框中框）。
- **情绪**：优雅的疏离/危险的静谧/「请君入瓮」的注视。

## 7. 失败模式与修正

1. **万圣节化**（廉价道具感：蝙蝠/南瓜乱入）→ 道具白名单制（配方内 1–2 件），禁节日符号。
2. **蕾丝糊团**→ 「蕾丝镂空细节清晰」+降低蕾丝覆盖面积（领口袖口点到为止）。
3. **黑成一坨**（暗调失去层次）→ 「黑色有材质层次（天鹅绒/绸缎/皮革的不同黑）」+轮廓光。
4. **色彩杂**（宝石色超过一个）→ 单宝石色声明。
5. **表情狰狞**（暗黑理解偏差）→ 「优雅淡漠的静谧表情」——哥特的危险是静的。

## 8. 延伸风味

- **×血宴**（吸血鬼特化）：红酒杯/一滴血珠的克制暗示——悬停美学的视觉版。
- **×白哥特**：黑基底反转为白+银（婚纱哥特/圣女感）——堕天使卡的净化变体。
- **×机械哥特**：蕾丝+黄铜齿轮/怀表机芯——蒸汽朋克边缘的杂交。
