# 吉卜力水彩（ghibli watercolor）—— 治愈顶流风格深度指南

> 心智定位：2026 现象级顶流（GPT-4o 上线后单日 2300 万相关提示词）/ 治愈的世界语。
> 首选模型：gpt-image-2（无需参考图——风格词汇已被模型深度学习）。

## 1. 美学 DNA

吉卜力风格的本体是**手绘水彩背景美术（男鹿和雄式的云与草地）+简洁温暖的角色造型（圆润线条/朴素五官/大而清澈的眼）+「烟火气的奇迹」叙事观（日常细节里藏魔法）**。它的治愈力有明确的技术来源：水彩的透明感（颜色之间透气）、暖色的克制（暖而不腻的黄绿色系）、以及最关键的——**画面里永远有「生活正在进行」的证据**（晾着的衣物/冒热气的锅/风吹的麦浪）。

版权纪律：借鉴风格元素合法，直接使用官方 IP 角色（龙猫/千寻等）不可商用——原创角色+吉卜力风格语法是唯一正确姿势。

## 2. 视觉要素解构

- **水彩质感**：透明水彩的叠色/纸纹的微颗粒/边缘的自然晕染。
- **云**：蓬松的积云是本风格的图腾（立体的白云山——天空占画面 1/3 以上时必配）。
- **绿**：多层次的绿（黄绿/深绿/蓝绿的植被层次）——吉卜力的绿是活的。
- **光**：金色时刻（golden hour）/树影光斑（木漏れ日）/雨后的透亮。
- **角色**：圆润简洁的造型、朴素的日常服（针织/工装裙/风衣）、动态自然（奔跑/骑车/迎风）。
- **烟火气**：生活道具的在场（便当/水壶/帆布包/自行车）。
- **构图**：人景各半（环境是叙事伙伴）、宽景深（前景花草+中景人+远景山云）。

## 4. 构图变体

- **默认·乡间人景**：麦田/小路的经典构图。
- **奔跑帧**：动态奔跑+裙摆飞扬——「起风了」的生命力帧。
- **小屋窗景**：室内视角看窗外+桌上的生活静物——慢生活卡的居家版。
- **雨中屋檐**：雨帘+屋檐下的两人——治愈系的情绪雨戏。

## 6. 分类绑定

首选：甜妹元气/校园纯爱（清新线）/异世界慢生活/母系治愈（乡下姑姑子型）/整活（无绝望的温柔面）/人外（兽耳萌系的田园变体）。
换风格信号：需要更成熟的浪漫 → 柔光厚涂；需要动画截图感 → retro-90s。

## 7. 失败模式与修正

1. **IP 角色乱入**（龙猫形似物出现）→ 「原创角色与场景，不出现任何既有动画角色」。
2. **水彩变厚涂**→ 「透明水彩质感、纸纹微颗粒」强调。
3. **绿色单一**（塑料草地）→ 「多层次的绿：黄绿深绿蓝绿的植被层次」。
4. **过度精致**（角色画成柔光厚涂脸）→ 「简洁朴素的角色造型、五官简化」。
5. **无烟火气**（空洞的风景+人）→ 生活道具至少一件入画。
