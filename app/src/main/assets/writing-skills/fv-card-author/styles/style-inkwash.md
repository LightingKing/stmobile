# 新中式水墨（ink wash）—— 意境文人风格深度指南

> 心智定位：小红书「电子功德」赛道的高粘性美学 / 留白的艺术 / 古风的写意线。
> 首选模型：seedream-5.0（水墨意境实测最佳）；gpt-image-2 备选。

## 1. 美学 DNA

新中式水墨承宋代美学的当代转译：**笔墨的书写性（写意的笔触/墨色的浓淡干湿）+留白的空间哲学（负空间占画面一半以上/无画处皆成妙境）+极简的色彩纪律（青黛与墨黑+仅一点朱红）**。「新」在构图的现代感（插画的视觉焦点管理）与人物的精致化（面容可以工笔级精细——「工笔脸+写意衣」的混搭是当代水墨插画的标准解法）。

它在角色卡的独特价值：**气质的文化背书**——水墨封面自动为角色注入「有文化底蕴」的预设（文人/隐士/古琴师/道士），这是其他风格给不了的气质快捷方式。

## 2. 视觉要素解构

- **墨色**：五档墨（焦浓重淡清）的层次运用、边缘的自然晕染（水痕感）。
- **留白**：负空间 ≥50%、留白参与构图（云雾/水面/天空的「无」）。
- **色彩**：青黛/黛蓝/墨黑的主系+**唯一朱红点睛**（一枝梅/一方印/一点唇色）。
- **笔意**：衣袂的写意几笔（宁简勿繁）、山石的皴法感、枝干的书法性线条。
- **人物**：工笔脸+写意衣的精粗对比、姿态的静（立/坐/执伞——水墨人物不奔跑）。
- **道具**：伞/琴/卷轴/灯笼/扁舟——文人道具库。
- **构图**：竖轴立轴式、对角线的气韵流动、一角式构图（马远「马一角」的现代用法）。

## 4. 构图变体

- **默认·雾桥执伞**：一角式的经典（实测样张同款）。
- **抚琴独坐**：琴与人的静物式构图+大留白——琴师/隐士卡。
- **崖边负手**：人物极小+山水极大——世界观卡/门派卡的「势」构图。
- **窗棂借景**：圆窗/花窗的框式构图——庭院深深的宅斗气质。

## 6. 分类绑定

首选：古风权谋（文臣线）/武侠江湖（隐士/剑客）/民俗灵异（道士——水墨+一点朱砂符纸是天配）/仙侠（写意线）/穿书（古言书中书的卷轴感）。
换风格信号：华丽感需求（宫廷/舞会）→ guofeng 厚涂；女性向古偶感 → 柔光厚涂×古风。

## 7. 失败模式与修正

1. **留白恐惧**（画面填满）→ 「大面积留白占画面一半、无画处皆成妙境」。
2. **色彩失守**（红色超过一处/出现第三色系）→ 「全画唯一的红」+青黛墨黑声明。
3. **日式枯山水化**（MJ 高发）→ 显式宋代美学+中式建筑元素锚定。
4. **人物照片化**（脸的精细度溢出到写实）→ 「工笔淡彩的脸、插画质感」。
5. **墨色脏**（灰成一团）→ 「墨分五色的浓淡层次、边缘清透」。
