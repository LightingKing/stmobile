# 日式厚涂概念（japanese impasto concept）—— 高级感风格深度指南

> 心智定位：MJ sref 热门的「高级感」代名词 / 男主卡的气质天花板 / 未完成的艺术感。
> 首选模型：gpt-image-2；niji 7 的厚涂向也可。

## 1. 美学 DNA

日式厚涂概念是概念艺术（concept art）工作流与日系审美的杂交：**脸部相对精细（保留动漫美感的五官）+服装与背景的大胆概括（松散的大笔触/色块的堆叠/可见的笔刷痕迹）+莫兰迪低饱和的色彩纪律（鼠尾草绿/石板蓝/暖灰/奶油黄）**。它的高级感来自「未完成的自信」——像画师灵感爆发时的速写稿，克制的笔数里全是准确（用最少的笔触表达结构）。

心理机制：精细与粗放的对比制造「焦点的绝对权力」（你的视线只能落在脸上——其他地方是故意不让你停留的），这正是男主卡需要的气质压制感。

## 2. 视觉要素解构

- **焦点分层**：脸部精细刻画 → 身体服装半概括 → 背景纯色块——清晰的三层焦点梯度。
- **笔触**：大而果断的方笔触/边缘的飞白与色彩溢出/「涂抹感」的保留。
- **色彩**：莫兰迪系低饱和（灰调的绿/蓝/黄）、全画 3–4 色以内、色块之间的呼吸。
- **光**：单侧硬光的明暗二分（脸部的立体来源）、背景不参与打光。
- **质感**：数字厚涂的干笔刷纹理（非油画布纹——是 Procreate 感不是画布感）。
- **情绪**：沉静/忧郁/疏离——「一个人的暴雨」。

## 3. 完整配方

```
日式厚涂概念艺术风格插画：脸部相对精细保留动漫美感，服装与背景用大胆松散的色块概括、
笔触清晰可见带未完成的速写感、莫兰迪低饱和配色（鼠尾草绿/石板蓝/暖灰/奶油黄）、
沉静高级略带忧郁的氛围。绘制新人物：
[年龄+职业身份], [姿态：侧身站立/低头点烟/回望], [脸部细节：眉眼锐利/疲惫/沉静],
[服饰：风衣/西装/制服——用大笔触概括], [一个道具：烟/伞/公文包],
[场景：雨夜街灯/站台/办公室windows——大笔触抹出+虚化车灯光斑],
[色彩声明：莫兰迪低饱和+全画3-4色], 脸部占画面上半近一半,
画面一侧竖排白色行草书法字标题「<角色名>」带小朱红印章,
除标题外画面中不出现任何其他文字（禁止韩文日文）, 竖版9:16
```

## 4. 构图变体

- **默认·雨夜侧身**：街灯下的定格（实测样张同款）。
- **窗前背影**：办公室落地窗+城市灯——权力系男主（黑道/总裁线）。
- **动态凝固**：转身瞬间的衣摆笔触飞散——武打/刑侦的动作帧。

## 6. 分类绑定

首选：悬疑刑侦/黑道大佬/赛博（低生活人物）/民国（报馆文人）/年上禁欲（艺术家变体）/权力交换（沉静主导者）。
换风格信号：女性角色的柔美需求 → 柔光厚涂（本风格的女性角色偏「飒/寡淡」系——女侦探/女杀手适用，甜妹不适用）。

## 7. 失败模式与修正

1. **全画精细化**（焦点梯度失效）→ 「只有脸部精细，服装背景保持大笔触概括」。
2. **油画化**（画布纹理出现）→ 「数字厚涂的干笔刷质感，非油画布纹」。
3. **色彩鲜艳化**→ 莫兰迪色名点名+「低饱和灰调」。
4. **笔触失控**（脸也被笔触吃掉）→ 「脸部边缘清晰完整」。
5. **背景叙事过度**（背景画太满）→ 「背景是色块与光斑的抽象概括」。

## 8. 延伸风味

- **×古风**：概念厚涂+古装（武侠篇的「写意刀客」封面——比 guofeng 冷比水墨硬）。
- **×双人**：一精一略的双人焦点（主角脸精细+背后同伴剪影化——群像的层次语法）。
- **×血色点睛**：莫兰迪灰调里唯一一抹暗红（领带/伤口/夕阳）——危险气质的一笔。
