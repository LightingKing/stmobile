# 日系柔光厚涂（soft-paint anime）—— 社区大盘风格深度指南

> 心智定位：酒馆卡社区的绝对主流（本地普查约五成）/「二次元」默认解 / 浪漫暖光。
> 首选模型：gpt-image-2 + ref-08；批量打样 seedream-5.0。

## 1. 美学 DNA

柔光厚涂是日系插画商业化的当代主形态（pixiv 排行榜/手游卡面/轻小说封面的主流画法）：**动漫的五官语法（大眼/小鼻/精致唇）+厚涂的体积渲染（皮肤的光泽层次/布料的质感堆叠）+柔光的氛围滤镜（暖调的浪漫光/漫射的柔和阴影）**。与赛璐璐的分界是「过渡」——赛璐璐色块之间是硬边界，柔光厚涂是无级渐变；与韩系的分界是「温度」——韩系冷雾面，柔厚涂暖光泽。

它统治酒馆卡的原因很实际：**它是「美得最没有争议」的画法**——暖光+光泽皮肤+精致五官的组合对最大公约数用户生效，御姐/人妻/纯爱这些大盘分类几乎全用它。

## 2. 视觉要素解构

- **皮肤**：细腻光泽、湿润高光（唇/眼下/锁骨的高光三角）、暖粉底色。
- **头发**：根根分明但整体柔和成绺、发梢透光、头顶天使环高光。
- **色彩**：暖色主调（奶油/蜜色/暖棕）、饱和度中等、背景与主体同色系。
- **光**：漫射暖光（午后窗光/夕阳/室内灯）、光斑 bokeh 背景。
- **构图**：胸上景为主（比韩系稍退半步——身体语言入画）、直视或浅笑视线可与观者接触（与韩系的回避相反——亲近感是本风格的资产）。
- **情绪**：温柔/浪漫/亲密——「她在等你」的镜头感。

## 4. 构图变体

- **默认·胸上景**：亲近感标准（她在你对面的距离）。
- **环境半身**：入画环境讲人设（飘窗+绿植=治愈系/吧台+酒=夜场系）。
- **俯拍躺姿**（浓度较高的卡）：发丝铺散的经典构图——注意分级边界，衣着完整。

## 6. 分类绑定

首选：御姐人妻/母系包容/清纯校花/甜妹（暖光线）/破镜重圆（回忆滤镜）/网恋电竞（女神卡面）/后宫多人/百合 GL。
换风格信号：需要「冷/飒/危险」情绪 → 韩系；需要「元气/校园感」→ 赛璐璐。

## 7. 失败模式与修正

1. **塑料娃娃脸**（3D 感）→ 补「手绘插画质感」，去 render 系词。
2. **糖水片化**（甜到失真）→ 收一档饱和度：「色彩柔和不艳俗」；加一个生活化道具锚真实感。
3. **光斑吞脸**（bokeh 过强）→ 「光斑只在背景，脸部清晰锐利」。
4. **发丝糊团**→ 「发丝分缕、发梢透光」强调重 roll。
5. **年龄漂移**（画太幼）→ 骨相锚定成年感：「成熟的骨相、身高比例成年」。

## 8. 延伸风味

- **×古风**：柔光厚涂+汉服=古风大盘画法（比 guofeng 厚涂轻、比水墨甜）。
- **×微醺夜场**：暖光换霓虹暖（酒吧色温）——御姐夜场卡的标准变体。
- **×雨天**：窗上雨痕+室内暖光的对比——破镜重圆的情绪封面。
