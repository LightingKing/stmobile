# 黑白漫画（manga monochrome）—— 本子扉页风格深度指南

> 心智定位：日漫杂志扉页的张力美学 / 同人本子系的原生审美 / 黑白灰的表现力极限。
> 首选模型：gpt-image-2。

## 1. 美学 DNA

黑白漫画风格是印刷限制孕育的完整视觉语言：**墨线承担全部造型（粗细/疏密/顿挫的线条表情）+网点纸的灰阶系统（screentone 的规则点阵替代渐变）+漫画符号学（速度线/集中线/情绪符号的抽象表达）**。它的表现力悖论——颜色越少，情绪越浓（黑白的强对比天然携带戏剧性，这是彩色永远给不了的「墨的暴力」）。

角色卡场景的价值：同人文化的用户对「本子扉页感」有原生审美认同（同人志的视觉母语）；热血/不良/双男主等类型的「劲」用黑白最正。

## 2. 视觉要素解构

- **墨线**：G 笔触感的粗细变化（外轮廓粗内部细/发梢的出锋）、果断的顿挫。
- **网点**：screentone 的规则点阵（灰阶分层）、渐变网点的天空/背景用法。
- **黑块**：大面积黑的构图权力（头发的纯黑块/逆光的黑剪影）——黑是本风格的主角。
- **白**：高光的留白（不是画白，是留白）/闪光的放射状白。
- **符号**：速度线/集中线（视线引导的暴力美学）/情绪线（阴影竖线/汗滴）。
- **构图**：杂志扉页的戏剧化视角（大仰角/大俯角/斜切）、出血框的张力。
- **情绪**：桀骜/热血/宿命感——「下一页就要开打」。

## 3. 完整配方

```
黑白漫画扉页风格：日式漫画的墨线笔触、网点纸质感（screentone）、
强对比的黑白灰层次、速度线与情绪线的漫画语言、杂志连载扉页的构图美学。绘制新人物：
[年龄+类型身份：不良少年/剑士/双男主之一], [姿态：回头/插兜而立/拔刀的定格],
[服饰：校服/大衣——衣褶用利落墨线], [发：大块黑发+出锋的发梢],
[背景：网点渐变的天空/铁丝网剪影/城市线稿], [漫画符号：速度线/集中线选1],
[视角：大仰角或斜切的扉页构图], 脸部精细刻画,
画面一侧竖排白色标题「<卡名>」带小朱红印章,
除标题外画面中不出现任何其他文字（禁止日文假名）, 竖版9:16
```

## 4. 构图变体

- **默认·天台扉页**：仰角+风衣+铁丝网（实测样张同款）。
- **对峙跨页感**：两个角色的斜对角构图——双男主/宿敌卡的原生语法。
- **走廊逆光**：大黑块剪影+窗格光——悬疑/病娇的黑白版。
- **四格彩蛋**：正经扉页+角落一格 Q 版吐槽——整活的漫画法。

## 5. 多模型适配

| 模型 | 表现 | 用法调整 |
| --- | --- | --- |
| gpt-image-2 | 基准（网点质感最稳） | 原配方直用 |
| niji 7 | 线稿艺术的另一强者 | `manga style, screentone, ink lines --niji 7`；扉页构图需显式描述 |

| z-image-turbo | 偏动画线稿（轻） | 快速打样 |

## 6. 分类绑定

首选：同人（本子扉页的原生感）/双人卡双男主/武侠（黑白刀剑）/整活（漫画分格）/黑暗惊悚（伊藤润二式的黑白恐怖——注意零血浆纪律照守）。
换风格信号：需要色彩情绪 → 全线让位；「少年感彩页」→ 赛璐璐。

## 7. 失败模式与修正

1. **灰阶照片化**（黑白照片感而非漫画感）→ 「墨线造型+网点灰阶，非黑白照片」。
2. **网点糊**（点阵变脏灰）→ 「网点点阵清晰规则」。
3. **线条软**（没有 G 笔的顿挫）→ 「墨线粗细变化果断、发梢出锋」。
4. **符号滥用**（速度线+集中线+情绪线全上）→ 漫画符号选 1。
5. **假名乱入**（拟声词自动生成）→ 「禁止日文假名与拟声词」。

## 8. 延伸风味

- **×红点睛**：全黑白+唯一一处红（血/眼瞳/椿花）——「罪恶」系的经典设计。
- **×少女漫**：网点换花朵网点+闪光大眼——少女漫扉页的复古流（BL/百合的另一皮肤）。
- **×水墨**：G 笔线换毛笔线——「漫画×水墨」的武侠混血（快意恩仇的扉页感）。
