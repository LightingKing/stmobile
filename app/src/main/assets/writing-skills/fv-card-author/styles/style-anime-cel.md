# 赛璐璐平涂（cel shading anime）—— 青春明快风格深度指南

> 心智定位：TV 动画的经典质感 / 校园青春的视觉母语 / 合法高饱和区。
> 首选模型：z-image-turbo（纯度第一）/ niji 7（线稿艺术）；带 ref 时 gpt-image-2 + ref-06。

## 1. 美学 DNA

赛璐璐（celluloid）源自传统动画的透明胶片工艺：**线稿承担全部造型（干净利落的封闭线条），色彩以平涂色块填充（一色一影的两阶着色），高光与阴影是形状而非渐变**。它是「动画感」的本体——用户看到赛璐璐就自动带入 TV 动画的叙事期待（青春/热血/日常）。

在角色卡场景它是校园/甜妹/元气类的最优解：明快=无压力，色块=清晰的识别度（缩略图下依然锐利——列表页的点击率优势）。它也是全库唯二的合法高饱和区（另一个是多巴胺）——但高饱和的纪律是「色相少而纯」（三主色内），不是彩虹轰炸。

## 2. 视觉要素解构

- **线稿**：干净的封闭轮廓线、粗细有序（外轮廓粗内部细）、深棕/深灰线色（纯黑线是漫画不是动画）。
- **着色**：平涂色块、一色一影（底色+一层阴影色）、阴影边界硬。
- **高光**：形状化高光（发丝的锯齿状色块高光/眼睛的圆点高光）。
- **色彩**：明快三主色（如水手服的蓝白红）、高明度、天空色系背景。
- **构图**：可全身可半身（线稿的表现力支持小尺寸人物）、动态姿势友好（回头/挥手/奔跑）。
- **情绪**：元气/明朗/青春——「夏天的风」。

## 4. 构图变体

- **窗边回头**：校园卡的黄金构图（ref-06 同款）。
- **全身动态**：奔跑/跳跃的青春帧——运动系人设。
- **动画截图感**：加「像一帧动画截图」+16:9 改竖切——TV 感强化。

## 6. 分类绑定

首选：校园纯爱（男女双向）/甜妹元气/年下奶狗/网恋电竞（日常线）/整活喜剧/清纯校花。
换风格信号：情绪要「深/暗/成熟」→ 柔光厚涂或韩系；怀旧感 → retro-90s。

## 7. 失败模式与修正

1. **厚涂化漂移**（渐变出现）→ 强调「平涂色块、一色一影、阴影边界硬」。
2. **色彩失控**（彩虹化）→ 「三主色以内」+点名主色。
3. **线稿脏**（碎线/重复线）→ 「干净封闭的线稿」重 roll。
4. **背景空白**（niji 7 高发）→ 必须显式写背景内容。
5. **眼睛无神**→ 「大眼+圆点高光+看向[方向]」三件套补齐。

## 8. 延伸风味

- **×夕阳**：橙色滤镜的放学后——青春卡的情绪 MAX 版。
- **×四格分镜**：赛璐璐+漫画分格边框——整活卡的表情包封面。
- **×粗线稿**（doodle 边缘）：线稿加粗+色块出线——手帐贴纸感，甜妹彩蛋向。
