# 国风厚涂（guofeng impasto）—— 古风华丽风格深度指南

> 心智定位：古风类目的第一视觉 / 仙侠权谋的正装 / 场景意境派。
> 首选模型：gpt-image-2 + ref-09；水墨写意需求转 style-inkwash。

## 1. 美学 DNA

国风厚涂是中式古典美学与数字厚涂的融合体（游戏立绘《原神》璃月系/古偶海报/仙侠网文封面的通用画法）：**厚涂的体积与材质渲染（绸缎的光泽/金属饰品的反光/纱衣的透叠）+中式的色彩体系（青绿山水色/朱砂金/黛蓝）+意境构图（人景交融/留白呼吸/竖轴卷轴感）**。与日系厚涂的分界在「场景地位」——日系人是绝对主角背景虚化，国风讲人景交融（山水云雾是人设的一部分）。

角色卡场景的价值：古风类目（权谋/仙侠/武侠/民俗）的用户对「氛围正确」极其敏感——服饰形制、色彩体系、场景语汇错一个就出戏，国风厚涂的成熟语法是最低风险选择。

## 2. 视觉要素解构

- **材质**：绸缎光泽/纱衣透叠/玉石温润/金属錾刻——材质的精细是国风厚涂的工笔底子。
- **色彩**：清冷系（月白/黛蓝/青灰+一点朱红或鎏金）或浓艳系（朱砂/石绿/鎏金——庙堂感）二选一。
- **场景**：山水云雾/宫阙飞檐/月下庭院——场景纵深参与叙事。
- **构图**：全身或七分身立绘（服饰是戏）、人物占画面 1/3–1/2、竖轴卷轴式留白。
- **发**：黑长直/高髻+发簪步摇的细节刻画。
- **情绪**：清冷疏离/仙气缥缈/威仪深沉——「距离感」是古风的性张力。

## 4. 构图变体

- **默认·场景立绘**：人景交融的全身像（ref-09 同款）。
- **怼脸古风**（人设特写需求）：借韩系构图锚+国风材质——古偶海报的近景版。
- **背影卷轴**：人物背影+山水主导——世界观卡/门派群像的封面。

## 6. 分类绑定

首选：古风权谋/仙侠师徒/武侠江湖（厚涂线）/民俗灵异（道观场景）/穿书女配（古言书中书）。
换风格信号：文人向/意境优先 → inkwash 水墨；现代古风混搭 → 韩系×古风延伸风味。

## 7. 失败模式与修正

1. **和风混入**（衣领右衽画反/振袖出现）→ 「汉服形制、交领右衽、禁止和服元素」。
2. **影楼风**（廉价古装写真感）→ 提高场景叙事比重+「电影感构图」，去掉纯色背景。
3. **饰品糊化**（步摇/绣纹细节崩）→ 「饰品细节精致清晰」+减少饰品数量（少而精）。
4. **色彩脏**（清冷浓艳混用）→ 二选一声明必须写。
5. **脸部太小**（场景吞人）→ 「人物占画面三分之一以上、脸部清晰」。

## 8. 延伸风味

- **×水墨边缘**：厚涂人物+水墨晕染背景——两个国风分支的官方杂交。
- **×妖异**（民俗卡）：清冷系换「烛火暖+阴翳蓝」的对冲色——聊斋气质。
- **×现代混搭**：古风人物+现代单品（西装外披/耳机）——穿越题材的封面语法。
