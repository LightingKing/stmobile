# 韩系半写实（semi-realistic manhwa）—— 默认风格深度指南

> 心智定位：头部卡站审美对标 / 颓废高级感 / 成人向角色卡的「氛围正装」。
> 首选模型：gpt-image-2 + ref-01~04 参考图（唯一全要素可靠的组合）。

## 1. 美学 DNA

韩系半写实的源流是韩国网漫（manhwa）成人向封面与 K-illustration 商业插画的混血：**写实的骨相打底（真实人体比例/立体五官），插画的皮肤处理（雾面磨皮/无真人毛孔），漫画的情绪语法（低垂眼帘/慵懒颓废）**。它与日系厚涂的分界在「体积感来源」——日系靠光泽（湿润高光），韩系靠骨相（结构阴影）；与真人写实的分界在「质感克制」——写实要毛孔，韩系要雾面。

这个风格在角色卡场景的统治力来自「情绪先于叙事」：一张韩系封面不讲故事，只讲状态（颓/拽/禁欲/慵懒）——状态恰好是角色卡用户选卡时的第一决策变量。

## 2. 视觉要素解构（杂交取词用）

- **皮肤**：雾面细腻、粉感、无油光无塑料反光——「matte porcelain skin」。
- **头发**：发丝分缕根根分明、有碎发飘出轮廓线——发是韩系的第二张脸。
- **色彩**：黑白灰主调+唯一点缀色（暗红/金/青任选一），点缀色面积 ≤一成。
- **光**：单侧光源、脸是画面最亮点、轮廓光强制可见。
- **构图**：脸部大特写占画面上半近一半、眼睛在上三分之一线、微俯/微仰凑近。
- **情绪**：视线不与观者对视（低垂/斜睨/看向画外）——回避即张力。
- **装饰**：竖排白色行草书法标题+小朱红印章（成品卡面的身份标识）。

## 4. 构图变体

- **默认·怼脸特写**：脸占上半近一半——人设卡标准。
- **半身氛围**：脸约 1/4+肩胸入画+手部道具戏——道具叙事重的角色（调酒师/医生）。
- **场景剪影**（群像/世界卡用）：前景主角半身剪影+中景环境+单色光源——脸不再是主角，氛围是。
- 禁：全身小人（脸小于 1/8 即废图，重 roll）。

## 6. 分类绑定

首选本风格的分类：年上禁欲/破镜重圆/娱乐圈/黑道大佬/病娇疯批/权力交换/NTR 背德/御姐人妻（暗调线）/伪骨科/民国（现代切片）。
换风格信号：用户说「二次元/可爱/治愈」→ 转 anime 系；古风题材 → guofeng/inkwash。

## 7. 失败模式与修正

1. **半身工作照化**（脸太小/正面证件照感）→ 补「脸部特写占画面上半近一半+微俯拍凑近」。
2. **整图铺暖**（暖色失控）→ 补「整体黑灰冷调，唯一暖色面积不超过一成」。
3. **衣物乱字**（假韩文/假英文）→ 补「除标题外不出现任何其他文字（禁止韩文日文）」。
4. **油画化**（笔触感/画布纹理）→ 禁用词检查：油画笔触/刮刀肌理/粗糙画布不入 prompt。
5. **塑料皮肤**（3D 渲染感）→ 补「雾面粉感、插画质感」，去掉任何 render 系词。
6. **书法标题缺笔**（4 字以上高发）→ 角色名压到 2–3 字或用「号」。

## 8. 延伸风味

- **韩系×古风**：韩系皮肤处理+汉服（新国风漫画感——古偶剧海报向）。
- **韩系×荧光**（Y2K 边缘）：点缀色换荧光青/粉，加一条霓虹轮廓光——网恋电竞卡的暗调变体。
- **双人韩系**：双人同框时点缀色一人一色（互补色）——双人卡篇的封面标准。
