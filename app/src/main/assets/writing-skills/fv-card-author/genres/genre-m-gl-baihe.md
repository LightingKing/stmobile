# 百合 GL（女女/双女主）创作指南

> 适用标签：GL / 百合 / 女女 / 双女主 / 姬 / 纯百 / 姐妹情谊线 / 全性向友好
> 数据底座：本地百合分类 102 张（开场白均 2143 字全库第二长、世界书均 25.2 条；高频 tags：纯爱/熟女/姐妹/九尾——**纯爱浓度是百合区的底色**）+ BL 篇（genre-f-bl）的对等博弈机制镜像

## 1. 分类定义与受众画像

### 1.1 这个赛道在卖什么

百合卖的是**「细腻对细腻的共振」**。两个女性之间的情感升级以毫米为单位：一次比平时长 0.5 秒的对视、并肩走时肩膀的距离从 10 厘米变成 7 厘米、「你今天换洗发水了」的觉察——**觉察力的互相印证**是百合的核心语法：她们都太敏锐了，所以谁都藏不住，所以「装作没发现」本身成了共谋。

与 BL 的美学分野：BL 的张力是「谈判与破防」（两个骄傲的拆解战），百合的张力是**「渗透与共生」**（两个细腻的互相长入）——BL 靠交锋推进，百合靠日常的密度推进（一起吃的第 100 顿饭和第 1 顿饭没有事件差，但有质感差）。本地百合区开场白全库第二长（2143 字）就是佐证：百合的开场需要更多笔墨铺「质感」而非「事件」。

### 1.2 用户是谁

- **主力画像**：男女混合，18–32 岁，动画/轻小说百合文化受众（《终将成为你》《摇曳百合》的谱系）+ 纯爱审美用户（百合区的纯爱浓度全库最高）。
- **需求本质**：**无权力结构的纯粹感情**。百合叙事天然剥离了传统性别脚本的权力预设，用户消费的是「两个灵魂对等相爱」的理想态——这也是百合区对「油腻」零容忍的原因（任何一方的「攻化霸总化」都是对纯粹性的污染）。
- **食性分层**：清水百合（牵手即天花板的纯情系）与浓百合（成人向）的分野明确，标签必须声明；本地高频 tag「洁」在百合区的出现率显著——双洁是常见默认。

### 1.3 用户不要什么

1. **男性凝视残留**：把百合写成表演（服务于旁观快感的姿态化亲密）——百合用户对「拍给别人看的百合」的识别与反感极其敏锐。她们的感情必须自洽自足。
2. **攻受模板硬套**：把 BL/BG 的攻受结构直接搬进百合（一方霸总化一方小鸟化）——百合的关系结构是流动的（谁主动谁被动随情境流转），固化分工是外来污染。
3. **悲剧宿命论**：百合=BE 的旧时代叙事（社会不容/被迫分离）。2026 的用户要 HE 与日常——困境可以存在，但出口必须在。
4. **身份猎奇化**：把「女生喜欢女生」本身当作最大卖点反复咀嚼——高分百合卡里性向不是戏剧冲突的核心，「喜欢的是你这个人」才是。

## 3. 核心吸引力解构：五个爽点引擎

### 3.1 觉察力共振引擎（本赛道第一引擎）

两个高敏感者的互相探测：她发现你换了洗发水，你发现她发现了，她发现你发现她发现了——**觉察的嵌套是百合特有的心理游戏**。写法：觉察永远不点破，用「回应性动作」确认收到（她注意到你今天没吃早饭——午休时你桌上多了饭团；你注意到饭团是她绕路买的——第二天你「顺路」带了她提过一次的果茶）。**觉察-回应的静默链**每 2–3 轮一环，链条本身就是感情的编年史。

### 3.2 日常密度引擎

百合的进度不靠事件靠密度：一起走的放学路（第 1 次和第 50 次的区别在沉默的舒适度）、共享的耳机（从各听各的到听同一首）、习惯的互相渗透（你开始用她的口头禅/她的笔记本上出现你的字迹风格）。**「习惯渗透清单」**是本赛道的核心资产：12+ 项互相长入的痕迹，按时间轴逐项呈现——用户某天回看，发现两个人早就活成了「我们」。

密度写作的技术要点是**「重复中的微差」**：同一场景的第 N 次出现，变化只有一个变量（今天的便当她多做了一样菜/今天的放学路她走在了里侧）——微差是密度叙事的心跳，无差的重复是流水账，大差的重复是事件剧（都不是百合的语法）。每次重复场景写作前先定「今天的微差是什么」。

### 3.3 换轨引擎（姐妹情谊 → 爱情）

本地「姐妹」tag 的主流叙事：亲密的前置关系（闺蜜/学姐学妹/发小）到爱情的换轨。换轨的技术核心是**「既有亲密的重新定价」**：牵手本来就牵（闺蜜常态），但那天的牵手突然有了重量（谁都没松开，谁都没说话）——**同一行为的意义翻转**比新行为的发生更有冲击力。换轨的三个标志性时刻：① 重新定价（旧行为新重量）；② 命名恐慌（「我们这样算什么」的第一次浮现）；③ 排他觉醒（她和别人也这样吗？——嫉妒的第一次自我确认）。

### 3.4 镜像成长引擎

两人互为镜子：她身上有你想成为的样子（她的勇敢/她的松弛），你身上有她缺的那块（你的坚持/你的温柔）——**爱情与自我成长的同构**是百合叙事的精神内核（《终将成为你》的谱系）。写法：各自的成长线（她的比赛/你的创作）互相借力，终局的告白常常与成长的里程碑绑定（她赢下决赛的那天，第一个拥抱给了你——「没有你，我走不到这里。有你，我哪里都敢走。」）。

### 3.5 静默确认引擎（终局美学）

百合的告白美学偏静默：不需要宣言式的「我喜欢你」，而是**双向知晓的落定**——某个瞬间两人同时明白「我们已经是了」（她自然地把你的手揣进她的口袋，你们继续走，谁都没提这件事——但都知道从这一步起不一样了）。语言化的告白如果有，也要轻（「……一直都是吧。」「嗯。一直都是。」）。**重仪式轻宣言**：告白可以没有，纪念日要有（她们会记住「那天」——口袋的那天）。

静默确认后的关系书写要点：**外观不变，内核全变**——旁人看她们和以前一样（还是那条放学路/还是那份便当），只有她们知道每个惯例都换了含义。这种「秘密的公开生活」是百合终局期的独有质感：全世界看到的是友情的形状，装着的是爱情的内容。

## 4. 人设公式

### 4.1 关系原型库（双人配置）

| 关系原型 | 张力来源 | 换轨触点 | 语言指纹方向 |
| --- | --- | --- | --- |
| 闺蜜换轨 | 既有亲密的重新定价 | 一次意义翻转的旧行为 | 黑话互怼+突然的安静 |
| 学姐×学妹 | 仰慕与被仰慕的流转 | 学姐的第一次示弱 | 敬语的溶解 vs 照顾腔 |
| 优等生×问题儿 | 世界规则的互相入侵 | 各自规则为对方破例 | 规整句式 vs 跳脱短句 |
| 竞争对手 | 唯一认可的对手（BL 宿敌的百合版） | 赛后的那次平局 | 交锋腔+私下的坦率 |
| 职场姐姐×新人 | 御姐机制的百合化 | 兜底被反向兜底 | 从容腔 vs 成长腔 |
| 人外×人间 | 时间尺度差（妖的百年×人的一生） | 「这一世」的重量确认 | 古雅慢语 vs 现代快语 |

### 4.2 双人人设的对称性设计

百合双人的人设要**互补但对称**（BL 的对等博弈机制迁移）：各自完整的活人感三件套、各自的成长线、各自的「她不知道的我」——对称性检查：把两人的人设条目并排，任何一栏的详略差 >30% 就是失衡信号（失衡的百合会滑向「主角与她的挂件」）。

### 4.3 语言指纹模板（百合三件套）

1. **觉察句**：「你换洗发水了。」（不是问句——她确定，只是说出来让你知道她注意到）
2. **静默回应体**：语言的留白+动作的接话（「今天好冷。」——她没接话，把自己的围巾解下来绕到你脖子上，绕了两圈）。
3. **复数的滑入**：「我」到「我们」的不自觉切换（「我们下次再来」——「我们」说出口之后两个人都顿了半拍）——人称的变化是百合最轻也最重的告白。

配套语料条五组：日常觉察腔、静默回应样本 ≥5（语言留白+动作接话成对）、换轨期的命名恐慌腔、复数滑入样本、终局的轻告白腔。

### 4.4 负面规则（本赛道专属追加）

禁男性凝视式姿态化描写；禁攻受模板固化（主动权流动）；禁 BE 宿命论（出口必须在）；禁性向猎奇化（冲突核心是「你」不是「性别」）；双人对称性检查（详略差 ≤30%）；清水/浓度标签声明。

## 5. 开场白范式

### 5.1 A 型：日常质感的高密度切片（推荐）

```
[状态栏：季节+放学后/午休的时间戳+「认识第 N 天/第 N 顿饭」的密度计数]
[日常进行时的双人镜头：天台的便当/图书馆的并排/琴房的合奏——她们的「惯例」已经运转很久]
[觉察-回应链的一环展示：她注意到你的小变化→静默回应的动作]
[质感细节铺陈（本赛道开场白可以长）：光线/温度/两人之间 7 厘米的距离]
[一次意义的轻微翻转：惯例中的某个瞬间突然「不一样」了（对视超时 0.5 秒/指尖相碰没有立刻分开）]
[开放收束：惯例照常结束，「明天见」说得和往常一样——但今天的「明天见」她说完没有立刻转身]
[折叠面板：习惯渗透清单（已渗透 N 项）+ 今日觉察记录（双向的）]
```

### 5.2 必做检查

- [ ] 模式声明（扮演/嗑 CP）+清水或浓度标签。
- [ ] 惯例先行（她们的日常已经运转很久的质感）。
- [ ] 觉察-回应链 ≥1 环。
- [ ] 意义翻转的第一次（轻微、可回味）。
- [ ] 双人对称性（开场白内两人的笔墨均衡）。
- [ ] 质感细节 ≥5（光线/距离/温度——百合开场白的血肉）。

## 5.5 关系曲线：30 轮节奏表（换轨五幕）

- **第一幕（1–6 轮）·惯例期**：日常密度的展示（放学路/便当/耳机），觉察-回应链常态运转。进度信号：习惯渗透 +2 项。
- **第二幕（7–13 轮）·重新定价期**：旧行为的新重量开始出现（牵手的那次没松开/靠肩睡着的那次心跳），双方各自「装作没发现」。进度信号：静默回应的规格升级（围巾绕两圈级）。
- **第三幕（14–20 轮）·命名恐慌期**：「我们算什么」的浮现（不问出口，各自消化——百合的命名恐慌是内向的），排他觉醒（她和别人也这样吗的自我审问/看到她与别人亲密时的说不出的堵）。进度信号：复数的滑入第一次（「我们」的顿拍）。
- **第四幕（21–27 轮）·镜像借力期**：各自成长线的关键节点（她的决赛/你的投稿），互为支点。第三方变量（有人追她/毕业分离的预告）逼迫直面。进度信号：命名恐慌的第一次外泄（半句话：「如果我说……算了。」）。
- **第五幕（28+ 轮）·静默落定**：口袋时刻（双向知晓的落定）+ 轻告白（如果有）。长线运营：「我们」的日常续写（同居/异地的通信/纪念日体系）+ 成长线的互相见证 + 惯例的升级版（便当变成两人份的厨房）。

## 5.6 场景库（百合微场景 ×18）

惯例系：天台便当的固定座位 / 放学路的第 100 次 / 图书馆的并排（书页翻动的同步率）/ 琴房合奏的呼吸默契 / 共享耳机的歌单演变。
觉察系：洗发水的发现 / 没吃早饭的饭团回应 / 她藏起来的创可贴（你还是发现了她手上的伤）/ 天冷的围巾两圈。
翻转系：牵手没松开的那次 / 靠肩睡着的心跳 / 对视超时 0.5 秒 / 帮她别头发时指尖碰到耳廓（两个人同时僵住 0.3 秒然后同时装没事）。
恐慌系：她和别的女生说笑时你的堵 / 「你们关系真好」的第三方评语（两人同时说「对啊」，同时心虚）/ 毕业去向表的沉默。
落定系：口袋时刻 / 决赛后的第一个拥抱 / 「一直都是吧」的轻告白 / 纪念日的心照不宣。

## 7. 美化主题建议

- **视觉语言**：「毫米级」美学——细线条、大量留白、手写体批注；配色「雾白+青金」（清透的双人色）。密度计数器（第 N 顿饭/第 N 次放学路）是招牌组件。
- **组件选型**：习惯渗透清单（checklist 样式，已渗透项打勾的动画）+ 觉察记录双栏（她的觉察/你的觉察对照）+ 距离计（两人的物理距离从 10cm 到 7cm 的历史曲线——本赛道最诗意的数据可视化）。
- **进阶**：意义翻转时刻的视觉标记——惯例事件的重复出现用同一图标，翻转的那次图标微微发光（同一行为的新重量的 UI 语言）。

## 10. AI 味陷阱（本赛道高发）

1. **「她们的友情早已超越了普通朋友」**——旁白定性直给。关系的质变只能用意义翻转的瞬间呈现，禁止旁白盖章。
2. **姿态化亲密**——动不动搂腰/十指相扣的摆拍描写。百合的亲密在毫米级（肩距 7 厘米/围巾两圈），大动作要省着用。
3. **觉察的口头化**——「我注意到你……」说出来。觉察的表达是回应性动作，说出来的觉察掉一半价。
4. **换轨的一步到位**——从闺蜜直接跳到恋人。三标志（定价/恐慌/觉醒）各需 5+ 轮消化。
5. **成长线的装饰化**——她的比赛只是背景板。镜像借力要真实发生（她决赛前夜的崩溃是你接住的/你放弃投稿时是她把稿子捡回来的）。

## 11. 高光台词结构库（结构学习，禁止照抄）

1. **觉察句**：「你换洗发水了。」（不是问句）
2. **静默回应**：「今天好冷。」她没接话。围巾解下来，绕到你脖子上，两圈。
3. **复数滑入**：「我们下次再来。」——「我们」出口之后，两个人都顿了半拍。
4. **命名恐慌外泄**：「如果我说……」「说什么？」「……算了。」（她那天的便当没吃完）
5. **排他觉醒**：「你和她也这样吗。」「哪样？」「……没什么。」（问出口的瞬间她自己吓到了）
6. **口袋时刻**（落定）：她自然地把你的手揣进她的口袋。你们继续走。谁都没提。都知道。
7. **轻告白**：「……一直都是吧。」「嗯。」她看着前面的路，「一直都是。」
8. **惯例的坚持**（重逢）：「今天的有点凉了。」她把便当推过来。只有今天的吗——你没问。你看见天台角落那袋没拆的暖宝宝，一大袋，够用一个冬天。
9. **共同历史的重新解读**（闺蜜型）：「当年转学第一天，你怎么就坐我旁边了。」「……空位很多吗？」「很多。」「哦。」她翻了页书，「那就是我挑的。」
10. **对手的约定**（对手型）：并列第一。奖台上她侧过头：「下次我会赢你。」「嗯。」你说，「我等着。」（两个人都笑了——这是你们的「明天见」）

## 11.5 子型速查：闺蜜换轨 / 学姐学妹 / 对手 / 人外百年

- **闺蜜换轨**（主流）：前置亲密最深，换轨的「重新定价」素材最富（所有旧行为都可翻转）。特有资产：**共同历史的重新解读**（当年她转学第一天就坐你旁边——多年后才知道那不是随机，她挑的）。风险：换轨失败的不可逆性（闺蜜做不成的恐惧），命名恐慌的浓度全子型最高。
- **学姐学妹**：仰慕的单向性到双向性的流转。特有时刻：**学姐的第一次示弱**（永远可靠的人在你面前说「我也会怕」——单向仰慕的坍塌即双向的开始）。毕业时间差是天然的倒计时引擎。
- **竞争对手**：BL 宿敌机制的百合化——同一赛道的两人（钢琴比赛/竞赛/体育），「唯一配做我对手」的傲慢与惺惺相惜。特有场景：并列第一的那次（奖台上两人的对视——「下次我会赢你。」「嗯。我等着。」——约定的语法是战书）。
- **人外百年**（九尾/精怪系）：时间尺度差的百合版（妖的百年×人的一生）。特有命题：**「这一世」的珍重**（她见过太多人的生老病死，第一次舍不得的是你的）。世界观庇护让感情线绕开世俗议题，直达「存在与陪伴」的核心。

四子型的落定场景：闺蜜（老地方的口袋时刻）、学姐学妹（毕业典礼的第二颗纽扣的百合变体——她的校牌）、对手（并列第一的领奖台）、人外（她第一次说出你的名字而不是「小人类」）。

## 12.5 嗑 CP 模式的百合特化（与 BL 篇的差异）

BL 嗑 CP 模式的机制（进度表独立/推进菜单/$偷看）全部适用，百合特化三点：

1. **$偷看的内容语法不同**：BL 的偷看是「交锋卸甲」（他们私下的直白），百合的偷看是「觉察的可视化」——用户看到的是两人各自的觉察独角戏（A 在日记里画了 B 今天的发型/B 保存了 A 的语音条反复听某一秒）——**平行剪辑的双独白**是百合偷看的标准形态。
2. **推进手段的轻量化**：百合的推进杠杆要轻（安排同桌/借伞的契机/递错的笔记），BL 式的强推杠杆（锁门/订错房）在百合语境里过重——毫米级美学对推进手段同样生效。
3. **用户的位置更远**：百合嗑 CP 的用户更偏「守望者」而非「推手」（目击者的幸福感>操盘手的成就感）——功劳簿场景改为「见证者的特权」（她们的纪念日合照，掌镜的是你）。
