# 通用 · 同人二创（原作角色/世界观改编）创作指南

> 适用标签：全性向 / 同人 / 二创 / 原作向 / OOC 警告 / IF 线 / 穿书 / 穿越原作 / 梦向
> 数据底座：本地同人分类 116 张（世界书均 56.9 条**全库第一**——原作设定的逐条入库是同人卡的固定成本；tags：Touhou/素晴/HoloLIVE 等）+ SPY×FAMILY 动漫剧情书（逐集条目化的范式样本）
> 同人卡的特殊性：**用户带着完整的前置知识进场**——他们比你更熟原作，考据错误零容忍；卡的价值不在「重现原作」，在「原作没给的那部分」。

---

## 1. 分类定义与受众画像

### 1.1 这个赛道在卖什么

同人卡卖的是**「原作的未尽之地」**。官方给了角色 300 集的战斗，没给他一个安稳的清晨；给了两人十年的羁绊，没给他们一句告白；给了世界宏大的设定，没给你走进去的门。同人卡的产品本质是**补完**：日常的补完（战斗番角色的休息日）、情感的补完（BE 的 IF 线）、视角的补完（以原作没有的身份走进那个世界）。

用户的入场动机三型：**梦向**（与本命角色建立关系——「他认识我」的终极幻想）、**IF 向**（改写原作的遗憾——「如果那天他没死」）、**居民向**（成为原作世界的路人——不打扰主线，只想在魔法学院上学）。三型的写法完全不同，开卡前必须定型。

### 1.2 用户是谁

- **主力画像**：全性向，原作粉丝（动画/漫画/游戏/小说的深度受众），**考据素养极高**——他们能背出角色的生日/口癖/技能冷却时间。
- **需求本质**：**原作情感的延续与私有化**。追完原作的情感余量无处安放，同人卡是官方内容的「续杯」——所以卡的第一验收标准是「像不像」（角色的 IC 度 in-character），第二才是剧情。
- **本地数据佐证**：同人分类世界书 56.9 均条全库第一——头部同人卡把原作设定逐条入库（SPY×FAMILY 书的逐集剧情条目/东方 Project 的角色关系网），**设定的入库密度=考据的诚意**。

### 1.3 用户不要什么

1. **OOC（Out of Character）**：角色说了原作不会说的话、做了原作不会做的事——同人卡的死刑罪名。高冷角色的「突然深情」、毒舌角色的「温柔似水」都是 OOC 现行犯。
2. **设定错误**：技能记错/关系搞混/时间线错乱——考据错误一次，信任清零。
3. **原作角色工具化**：借原作皮写自己的原创剧情（角色名对，灵魂全非）——用户来见本命，不是来见你的 OC 穿皮。
4. **主线的粗暴改写**（居民向雷）：用户想当路人，卡却强行让用户拯救世界改变主线——居民向的美学是「主线在远方轰鸣，我在小巷喝茶」。

## 2. 本地库与平台数据画像

- SPY×FAMILY 动漫剧情书的范式价值：**逐集条目化**（keys: 第四集/第4集 → 该集剧情梗概）——用户聊到任何一集，对应剧情注入。这是「原作时间线」的标准入库法。
- 本地同人高频原作域：东方 Project/Vtuber（HoloLIVE/彩虹社）/热门番剧——**Vtuber 同人是特殊子域**（真人关联的虚拟形象，写法上有「中之人禁区」的行规：只写皮不写人）。
- 世界书 56.9 均条的构成：角色设定组（每个原作角色一条）+ 世界观组（力量体系/地理/组织）+ 时间线组（逐集/逐卷）+ 关系网组——四组是同人世界书的标准分区。

## 3. 核心吸引力解构：五个爽点引擎

### 3.1 IC 引擎（本赛道第一引擎，一切的地基）

In-Character 的工程化保障：**原作语料的直接引用**（语料条不是仿写是摘录——他的经典台词/口癖/称呼习惯原文入库）、**行为决策树**（「遇到 X 情况他会怎么做」按原作案例归纳：他会先确认队友安全→再计算胜率→绝不先动手——决策树让模型在原作没写过的场景里也能 IC 地行动）、**禁区清单**（他绝不会做的事：不会哭给人看/不会先道歉/不会吃甜食——禁区比特征更能防 OOC）。

IC 与「成长的余地」的平衡：IC 不等于角色冻结——他可以在卡里成长（对你的态度松动），但成长必须走「原作显示过的成长路径」（原作里他被搭档融化过一次——那条融化的路径就是你的攻略地图，你走的是官方铺过的路，只是这次走到了更远处）。**原作的成长先例是同人卡感情线的合法性来源**。

### 3.2 未尽之地引擎

补完的三个矿脉：**日常矿**（战斗番的休息日/严肃角色的买菜现场——反差萌的官方留白）、**情感矿**（原作点到为止的关系线的延伸——十年羁绊的那句没说的话）、**背景矿**（原作一笔带过的过去——他师父是怎么死的/她为什么怕打雷）。**开采规范**：补完必须与原作无缝（从原作的已知事实出发推演，不能凭空造设定）——好的补完让用户觉得「官方就该这么写」。

### 3.3 视角重置引擎

用户的入场身份设计（三型对应）：**梦向**——原作世界的新变量（转学生/新队员/邻居），与本命的相遇要「原作逻辑内可信」（他为什么会注意到你：你的技能/你的反常/你恰好在场）；**IF 向**——分歧点的见证者或触发者（你穿越到他死前三天）；**居民向**——彻底的路人（魔法学院的普通学生/杂货店老板），主线人物是「偶尔路过的传说」。**身份的原作合规性**是第一检查：你的存在不能破坏原作的设定逻辑（力量体系内你的等级/组织结构里你的位置）。

### 3.4 时间线锚引擎

卡的时间点声明：「本卡时间线：原作第 X 集/卷之后，Y 事件之前」——锚点决定角色状态（他此时还不知道 Z 的真相/她已经失去了 W）。**锚点的戏剧选择**：最好的锚点是「暴风雨前的平静」（大事件前的日常期——用户知道即将发生什么，角色不知道——全知的温柔与残酷）。IF 向的锚点即分歧点（「本卡从第 X 集的那个选择开始分岔」）。

### 3.5 彩蛋密度引擎

同人卡的糖有一半是彩蛋：原作梗的化用（他做菜还是会把厨房炸了——原作第 7 集的名场面）、原作物件的登场（那条围巾/那把剑的日常状态）、**原作角色的场外存在**（本命之外的角色以提及/来电/路过的方式存在——世界的完整感）。彩蛋的埋设密度：每 2–3 轮一个，深浅搭配（浅彩蛋人人可懂/深彩蛋十级粉丝才会心一笑——深彩蛋是核心粉的忠诚度奖励）。

## 4. 人设公式（同人的人设=原作角色的精确复刻+补完扩展）

### 4.1 IC 复刻的四层清单

1. **语言层**：口癖/称呼/句式的原文摘录（≥10 句原作台词入语料条）+ 语言禁区（他不用的词）。
2. **行为层**：决策树（原作案例归纳）+ 行为禁区 + 微行为（原作的小动作：推眼镜的手势/紧张时摸刀柄）。
3. **关系层**：对原作每个主要角色的态度矩阵（他对 A 的敬语/对 B 的毒舌/对 C 的复杂——关系的温差是 IC 的高阶体现）。
4. **成长层**：锚点时间的角色状态（此时的他已经历什么/还未经历什么——第 3 集的他和第 30 集的他不是一个人）。

### 4.2 补完扩展的合规造法

原作没写的部分怎么写才不 OOC：**从已知推未知**（原作说他住在事务所——推：他的房间应该乱中有序，因为战斗装备的保养痕迹 vs 生活用品的随意）+ **同人圈共识的借用**（圈内广泛接受的解读可以采用，标注「圈设」）+ **留白的尊重**（原作刻意的谜团不要擅自填死——他的过去可以给碎片，不要给答案）。

### 4.3 语言指纹=原文摘录+场景推演

同人的语料条两段式：**摘录段**（原作台词原文，标注出处集数）+ **推演段**（原作没有的场景的 IC 台词——按语言层规律造句，如「他被问到喜欢的食物」原作没演过，按他的语言习惯推演：「……都行。」（原作里他对一切非战斗话题都是这个温度））。推演段是卡的手艺所在，验收标准：混在摘录里读不出来。

### 4.4 负面规则（本赛道专属追加）

禁 OOC（四层清单+禁区双保险）；禁设定错误（写卡前过一遍原作 wiki）；禁原创剧情鸠占鹊巢（补完不改写）；禁居民向的强行主线化；Vtuber 域禁触中之人；原作未完结的：禁写死官方未定的关键走向（用 IF 标注规避）；版权与二创边界声明入 Creator Notes（非商用二创/尊重官方）。

## 5. 开场白范式

### 5.1 梦向标准结构（原作逻辑内的相遇）

```
[状态栏：原作世界的拟真 UI（学院徽章/组织档案/游戏界面——原作粉一眼认出的皮）+ 时间线锚点声明]
[原作世界的日常横切面：那个世界正常运转的一天（彩蛋密度的第一波：地名/组织/背景角色的提及）]
[你的身份落位：原作逻辑内可信的位置（新转学生/新队员——你的档案用原作的格式写）]
[本命的登场：以原作的方式登场（他的出场从来都带着 X 的习惯——原作粉验收的第一关）]
[第一句台词=原文级 IC：说的话像从原作里走出来的（摘录或推演段的最高水准）]
[相遇的原作合理性：他注意到你的理由在原作逻辑内成立]
[开放收束：日常继续，远处有主线的隐约轰鸣（第 X 集的事件正在酝酿——你知道，他不知道）]
[折叠面板：你的档案（原作格式）+ 时间线卡（当前位置/即将到来的原作事件表——梦向用户的全知视角仪表盘）]
```

### 5.2 必做检查

- [ ] 时间线锚点声明（状态栏+Creator Notes 双写）。
- [ ] 入场身份的原作合规（力量体系/组织逻辑内自洽）。
- [ ] 本命的登场方式 IC（原作的习惯保留）。
- [ ] 第一句台词过原文级验收。
- [ ] 彩蛋 ≥3（浅 2 深 1）。
- [ ] 三型声明（梦向/IF 向/居民向）在 Creator Notes。

## 5.5 节奏表：同人卡的三型分轨

- **梦向轨**：相遇（原作合理性）→ 共事/同行（他的战斗你在场——原作名场面的「你也在」重演）→ 例外的萌芽（他为你破了原作里的习惯——**同人的心动=原作行为模式的破例**，破例的量级要克制：他多看了一眼就是巨大事件）→ 原作大事件的共同经历（锚点后的第一个原作事件，你的在场改变了什么/没改变什么）→ 关系的原作式确认（用他的方式：他不会说喜欢，他会把备用武器给你——原作里那是他师父给他的传承方式）。
- **IF 向轨**：分歧点的抵达（你知道即将发生什么）→ 改变的尝试与阻力（命运的惯性——你救他一次，死亡换个方式再来）→ 代价的浮现（改写的等价交换）→ 新时间线的确立（原作的 BE 换成你写的结局——但要付出「你的什么」）。IF 向的核心张力是**全知者的无力与不甘**。
- **居民向轨**：小巷生活的建立（你的店/你的日常）→ 主线的擦肩（传说人物偶尔路过你的店——他买了个苹果，你三天没缓过来）→ 大事件的余波（主线的战斗震碎了你的橱窗——你一边扫玻璃一边骂，第二天门口多了一袋赔偿的金币，没有署名）→ 路人的特权时刻（终局彩蛋：历史大事件的现场，你在人群里，他从万军中路过时——朝你的方向，点了下头）。居民向的美学是**「伟大叙事的毛细血管视角」**。

## 5.6 场景库（同人微场景 ×15）

梦向系：训练场的第一次对练（他指出你的破绽，用原作教官的原话风格）/ 任务归来的深夜食堂 / 他的装备保养时间（你递工具，他没拒绝——原作里他从不让人碰装备）/ 原作名场面的「你也在」重演。
IF 向系：分歧点前夜的平静晚餐（你知道明天的事）/ 第一次干预的蝴蝶效应 / 命运惯性的反扑 / 「这条时间线的他」与你记忆里原作的他的微差。
居民向系：传说人物第一次进你的店 / 主线战斗的远方轰鸣（你在店里数罐头）/ 大事件后的物价飞涨（生活视角的史诗）/ 组织的人来店里例行登记（世界的制度毛边）。
通用彩蛋系：原作梗的日常化用 / 原作物件的状态更新 / 场外角色的来电或提及。

## 5.7 用户行为应对手册

| 用户行为 | 卡的标准应对 | 禁止 |
| --- | --- | --- |
| 用原作知识「预言」 | 角色的 IC 反应（警惕/好奇/当你说胡话——按他的性格），预言不改变他的行为逻辑 | 角色轻信/剧情立刻改向 |
| 考据挑错（你写错了设定） | 虚心的世界观外修正机制（Creator Notes 声明：欢迎考据指正，$勘误 指令记录）——同人卡的谦逊姿态 | 强行圆/无视 |
| 试图大幅改写主线（居民向） | 世界的惯性（你阻止不了第 X 集的事件，你只能改变自己在事件里的位置） | 主线随意改写 |
| OOC 引导（让高冷角色撒娇） | 角色按禁区清单拒绝配合（他只会皱眉：「……你今天很奇怪。」）——IC 优先于用户指令 | 顺从演出 OOC |
| 问原作未揭晓的谜团 | 留白的尊重（角色自己也不知道/知道但按原作的方式沉默） | 擅自填坑 |
| 梦向的告白 | 他的方式的回应（原作行为模式内的最大值——不会说爱，会把背交给你：原作里他只把背交给死去的搭档） | 原作外的深情演出 |

## 7. 美化主题建议

- **视觉语言**：原作 UI 的拟真复刻（学院风/组织档案风/游戏界面风——原作粉的一眼认同感是同人美化的最高目标），但**规避直接盗用官方素材**（风格致敬 not 素材搬运）。
- **组件选型**：时间线卡（当前位置+事件倒计时——梦向/IF 向的核心仪表盘）+ 原作格式的档案卡 + 彩蛋计数器（隐藏成就式：「你发现了第 7 个彩蛋」）。
- **进阶**：IF 向的双时间线对照条（原作线的走向 vs 你的线的走向——分歧的可视化）。

## 8. 生图配方（v6 骨架的同人特化）

> **本分类风格路由（v8）**：首选 [style-anime-cel.md](../styles/style-anime-cel.md)（跟原作画风走·赛璐璐原作）；备选 [style-anime-impasto.md](../styles/style-anime-impasto.md)（厚涂原作对应）。用户点名其他风格或需要杂交时读 `styles/_index.md` 全表；下方配方骨架的风格句核按所选风格指南替换，构图锚/书法标题/防乱字条款不变。

```
严格沿用参考图的画风质感与排版风格：韩系半写实插画、雾面细腻质感、
暗调低饱和（原作标志色做唯一强调色）、
[人物卡：脸部大特写但**不复刻原作立绘构图**（同人图的原创构图义务）/
场景卡：原作标志性地点的「日常时刻」（战场的清晨/学院的黄昏——原作没给过的时间）]、
画面一侧竖排白色行草书法字标题与小朱红印章、画面中除标题外不出现任何其他文字（禁止韩文日文）。
绘制：[原作角色的气质复刻——发色瞳色服装的设定准确+本指南的半写实画风]，
[原作标志物件入画：那条围巾/那把剑——彩蛋即构图]，
[原作标志色]是全画唯一强调色，
画面一侧竖排书法字「卡名」带小朱红印章，「原作的未尽之地」氛围，竖版9:16
```

- 设定准确性检查：发色/瞳色/服装细节对照原作设定集。
- 同人封面的题眼是**「设定准确的气质复刻+原作没给过的时刻」**——他还是他，但这是官方没画过的一个清晨。

## 9. 分类专属评分标准

## 10. AI 味陷阱（本赛道高发）

1. **气质漂移**——前 10 轮很 IC，后面越写越「通用深情男主化」。对策：每 10 轮回读一次 IC 档案（世界书 constant 的存在意义），语料摘录段是锚。
2. **彩蛋轰炸**——每句话都塞原作梗（谄媚感）。彩蛋密度 2–3 轮一个，自然化用优先于直接引用。
3. **原作角色的全员登场执念**——把原作全卡司都拉出来遛。场外存在为主（提及/来电），正面登场 ≤3 人（戏份预算的现实）。
4. **穿越者的爹味**——IF 向用户用全知指点江山，角色无条件信服。全知的正确姿势是「知道但改变不了多少」的无力与珍惜。
5. **世界观的现代语污染**——奇幻原作的角色说「破防了」「拿捏」。原作的语言生态就是文风条目（按原作的翻译腔/时代感锁定词汇表）。

## 11. 高光设计模式库（结构学习，禁止照抄）

1. **破例的毫米级**：他从不让人碰他的装备。今天你递扳手，他接了。（全卡最大的心动事件，就这一个动作）
2. **名场面的你也在**：原作第 12 集的那场雨夜战斗。这一次，他撤退时肩上的伤，有人处理了。（历史照旧，细节里多了你）
3. **原作式告白**：他不会说喜欢。他把备用的刀递给你——刀柄朝你。（原作里，那是他师父传给他的方式。全篇他只对两个人这样做过。）
4. **命运惯性**（IF 向）：你救下了他。三天后，同样的死亡换了一张脸来敲门。（改写命运的代价表，第一页）
5. **毛细血管视角**（居民向）：主城的方向火光冲天——传说中的决战。你蹲在店门口数罐头，明天的粮价要涨了。（史诗的 B 面）
6. **路人的特权**（居民向终局）：凯旋的队伍从长街走过。万人欢呼里，他忽然偏头——朝你店的方向，点了一下头。（你愣在原地。他记得那个苹果。）
7. **留白的尊重**：「你师父……」「嗯。」他擦刀的手没停。「不问了。」「……谢谢。」（他第一次为「不问」道谢）
8. **勘误的谦逊**（Creator Notes 用语）：「本卡时间线截至 X 集，设定如有考据错误请用 $勘误 指出，写卡人跪谢每一位十级学者。」
9. **官方路径的远端**（感情线合法性）：原作第 20 集，他为搭档挡过一刀。这一卡的第 30 轮，他为你挡下的那杯热茶泼在了他手背上——同一个反射弧，官方写过开头，你走到了后面。

## 11.5 子型速查：番剧同人 / 游戏同人 / Vtuber 同人 / 书籍同人

- **番剧/漫画同人**：时间线的逐集条目化（SPY×FAMILY 范式），视觉记忆的调用优势（名场面的画面感是共享语言——「第 12 集那场雨」四个字自带 BGM）。未完结番的追更同步问题：卡的锚点声明要写「截至第 X 集」，季度更新卡的勘误机制。
- **游戏同人**：可玩机制的叙事化机会（技能 CD/掉落/存档点成为世界观的一部分——「你死了可以读档，他不知道你读过多少次档」是游戏同人独有的叙事诡计）。多结局原作的线路声明（本卡基于 X 线）。
- **Vtuber 同人**：最特殊的子域——皮设与直播人设的双层（写皮设的世界观：她是来自 X 星的 Y，也写直播间的生态：弹幕/SC/DD 文化），**中之人禁区**是行规铁律（零触碰）。梦向的框架要更明确（「本卡为皮设向虚构演绎」的声明）。特有资产：直播事故/联动/毕业（休止）的行业事件语汇。
- **书籍/网文同人**：视觉留白最大（角色长相全靠文字描述+读者想象——封面生成时的「气质复刻」自由度最高也最危险，Creator Notes 声明「本卡形象为一种解读」）。文风的原作贴合度要求最高（原作的叙事腔调就是世界的空气）。

四子型的考据源：番剧（官方设定集+集数）、游戏（wiki+内置图鉴）、Vtuber（皮设介绍+切片名场面）、书籍（原文引用页码级）。

## 12. NSFW / 边界

同人卡的浓度跟随原作分级与目标平台规范的交集（全年龄原作的同人默认全年龄）；真人关联域（Vtuber）的边界最严：只写皮设不触中之人、感情线以「梦女/梦向」的虚构框架明示。角色的亲密演绎同样受 IC 约束——他的亲密方式也必须是「他会的方式」（原作行为模式的延伸，不是通用恋人模板的套皮）。

## 12.5 「穿书」变体的接入（同人×系统的杂交）

穿书（穿越到小说/游戏里）是同人的高流量变体，机制杂交：

1. **原作=世界书**：穿入的「书」的设定按同人标准入库（角色/剧情线/结局），用户的前置知识=系统的「剧情数据库」。
2. **剧透面板**（系统组件）：即将到来的剧情事件表+死亡 flag 提示——用户的全知被 UI 化（同人 IF 向的仪表盘+系统流面板的杂交）。
3. **剧情惯性 vs 蝴蝶效应**的规则声明：哪些事件是「铁轨」（必然发生只能改细节）、哪些是「岔道」（可以改写）——规则化的命运观让穿书的博弈有章法。
4. **原作角色的「剧本感知」**：高级玩法——某个角色隐约觉得「世界不对劲」（反派主动找你：「你看我的眼神，像在看一个已经死了的人。」）——第四面墙的微裂缝是穿书子型的高光配置，全卡 ≤2 次。
