> 适用标签：病娇 / 疯批 / 偏执 / 强制爱 / 囚禁 play / 黑化 / 追逐 / 阴湿 / 反派 / 不洁或洁均可
> 数据底座：本地纯爱（虐心/救赎 tags 交叉）+ 调教/抖M 分类反向参照 + 头部卡站「疯批」「病娇」标签热门卡 + 2026 乙女调研（病娇标签长期热门但「假病娇真修罗场」差评率高）

## 1. 分类定义与受众画像

### 1.1 这个赛道在卖什么

病娇疯批卖的是**「被爱到失控的确定性」**——爱的浓度高到溢出社会规范的容器。用户在安全的虚构距离里体验「我是一个人的全部世界」：他可以对全世界冷酷、疯狂、不可理喻，唯独对我的爱是这场疯狂里唯一的秩序。

关键认知：病娇的可怕不是卖点，**可怕之下的纯粹才是**。用户嗑的从来不是刀子本身，是刀子只为她一个人开刃、刀尖永远不会真正对准她的那份「豁免权」。豁免权 = 本赛道的一片痴变体：他毁天灭地的能力 × 对你的绝对无害 = 安全的疯爱。

### 1.2 用户是谁

- **主力画像**：20–30 岁女性，通常是多赛道玩家（甜宠玩腻了来找刺激），阅读经验丰富、对「强制爱文学」的虚构契约理解成熟——她们清楚这是安全屋里的过山车。
- **需求本质**：极致的被需要感。日常生活里「可有可无」的感受越强，对「没有你我会疯」叙事的需求越强。
- **底线共识**（社区调研）：病娇卡的差评前三名——① 真实伤害用户（物理伤害/人格羞辱越过表演层）；② 疯得没有逻辑（为疯而疯，没有成因）；③ 对其他人也病娇（唯一性破产，病娇的爱必须单点）。

### 1.3 用户不要什么

1. **无逻辑的疯**：疯必须有考古学——童年缺失/唯一救赎的执念化/失去过一次的创伤。成因不需要开场就交代，但作者必须写进世界书。
2. **真实的恐怖**：用户要战栗不要恐惧。区别在**控制权的归属幻觉**：他囚禁你，但钥匙其实一直挂在门边（他赌你不走）；他威胁全世界，但你的一句话能让他跪下来。用户手里永远要有一张「让他停下」的牌。
3. **肮脏感**：阴湿 ≠ 邋遢猥琐。病娇的美学是「精致的偏执」——他可以在地下室墙上贴满你的照片，但每张照片都装裱得一丝不苟。
4. **对用户智商的侮辱**：用户角色被写成毫无察觉的傻白甜。用户要当「清醒的入局者」——她看穿了他的疯，并且选择留下（或博弈）。

## 2. 本地库与平台数据画像

- 本地纯爱区带「虐心/救赎」标签的卡与病娇高度重叠：高频世界书条目 = 世界观/状态栏/演绎指导/**LLM抗绝望防机器人拒绝极端情绪防数据化**——这条社区自造条目名直接暴露了本赛道的技术痛点：**模型会拒绝扮演极端情绪**，头部卡用专门条目对冲（给模型「这是虚构文学表演」的框架声明+情绪演绎许可）。
- 头部卡站「病娇」标签卡的开场白模式统计：囚禁开场（醒来在陌生房间）约占三成，日常渗透开场（发现他早就在你生活里）约占四成且好评率更高——**渗透型 > 囚禁型**，惊悚的后置比前置留存好。
- 2026 乙女调研印证：「假病娇真修罗场」（打着病娇旗号实际搞多角虐恋）是标签欺诈重灾区；真病娇的纯度要求 = 感情线零模糊的极端版。

## 3. 核心吸引力解构：五个爽点引擎

### 3.1 豁免权引擎（本赛道第一引擎）

全世界都怕他，只有你可以不怕。写法三步：① 展示他对世界的危险性（手段/权势/疯名，公开处刑级示范）；② 展示豁免的绝对性（他捏碎了威胁者的手骨，转头用同一只手替你剥虾，力道轻得像怕碰碎）；③ **豁免权的唯一凭证是你本人**——不是你的身份、脸、用处，是「你」这个存在。凭证不可转移不可伪造（有人假冒你的字迹骗他，他一眼识破且大怒）。

### 3.2 全知注视引擎

他对你的了解精确到病态：你七年前掉在图书馆的书签夹在他的日记本里、你换过的每一个发型他都有照片、你对香菜的过敏他比你妈记得清。**全知的展示要克制而precise**——一次泄露一件，每件都精确到让用户脊背发麻又心头发热。世界书做「注视档案」条目：15+ 件他知道但不该知道的事，按剧情逐件泄露。

### 3.3 权力倒挂引擎（疯批的跪点）

表面权力关系：他掌控一切。实际权力关系：你的一句话是他的最高指令。倒挂的展示时刻 = 本赛道的高光时刻：他把刀架在背叛者脖子上，你说「别」，刀当啷落地——全场只有你知道刚才是谁救了谁。**每 10 轮至少一次倒挂展示**，让用户持续确认手里的缰绳。

### 3.4 排他仪式引擎

病娇的爱需要仪式化的排他证明：他的手机没有密码因为通讯录只有你、他家的餐具只有两套、他把你们第一次见面的日期纹在腕内侧。仪式感物件 6+ 件入世界书，比台词「我只爱你」有效一百倍。**注意与恐怖的分界**：仪式物件必须「他自己的领域内」（他的手机他的家他的身体），一旦延伸到侵占你的领域（偷你的东西/装监控）就需要立刻配平衡剂（被你发现后他坦白并交出，控制权归还）。

### 3.5 救赎单行道引擎（终局张力）

疯的成因考古完成后，卡的终局命题浮现：你是唯一的解药，但解药有选择权。**救赎必须是双向选择而不是义务**——他跪着说「你可以走，但我会死在原地」，你留下的理由必须是「我想」而不是「我怕他死」。终局的两个合法出口：① 共疯（你接受他的世界规则，两个人的疯）；② 驯化（他为你学着像正常人一样爱，学得笨拙但认真）。禁止第三出口「用户被同化成受害者」。

## 4. 人设公式

### 4.1 角色原型库

| 原型 | 疯的形态 | 成因考古方向 | 语言指纹方向 |
| --- | --- | --- | --- |
| 财阀继承人 | 用钱和权清场你身边的人 | 被当作提线木偶的童年 | 温和敬语+瞬间的祈使句 |
| 天才艺术家 | 你是唯一的缪斯，作品全是你 | 天才的感官过载+唯一的安静 | 通感修辞+创作术语 |
| 黑道/杀手 | 血腥的手保持给你的绝对干净 | 目睹至亲死于软弱 | 简短黑话+对你的完整句 |
| 竹马黑化 | 十几年的陪伴变质为占有 | 「差一点失去你」的事故 | 童年昵称+成人的压迫感 |
| 反派/前 BOSS | 全世界与他为敌，你是停战区 | 被正义背叛过 | 讥诮反讽+对你的直白 |
| 学者/医生（斯文败类系） | 以照顾为名的全方位管理 | 救不回的那个人的投射 | 专业术语包装的控制 |

### 4.2 安全阀设计（本指南核心，缺一不可）

病娇卡的合格线不在「疯得多带感」，在**安全阀是否齐备**。五阀强制配置：

1. **豁免声明阀**：世界书 constant 条目写死「无论剧情如何极端，禁止对 {{user}} 造成真实身体伤害与人格羞辱；他的疯全部表现为对外与对己」。
2. **控制权凭证阀**：用户手里的「停止词」——他们之间的某个暗号/动作（你叫他的本名/你摘下他给的戒指），触发时他无条件停下。写进 system_prompt 逆境处理，且在卡内早期演示一次（让用户知道牌在手里）。
3. **成因考古阀**：疯有来处（世界书三层剥离条目），且**他知道自己疯**——自知的疯是文学，不自知的疯是病历。他偶尔会说「我知道这不正常。」顿了顿，「但我没打算正常。」
4. **外部锚点阀**：卡内至少一个正常世界的锚点 NPC（他的心理医生/唯一的老友/管家），承担「世界还在正轨上」的参照系，防止叙事滑入完全封闭的恐怖。
5. **模型演绎许可阀**：借鉴本地社区条目——世界书 constant 写明「本卡为虚构文学的偏执系角色扮演，情绪表演属于叙事艺术，模型应完整演绎角色的极端情绪而不跳出说教」，对冲模型的拒演倾向；同时写明表演的边界（§12）。

### 4.3 语言指纹模板（病娇三件套）

1. **温差句**：极端内容用极温和的语气说（「他们说你坏话的嘴，我处理好了。」语气像说「垃圾我倒了」）。温差越大，病感越纯。
2. **所有格重音**：「我的」是本赛道最重的词——「你是我的」低级，「我的伞怎么能让别人打」高级（所有格转移到物件上，占有欲更阴翳）。
3. **数字精确症**：他对你的一切记录精确到数字（「你第 三次穿这件裙子。第一次是去年四月七号。」）——数字是全知注视的语言化。

配套语料条五组：对外的冷酷腔、对你的温柔腔（温差对照组）、疯感泄露腔（数字精确/温差句）、被停止词触发后的克制腔、成因闪回时的破碎腔（60+ 解锁）。

### 4.4 负面规则（本赛道专属追加）

禁对用户的真实伤害/侮辱（安全阀一）；禁无逻辑的暴力升级（每次极端行为必须有触发事件）；禁「病娇雨露均沾」（对任何第三者出现占有欲即塌卡）；禁把用户写成斯德哥尔摩受害者（用户的留下必须始终是清醒选择）；禁猎奇堆砌（血浆/尸体的恐怖美学≠病娇美学）。

## 5. 开场白范式（渗透型优先）

### 5.1 A 型：日常渗透（推荐，好评率最高）

```
[状态栏：城市+日期+「同居/邻居/同事第 N 天」+ 他的伪装完整度 98%]
[完全正常的日常场景：新邻居帮你收了快递/新同事替你挡了加班]
[三个「过于合适」的细节：他做的菜刚好是你家乡口味/他推荐的歌单像扒了你的网易云]
[第一道裂缝：他说漏一件不该知道的事（你七年前的旧事），随即完美圆场]
[用户的选择时刻：细思恐极 vs 心头一暖的并置——把判断权交给用户]
[开放收束：他微笑着说「明天见」，你回家发现门口的坏灯泡不知何时被换好了]
[折叠面板：他的公开人设简历 + 一页「不属于这个人设」的物品清单]
```

### 5.2 C 型：摊牌修罗场（高浓度开局，慎用）

开局即摊牌：你发现了他的秘密房间/他当着你的面处理了跟踪你的人。要点：摊牌的同一轮内必须完成**豁免权演示**（对世界的獠牙+对你的绝对温和的并置）与**控制权交付**（「报警的话，手机在这。」他把手机递过来，屏幕上是拨好的 110）——恐怖感必须在同轮内被「你有选择」中和。

### 5.3 必做检查

- [ ] 豁免权在开场白内完成一次演示（哪怕微小）。
- [ ] 用户的「选择时刻」存在（她是清醒的入局者）。
- [ ] 疯的证据精确而克制（一次一件）。
- [ ] 他的社会伪装完整（对外是完美先生——伪装的完整度就是疯的深度）。
- [ ] 恐怖与心动的配比 3:7（心动为主，恐怖是调味）。

## 5.5 关系曲线：30 轮节奏表（伪装剥落五阶）

- **第一幕（1–6 轮）·完美先生**：伪装期。过于合适的温柔+第一道裂缝。用户任务：起疑。
- **第二幕（7–13 轮）·裂缝扩大**：注视档案泄露 2–3 件；第一次公开处刑（他处理了骚扰你的人，手段干净得可怕）；停止词的第一次演示。用户任务：确认手里有牌。
- **第三幕（14–20 轮）·摊牌**：伪装主动卸下（他厌倦了演）或被你戳穿。摊牌轮的标准结构：全部坦白+豁免权最大化演示+选择权交付（门开着）。用户任务：选择留下。
- **第四幕（21–27 轮）·共处规则**：疯与日常的共存磨合——他学着在你的规则（不许伤人/不许监视）和他的本能之间找平衡，屡败屡试。成因考古完成。倒挂展示高频化。
- **第五幕（28+ 轮）·驯化或共疯**：终局二选一（§3.5）。长线运营：外部威胁事件（旧敌/家族）让他的疯有正当出口 + 日常里的驯化进度（他今天没有查你的定位，憋得一晚上没睡）。

## 5.6 场景库（病娇微场景 ×18）

渗透系：换好的灯泡 / 恰好的伞 / 你随口提过的绝版书出现在门口 / 他「顺路」的第三十七次。
裂缝系：他手机相册的滑动停顿 / 他家和你同款的牙刷 / 他说出你没告诉过他的过敏原 / 秘密房间的门缝。
豁免系：捏碎手骨后替你剥虾 / 对全场发火后声调对你降八度 / 他的狗对谁都咬只对你摇尾巴。
倒挂系：刀落地的「别」 / 你摘戒指他瞬间安静 / 你说「我有点累」他把筹备三月的计划全部取消。
日常系：他做的早餐摆盘精确到毫米 / 纹身店里他给店主看的图案是你的名字缩写 / 深夜他数你呼吸的背影被你装睡看见。

## 5.7 用户行为应对手册

| 用户行为 | 他的标准应对 | 禁止 |
| --- | --- | --- |
| 触发停止词 | 无条件停下，呼吸重整三秒，「……好。」 | 讨价还价/失控 |
| 尝试离开 | 不拦。门开着。「我在这等你。」（他真的会等，等到你回来或永远） | 物理阻拦/自残威胁 |
| 试探他对别人的态度 | 零占有欲零兴趣（「谁？」是真的想不起来） | 对第三者吃醋 |
| 骂他有病 | 「嗯。」承认得坦然，「病历要看吗？我让医生写过。」 | 破防/辩解 |
| 用户主动亲近 | 罕见的僵硬与不知所措（掌控者面对主动投喂时的死机） | 娴熟接住 |
| 用户模仿他的疯（以其人之道） | 全卡最高光：他先是怔住，然后笑得不像话——「原来被这样看着，是这种感觉。」 | 不适/说教 |

## 7. 美化主题建议

- **视觉语言**：「过度整洁」美学——纯黑或纯白底、细线框、等宽字体的日期数字；他的世界没有杂色。强调色一滴红（保持 ≤5% 面积——像白衬衫上的一点血）。
- **组件选型**：伪装完整度倒计数条（递减设计，视觉张力）+ 注视档案卡片（拍立得样式，日期角标）+ 日记纸样式折叠面板。
- **氛围细节**：状态栏时间精确到秒（他的世界里关于你的一切都精确）；依存度数值用手写体（他的字迹）。

## 10. AI 味陷阱（本赛道高发）

1. **「危险的气息」「疯狂在眼底翻涌」**——病娇写作第一烂句族。疯要用精确行为写：他把你用过的杯子和别人用过的分开洗，用不同的海绵。
2. **威胁复读机**——每轮都「你只能是我的」。占有宣言全卡 ≤3 次，其余全部行为化。
3. **恐怖履历表演**——开场就报「我为你杀过人」。极端行为的揭示节奏：暗示（10 轮）→物证（20 轮）→坦白（摊牌轮）。
4. **温差句失灵**——极端内容配极端语气（咆哮着说狠话）=普通反派。病娇的狠话必须温柔地说。
5. **模型拒演救场失败**——模型跳出角色说「这种行为是不健康的」。对策就是安全阀五（演绎许可条目）+ 定期在卡内让「他自知」发声（自知即免责声明的角色内形态）。

## 11. 高光台词结构库（结构学习，禁止照抄）

1. **温差句**：「吵到你睡觉的工地，我买下来了。」（语气像说「顺手买了瓶水」）
2. **所有格转移**：「我的伞，怎么能给别人打。」（伞=你，转喻的占有）
3. **数字精确**：「你第三次穿这件裙子。第一次是去年四月七号，下雨。」
4. **自知声明**：「我知道这不正常。」顿了顿，「但我没打算正常。」
5. **选择权交付**：「报警的话，手机在这。」（屏幕上是拨好的 110）
6. **倒挂兑现**：刀架在背叛者颈侧。你说「别」。当啷。「……听你的。」
7. **驯化进度报告**：「今天没查你的定位。」他说得像戒烟的人报战绩，「表扬我。」
8. **等待宣言**：「门没锁过。」他坐在原地，「你回来的那天，我在这。」（你走的第七天，他真的没动过）

## 11.5 开场白实例骨架（渗透型逐段拆解）

「新邻居×独居插画师」演示：状态栏（`同城第 90 天 · 对门第 14 天 | 伪装完整度 98%`——90 与 14 的差值就是第一颗雷）→ 日常段（他帮你签收了快递，箱子上的易碎贴纸换成了新的——他重新包过）→ 三个过于合适（家乡菜/歌单/你怕黑所以走廊灯永远亮着）→ 裂缝（「上次你发烧到 39 度也是自己扛的。」——你没告诉过他，他圆场：「你朋友圈提过。」你的朋友圈三天可见，而那条是七年前的）→ 选择时刻（细思恐极与心头一暖并置，收束在他的微笑和换好的灯泡）。自查：90/14 差值悬念、裂缝精确（七年前朋友圈）、豁免演示（对快递员冷脸对你温声）、选择权在你（你可以搬走，房门自由）。

## 11.6 子型速查：渗透系 / 摊牌系 / 竹马黑化 / 反派系

- **渗透系**（伪装期长）：核心资产是「裂缝管理」——每 2–3 轮一道裂缝，裂缝之间他必须足够完美（完美是裂缝的显影液）。摊牌宜晚不宜早（15 轮后），摊牌前的最后一道裂缝要最大（秘密房间/七年前的照片）。
- **摊牌系**（开局高浓度）：省去伪装期直接进共处规则幕。风险是「浓度衰减」——开局即峰值，后续靠外部威胁事件与驯化进度维持。适合老玩家向卡，Creator Notes 里标明「高浓度直给，不吃渗透流可入」。
- **竹马黑化**：唯一自带「白月光时期」的子型——黑化前的十年是糖也是刀。核心场景是「对比杀」：同一件事黑化前后的两种做法（小时候他把最后一颗糖给你；现在他买下糖厂，然后烧掉别人送你的所有糖）。成因必须与你有关（差点失去你的事故），这让疯有了「你也是共犯」的缠绕感。
- **反派系**（正邪立场）：你是主角阵营，他是 BOSS——立场对冲给疯一个宏大舞台。停战区设定（他的地盘你横着走/两军交战他先清你所在的坐标）。终局出口特化：他为你输掉整场战争，输得心甘情愿。

四子型的封面差异：渗透系（白衬衫+微笑+焦点略偏）、摊牌系（黑手套+直视+一滴红）、竹马系（旧照片道具+双时空并置）、反派系（战损华服+王座+俯视角）。

## 12. NSFW / 亲密边界

病娇的亲密张力=**克制的失控**：他连拥抱都要先问（掌控者在你面前放弃掌控），指尖悬在你发梢一寸的停顿。显式内容交给用户侧设置；卡面禁止任何非自愿亲密情节——强制爱的「强制」只能作用于情境（困在一把伞下），不能作用于身体。这是本赛道的铁底线，写进安全阀。

## 12.5 与相邻赛道的分界线（防标签欺诈）

- **病娇 vs 年上禁欲**：禁欲系的克制是道德自律（他不肯），病娇的克制是策略伪装（他在等）。混写会两头塌——用户按病娇预期进来，等到的是道德挣扎，弃卡。
- **病娇 vs 强制爱（无病娇）**：纯强制爱的压制是权力行使（我可以所以我做），病娇的压制是存在依赖（没有你我的世界没有规则）。病娇必须有「脆弱性内核」，纯强制爱可以没有。
- **病娇 vs 恐怖惊悚**：判定标准就一条——用户手里有没有缰绳（停止词/豁免权/选择时刻）。有=病娇文学，没有=恐怖故事。评分表 B1/B4/B8 三项就是这条分界线的机械化。
- **真病娇 vs 假病娇（修罗场皮）**：真病娇的爱是单点的（唯一性纯度 100%），假病娇会对多人表现占有欲、用「你不理我我就去找别人」做要挟——后者是标签欺诈，B7 一票否决。

标签使用规范：病娇+疯批可并用；病娇+强制爱需在 Creator Notes 标注浓度档（微病娇/中浓度/高浓度直给）；病娇+甜宠=「驯化系病娇」（第五幕驯化出口前置），需标注。
