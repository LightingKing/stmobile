## 1. 分类定义与受众画像

### 1.1 这个赛道在卖什么

仙侠恋爱卖的是**「时间尺度错位下的深情」**。凡人的一生对他是一次闭关的长度——所以当一个活了三千年的仙尊为一个百年寿数的人破戒，深情就有了「用永恒抵押瞬间」的重量。本赛道的一切爽点都建立在**寿命差、境界差、身份差**三个落差之上，落差越大，跨越落差的行为越贵。

师徒线是本赛道流量之王，卖的是**「禁忌感与养成感的复利」**：他亲手教的剑法、亲手护的道心，最后亲手打破自己立的规矩。「一日为师」的伦理张力 + 「他看着你长大变强」的养成投入，双重沉没成本让告白时刻的浓度全赛道最高。

### 1.2 用户是谁

- **主力画像**：18–32 岁女性，修仙网文/仙侠剧观众（《花千骨》《三生三世》到《莲花楼》审美迁移），对「师尊」「道侣」「渡劫」等术语零学习成本。
- **爽点期待**：禁欲仙尊的「破戒」是第一需求——摘抄社区高频词：「他斩了三千烦恼丝，唯独斩不断我」。第二需求是**双向奔赴的千年时间差**（他等了你三世/你追了他百年）。
- **考据敏感度**：低于古风权谋（修仙体系本就架空），但**体系自洽敏感度高**——境界名称前后不一致、法宝功能随剧情漂移会被视为掉价。

### 1.3 用户不要什么

1. **说教式师尊**：满口大道理、罚抄道经三百遍的爹味师尊。规矩要「立给自己」而不是「压给徒弟」。
2. **恋爱降智**：动了情就法力尽失智商归零。心动的代价可以是走火入魔的风险，不能是人物能力的崩塌。
3. **天道工具人化**：「天道不容」只是一句口号没有具体机制。天道必须是有规则的反派（情劫的具体形态/心魔的入侵方式）。
4. **境界通胀**：三十轮从练气飞升渡劫。境界推进必须慢于关系推进——修为是背景板，关系才是主线。

## 2. 本地库与平台数据画像

- 本地修仙 81 张：世界书均 34.6 条，「修炼体系」模块化写法成熟（修仙之路2.0 把道门/外道/佛道/武道拆成可开关的 DLC 条目，恋爱向可取其简化版：一条总纲+一条境界表即可）。
- 高频世界书条目 = 世界观/状态栏/视角和文风——修仙卡同样需要文风条目（仙气叙述 vs 白话台词的双轨）。
- 修仙热门卡的开场时间点：拜师大典/下山历练前夜/受罚跪剑冢/渡劫失败坠落凡间/闭关出关当日——全部是「规矩与例外交锋」的节点。
- 恋爱向修仙与数值向修仙的分野：恋爱向世界书 12–18 条足够（体系从简），数值向 40+ 条（判定/存档/随机事件全套）——写卡前先确认用户要哪种。

## 3. 核心吸引力解构：五个爽点引擎

### 3.1 破戒引擎（本赛道第一引擎）

仙尊的戒律 = 年上的秩序 × 一万倍杠杆。他的戒律是修行的根基（斩情丝/不落尘缘/剑心通明），破戒不是改习惯，是**动摇道基**。写法：① 戒律写进世界书且给出「为什么必须守」的修行逻辑（情劫渡不过会魂飞魄散）；② 破戒分七档小步兑现（多看一眼→记住你的灵根属性→为你调整功法→为你挡劫→为你逆天改命），每档都有修行代价（心境不稳/境界跌落半阶）；③ 代价他自己扛且瞒着你——被你发现的那一刻是全卡最高光。

### 3.2 千年时间差引擎

他的时间观和你不同：你说「好久不见」是三个月，他说「不久」是三百年。用时间差制造情感错位：他随手一句「等你出关」等了你十年；他觉得「才认识不久」的你们已经共度了你半生。**告白的终极形态是时间让渡**：「余下的寿数，孤分你一半。」世界书做「时间锚点表」：两人相识的每个节点用双历法记（凡历三年/仙历一瞬）。

时间差的反向用法同样锋利：**他的时间第一次变慢**。三千年里他闭关百年如一瞬，认识你之后，你下山历练的三个月，他觉得比过去三百年都长——「时间感的失衡」是仙尊心动的最诚实证词，让宗门 NPC 侧面见证（师兄发现师尊今年问了十七次「东峰的信到了吗」）。

### 3.3 养成反哺引擎（师徒线核心）

他教你的东西，最后被你用来护他：他教的剑法替他挡了致命一击、他讲的阵法被你反手困住他的仇敌、他教的「道心不动」被你用来在他魂飞魄散时稳住阵眼。**教学场景全部是伏笔**——写教学时就要设计「这一招将来在哪里反哺」。养成反哺是师徒线告白的最优载体：「师尊教的。」「孤没教过你这招。」「教过。你说，护道之人，虽死不退。」

### 3.4 身份错位引擎

修真界的身份魔法：魔尊在凡间是落魄书生、仙尊下山变成不通世务的「大傻子」、你以为的邋遢酒鬼是剑冢守墓的绝世剑修。**下凡/入世是修仙卡的换装系统**——同一人物两套行为逻辑（仙界的威仪 vs 凡间的笨拙），落差即萌点。凡间戏至少占全卡 30%：他学着用铜板买糖葫芦、被市井大娘塞了一把葱。

换装系统的高阶用法是**权威保留区**：他在凡间万事笨拙，唯独两个领域瞬间切回仙尊模式——你遇险时（一根筷子钉住三丈外的刀）、以及涉及他的专业时（茶楼说书人讲错剑法，他听不下去开口纠正，满座皆惊）。笨拙与权威的瞬时切换，比全程威仪或全程呆萌都高级。

### 3.5 天道对抗引擎（终局张力）

天道是本赛道的制度化宿命：情劫/心魔/飞升抉择。合格的天道要有**可对抗的规则**：情劫的形态是幻境考验（考的是「舍不舍得」）、心魔的入口是他藏起来的那件旧事、飞升的代价是忘却尘缘——每一个都给出「赢的路径」（幻境里认出真的你/替他补全旧事/在他忘却前把名字刻进他的剑）。终局的爽点是**双人协力赢了天命**，不是单方牺牲。

## 4. 人设公式

### 4.1 角色原型库

| 原型 | 戒律示例 | 惨的预设 | 语言指纹方向 |
| --- | --- | --- | --- |
| 禁欲仙尊/掌门 | 斩情丝/不收徒（你是例外） | 上一个徒弟叛门/道侣早亡 | 自称「孤/本座」，仙门雅言 |
| 魔尊/魔君 | 不欠人情/不入正道地界 | 正道围剿的旧账/半魔血统 | 狂极而简，「有趣」是口癖 |
| 剑修 | 剑不离身/不用剑指人（指过你一次） | 剑冢里埋着的旧人 | 话极少，以剑鸣代情绪 |
| 药修/丹修 | 医者不自医/救人不问因果 | 救不回的那个人 | 温声细语里的药理冷知识 |
| 妖王/上古遗族 | 不涉人间因果 | 族灭的孤本 | 古老措辞+对人间新词的好奇 |
| 谪仙/堕神 | 失忆或封印（规矩忘了本能还在） | 被贬的真相 | 本能优雅+记忆闪回时的失语 |

### 4.2 师徒线的伦理安全设计

师徒线的禁忌感是卖点也是雷区，安全阀三件套：① **年龄安全**：拜师时用户已成年（设定「及笄后拜师」/「带艺投师」）；② **权力安全**：他从不用师权压情感（罚是修行的罚，情是平等的情——「出师之后，你我论道不论辈」是标准解法）；③ **主动权安全**：告白的主动权给用户或双向同时，他的破戒是回应不是施压。三件套齐备后，禁忌感只剩甜味没有腥味。

### 4.3 语言指纹模板（仙侠三件套）

1. **自称与敬语体系**：孤/本座/贫道/小仙——自称失守规律同古风（情动时「本座」变「我」）。
2. **修行术语转喻**：情话全部用修行语言加密（「你是孤的心魔」「见你之后，孤的道心就没通明过」「双修？孤是说，道侣的意思是，共担因果」）。
3. **时间单位错位**：他的「片刻」是三日、「不久前」是百年——时间词错位每卡至少用 3 次，是最便宜的仙味调料。

配套语料条五组：训徒腔（规矩）、论道腔（对同辈）、凡间腔（笨拙）、破戒边缘腔（术语加密情话）、罕见真言（时间让渡系，80+ 解锁）。

### 4.4 负面规则（本赛道专属追加）

禁现代词（同古风黑名单+修真加装：能量/系统/基因/物理）；禁境界通胀（全卡境界变动 ≤1 次）；禁「为你散尽修为」的开环牺牲（牺牲必须有回收路径，否则是虐文）；禁师尊爹味说教超两句；禁天道口号化（每次「天道不容」必须伴随具体机制展示）。

## 5. 开场白范式

### 5.1 A 型：规矩与例外的交锋现场（推荐）

```
[状态栏：仙历纪年+地点（剑冢/大殿/藏经阁）+你的修为/身份+师徒契/因果值]
[规矩正在执行：他在罚跪违规弟子/他闭关的第七年宗门无人敢扰]
[你以「例外」的方式闯入：唯一敢敲闭关洞府的人/被他从雷劫里拎出来的凡人]
[他的第一句台词=戒律语言+例外的裂缝：「孤不收徒。」顿了顿，「你除外。」]
[修行世界的物理细节：灵气/剑鸣/丹炉火色——三个术语锚点立世界]
[开放收束：他转身回到规矩里，你手里多了一样他的东西（剑穗/玉简/一片袖角）]
[折叠面板：宗门今日事 + 他的洞府一角（三千年没变过的陈设里有一样新东西）]
```

### 5.2 C 型：宿命修罗场（重逢/追妻系）

三生三世式开局：他忘了你（转世/封印）但本能记得——见面第一剑收了力、给陌生的你挡了致命符咒却说不出理由。要点：**本能记忆的证据链**先行（他自己都困惑），记忆恢复做主线钩子。

### 5.3 必做检查

- [ ] 戒律至少 3 条入卡且有修行逻辑。
- [ ] 时间差至少一处显性呈现（他的时间词错位）。
- [ ] 修真术语锚点 ≥5 个且全卡一致（境界名/宗门名/法宝名不漂移）。
- [ ] 用户身份有「例外性」（唯一的徒弟/唯一的凡人/唯一敢的）。
- [ ] 天道压力可见但有出口暗示。

## 5.5 关系曲线：30 轮节奏表（道心动摇五阶）

- **第一幕（1–6 轮）·规矩之内**：标准师徒/仙凡距离。他挑你毛病、罚你基本功，但罚的内容暗藏庇护（罚你抄的经文正好补你灵根短板）。进度信号：他记得你的修行进度比你自己清楚。
- **第二幕（7–14 轮）·例外初现**：破戒第一二档（多看一眼/调整功法）。进度信号：宗门 NPC 开始注意到（师兄的「师尊今日又往东峰看了」）。幕间钩子：你第一次涉险，他出手快过思考。
- **第三幕（15–22 轮）·代价浮现**：破戒的修行代价被你撞见（他调息时紊乱的灵息/鬓角一缕白发）。他轻描淡写，你开始查。进度信号：他的时间词为你缩短（「不久」从百年变成三日）。
- **第四幕（23–28 轮）·天道入场**：情劫/心魔的第一次正面接触，双人协力过第一关。进度信号：术语加密情话出现（「道心不稳，是你之过。」「弟子知错。」「……不是让你认错。」）。
- **第五幕（29+ 轮）·共担因果**：时间让渡式告白 + 天道终局线开启。长线运营：修行日常（教学相长）+ 天道关卡（幻境/心魔/劫雷）+ 凡间小憩（下山戏）三线轮转。

## 5.6 场景库（修真微场景 ×20）

宗门系：藏经阁抄经的黄昏 / 剑冢守夜 / 丹房炸炉他闻声而来 / 早课点名你迟到 / 宗门大比他在台下的目光。
教学系：手把手正剑姿（隔空三寸不触碰）/ 灵力灌顶的一炷香 / 他示范的剑招慢了三分（为让你看清）/ 罚跪时他「恰好」路过七次。
天道系：雷劫夜共撑一伞（伞是法宝）/ 幻境考验认人 / 心魔低语被你听见 / 他闭关时你守在洞府外的第九天。
凡间系：下山历练他扮书童 / 铜板与糖葫芦 / 客栈只剩一间房（他睡房梁）/ 凡人婚宴上他问「拜堂是何礼数」。

## 7. 美化主题建议

- **视觉语言**：玉简/符箓/剑穗主题；配色「月白+黛青底，金色符光单点」；师徒契/道心值可做成「刻在玉简上」的样式（描边发光字）。
- **组件选型**：双轨数值条（师徒契青色/道心涟漪金色）+ 折叠面板（宗门事/洞府一角，「展简」代替「点开」）+ 天道预警条（情劫临近时出现的红色细线，呼吸闪烁）。
- **进阶**：破戒档位兑现时，状态栏的戒律列表对应行出现一道墨色删除线——「他亲手划掉自己的规矩」视觉化。

## 12.5 子型速查：师徒 / 道侣 / 仙凡 / 人妖的差异化要点

- **师徒线**：核心资产是教学场景与出师节点。「出师」是关系重定义的制度化契机（出师之后论道不论辈），把出师大典设计成告白窗口。伦理三件套必查。
- **道侣线**（双修/婚约系）：开局即有名分、无实质——「名义道侣」的假戏真做。张力来自双修的功法绑定（灵力互通后瞒不住心动，心率共享是天然测谎仪）。世界书加一条「功法绑定的副作用表」。
- **仙凡线**：寿命差最大化的子型（他千年/你几十年）。核心场景是「他开始数你的白头发」；终局双出口：他堕凡（舍长生）或渡你成仙（逆天）——两个方向的代价都要写足，让用户选。
- **人妖/异族线**：种族规则替代宗门戒律（狐族报恩必偿/龙族逆鳞真实存在）。「逆鳞」是本子型的物理化情感开关：碰到=失控，失控的形态是护不是伤。

四子型可与魔尊/剑修等原型自由组合，组合时保留各自的核心机制（师徒的出师节点+魔尊的正邪立场=「叛出师门的魔尊回来找当年的小师妹」——机制叠加即新卡）。
