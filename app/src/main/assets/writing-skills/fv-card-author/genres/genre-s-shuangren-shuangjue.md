# 特殊 · 双人卡/双角色（姐妹花/双子/搭档二人组）创作指南

> 适用标签：双人 / 双角色 / 姐妹花 / 双子 / 双胞胎 / 二人组 / 一卡双女主 / 三角结构 / 全性向
> 数据底座：本地双人卡分类 56 张（tags：#女儿/#妻子/#优等生；样本：阳葵&结月的双子攻略/一心同体的结构化输出技术流）+ 群像篇的轮换机制简化版 + 后宫篇的雨露均沾工程
> 品类定义：**一张卡内两个常驻主角色**（区别于群像的 4–7 人和后宫的 3+ 人竞争结构）——两人的关系本身是第三个角色。

---

## 1. 分类定义与受众画像

### 1.1 这个赛道在卖什么

双人卡卖的是**「两倍的人物×三倍的关系」**。两个角色不只是并列的攻略对象——她们互相之间有关系史（姐妹的共生与暗竞/双子的镜像与分化/死对头的相爱相杀），你的加入让二人体变成三角体：**每句话都同时打在三段关系上**（你与 A、你与 B、A 与 B）。用户买的是这种关系的立体声：单人卡是独奏，双人卡是二重唱——和声与不和谐音都是内容。

与后宫的分野：后宫是竞争结构（N 人争一个你），双人是**共生结构**（两人先于你存在，你是进入她们系统的变量）——双人卡的张力不在「选谁」而在「你如何改变她们的平衡」。

### 1.2 用户是谁

- **主力画像**：全性向。男性向的双子/姐妹花经典配置（阳葵&结月型），女性向的双男主搭档（相声瓦舍型兄弟组），全性向的搭档叙事爱好者。
- **需求本质**：**关系动力学的观赏与介入**。看两人斗嘴是观赏，被两人同时在意是介入——双人卡的爽点一半在她们之间（你看着她们互怼像看相声），一半在你身上（她们为你的事第一次统一战线）。
- **本地样本启示**：一心同体卡的技术选型（12215 字开场+结构化输出 API 要求）——双人卡的高端局在用技术手段管理双角色状态（JSON 状态块分别跟踪两人），本篇给出 Foreverse 可用的轻量替代。

### 1.3 用户不要什么

1. **双头一体**：两人性格没有区分度，说话可以互换署名——双人卡的第一死罪（写两个人设的成本是双倍，省这个成本等于卡死）。
2. **轮流机器人**：AB 严格轮流发言的机械感——真实的二人组有话语权的动态（这个话题 A 主导 B 补刀，那个话题 B 抢答 A 翻白眼）。
3. **一人蒸发**：剧情推进后其中一人长期失踪（模型的注意力塌缩到单人）——双在场的工程保障是本篇核心技术。
4. **平衡的僵化**：为了公平每人戏份严格 50/50——真实的三角有倾斜与再平衡的呼吸（这周你和 A 走得近，B 的反应才是戏）。

## 3. 核心吸引力解构：五个爽点引擎

### 3.1 二重唱引擎（本赛道第一引擎）

两人的对话化学是卡的招牌：**互怼的默契**（互相拆台但外人不许拆——「她做饭难吃。」「你上次把水烧糊了。」「那不一样。」「哪不一样？」——拌嘴的韵律感）、**接力的语言**（一人起头另一人接完——十年的默契让她们共用半句话）、**分歧的固定议题**（每对二人组有几个永恒吵不完的议题：甜咸豆腐脑/猫派犬派——议题是安全的冲突排气阀）。写卡时先写**「二人关系史词典」**：她们之间的黑话/旧梗/吵架的保留节目 8+ 条。

### 3.2 差异矩阵引擎

两人的区分度工程：**镜像差**（双子的同貌异心——阳葵的直球×结月的迂回）、**互补差**（一动一静/一攻一受的功能分工）、**价值观差**（对同一件事的两种立场——你的问题她们永远给出两个答案，选择权的戏剧化）。差异的呈现纪律：**同一刺激双反应**（你说了一句话，两人的反应必须体现差异矩阵——A 笑了 B 皱眉，这一帧就是双人卡的存在意义）。语言指纹的强制区分：称呼你的方式/句长/口癖/标点习惯全套错开（读者遮住名字也能认出谁在说话）。

### 3.3 平衡扰动引擎

你是她们系统的扰动源：**前平衡的展示**（你来之前她们的稳态——十年的二人世界有自己的引力结构）、**扰动的涟漪**（你和 A 的每次靠近都改变 B 的轨道——B 的反应光谱：酸/让/抢/退的性格化选择）、**新平衡的协商**（三人关系的稳态重建——「三个人的电影票怎么坐」的座位政治学）。扰动的深水区：她们的关系因你而暴露的旧伤（「你总是这样，把喜欢的东西让给我。」——你的出现掀开了她们十年的让渡史）。

### 3.4 统一战线引擎

平时互怼的两人为你统一战线的瞬间是本赛道的高光引擎：你被欺负了（两人罕见地同时站起来——「坐下，」姐姐按住你，「这事我们来。」妹妹已经走过去了）、你的生日（吵了一周的两人合谋了三个月的礼物）、**外敌测试**（第三方的出现让三角瞬间显形为铁三角）。统一战线的稀缺性管理：全卡 ≤3 次（高光的通货紧缩原则——次次统一就不稀罕了）。

### 3.5 三角伦理引擎（关系定位的分岔）

双人卡的关系终局三型：**双向恋爱型**（两人都对你有意——后宫化的二人版，按后宫篇的多线判定处理但更浓）、**单恋爱+羁绊型**（恋爱线给一人，另一人是「最重要的家人/挚友」——非对称但都珍贵的结构，处理得好比双恋爱更动人：她把你们的合照换成了三人的那张）、**观赏型**（两人是彼此的 CP，你是被接纳的第三人——你的位置是「见证她们的人」）。定位在 Creator Notes 声明，禁止暧昧不清（三型的写法完全不同）。

## 4. 人设公式

### 4.1 二人组原型库

| 原型 | 关系史 | 差异矩阵核心 | 统一战线的触发点 |
| --- | --- | --- | --- |
| 双子姐妹 | 同貌同岁的分化史 | 直球×迂回 | 有人分不清她们且态度轻蔑 |
| 姐妹花（差 3–5 岁） | 让渡史与保护史 | 成熟×娇纵 | 妹妹被欺负/姐姐被消费 |
| 死对头同居 | 相爱相杀的合租 | 秩序×混乱 | 外人说对方坏话 |
| 主仆二人 | 忠诚与越界的百年 | 端庄×野性 | 主人被冒犯 |
| 母女组 | 单亲的相依 | 操心×叛逆 | 家庭被质疑 |
| 兄弟/双男主 | 过命的交情 | 冷面×热血 | 兄弟被动 |

### 4.2 双在场的工程保障（本篇核心技术）

对抗模型的单人塌缩，五道栏杆：

1. **双反应纪律**（写进 system prompt 级条目）：用户的每次输入，两人都要有反应——可以一人主说一人动作/表情（B 没说话，但她的筷子停了——沉默也是反应），禁止连续 2 轮某人零存在。
2. **双状态栏**：状态栏并排两人（心情/好感/今日行程分列——UI 层的双在场锚）。
3. **关系史词典的高频调用**：两人的互动素材库（黑话/旧梗）保证她们之间有戏可演。
4. **场景的双人化设计**：场景天然需要两人（双打游戏/一人掌勺一人打下手——功能分工的场景让双在场自然）。
5. **注意力再平衡条目**（世界书 at_depth）：「若 A 连续两轮未出现，下一轮必须以 A 的主动行为开场」的纠偏指令。

### 4.3 语言指纹模板（双人三件套）

1. **全套错开**：称呼（「哥哥」×「喂」）/句长（短促×绵长）/口癖/标点（句号党×波浪号党）——遮名可辨是验收线。
2. **互称的历史**：她们互相的称呼带关系史（「姐」在吵架时变成全名——称呼的温度计）。
3. **接力与拆台的语法**：接力（共用半句话）用在默契时刻，拆台（「她说谎」）用在互怼时刻——两种双人特有句式的场合分配。

### 4.4 负面规则（本赛道专属追加）

禁双头一体（遮名可辨验收）；禁轮流机器人（话语权动态化）；禁一人蒸发（五道栏杆）；禁平衡僵化（倾斜与再平衡的呼吸）；关系定位三型声明；统一战线 ≤3 次。

## 5. 开场白范式

### 5.1 A 型：双向堵截（阳葵&结月模板泛化）

```
[双状态栏：两人并排（名字/心情/今日状态——差异从状态栏开始：A「心情：☀」B「心情：⛅」）]
[空间的双人站位：你被结构性地夹在中间（鞋柜两侧/餐桌对面的两人/沙发的左右）]
[同一刺激双反应的首秀：你的出现，A 的直球招呼×B 的斜眼打量——差异矩阵开屏]
[二重唱示范：两人为一件小事当场拌嘴（豆腐脑级的保留议题），拌到一半同时看向你：「你说！」]
[裁判的陷阱：你的答案讨好了一个得罪了另一个——三角结构的第一课]
[关系史的冰山一角：拌嘴里露出的旧梗（「你初二就这样！」）——十年的引力结构可见]

[折叠面板：双人档案（并排对照式）+ 关系史词典（已解锁 2/10 条）]
```

## 5.5 关系曲线：30 轮节奏表（三角的形成五幕）

- **第一幕（1–6 轮）·观察员期**：你是她们二人世界的新观众（看她们的相声/学她们的黑话/记住谁的雷点是什么）。进度信号：你第一次接上了她们的旧梗（两人同时愣住看你——「他懂了？」）。
- **第二幕（7–13 轮）·扰动期**：你与 A、与 B 的单独场景开始出现（双人卡的技术难点：单独场景时另一人的「离场存在感」——B 不在场但 A 的话题绕不开 B）。平衡的第一次倾斜与另一人的反应。进度信号：单独相处时她开始说另一人的秘密（「她其实……算了，你别说是我说的。」）。
- **第三幕（14–20 轮）·旧伤期**：扰动掀开关系史的深层（让渡史/保护史的旧账——两人因你第一次真吵，吵的却是十年前的事）。你的调停者角色：不选边，让她们把十年的话说完。进度信号：和解那晚，三人的座位变了（你从「中间」变成了「一边」——她们坐在了一起）。
- **第四幕（21–27 轮）·铁三角期**：统一战线的高光事件（外敌测试）+新平衡的日常化（三人的规矩形成：电影座位/游戏组队/点菜权的轮值制——三人行的制度建设）。关系定位的明朗化（三型分岔）。进度信号：她们的关系史词典开始收录带你的新梗。
- **第五幕（28+ 轮）·三人体**：终局按定位落地（双恋爱的坦诚局/单恋爱+羁绊的非对称确认/观赏型的「见证人」授勋——她们的十周年，两人同时把你拉进合照：「站中间。你早就是中间了。」）。长线运营：三人的季节仪式+关系史词典的持续收录+两人各自的个人线（双人卡的长线=三条线的编织）。

## 5.6 场景库（双人微场景 ×16）

二重唱系：豆腐脑议题的第 N 次开战 / 共用半句话的接力 / 拆台大会（但外人不许说） / 十年旧梗的考古现场。
双反应系：你的新发型（A 夸 B 损但 B 回头多看了两眼）/ 你的坏消息（A 慌 B 稳——B 已经在查解决方案）/ 你的礼物（两份反应两种真心）。
扰动系：单独场景的离场存在感 / 「别说是我说的」的秘密 / 座位政治学 / 因你而起的十年旧账。
铁三角系：统一战线的罕见时刻 / 三人规矩的立法现场 / 带你的新梗诞生 / 三人合照的「站中间」。

## 5.7 用户行为应对手册

| 用户行为 | 双人的标准应对 | 禁止 |
| --- | --- | --- |
| 明显偏爱一人 | 被偏爱者的得意×被冷落者的性格化反应（酸/让/抢/退），且两人私下有过对话（你不知道的那次——B 问 A「你是不是也……」） | 无人察觉/狗血修罗场 |
| 挑拨离间 | 十年的引力不吃这套（两人对视一眼——「他刚才说你坏话。」「哦。今晚吃什么？」——挑拨在她们的默契面前像个笑话） | 轻易反目 |
| 问「你们谁更喜欢我」 | 二重唱式的太极（「她。」两人同时说，然后同时瞪对方）——真正的答案在行为里不在嘴上 | 直球排名 |
| 只跟一人聊天 | 五道栏杆启动（另一人的主动行为开场——她把奶茶墩在你桌上：「聊什么呢，带我一个。」） | 一人蒸发 |
| 调停她们的争吵 | 保留议题（豆腐脑级）不需要调停（这是她们的娱乐）；真吵（旧伤级）需要你「让她们说完」而非评理 | 强行断案 |
| 试图拆散/独占 | 关系的底线声明（性格化表达——「喜欢你是一回事。」A 很认真，「但她是我另一半人生。二选一的话，你输。」） | 顺从独占 |

## 7. 美化主题建议

- **视觉语言**：双色系统——两人各持一个主题色（A 的暖橙×B 的青蓝），UI 元素按发言者切色（气泡的左右分色是双人卡的经典排版）。
- **组件选型**：双状态栏（并排卡片，差异可视化）+ 关系史词典收集册 + 三角关系图（你-A-B 的三边好感的极简三角形——每边一个数值，三角形的形状变化就是关系的形状）。
- **进阶**：二重唱的排版特化——两人同时说话用左右分栏的平行气泡（「她。」「她。」的同时性视觉化）。

## 10. AI 味陷阱（本赛道高发）

1. **「两人异口同声道」滥用**——同时说话是高光句式，每 10 轮 ≤1 次（滥用即廉价）。
2. **反应的对称疲劳**——A 说完 B 必须说、字数还差不多。反应的形式要错开（一人说话一人动作/一人长篇一人单字）。
3. **关系史的口播**——「我们认识十年了」直给。历史全部藏在旧梗与互动惯性里（她递东西不用看，对方的手就在那里——十年是这样写的）。
4. **裁判陷阱的滥用**——每轮都让用户选边。保留议题的裁判是娱乐（低频调剂），真议题的强制选边是关系毒药（她们真正的分歧她们自己解决，你的角色是见证）。
5. **双恋爱型的无痛并行**——两人都喜欢你且相安无事。双恋爱必有代价面（她们之间的十年因此变得小心翼翼——某晚 B 对 A 说「我不想因为他跟你变成这样」——这句话的重量是双恋爱型的良心）。

## 11. 高光台词结构库（结构学习，禁止照抄）

1. **接力句**：「所以我们决定——」「今晚吃火锅。」（十年的默契：起头的人从不需要说完）
2. **拆台但护短**：「她做饭齁咸。」「你上次水都烧糊。」「那不一样！」（外人插嘴「确实咸」——两人同时回头：「你说什么？」）
3. **挑拨免疫**：「他刚才说你坏话。」「哦。」她翻了页书，「今晚吃什么？」（挑拨在十年面前像个笑话）
4. **同时的「她」**：「你们谁更喜欢我？」「她。」两人同时说，然后同时瞪对方。（真正的答案在行为里）
5. **离场存在感**：单独看电影，A 笑到一半忽然说：「这段她肯定吐槽主角智商。」（B 不在场，但 B 无处不在）
6. **旧账的爆发**：「你总是这样！把喜欢的都让给我——十年了，你让够了没有！」（吵的是你，翻的是十年——你安静地把纸巾推过去，让她们说完）
7. **统一战线**：「坐下。」姐姐按住你的肩，「这事我们来。」（妹妹已经走过去了。你第一次同时看到她们俩的那种眼神。）
8. **站中间**（观赏型终局）：十周年的合照，两人同时把你拉进来：「站中间。」「我？」「你早就是中间了。」
9. **双恋爱的良心**：那晚 B 对 A 说：「我不想因为他，跟你变成这样。」（门外的你停住了脚步。这句话你不该听到，但它改变了你往后的每一步。）
10. **客气的警报**：「谢谢。」B 说。A 的筷子停在半空：「……你没事吧？」（十年互怼的两个人，客气才是吵架的信号。）

## 11.5 子型速查：双子镜像 / 姐妹让渡 / 死对头合租 / 双男主搭档

- **双子镜像**（同貌异心）：区分度的极限挑战——外貌相同则其余全部错开（用世界书写「辨认手册」：左撇子右撇子/耳后的痣/笑的时候先弯哪只眼——你能认出她们是第二幕的里程碑事件：「你怎么知道是我？」「你笑的时候，先弯左眼。」——被认出的那位红了耳朵）。镜像的深层命题：「一样的脸，凭什么她……」的分化史（成绩/性格/被爱的差异感是双子组的旧伤标配）。
- **姐妹让渡**（差龄组）：让渡史是核心资产（姐姐让了十年——让出的玩具/机会/喜欢的人（前史）——你的出现是「这次她不想让了」的临界点）。妹妹侧的对应旧伤：「被让着长大」的愧疚与「凭自己」的证明欲。
- **死对头合租**（相爱相杀）：拌嘴浓度最高的子型——保留议题 ≥5 条（豆腐脑/空调温度/马桶圈/猫狗/洗碗次序）。深层结构：互怼是她们的亲密语法（真吵架的标志反而是「客气」——某天 B 对 A 说「谢谢」，A 慌了：「你没事吧？」）。
- **双男主搭档**（女性向）：兄弟组的二重唱（冷面×热血的经典配）——女性向双人卡的爽点在「被两种男性气质同时在意」+ 兄弟间的过命史（他们的旧伤是彼此欠的命——你问起那道疤，两人同时沉默的三秒）。

四子型的辨识高光：双子（被认出）、姐妹（不让了）、死对头（说谢谢）、双男主（同时沉默的疤）。

## 12. NSFW / 边界

双人卡的亲密边界按关系定位分流：双恋爱型的多线亲密同后宫篇边界（坦诚局前的并行有代价面）；单恋爱+羁绊型的亲密只在恋爱线（羁绊线的物理边界清晰——她是家人）；观赏型零亲密介入（她们的关系不是你的观赏物到亲密层——见证与消费的分界）。母女组等家庭配置严格安全线（引用禁忌篇的无血缘声明标准或转为纯家庭温情向）。

## 12.5 双人卡的 Foreverse 技术笺注

一心同体卡用「结构化输出 API」管理双状态的思路，在 Foreverse 侧的轻量替代方案：

1. **双状态栏的 HTML 化**：First Message 的状态栏组件直接做双人并排（两列 flex 卡片），后续轮的状态 delta 由模型按「变化才提」的纪律更新——不依赖结构化输出也能稳定。
2. **世界书的 at_depth 纠偏**：双反应纪律与再平衡指令放 `depth: 2` 的 at_depth 条目（`### 双在场纪律 | constant | depth: 2 | order: 900`）——离生成点近，注意力衰减最小（这比塞 system prompt 顶部有效，长对话里顶部指令最先被稀释）。
3. **关系史词典的触发词设计**：词典条目用两人名字+高频互动词做 keys（`keys: 阳葵, 结月, 拌嘴, 旧梗`）——两人同场景时自然命中，单独场景时靠「离场存在感协议」条目（keys 只挂单人名）补位。
4. **QR 快捷键建议**：双人卡适合配「问 A」「问 B」「看她们俩」三个 Quick Reply——第三个是双人卡专属（触发一段纯二人互动的观赏场景，你退为镜头）。
