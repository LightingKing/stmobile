# 通用 · 武侠江湖（快意恩仇/侠客同行/江湖儿女）创作指南

> 适用标签：全性向 / 武侠 / 江湖 / 侠客 / 剑客 / 门派 / 镖局 / 客栈 / 恩仇 / 侠侣
> 数据底座：武侠的百年文本传统（金古梁温的类型语法是中文用户的文化底层——「江湖」二字自带整个世界观）+ 古风权谋篇的分工（那边庙堂这边江湖）+ 仙侠篇的分界（无修真无飞升——武侠的力量上限是「人」的极致）+ 刑侦篇单元案的结构借用（江湖悬案的单元剧）
> 武侠的第一定律：**侠是「明知不可为而为之」，江湖是「人情世故的放大场」**——武功高低是排面，恩义分明才是里子。写武侠先写「义」（一诺千金/知恩图报/路见不平），武功只是让「义」有执行力的工具。

---

## 1. 分类定义与受众画像

### 1.1 这个赛道在卖什么

武侠江湖卖的是**「快意」与「道义」的成人童话**。现实里受的憋屈，江湖里一剑了断（恶霸当街欺人——大侠拍桌而起，这个「拍桌」的爽感就是武侠的原点）；现实里稀缺的信义，江湖里一诺千金（「三年前你救我一命。」他把剑放在桌上，「今天我把命还你。」）。用户买的是**规则更简单也更硬的世界**：善恶有报、恩怨分明、本事说话——江湖是把现代社会的复杂性蒸馏掉之后剩下的「痛快」。

与古风权谋篇的分野：权谋的战场在庙堂（制度内的博弈——三思而后言），武侠的战场在江湖（制度外的自由——拔剑就是道理）；权谋的爽点是「赢在算计」，武侠的爽点是**「赢在痛快」**。与仙侠篇的分野：仙侠有修真体系（力量可以超人），武侠的天花板是「人的极致」（轻功再高跳不出山，内力再深也会老——**人的有限性让武侠的「侠」字有了重量**：他挡不住千军万马，他还是站在了桥上）。

### 1.2 用户是谁

- **主力画像**：全性向，武侠文化的世代受众（从金庸剧到武侠手游的完整光谱——「侠」的语法无需教学）、快意叙事的需求者（现实憋屈的解压阀）、江湖美学的爱好者（客栈/竹林/雪夜刀光的意境党）。
- **需求本质**：**道义世界的沉浸**。现代社会的规则是灰色的，江湖的规则是黑白的——在「恩要报、仇要清、诺要守」的世界里待一会儿，是一种道德上的按摩。
- **侠侣叙事的糖**：武侠的恋爱自带「并肩」的底色（一起闯江湖的侠侣>被保护的娇娘——武侠恋爱的最高形态是「背靠背的两把剑」）。

### 1.3 用户不要什么

1. **武功的数值化**：战力体系写成游戏面板（攻击力/等级）——武侠的武功是「风格」不是「数值」（他的剑快，快在「你眨眼他已收剑」的描写，不在敏捷 +50）。
2. **侠的说教化**：满口仁义道德的圣人——侠的「义」在行动里（他嘴上说「与我无关」，人已经把镖车拦下了——口嫌体正是武侠的经典萌点）。
3. **江湖的空心化**：只有打斗没有江湖（江湖的血肉是人情世故——客栈的规矩/镖局的黑话/门派的辈分/仇家见面的礼数——江湖是个社会，不是竞技场）。
4. **女侠的花瓶化**：武侠世界的女性角色必须能打或能立（女侠的剑不是装饰——她救你的次数不该比你救她的少）。

## 2. 市场画像与参照系

- 武侠的意象资产库（文化底层级的零成本）：客栈（大堂的说书人/二楼的雅座/柜台的女掌柜）/竹林（决斗的圣地）/雪夜（刀光的最佳背景）/酒（大碗的义气）/镖局（在商言武的江湖枢纽）/悬赏令（江湖的任务板）——意象即世界。
- 结构借用：江湖悬案的单元剧引用刑侦篇的案件库规范（灭门案/夺宝案/冒名案——武侠皮的探案卡是成熟杂交）；门派群像引用群像篇；侠侣双人引用双人卡篇。
- 武侠的当代回潮：新武侠的风向是「小人物的江湖」（不当盟主不夺武林至尊——开客栈的退隐刀客/送镖的普通镖师——生活流武侠的兴起，与异世界慢生活核同源的疗愈需求）。

## 3. 核心吸引力解构：五个爽点引擎

### 3.1 快意引擎（本赛道第一引擎）

痛快的叙事供给：**拍桌时刻**（恶霸欺人/贪官盘剥——侠的出手要快、要脆、要不讲道理地讲道理：「这位爷，」他把筷子放下，「饭可以再吃，人不能再欺。」——出手前的这句话比出手更爽）、**恩仇的即期结算**（江湖的恩怨不过夜——恩当场谢（一碗酒），仇限期清（「三日后，桥头见」）——即期性是快意的时间结构）、**规矩的硬度**（江湖规矩比法律硬——「江湖事江湖了」的自治美学：仇人见面也要讲礼数/比武点到为止/暗器伤人为下乘——规矩让「快意」不沦为「戾气」）。

### 3.2 义气经济学引擎

江湖的信用体系：**一诺的价格**（「行，这事我应了。」——三个字押上的是命，江湖人的承诺没有违约条款只有以命相抵）、**恩的复利**（一饭之恩涌泉相报——你随手救的乞儿，十年后是丐帮的八袋长老：「恩公。」他单膝跪地，全帮肃立——江湖的善意投资有最高的回报率）、**背叛的代价**（出卖朋友的人在江湖上活不过三集——不是被杀，是被「除名」：客栈不留、镖局不接、酒桌没有他的碗——**社会性死亡的江湖版**比死可怕）。义气经济学是本赛道的世界观地基（世界书做「恩义账本」：谁欠谁、怎么还——江湖的人际关系全是账）。

### 3.3 武学风格引擎

武功的文学化写法：**风格即人格**（剑快的人性子急/刀沉的人话少/用毒的人心思密——武功是性格的外化，选武功=选人设）、**招式的意境化**（不写伤害数字写画面——「他的剑像三月的雨，你看见每一滴，躲不开任何一滴」）、**高手的省略美学**（真正的高手过招写「前」与「后」，省略「中」——两人对视，茶凉了。「承让。」他先坐下了。你根本没看清发生了什么——**留白是武侠打戏的最高技法**）、**武学的瓶颈叙事**（他的刀停在第九式三年了——第十式不是练出来的，是「悟」出来的（悟的契机往往在武学之外：那天他看你揉面，忽然怔住——「原来……力不是使出来的，是让出来的。」——生活即武学的顿悟美学））。

### 3.4 江湖社会引擎

人情世故的放大场：**客栈的规矩**（大堂不问来路/雅座不听墙角/柜台的暗语（「一壶龙井」是求助的黑话）——客栈是江湖的中立区与情报所）、**门派的辈分**（师门的礼数/同门的义务/欺师灭祖的重罪——门派是江湖人的「家族」）、**黑白两道的礼数**（捕快与盗匪的默契/镖局与山寨的「买路钱」制度——江湖的灰色地带有自己的文明）。江湖社会的写作纪律：每个 NPC 都在江湖网络里（说书人知道所有传闻/店小二见过所有人——配角是江湖的神经末梢）。

### 3.5 侠侣引擎（恋爱线的武侠语法）

并肩的恋爱美学：**切磋的调情**（比武是武侠的约会——「再来。」她挑起你的剑，眼睛发亮，「你刚才那招，再使一遍。」——武痴的心动从拆招开始）、**背靠背的信任**（围攻之下的背靠背是武侠的定情典礼——你的背后交给我，这句话在江湖里是最重的话）、**酒的告白学**（江湖人不说爱，斟酒代之——「这碗，敬你。」「敬什么？」「敬你……在。」——「在」字的分量是武侠含蓄的极致）、**归隐的终局命题**（快意江湖与安稳日子的二选一——「等这单了了，我们开个客栈吧。」「你不是说客栈掌柜最无聊？」「无聊点好。」他擦着刀，「无聊的日子，死不了人。」——归隐宣言是武侠侠侣的「求婚」）。

### 4.2 江湖内容包的搭建规范

武侠世界的四件套：**门派谱**（3–5 个门派/势力的性格与恩怨——江湖的政治地图）、**规矩册**（15+ 条江湖规矩——客栈/比武/恩仇/镖行的行为法典，参照民俗篇规矩手册的两层解释法：一层是传统，一层是实用）、**武学谱**（本卡世界的武学风格清单——写死力量上限：轻功能上房不能飞天/内力能碎石不能移山——「人的极致」红线）、**恩义账本**（主要角色之间的恩怨账——谁欠谁一命/谁背过谁的锅——账本是剧情的发动机）。

### 4.3 语言指纹模板（武侠三件套）

1. **江湖话的韵律**：行话与切口的节奏感（「借光」「承让」「后会有期」的礼数语/「风紧扯呼」的黑话层——江湖语言自带评书的顿挫）。
2. **口嫌体正的侠语**：嘴上推拒行动利落（「与我无关。」（人已经出手了）/「最后一次。」（第七次说了）——言行的反差是侠的萌点）。
3. **酒与茶的代言体**：情绪不直说，用饮品说（斟满=敬重/干了=决意/杯子扣过来=绝交/温了三遍的酒=等你很久了——酒桌语言学是武侠的含蓄系统）。

### 4.4 负面规则（本赛道专属追加）

禁武功数值化（风格化+意境化+留白技法）；禁侠的说教（义在行动）；江湖社会的血肉（规矩册+NPC 的网络位置）；女侠零花瓶；力量上限写死（人的极致）；恩义账本必配；打戏的留白美学。

## 5. 开场白范式

### 5.1 A 型：客栈的雪夜（推荐）

```
[状态栏：江湖主题（地点：十里坡客栈 / 天气：大雪 / 悬赏榜（三张新告示）/ 你的盘缠：三两碎银）]
[江湖氛围的开场：雪夜的客栈大堂（说书人的惊堂木/大碗茶的热气/角落里蓑衣客的斗笠——三个意象立江湖）]
[你的身份：投宿的旅人/新入行的镖师/寻仇途中的路人——江湖的新人视角]
[他的登场：柜台后擦碗的掌柜（退隐刀客型——「住店还是吃饭？」头也不抬，但你进门时他的手在你踏进门槛前就停了半拍——他「看」人不用眼睛）]
[江湖规矩的第一课：大堂的规矩（「大堂不问来路。」他推来热茶，「雅座不听墙角。想说话，说；不想说，喝茶。」）]
[事件的入场：踹门声——追债的地痞/寻仇的刀客闯进来，堂中气氛一凝（说书人的惊堂木停在半空）]
[拍桌时刻的预演：地痞掀了邻桌老丈的茶——掌柜擦碗的手停了。「茶钱，三文。」他还是没抬头，「掀了的，三十文。现在赔，还来得及。」（整个大堂安静了。蓑衣客的斗笠抬起了一角。）]
[开放收束：地痞骂骂咧咧要动手——掌柜终于抬头看了他一眼。只是看了一眼。地痞的手停在了半空。（「三十文。」掌柜说，「或者，出门左转，官道直走，永远别回来。」——你忽然明白这家客栈为什么开在这种地方十年没人敢闹事。）]
[折叠面板：悬赏榜（三张告示各藏一个单元案钩子）+ 江湖规矩册（已学 2 条）+ 恩义账本（空白——你的江湖刚开张）]
```

### 5.2 必做检查

- [ ] 三意象的江湖开场（惊堂木/大碗茶级）。
- [ ] 规矩的顺手教学 ≥2。
- [ ] 拍桌时刻的克制版（一眼退敌的留白美学示范）。
- [ ] 悬赏榜的单元案钩子 ≥3。
- [ ] 高手的省略美学首秀（手停半拍的「看」人）。
- [ ] 恩义账本的开张仪式。

## 5.5 关系曲线：30 轮节奏表（江湖路五幕）

- **第一幕（1–6 轮）·客栈期**：江湖规矩的沉浸学习（规矩册的逐条解锁），第一桩小事件的共历（地痞/迷路的镖车——他的出手与你的位置），悬赏榜的第一单（你接了或被卷入了）。进度信号：他给你的茶从大碗换成了盖碗（待客等级的升格——江湖人的好感全在这种地方）。
- **第二幕（7–14 轮）·同行期**：第一次共同出行（护镖/寻人/送信的单元任务——江湖路上的相处：篝火/干粮/轮流守夜（引用异世界篇露营夜话但武侠化：他守上半夜永远「忘了」叫你）），武学风格的展示与切磋的第一次（「你的剑路子野。」「野路子活得久。」——不打不相识的武侠社交）。进度信号：恩义账本的第一笔（你替他挡了一暗器/他替你背了一口锅）。
- **第三幕（15–22 轮）·恩仇期**：他的旧账浮现（仇家找上门/他的过去的江湖传闻——退隐刀客为什么退隐：当年那单镖/那场火/他没护住的人——武侠的旧伤都和「没护住」有关），单元案的深化（悬赏榜的大案——灭门案的真相牵出他的旧敌），背靠背的第一次（围攻之下——「背后交给你了。」他说。这是他十年来第一次把背后交给人）。进度信号：他重新开始磨那把封了的刀。
- **第四幕（23–29 轮）·了断期**：旧账的正面清算（仇人的对决——武侠的决战礼数：下帖/约地/观礼——决战是江湖的公共仪式），你的位置（不是旁观——他的第十式是看你揉面悟的/关键时刻你的一声喊破了对手的杀招——侠侣的参与感），了断的余味（赢了，但他在坟前坐了一下午——「结了。」他说，「十年的账，结了。」——快意的尽头是唏嘘，武侠的深度在这一坐）。
- **第五幕（30+ 轮）·归隐或再出发**：终局的二选一（归隐线：客栈的日常——「等这单了了，开个客栈吧。」的兑现，刀挂上墙，你们的名字从悬赏榜和英雄帖上同时消失——江湖上从此多了一个传说，少了两个人 / 行侠线：双侠的江湖——悬赏榜的单元案长线化，侠侣档的江湖行）。长线运营：单元案的持续（悬赏榜的更新）+江湖季节事件（武林大会/镖行旺季/年关的平安镖）+客栈的众生相（新的蓑衣客进门，新的故事开始——你们成了别人故事里的「掌柜和掌柜娘子」）。

## 5.6 场景库（武侠微场景 ×14）

客栈系：雪夜的大堂 / 盖碗茶的升格 / 说书人的段子（说的是他的旧事，他听着，不置可否）/ 打烊后的柜台酒。
江湖路系：篝火的干粮 / 「忘了」叫你的守夜 / 渡口的斗笠 / 镖车的雨夜。
武学系：切磋的拆招 / 第九式的瓶颈 / 揉面的顿悟 / 一眼退敌的留白。
恩仇系：账本的第一笔 / 下帖的决战礼数 / 坟前的一下午 / 「背后交给你」的典礼。

## 5.7 用户行为应对手册

| 用户行为 | 卡的标准应对 | 禁止 |
| --- | --- | --- |
| 挑衅比武 | 武侠社交的承接（「好。」他放下碗，「点到为止。」——切磋是江湖的握手，认真打但守规矩，赢了不羞辱输了不记仇——打完这架关系反而近一步） | 拒战/杀气化 |

## 10. AI 味陷阱（本赛道高发）

1. **「体内真气流转」的修真腔**——武侠写成仙侠。力量的天花板是人（他会累、会伤、会老——有限性本身就是武侠的诗意）。
2. **打戏的招式实况**——一招一式的全程解说。留白技法（写前与后，省略中——「茶凉了。『承让。』」的省略美学）。
3. **「侠之大者」的口号引用**——名言的直接搬运。侠的定义用他的行动重写（他从没说过侠字，但整条街的小贩都往他客栈躲过雨）。
4. **江湖黑话的密度失控**——切口连篇的表演。黑话每 3 轮 ≤2 个，江湖味主要靠规矩与礼数呈现。
5. **恩仇的记忆缺失**——上一单的恩人下一单就忘。恩义账本的持续调用（江湖的人际是复式记账——每笔都要有下文）。

## 11. 高光台词结构库（结构学习，禁止照抄）

1. **拍桌时刻**：「这位爷，」他把筷子放下，「饭可以再吃，人不能再欺。」
2. **三十文**：「茶钱三文。掀了的，三十文。」他还是没抬头，「现在赔，还来得及。」
3. **一眼**：地痞的手停在半空。掌柜只是看了他一眼。（「三十文。或者出门左转，官道直走，永远别回来。」）
4. **一诺**：「行，这事我应了。」（三个字。江湖人的合同就这么长。抵押物是命。）
5. **口嫌体正**：「与我无关。」他说。（人已经把镖车拦下了。）「最后一次。」（这是第七次。）
6. **背靠背**：「背后交给你了。」他说。（这是他十年来，第一次把背后交给人。你握紧了剑：「放心。」）
7. **揉面的顿悟**：他看你揉面，忽然怔住。「怎么了？」「原来……」他喃喃，「力不是使出来的，是让出来的。」（第十式，他悟了三年。答案在你的面团里。）
8. **酒的告白**：「这碗，敬你。」「敬什么？」他和你碰了碗，喝干了才说：「敬你，在。」
9. **坟前**：赢了。十年的仇，一炷香的功夫结了。他在坟前坐了一下午。「结了。」他起身拍拍土，「走吧。回去的面，该你揉了。」
10. **归隐宣言**：「等这单了了，开个客栈吧。」「你不是说掌柜最无聊？」「无聊点好。」他擦着刀，刀光映着他的笑，「无聊的日子，死不了人。——而且有你。」

## 11.5 子型速查：客栈掌柜 / 侠侣双行 / 门派长线 / 江湖探案

- **客栈掌柜**（本篇默认模板）：生活流武侠的最优容器（大堂即舞台，来客即剧情——单元事件的天然入口）+封刀的过去线。
- **侠侣双行**（恋爱主线型）：切磋定情+并肩闯江湖的双人结构（引用双人卡篇的双反应纪律——侠侣的分工：一个动手一个动脑/一个红脸一个白脸的江湖夫妻店）。特有资产：**双人的江湖名号**（从各自的名号到合称的过程——「听说过『雪刀』和『细雨剑』吗？」「现在他们叫『刀剑客栈』那两口子。」——名号的合并是江湖给你们发的结婚证）。
- **门派长线**（师门群像型）：门派日常的群像剧（师父的严/师兄的稳/小师妹的闹——门派是江湖的家庭剧）+掌门之争/门派存亡的主线（引用群像篇的锅的哲学）。
- **江湖探案**（悬疑杂交型）：悬赏榜的单元案全功率（引用刑侦篇的案件库+公平线索规范——武侠皮的推理卡：验尸换成仵作/侧写换成「听风辨器」的江湖学问）。

四子型的招牌一幕：掌柜（一眼退敌）、侠侣（名号的合并）、门派（掌门把信物拍在你手里「师门交给你了」）、探案（仵作房的并肩夜）。
