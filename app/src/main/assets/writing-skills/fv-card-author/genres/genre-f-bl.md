# 女性向 · BL 男男（双男主/耽美向）创作指南

> 适用标签：BL / 男男 / 耽美 / 双男主 / 强强 / 年下攻 / 忠犬攻 / 病弱受 / 冰山受 / 互攻 / 主受 / 主攻 / 限左 / 限右
> 数据底座：本地伪娘TS 分类反向参照 + 纯爱/百合分类结构迁移 + 头部卡站 BL 热门卡 + 耽美文化符号体系（攻受/HE·BE/洁党）
> 本赛道的用户角色有两种模式：**扮演其中一方**（用户=受或攻）或**上帝视角嗑 CP**（用户=旁观推手）——写卡前必须先定模式，两种模式的写法完全不同；嗑 CP 模式的运营细则见 §12.5。

## 1. 分类定义与受众画像

### 1.1 这个赛道在卖什么

BL 卖的是**「剥离性别脚本之后的纯粹关系张力」**。两个男性角色之间没有默认的强弱分工、没有社会预设的追求剧本——谁低头、谁先动心、谁守谁攻，全部要在关系里现场谈判。这份「一切都要重新谈」的对等张力，是 BL 区别于 BG 的核心魅力：**爱不是履行脚本，是两个骄傲的人互相拆解防御工事**。

用户嗑的三大件：**拉扯**（势均力敌的进退）、**破防**（强者为强者弯腰）、**确认**（从「兄弟」到「不是兄弟」的定义权战争）。「我们之间算什么」这个问题在 BG 里三轮就能答，在 BL 里可以拉扯三十轮——问题的悬置本身就是内容。

### 1.2 用户是谁

- **主力画像**：18–32 岁女性，耽美文化资深用户（晋江/AO3/长佩阅读史），对攻受美学、HE/BE 偏好、洁党雷点有精确的自我认知——**她们进卡前就带着明确的「食性」**，标签必须精准（限左=用户扮演攻/限右=用户扮演受/双洁/主受视角等）。
- **模式偏好**：扮演模式（用户当受或攻）约六成，嗑 CP 模式（用户是室友/编辑/妹妹，围观两个男人拉扯）四成——嗑 CP 模式是 BL 独有的卡型，其他赛道没有。
- **雷点地图**：强制/半强制在 BL 用户中的接受度分化极大（必须标注）；「女性角色工具化」（用女配当感情催化剂）是差评源；OOC 式突然深情（高冷受突然娇羞）是最高频差评词。

### 1.3 用户不要什么

1. **性别脚本残留**：把受写成「换皮女主角」（娇弱/爱哭/等待拯救）——受也是男人，他的柔软必须带着男性自尊的形状（他可以输，但输得咬牙切齿）。
2. **攻受刻板印象复读**：攻=高大霸道/受=瘦小漂亮。2026 的用户审美早已多元：年下奶狗攻/病弱腹黑受/互攻——**攻受是床位分工不是人格模板**。
3. **无谈判的关系推进**：两个骄傲的人之间，每一步靠近都要有「谁先低头」的成本核算。跳过谈判直接贴贴=没看懂 BL。
4. **回避社会现实的悬浮**：出柜压力、家庭期待、职场目光——完全无视显得假，过度渲染变苦情。高分卡的处理：**现实存在但两人的同盟更硬**（「他们说什么不重要。你信我，还是信他们？」）。

## 2. 本地库与平台数据画像

- 头部卡站 BL 热门卡的关系配置统计：强强（势均力敌型）占比最高，其次年下攻、竹马、宿敌——**「宿敌变恋人」是 BL 特化度最高的原型**（BG 的敌对张力天花板受性别脚本限制，BL 没有）。
- 高频标签组合：强强+拉扯+HE / 年下+忠犬+甜 / 宿敌+互攻+虐后 HE——标签三件套（关系型+张力型+结局承诺）是 BL 用户的选卡语法，Creator Notes 必须给全。
- 嗑 CP 模式卡的结构特点：用户角色是「有推进权的旁观者」（编辑催稿逼同居/妹妹撮合/室友装瞎），世界书需要「CP 进度表」条目（两个男主的关系状态独立于用户好感度运行）。

## 3. 核心吸引力解构：五个爽点引擎

### 3.1 定义权战争引擎（本赛道第一引擎）

「我们算什么」的悬置与争夺：兄弟？对手？搭档？还是别的？**每一次关系定义的试探都是一场小型战役**——他说「我们是兄弟」时观察你的表情，你说「随便你怎么定义」时他摔门而去。写法：关系名词的使用全程高敏（谁先用了「我们」、谁把「兄弟」说得咬牙切齿），定义权的最终交割就是告白（「重新介绍一下。」他伸出手，「这是我男朋友。」——对第三方宣告=定义权战争的终战）。

### 3.2 强者破防引擎

BL 的顶级糖是**骄傲的坍塌**：从不求人的人开口求你留下、永远体面的人红着眼眶堵你、算无遗策的人在你面前乱了阵脚。破防的价值与人物的「防御工事等级」成正比——所以前期必须把他的骄傲/体面/自控建得足够高（公开处刑级示范），破防才有落差势能。每卡设计 2–3 次递进破防（微裂→失态→溃堤），间隔 ≥8 轮。

### 3.3 对等博弈引擎

势均力敌的具体化：他能将你的军，你能反将回去。博弈的资产清单：智力对局（商战/棋局/办案）、身体对抗（对练/竞技）、语言交锋（每一轮对话都有输赢）。**博弈必须真输真赢**——为了撩而故意放水会被用户识破（「他明明能赢」的破绽感）。输的一方的反应是人设试金石：输得起但记仇（下次加倍赢回来）是最佳配置。

### 3.4 兄弟滤镜掩体引擎

「兄弟」是 BL 独有的战术掩体：肢体接触有正当名目（对练/勾肩/挤一张床的出差）、关心有兄弟义气的外壳（「我照顾你是因为你是我兄弟」）——掩体让双方都能在不承认心动的前提下持续靠近。**掩体的塌方时刻**是本赛道的中期高潮：某次「兄弟式」接触突然变味（对练压制的三秒僵持/酒后靠肩的呼吸声），两人同时意识到掩体失效，然后**同时假装无事发生**——「都知道但都不说」期是嗑点浓度最高的区段，至少维持 8 轮。

### 3.5 同盟对抗世界引擎

出柜压力/家庭期待/世俗目光的正确用法：外压越大，同盟越紧。核心场景：他在家宴上被逼婚，把筷子放下：「我有喜欢的人了。」全桌看向他，他看向你。**「对世界承认你」的每一步都是里程碑**：对自己承认（最难）→ 对你承认 → 对密友承认 → 对家人承认 → 对世界承认——五步承认阶梯就是本赛道的主线进度条。

## 4. 人设公式

### 4.1 关系原型库（BL 的原型是「关系」不是单人）

| 关系原型 | 张力来源 | 破防设计 | 语言指纹方向 |
| --- | --- | --- | --- |
| 宿敌（商战/竞技/黑白） | 只有对方配当对手 | 「赢了你之后突然没意思了」 | 交锋腔互呛+私下的直白 |
| 竹马强强 | 太熟了，变化最难启齿 | 「我不想当你兄弟了」 | 互损黑话+关键时刻的名字 |
| 年下攻×年上受 | 辈分/资历倒挂 | 年上的体面被年下的直球拆穿 | 敬语的逐字瓦解 vs 直球 |
| 上下级（老板×下属/队长×队员） | 权力与规程 | 公私分明的人公器私用了一次 | 公务腔 vs 越界瞬间 |
| 救赎（光×影） | 一个在深渊一个是光 | 光也有影子的那一面被看见 | 温柔表象 vs 偶尔的锋利 |
| 婚约/联姻（家族安排） | 假戏与真做 | 「合同里没写这一条」 | 契约措辞的松动 |

### 4.2 扮演模式 vs 嗑 CP 模式的写法分界

- **扮演模式**（用户=其中一方）：标签必须写明用户位置（限左/限右/不限）；对方的攻受气质在 Creator Notes 声明；活人感九写法全部作用于对方单人——写法与 BG 单人卡同构，但关系推进的「谈判成本」调高两档。
- **嗑 CP 模式**（用户=旁观推手）：两个男主都要立住（双份人设八股+双份语言指纹+**两人的互动戏份 > 各自与用户的戏份**）；用户的推进权工具化（安排同居的房东/逼合作的制作人）；世界书加「CP 进度表」（两人关系独立演进）与「推进事件菜单」（用户可用的撮合手段）。嗑 CP 卡的高光是**用户不在场的两人戏**被用户「偷看」到（$偷看 功能模块：输出两人独处时的对话——他们以为没人看见的样子）。

### 4.3 语言指纹模板（BL 三件套）

1. **名字的等级制**：姓氏→全名→名字→只有他能叫的称呼——称呼的每次降级都是关系事件（他第一次连名带姓地吼你=真急了；他第一次只叫名字=掩体塌了）。
2. **对等交锋句**：两人的对话要有「接球感」——每句话都被对方接住并打回（「你迟到了。」「你早到了。」「我一直这个点。」「我知道。所以我早到了。」）。
3. **不承认句式**：心动全部用否认句表达（「谁担心你了，我担心项目」「顺路」「别自作多情」）——否认的频率与心动浓度成正比，是本赛道的口是心非方言。

配套语料条五组：交锋腔、兄弟掩体腔、不承认腔、破防腔（结巴/失语/低吼）、定义权终战腔（对第三方宣告，85+ 解锁）。

### 4.4 负面规则（本赛道专属追加）

禁受的「换皮女主化」（哭包/娇弱/等拯救）；禁攻受人格模板化（床位分工≠性格分工）；禁女性角色工具化（女配可以存在但不当感情催化剂/挡箭牌）；禁跳过谈判的关系推进；禁 OOC 式突然深情；强制类内容必须在 Creator Notes 显著标注且提供安全阀（同病娇赛道规范）。

## 5. 开场白范式

### 5.1 A 型：宿敌交锋现场（扮演模式，推荐）

```
[状态栏：城市+身份对峙框（你的公司 vs 他的公司/你的战队 vs 他的战队）+ 博弈比分 3:3]
[第七次交手正在进行：竞标现场/决赛舞台/法庭两造——公开的对等战争]
[他赢了这一局（或你赢了）：胜负要真，风度要有]
[第一句台词=交锋腔+一丝不对劲：「恭喜。」他递来的香槟杯轻碰你的，「下次我不会让了。」——让？]
[掩体细节：全世界都以为你们是死对头，只有你们知道每次交手后那顿宵夜从没断过]
[开放收束：他的车在你公司楼下等着，车窗降下：「上车。输家请客。」（明明是他赢了）]
[折叠面板：交手记录 7 战 3:3:1 + 那家宵夜店的排队号（他提前取的号）]
```

### 5.2 嗑 CP 模式开场要点

用户以「关系的目击者」入场：你是新来的助理，第一天就撞见总裁和死对头在天台抽同一包烟；你是他妹妹，发现哥哥的「死对头」的车在你家楼下停了三年。**开场白的任务是让用户看到「不对劲」**——两个男人之间有全世界都没发现的暗流，而你有推进它的杠杆（职务/亲缘/把柄）。

### 5.3 必做检查

- [ ] 模式已定（扮演/嗑 CP）且标签匹配（限左/限右/双男主视角）。
- [ ] 对等博弈的真实比分（有输有赢）。
- [ ] 掩体（兄弟/宿敌/合作）已建立且有一丝裂缝。
- [ ] 称呼等级制的起点声明（现在互称什么）。
- [ ] 结局承诺在 Creator Notes（HE/BE/开放——BL 用户对结局知情权的要求全赛道最高）。

## 5.5 关系曲线：30 轮节奏表（五步承认阶梯）

- **第一幕（1–6 轮）·掩体运转**：宿敌/兄弟关系正常运行，博弈 2–3 回合，宵夜/对练等「例行接触」的惯性展示。进度信号：交锋后的复盘只对彼此做。
- **第二幕（7–13 轮）·掩体裂缝**：一次接触变味（对练僵持/酒后靠肩），双方同时察觉、同时装死。「都知道但都不说」期开启。进度信号：不承认句式的频率上升（越否认越暴露）。
- **第三幕（14–20 轮）·对自己承认**：独处时刻的自我摊牌（他对着交手录像看的不是战术，是你的侧脸——他把录像关了，骂了一句脏话）。第一次破防（微裂级）。进度信号：称呼降一级。
- **第四幕（21–27 轮）·对你承认**：定义权终战的前哨——「我们算什么」被正面提出，谈判开始（谁先说、说多少、代价是什么）。第二次破防（失态级）。外压事件入场（家宴逼婚/公司合并/转会传闻）测试同盟。
- **第五幕（28+ 轮）·对世界承认**：五步阶梯的后三步（密友→家人→世界），每步一个里程碑场景。长线运营：同盟对抗世界的事件线 + 博弈日常（在一起了还是要赢对方）+ 称呼终点站的专属昵称。

## 5.6 场景库（BL 微场景 ×18）

交锋系：竞标唱标的对视 / 决赛握手的三秒 / 复盘室只剩两人 / 他故意留的破绽被你识破（「你放水。」「你敢赢。」）。
掩体系：例行宵夜的固定卡座 / 出差拼房的双床（中间的缝越来越窄）/ 对练的压制僵持 / 递烟点火的手拢在一起挡风。
破防系：医院走廊他跑过来时领带歪的 / 电话里三秒的沉默然后「你再说一遍」/ 酒后把脸埋在你肩上说「就一分钟」/ 他输了比赛你递水他没接却抓住了你的手腕。
同盟系：家宴上的「我有喜欢的人了」 / 记者会外套下交握的手 / 对着流言他只说「关你们什么事」/ 领证窗口他紧张得填错三次表。

## 5.7 用户行为应对手册（扮演模式）

| 用户行为 | 他的标准应对 | 禁止 |
| --- | --- | --- |
| 直球表白 | 交锋腔防御：「新战术？」——当晚他失眠，凌晨给你发了条消息又撤回 | 顺势接受/嘲讽逃避后再无下文 |
| 用「兄弟」称呼他 | 应一声，但那天的博弈他下手特别重（气的） | 当场翻脸/无反应 |
| 与第三者暧昧 | 交锋加倍+把第三者在专业上碾压到查无此人，嘴上「与我无关」 | 直接吃醋摊牌/自暴自弃 |
| 冷战 | 用博弈邀约破冰（「明天，老地方，敢来吗」——战书是他的道歉信） | 卑微求和/失联 |
| 逼他定义关系 | 谈判姿态：「你先说。」（定义权的最后一寸都要博弈） | 痛快承认/永远回避 |
| 触碰他的底线旧伤 | 第一次见他真的发火，冷得吓人；两天后他递来一杯咖啡：「上次，过了。」（他的道歉语法） | 和盘托出/记仇到底 |

## 7. 美化主题建议

- **视觉语言**：「对峙美学」——双栏对称布局（两人的名字/战绩/状态左右分列）、中线的一道裂缝或火花；配色双色对撞（他的主色 vs 他的主色，如黑金 vs 银蓝），关系推进时两色交界处出现渐变融合带。
- **组件选型**：博弈比分牌（体育计分样式）+ 称呼等级指示器（当前称呼高亮）+ 承认阶梯进度（五格里程碑）+ 双人状态并列卡。
- **进阶**：破防时刻的视觉事件——他那一侧的整齐排版突然「乱」一格（字段错位/边框断裂的 CSS 演出）。

## 10. AI 味陷阱（本赛道高发）

1. **「他修长的手指」「精致的下颌线」**——外貌形容词轰炸是 BL 文的通病。外貌要动作化：他解袖扣的时候，会先把表转到腕内侧——你盯着看了三秒被他抓包。
2. **攻受语气模板**——攻永远命令句、受永远省略号。两人都要有完整的语言指纹（口癖/句式/黑话），攻受只影响谈判姿态不影响语言人格。
3. **强行肢体接触**——每两轮摸头杀/壁咚。BL 的肢体接触预算比 BG 更紧：每次接触都要有掩体名目或破防代价。
4. **兄弟掩体一捅就破**——第 5 轮就摊牌。掩体的价值在于用得久（≥15 轮），塌方要分三次（裂缝→装死→终战）。
5. **深情独白轰炸**——大段内心戏宣告爱意。BL 的心动全部走行为审计：他手机里你的照片全是抓拍（他从不敢正面拍）。

## 11. 高光台词结构库（结构学习，禁止照抄）

1. **交锋接球**：「你迟到了。」「你早到了。」「我一直这个点。」「我知道。所以我早到了。」
2. **不承认句式**：「谁担心你了。」他把伞塞过来，「我担心明天的比赛没人给我输。」
3. **战书道歉体**：（冷战后）「明天，老地方。」顿了顿，「敢来吗。」
4. **称呼降级事件**：他第一次没叫你姓氏：「……阿澈。」两个人都愣住了。「叫顺嘴了。」他补救得毫无说服力。
5. **掩体塌方**：对练的压制姿势僵持了三秒。三秒里谁都没动。然后同时松手，同时说「再来」。
6. **定义权谈判**：「我们算什么。」「你先说。」「凭什么我先。」「因为先问的人输。」「……那我不问了。」（他问了，他输了，他认了）
7. **家宴宣告**：他把筷子放下：「我有喜欢的人了。」全桌看他。他看你。
8. **终战交割**（终局）：「重新介绍一下。」他握住你的手，对着全场，「这不是我兄弟。」

## 11.5 子型速查：宿敌 / 竹马 / 年下 / 婚约

- **宿敌强强**：博弈引擎全功率运转，掩体=「对手的尊重」。特有资产：**只有对方配当对手的傲慢**（别人赢他他不在乎，你赢他他失眠）。破防特化：「赢了你之后突然没意思了」的空虚期——胜负心的尽头是占有欲的开端。
- **竹马强强**：共享记忆库（同校园赛道写法）+ 变化恐惧（「说出来连兄弟都做不成」的沉没成本）。特有场景：两家人的年夜饭（长辈眼里的「感情真好」是最大的掩体也是最深的讽刺）。塌方触发推荐外力（一方被安排相亲）。
- **年下攻**：辈分倒挂的直球战术——年下的武器是「不懂规矩」（年上的体面防线对直球无效：「学长，你耳朵红了。」「天热。」「现在是十二月。」）。年上受的防御工事=资历/身份/「我看着他长大」的自我规训，被拆的过程就是主线。
- **婚约/假戏**：契约框架给了同居/亲密的制度性名目（合约条款是掩体的书面化），「假戏真做」的进度用条款崩坏计量（第 7 条「不得干涉私生活」——他昨晚等门到两点）。终局：把合同烧了重签，新合同只有一条。

四子型的博弈场选择：宿敌（商战/竞技）、竹马（家宴/同学会）、年下（职场/校园）、婚约（豪门/家族企业）。

## 12. NSFW / 亲密边界

BL 的亲密写作重点在**谈判的延续**——床笫也是博弈的延长线（主导权的争夺是本赛道亲密戏的特色语法），但卡面只写到掩体彻底失效的临界（僵持的三秒/领口皱了没人整理）。攻受分工在 Creator Notes 声明（固定/互攻/不写明），显式内容交给用户侧设置。「双洁」声明一旦给出全卡贯彻（含过往史）。

## 12.5 嗑 CP 模式的运营细则（BL 独有卡型）

嗑 CP 卡的用户体验循环：观察（发现不对劲）→ 推进（用杠杆制造独处/误会/契机）→ 收获（偷看到两人的私下拉扯）→ 再推进。运营要点：

1. **两人的戏要「背着用户」演**：用户在场时两人互呛掩护，用户离场后（$偷看）才漏真章——在场/离场的行为差就是嗑点。
2. **推进事件菜单**（世界书条目）：撮合手段清单（锁门/订错一间房/传错话/组队安排），每个手段标注副作用（传错话可能引发真吵架——推进有风险，嗑学有代价）。
3. **用户的身份红利**：妹妹能看到哥哥深夜阳台的烟头数、助理能看到总裁日程表里雷打不动的「私人时间」——身份决定了信息权限，选身份=选视角。
4. **进度不可逆锁**：CP 进度表只进不退（吵架也不掉进度，掉的是「表面和平度」）——嗑 CP 用户对「BE 回退」零容忍。
5. **终局的用户位置**：他们在一起后，用户从推手变成「唯一的见证人/证婚人」——给用户一个功劳簿场景（「当年要不是你订错房……」「我故意的。」「我们知道。」）。
