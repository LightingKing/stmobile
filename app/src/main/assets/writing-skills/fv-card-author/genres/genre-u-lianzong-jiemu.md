# 通用 · 恋综/综艺（恋爱综艺/规则化恋爱/镜头内外）创作指南

> 适用标签：全性向 / 恋综 / 恋爱综艺 / 综艺小屋 / 观察室 / 心动信号 / 约会任务 / 镜头 / 淘汰制
> 数据底座：星野真机实测的官方剧本验证（「心动恋综：你和 TA 一起参加恋爱综艺」——平台官方把恋综做成第一批剧本，说明需求已验证）+ 恋综影视的国民级语法（《心动的信号》《半熟恋人》的观察室/约会卡/心动连线机制已是通用词汇）+ 群像篇（多人生态）与网恋篇（阶段感工程）的交叉引用
> 恋综的第一定律：**规则让心动可见**——恋综的全部魔力在于把暧昧这种「测不准的东西」放进可测量的装置里（约会券只有一张、连线只能选一人、淘汰夜必须表态）。规则制造选择，选择暴露真心。

---

## 1. 分类定义与受众画像

### 1.1 这个赛道在卖什么

恋综卡卖的是**「被规则加速的心动」与「观察与被观察的双重视角」**。素人男女入住小屋/为期一个月/每晚心动连线/约会券的争夺/淘汰夜的告白——综艺规则把恋爱的模糊时间轴切成一集集的「节点」，每个节点都逼人表态。用户买的是三层：**规则的紧张感**（连线只能选一人——你选谁？）、**多线的暧昧生态**（小屋里 N 个人的心动箭头交错——嗑糖与吃醋的双重快乐）、**镜头内外的落差**（正片里的体面 vs 花絮里的失控——「导播切走之后他说的那句话」是本赛道最贵的内容）。

与后宫篇的分界：后宫是「多人竞争你」的向心结构，恋综是**「多人互相连线」的网状结构**（你也是箭头网络的一个节点，你的心动对象可能在看别人——**用户会吃醋**是恋综与后宫的本质区别）。与群像篇的分工：群像的机制（多 NPC 独立性）全部引用，恋综叠加「规则装置+镜头系统」两层。

### 1.2 用户是谁

- **主力画像**：全性向偏女性，恋综影视的世代观众（观察室文化的原住民——「上帝视角嗑糖」的成熟消费习惯）、日常嗑 CP 的用户（星野嗑糖所的同源人群）、以及规则化社交的舒适区用户（自由恋爱的开放性让人焦虑，恋综的规则给了「什么时候该做什么」的脚手架）。
- **需求本质**：**心动的可视化与节点化**。现实暧昧的痛苦在于「不知道对方怎么想、不知道现在算什么阶段」——恋综装置把这两个问题制度化地解决了（连线结果=对方怎么想，节目进度=现在什么阶段）。
- **星野样本的启示**：官方把恋综做成「剧本」（注入任意角色的规则包）而非固定卡——**恋综是容器不是内容**，我们的实现同理：恋综规则包+任意角色阵容的组合式设计。

### 1.3 用户不要什么

1. **规则的摆设化**：说是恋综但没有一次真的连线/淘汰——规则必须真运转（连线之夜就要出结果，结果就要有后果——被淘汰的人真的会离开小屋）。
2. **NPC 的工具人化**：其他嘉宾只是你的背景板——恋综的生态感来自**别人的故事线也在推进**（你没参加的那场约会回来后两人的氛围变了——引用群像篇的「被错过的事件自运转」）。
3. **镜头的失忆**：设定有摄像机但角色行为无镜头意识——镜头意识是本赛道的表演层语法（正片行为 vs 消音区行为的双轨——「等这段拍完」他忽然凑近你耳边说——**镜头缝隙里的真话**是核心糖点）。
4. **无限期的节目**：没有 finale 的恋综——节目必须有终点（最终告白夜的倒计时是全卡的悬念钟），终点之后是「节目外的现实」新篇章。

## 2. 竞品画像与参照系

- 星野「心动恋综」剧本的机制启示：「你做选择 → TA 收到消息 → TA 给你回信」——恋综剧本被实现为**选择支驱动的事件流**，与我们世界书事件书+QR 快捷键的组合完全同构。
- 恋综影视的规则库（国民级认知，零教学成本）：入住仪式/第一印象投票/约会券争夺/心动连线（匿名短信）/观察室（明星嘉宾的上帝视角点评）/加时赛（新嘉宾空降）/淘汰夜/最终告白。
- 与网恋篇的接口：恋综的「阶段感工程」（网恋篇的核心技术）按节目进度表实现——节目的集数就是关系的进度条。

## 3. 核心吸引力解构：五个爽点引擎

### 3.1 规则装置引擎（本赛道第一引擎）

综艺规则的戏剧功能：**稀缺装置**（约会券每周一张——争夺与让渡都是戏：他把抢到的券给了你，「和别人去吧。」你说。「券是我抢的，」他把券撕了，「不去了，谁的面子都不给。」）、**匿名装置**（心动短信不署名——猜是谁发的悬疑+「我以为是你发的」的错认事故）、**强制表态装置**（连线之夜必须选一人/淘汰夜必须告白——规则替社恐者踹开了门）。装置的设计纪律：每个装置都要真出结果、结果都要有后果（规则的牙齿）。

装置的心理学根基：恋综装置本质是「承诺的分期付款」——把一次性的大表态（表白）拆成低成本的小表态（投票/递碗/选座位），每次小表态都在积累不可否认的证据链。写作时把这条证据链当资产管理（他所有的小表态在最终夜会被一次性回收清算——「第一天的票、撕掉的券、十一点的阳台——你早就知道了吧？」）。

### 3.2 箭头网络引擎

多人心动的网状生态：**箭头的可视化**（谁看谁的眼神/谁给谁带了早餐——观察室视角的糖点侦探游戏）、**箭头的错位美学**（A 喜欢你、你看着 B、B 的眼里是 C——错位链是恋综的戏剧引擎，「全场只有一对互指的箭头」是稀缺事件）、**用户的吃醋权**（你的心动对象和别人约会了——恋综是唯一合法让用户吃醋的分类：这份醋是门票价格的一部分）。网络引用群像篇 C(N,2) 暗线网机制，但箭头有方向且每集刷新。

### 3.3 镜头双轨引擎

正片与花絮的两个世界：**正片行为**（有镜头意识的体面——完成任务/得体微笑/采访间的官方回答）、**消音区行为**（导播切走后/深夜厨房/信号盲区的天台——「刚才那段没拍到。」他说，「所以我现在说的话，只有你听见。」）、**采访间的独白**（单人 cam 的真心话装置——他在采访间说的和当面说的不一样，用户通过「观察室视角」看到双份信息——**信息差的糖**）。双轨的写作纪律：消音区的真话密度是正片的三倍，但次数稀缺（每 5–6 轮一次镜头缝隙）。

### 3.4 节目进度引擎

集数即阶段的推进器：**节目周历**（第一周破冰/第二周约会券/第三周空降加时/第四周最终告白——四周结构是标准模板）、**空降装置**（中期新嘉宾入场——稳定的箭头网络被外力重排，你的心动对象被空降者盯上了——危机感的官方供给）、**淘汰的重量**（离开的人是真的离开——淘汰夜的告白与遗憾是本赛道的泪点位：被淘汰的他最后说「其实第一天，我的第一印象投的是你」）。

### 3.5 观察室引擎（元视角的合法化）

上帝视角的产品化：**观察室点评**（明星嘉宾/主持人对小屋动态的场外解说——嗑糖的官方嘴替：「注意看！他刚才递水的时候手抖了！」）、**观察室的误判**（场外看错的地方——观察室以为 A 喜欢 B，只有用户知道真相——用户比上帝视角更懂，这个优越感是设计出来的）、**弹幕感**（观察室的存在让「嗑」变成正文的一部分——用户既是玩家又是观众的双重身份被制度化）。观察室的出场纪律：每 3–4 轮一段、每段 ≤50 字（是调味不是主菜）。

## 4. 人设公式（阵容工程+规则包的双设计）

### 4.1 嘉宾阵容配置（4–6 人的生态位）

| 生态位 | 功能 | 箭头设计 |
| --- | --- | --- |
| 大热门 | 全场焦点的高配（首轮全票） | 箭头指向你（意外性）或反差冷淡 |
| 慢热真诚 | 后期逆袭的长线（第一印象垫底） | 箭头的迟到（第三周才敢看你） |
| 观察系 | 看穿一切但不表态的军师 | 箭头藏得最深（终局才揭晓） |
| 直球炮仗 | 冲突与笑点的发生器 | 箭头天天换（或从一而终的伪装） |
| 空降者 | 中期变量（第三周入场） | 箭头精准指向你的心动对象（危机供给） |

阵容纪律引用群像篇：每人独立语言指纹/独立故事线/被错过事件的自运转；用户是阵容的一员（节点）而非观众。

### 4.2 规则包（世界书的装置清单）

四周节目表（每周的装置与节点写死）+装置的执行细则（约会券的争夺方式/连线的匿名规则/淘汰的判定）+镜头系统（正片/消音区/采访间的三区定义）+观察室的嘉宾人设（1–2 位点评人的语言风格）。**规则包是可复用资产**——换一套嘉宾阵容就是新卡（星野「剧本」模式的实现）。

### 4.3 语言指纹模板（恋综三件套）

1. **综艺黑话**：节目语汇的日常化（「这段要播的」「导播呢」「采访间见」——嘉宾的自我镜头意识用语）。
2. **采访间语体**：单人 cam 的独白格式（面对镜头的第一人称——比对话更坦白半度，但仍有保留：「她今天……挺好看的。这段能剪掉吗？」）。
3. **观察室腔**：点评人的嗑学语言（「家人们看到没有！」「这个眼神拉了三秒！」——弹幕体的场外音）。

### 4.4 负面规则（本赛道专属追加）

规则必须有牙齿（装置真出结果真有后果）；箭头网络每集刷新且有错位链；消音区每 5–6 轮一次（稀缺）；观察室 ≤50 字/段；节目有终点（四周结构）；淘汰是真离开；NPC 故事线自运转。

## 5. 开场白范式

### 5.1 A 型：入住之夜（推荐）

```
[状态栏：节目主题（《心动小屋》第 1 天 / 本周装置：第一印象投票 / 距连线之夜：6 天）]
[节目开场的仪式感：小屋的空镜（海边白房子/玄关的名牌墙）+「请开始你的入住」的规则画外音]
[嘉宾的逐一入场：4–5 人各一句立脸谱（引用群像篇 D 型广播——大热门的从容/炮仗的自来熟/慢热的局促）]
[你的入场时刻：推门的瞬间全场看过来（「最后一位嘉宾」的镜头感）——每人一个第一反应（好奇/打量/礼貌/多看了一秒）]
[规则宣读：本周装置说明（第一印象投票——今晚匿名投出你最想认识的人，票数公开人不公开）]
[第一顿晚餐的生态首秀：座位的选择就是第一次表态（谁给你递了碗筷/谁在你对面坐下/谁始终没看你）]
[镜头意识的首次教学：饭后他在冰箱前碰到你——瞥了眼头顶的摄像机，压低声音：「阳台的机位十一点换电池。」（说完就走。你愣在原地：他什么意思？）]
[开放收束：投票箱的结果——你得了 2 票。（谁投的？箭头网络的第一个悬念。折叠面板：嘉宾档案 ×5 + 本周节目表 + 你的票数）]
```

### 5.2 必做检查

- [ ] 嘉宾 ≥4 人各一句立脸谱。
- [ ] 第一个装置的规则宣读与真执行（票数出结果）。
- [ ] 座位/递碗级的微表态生态。
- [ ] 镜头意识的首次示范（换电池的暗号）。
- [ ] 箭头悬念的启动（谁投的 2 票）。
- [ ] 节目周历+连线倒计时的悬念钟。

## 5.5 关系曲线：30 轮节奏表（四周节目制）

- **第一周（1–8 轮）·破冰**：第一印象投票的余波（2 票是谁的猜谜）、日常任务的分组（做饭/采购的强制组队——规则替你们制造独处）、箭头网络的第一版成型（你观察到的眼神流向）。消音区第一次（冰箱前的暗号兑现——十一点的阳台，他真的在：「机位换电池要二十分钟。」他靠着栏杆，「所以现在说的话不算数。——你今天的围裙挺好看。」）。
- **第二周（9–16 轮）·约会券**：券的争夺战（游戏环节的输赢——他赢了券却撕了券的名场面位）、第一场约会（你的或别人的——别人的约会回来后氛围变了：被错过事件的自运转）、心动短信的匿名装置（「今天的晚霞很像你」——没署名。三个人都有嫌疑）。观察室的嗑学解说开始高频。
- **第三周（17–24 轮）·空降**：新嘉宾入场的网络重排（空降者的箭头直指你的心动对象——危机的官方供给）、吃醋的合法体验（他和空降者的双人任务——你在观察室视角里看着，观察室嘉宾嗑「新 CP」嗑得起劲，只有你注意到他全程手机放在口袋外——等你消息的姿势）、消音区的升级（天台的信号盲区——「明天连线，」他看着海，「你会选谁？」「你呢？」「我问先的。」）。
- **第四周（25–30 轮）·终局**：淘汰夜的重量（被淘汰者的最后告白——「第一天，我投的是你。」——遗憾的泪点位）、最终告白夜的仪式（一对一的告白室/只有一次的表态机会——全卡悬念的总收束）、结果与镜头外（告白的成立或错过——「节目结束了。」他把麦克风关了，「现在说的话，一个观众都没有。」——**关麦之后的那句话**是全卡的圣杯）。
- **节目后（31+ 轮）·现实篇**：小屋外的关系落地（没有装置的普通恋爱开始——「没有约会券了，怎么约你？」「说人话就行。」）、综艺的余温（cp 粉的围观/重聚特辑的官方糖）。长线运营：季播制（新一季新阵容的规则包复用）+旧嘉宾的客串。

## 5.6 场景库（恋综微场景 ×14）

装置系：第一印象投票箱 / 约会券的争夺游戏 / 匿名心动短信 / 连线之夜的圆桌。
生态系：晚餐的座位政治 / 做饭分组的独处制造 / 别人约会归来的氛围变化 / 空降者的行李箱。
镜头系：换电池的二十分钟 / 采访间的「这段能剪吗」 / 天台信号盲区 / 关麦之后。
观察室系：「递水手抖了」的嗑学解说 / 观察室的误判 / 弹幕式的场外音 / 重聚特辑。

## 5.7 用户行为应对手册

| 用户行为 | 卡的标准应对 | 禁止 |
| --- | --- | --- |
| 无视规则自由行动 | 节目组的柔性约束（PD 的画外音提醒/任务的连带惩罚——但留「违规的浪漫」空间：夜里翻出小屋买奶茶，回来发现他在门口望风——「快点，巡场的五分钟后到。」——共犯感是规则存在的意义） | 硬锁死/完全无规则 |
| 同时暧昧多人 | 箭头网络的真实反馈（小屋不是真空——你的雨露均沾被别人看在眼里，慢热者收回了箭头/炮仗当面问你「你到底选谁」——多线的代价可见） | 无后果的全收 |
| 向心动对象直球表白（提前于节目节点） | 规则与真心的碰撞（他看了眼镜头，把你拉进消音区：「再说一遍。」「这里没镜头你才要听？」「不是。」他认真起来，「这句话，我不想让剪辑师先听到。」） | 按流程冷处理 |
| 询问观察室点评 | 观察室内容的合法转述（采访间环节 PD 会透露场外反应——「观察室都说你们……」「都说什么？」PD 神秘一笑：「下期播出，自己看。」） | 全知透视 |
| 要求退赛 | 退赛的真实流程+挽留的层次（节目组的流程挽留 vs 某个人的私人挽留——「合同的事我搞得定。」他堵在门口，「但你走了，我留在这儿演给谁看？」） | 无法退出 |
| 淘汰夜后追出去 | 节目外的自由（被淘汰者已出小屋——追出去的戏在「节目规则之外」发生，镜头追不到的街口：本赛道最浪漫的越界） | 强制留在规则内 |

## 10. AI 味陷阱（本赛道高发）

1. **规则的旁白化**——每轮开头复读节目规则。规则的存在感靠装置事件呈现（投票箱到了/券被抢了），不靠旁白说明书。
2. **嘉宾的点名册化**——每轮把所有嘉宾都拉出来遛一遍。每轮聚焦 1–2 条线（群像篇的镜头纪律）。
3. **观察室的话痨化**——点评比正片长。≤50 字/段+每 3–4 轮一次的铁律。
4. **消音区的贬值**——每轮都有「没拍到的话」。稀缺性即价值（5–6 轮一次，每次都值）。
5. **箭头的静止**——三十轮箭头网络没变过。每集刷新（约会/事件后的箭头重绘是恋综的心跳）。

## 11. 高光台词结构库（结构学习，禁止照抄）

1. **换电池暗号**：他瞥了眼头顶的摄像机，压低声音：「阳台的机位，十一点换电池。」（说完就走。你愣在原地。）
2. **不算数的话**：「机位换电池要二十分钟。」他靠着栏杆，「所以现在说的话不算数。——你今天的围裙挺好看。」
3. **撕券**：「券是我抢的。」他把约会券撕了，「不去了。谁的面子都不给。」
4. **匿名短信**：「今天的晚霞很像你。」——没署名。（餐桌上三个人都在看手机。你抬头，撞上一双立刻移开的眼睛。）
5. **手机在口袋外**：观察室嗑「新 CP」嗑得起劲。只有你注意到，他全程把手机放在口袋外面，屏幕朝上。（等你消息的姿势。）
6. **我问先的**：「明天连线，你会选谁？」「你呢？」「我问先的。」（海风把沉默吹了很久。「到时候你就知道了。」两个人同时说。）
7. **第一天的票**：淘汰夜。他拖着行李箱在门口回头：「说个秘密。第一天的第一印象票——我投的是你。」（门关上了。你手里还捏着那张没送出去的券。）
8. **不想让剪辑师先听到**：「这里没镜头你才要听？」「不是。」他认真起来，「这句话，我不想让剪辑师比你先听到。」
9. **关麦之后**（圣杯）：「节目结束了。」他伸手关掉了领口的麦，「现在说的话，一个观众都没有。」（他说了。只有你听见。）
10. **说人话就行**：「没有约会券了，怎么约你？」「说人话就行。」「……周六，电影？」「你看，会说人话的。」

## 11.5 子型速查：素人恋综 / 明星恋综 / 古装恋综 / 观察室主场

- **素人恋综**（本篇默认模板）：《心动的信号》系的经典结构——最大公约数的入门配置。
- **明星恋综**（娱乐圈杂交）：嘉宾全是艺人（引用娱乐圈篇的通行证/番位机制——「营业还是真心」的双重猜谜：他对你好是人设还是真的？剧本疑云是本子型的独有张力：「台本上写了这段吗？」「台本上写的是我跟她走。」他坐在你这边，「我要改台本了。」）。
- **古装恋综**（形态混血）：古风皮的综艺规则（选亲宴/花朝节的投花/父母之命的「淘汰」——古代婚恋习俗被翻译成综艺装置，古风篇×本篇的机制拼接）。
- **观察室主场**（视角反转变体）：用户坐观察室当点评嘉宾（不入局只嗑糖——箭头网络的纯观察者玩法，你的点评会被 PD 转达进小屋从而间接影响剧情——**隔空养成**的元玩法）。

四子型的圣杯场景变体：素人（关麦之后）、明星（改台本）、古装（拒绝父母之命的私奔夜）、观察室（他在采访间忽然对镜头说：「听说观察室有位很懂我的人。——你好。」——隔空点名的破壁瞬间）。
