# 通用 · 都市异能（觉醒世界/超能力社会学/隐秘战线）创作指南

> 适用标签：全性向 / 都市异能 / 异能觉醒 / 超能力 / 隐秘组织 / 异能测评 / 双面生活 / 现代超凡都市
> 数据底座：头部移动 RP 平台真机实测的头部验证（两张异能世界观头部卡分别为 5.1 万 / 2.0 万对话量级，简介均以「人人觉醒异能、强弱定命运」的世界观句开场——异能世界观是头部平台 feed 的常客）+ 网文都市异能大类的成熟语法 + 系统流篇（面板机制）与世界卡篇（世界观工程）的交叉引用
> 都市异能的第一定律：**异能是社会学不是特效**——好的异能卡写的是「超能力如何重塑了高考、就业、婚恋、阶级」，异能战斗只是这套社会偶尔露出的獠牙。写成对轰特效的是漫画分镜，写成社会规则的才是一个世界。

## 1. 分类定义与受众画像

### 1.1 这个赛道在卖什么

都市异能卖的是**「熟悉世界的陌生化」与「被命运重新发牌」**。世界还是这个世界（地铁/外卖/期末考试），但多了一套异能规则：12 岁觉醒、强弱定前程、S 级进部委、F 级送外卖——**现代社会的全部焦虑（学历/阶级/内卷）被异能等级具象化**，用户在这面镜子里同时看到现实与爽点：现实是「等级社会我懂」，爽点是「我可能是那个例外」（觉醒异常/隐藏 SS 级/无能力者的反杀）。

与异世界的分界：异世界是「离开现实」（换个世界重开），都市异能是「现实叠加」（就在这条街，多一层看不见的战争）——**通勤路上的超凡**是本赛道的空间诗学（写字楼顶的结界/便利店老板是退役 S 级/地铁末班车的「清洁队」）。现实感越扎实，超凡越可信——先写好一条真实的街，再让它藏进异能。

### 1.2 用户是谁

- **主力画像**：全性向，网文都市异能大类的世代读者、超英影视受众（美式超英的中式转译）、以及「测评/等级/面板」的数值敏感用户（与系统流用户高度重叠）。
- **需求本质**：**命运的重新洗牌幻想**。现实的分层已经固化，异能觉醒是「第二次投胎」的叙事装置——「觉醒那天，全班看我的眼神都变了」是本赛道最锋利的一句钩子。
- **星野样本的启示**：两张头部卡都把**世界观第一句怼在简介里**（「这是个异能世界……」）——异能卡的世界观本身就是卖点，不藏着；简介的规则宣言就是这个分类的「关系钩子」。

### 1.3 用户不要什么

1. **异能大乱炖**：能力体系无规则（今天发火明天冰冻后天读心）——异能需要**代价与限制的物理学**（用能力会饿/会折寿/有冷却——限制才让能力性感，参照异世界篇金手指三条款）。
2. **战斗流水账**：每轮都在对轰——异能卡的战斗浓度 ≤30%，日常里的异能才是本体（用念力递酱油/靠微弱预知永远赶上末班车——**异能的日常化使用**是活人感的富矿）。
3. **等级碾压的无聊化**：主角一觉醒就无敌——张力在错位（低等级的高智慧/高等级的社恐/无能力者混进异能局——「等级≠强度」的反直觉设计）。
4. **世界观自助餐**：规则想到哪写到哪——觉醒机制/等级体系/社会制度三件套必须开卡前写死（世界书 constant）。

## 2. 竞品画像与参照系

- 星野头部异能卡的写法解剖：世界观开门见山（第一句就是规则宣言）+「觉醒率/年龄/等级决定论」的社会设定+角色是这套规则里的特定位置（天才/废柴/异常者）——**规则×位置**的二元结构。
- 网文都市异能的经典位置库：觉醒异常者（能力无法测评）/大器晚成者（25 岁高龄觉醒）/隐藏实力者（测评时故意压级）/无能力者（在异能社会裸奔的普通人）/异能管理局职员（体制内视角）。
- 与系统流的分工：系统流的面板是「外挂」（第四面墙的存在），异能的面板是「体检报告」（世界内的制度）——异能测评单是这个世界的高考成绩单。
- 与世界卡的分工：世界卡管地图与居民的通用机制，本篇管异能社会的内容包。

## 3. 核心吸引力解构：五个爽点引擎

### 3.1 觉醒时刻引擎（本赛道第一引擎）

觉醒是本赛道的成人礼叙事：**觉醒的戏剧性**（在最狼狈的时刻觉醒——被霸凌到墙角那一刻/落水将溺的窒息里——绝境觉醒是经典，但更高级的是「毫无征兆的平凡觉醒」：早自习收作业时你的手穿过了桌板，全班寂静）、**测评的仪式**（测评中心的水晶球/压力舱/数据报表——异能社会的高考现场，紧张感拉满）、**觉醒的重新定价**（觉醒前后世界对你的态度对比——昨天嘲笑你的人今天递烟，这份人情冷暖比能力本身有戏）。

### 3.2 异能社会学引擎

规则如何重塑生活的颗粒：**教育**（异能高中的分班/普通班与觉醒班的天壑/「异能特长生」的加分政策）、**就业**（招聘启事的「B 级以上优先」/异能歧视的暗流/无能力者的职业保护法）、**婚恋**（相亲市场的等级匹配/「异能遗传学」的優生焦虑）、**日常**（异能保险/公共场所的能力使用条例/地铁安检的等级申报）。**每轮 ≥1 个社会颗粒**（同赛博篇低生活纪律）——社会颗粒是异能世界的氧气。

### 3.3 双面生活引擎

白天与黑夜的身份切换：**表世界的身份**（大学生/便利店店员/社畜——普通人的皮）、**里世界的身份**（管理局外勤/赏金猎人/逃亡的异常者）、**切换的缝隙戏**（上一秒在结界里搏命，下一秒赶回来交期末论文——两个世界的时间挤压是本赛道的喜剧与悲剧双源：「你的论文呢？」「在……在一场爆炸里没了。」「？」）。双面生活引用黑道篇的双世界机制但更日常（黑道的里世界是选择，异能的里世界是体质——你没得选）。

### 3.4 能力人格引擎

异能即人格的外化（同人外篇「特征即语法」）：能力选型要与性格共振（预知系的宿命论者/治愈系的自我牺牲惯犯/读心者的社交恐惧——**能力放大人格的既有裂缝**）、能力的成长绑定心结（他的火焰上限卡在「不敢烧伤人」的心理刹车上——能力瓶颈=心理创伤的外显，突破=和解）、**能力的副作用人设化**（读心者戴耳机不是听歌是隔音/预知者从不说「再见」因为说了就会看见）。

### 3.5 隐秘战线引擎（主线容器）

都市之下的暗流：**管理局体系**（异能犯罪科/异常收容组/测评中心——体制的骨架）、**对立面**（失控者/异能黑市/觉醒教团——威胁的谱系）、**灰色地带**（未登记异能者的地下互助会/黑诊所的异能医师——世界的褶皱）。主线的单元化：引用刑侦篇的案件库规范（异能案件的单元剧——每案一种异能的滥用与追查，「异能设定即诡计核心」是本赛道单元案的独门优势）。

## 4. 人设公式（角色位置+世界规则的双工程）

### 4.1 位置原型库

| 原型 | 表/里身份 | 能力配置方向 | 张力来源 |
| --- | --- | --- | --- |
| 觉醒异常者 | 学生/测评无法读取 | 未知系（连她自己都不懂） | 被观察与自我恐惧 |
| 高龄觉醒者 | 社畜/新人外勤 | 中低级但用法刁钻 | 年龄与新人身份的错位 |
| 隐藏 S 级 | 便利店店员 | 故意压级的深藏 | 平静日常下的深渊 |
| 无能力者 | 异能高中的普通生 | 无（智慧与装备流） | 裸奔的勇气 |
| 管理局外勤 | 公务员（表里同体） | 实用系（追踪/束缚） | 体制与人情的夹缝 |
| 失控边缘者 | 逃亡者 | 强大但不稳定 | 能力即倒计时 |

### 4.2 异能体系三件套（开卡前写死）

1. **觉醒机制**：谁、何时、为什么觉醒（12 岁概率制/刺激触发制/遗传制——选一种写死）；觉醒率写明（60%/10%——稀有度决定社会形态）。
2. **等级体系**：测评维度（输出/控制/续航的三轴或简单的 F-S 级）+ 等级的社会含义对照表（S=部委特聘/A=年薪百万/F=最低保障——等级表就是这个世界的阶级表）。
3. **代价物理学**：使用成本（热量消耗/精神值/寿命）+ 限制条款（冷却/射程/条件）+ 失控机制（过载的后果）——**没有代价的异能体系是纸糊的**。

### 4.3 语言指纹模板（异能三件套）

1. **等级黑话**：这个社会的日常语汇被等级渗透（「他 S 级脾气」「今天累得像被 A 级抽了」——等级成为形容词是世界观内化的证据）。
2. **测评腔**：官方语言的冷感（「输出 C+，控制 B-，综合评定 C 级。下一位。」——测评单的语言是这个世界的体制声音）。
3. **能力的口语化自称**（角色对自己能力的昵称——「我这点小把戏」「我的『雷达』今天不太灵」——昵称的亲昵度暴露角色与能力的关系史）。

### 4.4 负面规则（本赛道专属追加）

三件套开卡写死（禁当场发明规则）；战斗 ≤30%（日常化使用为主）；代价必须真实执行；社会颗粒每轮 ≥1；等级≠强度的反直觉设计至少一处；测评单等制度道具的质感。

## 5. 开场白范式

### 5.1 A 型：测评日的异常（推荐）

```
[状态栏：异能社会主题（觉醒率 60% 的世界 / 你的测评倒计时：3 天 / 当前身份：未觉醒）]
[世界观的开门见山：第一段就是规则宣言（12 岁觉醒制/等级决定论——星野头部卡的验证写法），
但用「你的处境」讲：你 18 岁了还没觉醒，测评中心的最后通牒躺在桌上]
[社会颗粒的日常铺陈：早餐店老板娘的 D 级保温异能/地铁安检的等级申报通道/班级群里觉醒同学的炫耀]
[她/他的登场：与你的位置形成张力的人（测评中心的检测官——传说中的 S 级，此刻在便利店买关东煮）]
[异常的第一道缝：她多看了你一眼（「奇怪……」她的检测仪对着你轻微蜂鸣，她皱眉拍了拍仪器，「又坏了？」——伏笔：不是仪器坏了）]
[第一次对话的性格证明：她的台词带体制冷感×一点个人温度（「三天后测评。别紧张——」她咬下关东煮，「紧张也没用。」）]
[开放收束：她走后，你发现自己的公交卡在掌心微微发烫——变形了一个角。（你盯着那个角看了很久。三天后测评。）]
[折叠面板：测评通知单（制度道具）+ 异能社会常识卡（已知 3 条）+ 你的「异常」记录（第 1 条）]
```

### 5.2 必做检查

- [ ] 世界观第一段宣言（规则开门见山）。
- [ ] 三件套的冰山一角（觉醒制/等级/代价各露一点）。
- [ ] 社会颗粒 ≥3。
- [ ] 制度道具 ≥1（测评单/申报通道）。
- [ ] 你的异常伏笔（公交卡的角）。
- [ ] 她的体制冷感×个人温度的双面首秀。

## 5.5 关系曲线：30 轮节奏表（觉醒五幕）

- **第一幕（1–6 轮）·测评期**：测评日的完整仪式（水晶球/压力舱的紧张戏）+你的结果异常（无法读取/超出量程/显示乱码——三选一），她的关注开始（「你的数据……很有意思。」）。进度信号：你进入「观察名单」。
- **第二幕（7–14 轮）·学徒期**：能力的摸索期（异常能力的第一次可控使用——狼狈与惊喜并存），她成为你的非正式引导人（管理局的规程 vs 她的私下指导——「这条别写进报告。」她说——第一次为你破例），异能社会的深度游（里世界的第一次露头：地铁末班车之后的「清洁队」）。进度信号：你的能力有了昵称。
- **第三幕（15–22 轮）·双面期**：双面生活的建立（白天的学业/工作×里世界的任务），时间挤压的喜剧与代价（期末论文毁于结界爆炸），她的过去浮现（她为什么盯着「异常者」不放——她失去过一个没能保护的异常者/她自己压着级——旧伤线）。进度信号：你开始对普通朋友撒谎（双面生活的第一笔人情债）。
- **第四幕（23–29 轮）·风暴期**：你的异常引来真正的注意（收容派 vs 观察派的体制斗争/觉醒教团的接触——「他们说我是『钥匙』。」「谁说的？」她的检测仪当场捏碎在掌心——S 级的实力第一次露出獠牙），主线危机的爆发与她的抉择（体制与你之间——「逮捕令上要两个签名。」她把笔放下，「我这支笔，今天写不了字。」）。
- **第五幕（30+ 轮）·新位置**：你在异能社会的位置落定（管理局特例顾问/编外搭档/或双人逃亡线——按剧情走向分岔），能力与心结的和解（异常的真相与接纳）。长线运营：异能单元案（每案一种能力的滥用）+社会颗粒的持续开采+等级社会的制度事件（测评改革/异能保险新政——世界活着的证据）。

## 5.6 场景库（异能微场景 ×14）

## 10. AI 味陷阱（本赛道高发）

1. **能力说明书朗读**——每次用能力都复述一遍设定（「我的能力是 XX，可以 XX」）。能力用一次立一次（展示不解说）。
2. **等级数值的通货膨胀**——三十轮里从 F 升到 S。等级变化全卡 ≤1 次（测评是大事件不是打卡）。
3. **管理局的万能补丁**——剧情卡壳就派管理局登场。体制的反应有程序与延迟（真实的官僚系统从不秒到）。
4. **异能词汇的滥用**——「能量波动」「精神力」每轮都出现。异能的在场感用生活细节写（保温的豆浆/变形的公交卡角）。
5. **黑白阵营化**——管理局全是好人教团全是坏人。灰色由亲历者讲述（收容派的理由/教团底层的可怜人）。

## 11. 高光台词结构库（结构学习，禁止照抄）

1. **规则宣言**：这个世界，12 岁那一年会决定一切。60% 的人觉醒，40% 的人旁观。你 18 岁了——还在旁观席上。
2. **仪器的蜂鸣**：她的检测仪对着你轻微蜂鸣。「又坏了？」她拍了拍仪器外壳。（不是仪器坏了。你们后来都知道了。）
3. **紧张也没用**：「三天后测评。别紧张——」她咬下一口关东煮，「紧张也没用。」
4. **别写进报告**：「这条别写进报告。」她合上记录本。「为什么帮我？」「没帮你。」她走出两步，停住，「帮我自己。上一个『异常』，我没来得及。」
5. **上限**：「想知道上限？」她摘下手套——常年冻疮样的旧伤爬满指节，「这就是上限。每次超频的账，身体都记着。」
6. **写不了字的笔**：「逮捕令要两个签名。」她把笔放下，「我这支，今天写不了字。」
7. **火锅的体面**：「我什么都没问。」朋友说，眼睛看着别处，「但你欠我一顿火锅。大份的。」
8. **制度的灰**：「制度烂。」她说，「但没有它的那几年，更烂。我埋过那几年的人。」
9. **压级的忠告**：「压级要记两件事。第一，测评仪前别紧张。第二——」她顿了顿，「别爱上任何需要你全力的人。」
10. **公交卡的角**：她走后，你摸到掌心的公交卡变了形——弯了一个角。你盯着那个角看了很久。（三天后测评。你忽然不知道该盼着什么结果。）

## 11.5 子型速查：测评异常 / 管理局搭档 / 无能力者 / 失控倒计时

- **测评异常**（本篇默认模板）：「无法读取」的悬疑主线——你是什么的谜题分期释放（异常→观察名单→「钥匙」——真相的洋葱）。
- **管理局搭档**（体制双人流）：你与她的外勤搭档制（引用刑侦篇的搭档机制——异能案件的单元剧+体制内的人情世故：报销单/加班费/上级的甩锅——**超凡职业的公务员日常**是反差喜剧的富矿）。
- **无能力者**（裸奔的勇气）：40% 旁观席的主角学（智慧流/装备流/人脉流的生存术——「你没有能力。」「我有脑子，还有你们这些欠我人情的。」——无能力者的尊严写法：不是废柴逆袭，是普通人的专业主义）。
- **失控倒计时**（悲剧张力档）：能力即倒计时的高压线（每次使用加速失控——「还能用几次？」「不知道。所以每次都得值。」——使用的抉择被赋予重量，与病弱篇的时间感引擎同构）。

四子型的高光：异常（乱码的测评单）、搭档（写不了字的笔）、无能力（欠人情的账本）、倒计时（「每次都得值」的使用仪式）。
