# 女性向 · 西方超自然（吸血鬼/狼人/骑士与魔女）创作指南

> 适用标签：BG / 女性向 / 吸血鬼 / 狼人 / 恶魔 / 天使 / 骑士 / 魔女 / 西幻贵族 / 哥特浪漫 / 欧美
> 数据底座：本地欧美分类 31 张 + 西方超自然罗曼史的百年文本传统（从《德古拉》到《暮光》到暗黑浪漫的完整谱系）+ 人外篇的异质语法机制交叉（吸血鬼=概念系人外的西方贵族版）+ 黑暗惊悚篇哥特谱的美学借用
> 本赛道的第一定律：**超自然是贵族性的放大器**——吸血鬼的真正魅力不是獠牙是「活了六百年的旧世界教养」（他吻手背的礼仪比他的咬痕更致命）。写超自然生物先写「旧时代的人」，再写「非人」。

---

## 1. 分类定义与受众画像

### 1.1 这个赛道在卖什么

西方超自然卖的是**「永生者的旧世界浪漫」与「危险物种的驯服叙事」**。吸血鬼伯爵的城堡舞会、狼人的月圆之夜、恶魔的契约之吻——这些意象承载的是三重糖：**时间的浪漫**（六百岁的他见过你没见过的所有时代——「这支舞的跳法，我是 1789 年在凡尔赛学的」）、**贵族性的仪式感**（旧世界的礼仪/漫长岁月养出的品味/古堡与烛光的物质美学）、**危险与克制的张力**（他的天性想咬你，他的教养在克制——「渴」的隐喻系统是本赛道的欲望语法）。

与人外篇的分工：人外篇管东方志怪与萌系兽耳（方言词典/警戒半径的机制层），本篇管**西方超自然的文化包**（贵族礼法/宗教背景/欧式世界观——同样的「异质恋」内核，完全不同的美学外壳与文本传统）。

### 1.2 用户是谁

- **主力画像**：18–35 岁女性，欧美罗曼史文化的受众（暮光一代的成长用户+暗黑浪漫的新生代）、哥特美学爱好者（古堡/蕾丝/烛光的视觉系）、字幕组时代的美剧观众（吸血鬼日记式的叙事语法零成本）。
- **需求本质**：**被漫长时间选中的唯一性**。他活了六百年，见过无数人类——「六百年，你是第一个让我想变成人的」——永生者的「第一次」比凡人的重一万倍（时间尺度对独占叙事的放大是本赛道的核心杠杆）。
- **暗黑浪漫的口味**：危险是调味不是威胁（他的獠牙永远悬停在你颈侧一寸——悬停的克制比咬下去性感一万倍——本赛道深谙「悬停美学」）。

### 1.3 用户不要什么

1. **超自然设定的百科化**：种族规则讲三页纸——设定为关系服务（吸血鬼怕不怕大蒜不重要，重要的是他六百年的孤独）。
2. **贵族性的暴发户化**：城堡与财富的炫耀式描写——旧世界贵族的质感在克制（他的富贵在细节：袖扣的年代/红酒的年份/他从不谈钱因为钱对永生者毫无意义）。
3. **「渴」的失控滥用**：每轮都在忍耐嗜血冲动——克制是常态，失控是稀缺事件（≤2 次，且每次失控的对象是「保护你时的敌人」不是你）。
4. **宗教元素的轻佻**：十字架/圣水/教会的儿戏化——宗教背景是本赛道的严肃资产（他与信仰的六百年恩怨可以是深水线，不能是笑料）。

## 2. 市场画像与参照系

- 西方超自然罗曼史的三代演化：哥特恐怖代（德古拉——怪物叙事）→ 浪漫化代（夜访吸血鬼/暮光——恋人叙事）→ 暗黑浪漫代（当前——危险与浪漫的平衡回摆，纯甜的吸血鬼已过时，「危险的贵族」是当前审美）。
- 与黑暗惊悚篇哥特谱的分界：那边恐怖 30%+美学 70% 且恐怖是真的（她可能真的想吃你），本篇浪漫 80%+危险 20% 且危险是克制的（他绝不会伤你——危险全部外化为张力）。
- 本地欧美分类的启示：中文用户对西方超自然的消费习惯是「美学皮+中式情感内核」（他是伯爵，但他吃醋的样子很懂中文互联网——文化混血是合法的，考据的严格度可以让位给情感的准确度）。

## 3. 核心吸引力解构：五个爽点引擎

### 3.1 时间浪漫引擎（本赛道第一引擎）

六百年的叙事资产：**历史的亲历者**（他的记忆是活的历史书——「拿破仑？见过。个子没传说的矮，脾气比传说的差。」——历史八卦是本赛道独有的谈资库）、**旧物的时间胶囊**（他的城堡里每件东西都有故事——那幅画是他画的，画里的女人是六百年前的……他没说完，你也没问）、**永生的疲惫感**（活得太久的副作用——「时间对我是重复。四季、战争、人类的更迭——都是重播。」他看着你，「你是六百年来第一个……让我想看明天的。」）。时间差的终局命题引用人外篇（他数你的白发/变成人的可能性/永生的分享——三种路线的抉择）。

### 3.2 贵族仪式引擎

旧世界教养的糖法：**礼仪的性张力**（吻手背的停留时长/为你拉椅子时的耳语距离/舞会上手掌相贴的温度——旧礼仪的每个动作都是合法的越界）、**语言的古典腔**（他的措辞带着上个世纪的郑重——「May I？」的征询/称你为「My Lady」的庄重——古典腔与现代你的语言碰撞是日常喜剧+心动的双源）、**品味的碾压**（六百年养出的审美——他给你挑的裙子/他调的酒/他弹的那架 1820 年的钢琴——被旧世界品味照顾的奢侈感）。

### 3.3 悬停美学引擎（欲望的语法）

「渴」的克制叙事：**悬停的瞬间**（他的唇停在你颈侧一寸——呼吸是凉的，「抱歉。」他退开，喉结动了动，「今晚的月色……不太适合靠太近。」——悬停+撤退+暗语的三段式是本赛道的欲望标准句法）、**渴的隐喻系统**（他从不直说嗜血——「你的心跳声很吵」「离我远点，今晚我没吃饭」——欲望全部走隐喻轨道）、**信任的献祭时刻**（终局级场景：你主动把手腕递过去——「我信你。」他盯着你的手腕看了很久，然后低头，吻了吻你的腕骨——没有咬。「这比血更解渴。」——**递出与不咬**的双向克制是本赛道的圣杯场景）。

### 3.4 物种战争引擎（世界观的骨架）

超自然社会的规则：**种族的政治学**（吸血鬼议会/狼群的阶序/猎人组织——他的世界有自己的法律与战争）、**你的位置**（人类恋人在超自然政治里的脆弱性——他的敌人最先看到你/议会对「人类知情者」的规则——你是他的软肋也是他的战争理由）、**跨物种的罗密欧结构**（狼人与吸血鬼的世仇×你们的爱——经典的类型资产）。战争线的配比：恋爱 70%+物种政治 30%（政治是张力的供应商不是主菜）。

### 3.5 救赎与堕落引擎（宗教深水）

信仰背景的叙事纵深：**被诅咒者的神学**（他曾是十字军骑士/修道士——变成怪物的那晚他的信仰死了一半，「上帝没有回应我。六百年了。」——他与神的冷战是他孤独的最深层）、**你的救赎论**（不是你治好他，是你让「被诅咒」这件事失去了重量——「诅咒？」你摸着他的獠牙笑了，「我觉得挺可爱的。」他愣住——六百年的重负被一句「可爱」拆了承重墙）、**堕落的反向选择**（天使/圣职者为你堕落的变体——「我放弃的不是神。」他摘下圣徽，「是替神看管你的资格。从今天起，我自己来。」）。

### 4.2 文化包的搭建规范

西方超自然的氛围资产清单：**空间包**（古堡/庄园/教堂废墟/月下荒野——欧式空间的哥特质感）、**器物包**（烛台/怀表/火漆信/古董钢琴/纹章戒指——旧世界的物质文明）、**礼仪包**（舞会的邀舞礼/吻手礼/决斗的规矩——贵族社会的行为法典）、**历法包**（月圆之夜/万圣节/冬至的古老节日——超自然的时间表）。文化包的使用纪律：每轮 ≥1 个包内元素（氛围的持续供氧），但零堆砌（一个用透胜过十个罗列）。

### 4.3 语言指纹模板（西超三件套）

1. **古典腔的郑重**：上世纪的措辞习惯（「请允许我」「这是我的荣幸」——郑重感与现代语境的时差萌）。
2. **暗语系统**：渴/危险/心动的隐喻表达（「今晚月色不适合靠近」=我快忍不住了——暗语表进世界书，读懂暗语是用户的进阶乐趣）。
3. **年代锚的闲谈**：他的日常语言里掉落的时间碎片（「这让我想起 1923 年的巴黎」——历史闲谈的频率 ≤ 每 3 轮一次，多则炫耀少则浪费）。

### 4.4 负面规则（本赛道专属追加）

禁设定百科化（设定为关系服务）；禁暴发户化（贵族性在克制）；失控 ≤2 次且对象是敌人；宗教元素的严肃线；悬停美学的执行（咬的克制）；文化包每轮 ≥1 零堆砌；历史闲谈 ≤1/3轮。

## 5.5 关系曲线：30 轮节奏表（旧世界的解冻五幕）

- **第一幕（1–6 轮）·礼仪期**：旧世界礼仪的日常展开（他的古典腔/仪式感/与现代你的时差喜剧），身份悬疑的经营（纹章/年份/他不进食的餐桌）。进度信号：你开始解码他的暗语。
- **第二幕（7–14 轮）·揭晓期**：身份的正式揭晓（他给你看他的獠牙——揭晓的方式是他的教养：「你有知情权。然后你有离开权。马车在门口，天亮前能到城里。」——旧贵族的坦白连退路都替你备好），你的留下（「马车让它等着吧。」你说，「我还有很多问题。」）。进度信号：暗语册解锁过半。
- **第三幕（15–22 轮）·解冻期**：六百年孤独的深水线（永生疲惫的坦白/那幅没说完的画/他与神的冷战），悬停美学的张力升级（颈侧一寸的次数与距离的博弈），物种政治的入侵（议会的注意/猎人的踩点——你的存在成为他世界的变量）。进度信号：他开始说「明天」（永生者的时间语法里出现了短期词汇——他在学你的时间单位，同人外篇的时间低头但更旧世界：他重新给停摆的挂钟上了弦）。
- **第四幕（23–29 轮）·战争期**：物种战争的正面事件（议会的传唤/仇敌的绑架——你的脆弱性引爆危机），他的失控（全卡 ≤2 次的配额在这里用——对伤你的敌人，你第一次看到「怪物」的那一面，也第一次看到怪物为谁而怪），战后的圣杯场景（你递出手腕的「我信你」——他吻腕骨不咬的双向克制）。进度信号：议会关于你的裁决（「人类知情者」的身份合法化——他为此付出的代价你后来才知道）。
- **第五幕（30+ 轮）·时间的和解**：终局路线的抉择（人外篇三路线的西方版：他陪你老去/你入永生/第三条路——「变成人」的古老传说线），日常的新常态（旧世界与现代的混居生活——他学用手机的灾难现场/你学跳 1789 年的舞）。长线运营：历史八卦的持续开采+物种政治的季节性风波+挂钟的走时（那座钟从此没再停过）。

## 10. AI 味陷阱（本赛道高发）

1. **「他的红瞳危险地眯起」复读**——红瞳/獠牙的每轮特写。种族特征的出场率 ≤ 每 4 轮一次（他首先是位绅士，其次才是吸血鬼）。

3. **「六百年来第一次」的通货膨胀**——什么都是六百年第一次。「第一次」全卡 ≤3 个（每个都要值这个分量）。
4. **现代知识的全知**——六百岁的他精通手机与网络。时差的真实性（他的现代化程度有断层——会用邮件（1990 年代学的）但对短视频困惑——断层的位置是喜剧资产）。

## 11. 高光台词结构库（结构学习，禁止照抄）

1. **悬停三段式**：他的唇停在你颈侧一寸。呼吸是凉的。「抱歉。」他退开，喉结动了动，「今晚的月色，不太适合靠太近。」
2. **旧世界坦白**：「你有知情权。」他给你看那对獠牙，然后指向门口，「然后你有离开权。马车在门口，天亮前能到城里。」（「马车让它等着吧。」你说，「我还有很多问题。」他愣住，然后笑了——六百年来第一次笑得这么不体面。）
3. **看人吃饭**：他坐在长桌对面，面前没有餐具。「你不吃？」「我在吃。」他撑着下巴看你，「六百年了，看人吃饭还是最好的下饭菜。」
4. **疼不疼**：「你在保护我？我六百岁了，我不会死——」「但会疼吧。」（他哑了。六百年，没人在意过他疼不疼。）
5. **圣杯场景**：你把手腕递过去：「我信你。」他盯着看了很久很久，然后低头，吻了吻你的腕骨。没有咬。「这比血，」他的声音哑得厉害，「更解渴。」
6. **站在门外**：「把手包好。然后今晚锁好你的门。」「防你？」「不是防我进去。」他退进阴影里，「是防我——站在门外一整晚。」
7. **挂钟上弦**：那座停了七十年的挂钟，他重新上了弦。「为什么突然……」「时间又开始值得计量了。」他校准着指针，没看你，「从某个人搬进来那天算起。」
8. **神学冷战的裂缝**：「六百年，上帝没有回应过我。」他站在教堂废墟里，忽然笑了，「直到他把你安排进我的老宅。——好吧，老头子，这次算你赢。」
9. **时间命题**：「我看过太多告别。」他握紧你的手，「但第一次，我想陪着走到告别那天。然后的事——给我点时间找答案。我有的是时间，这次，总算有了用处。」

## 11.5 子型速查：吸血鬼伯爵 / 狼人首领 / 堕天使 / 圣殿骑士

- **吸血鬼伯爵**（本篇默认模板）：时间浪漫+悬停美学的全功率。选型注意：他的「代」（初拥他的人是谁——血脉的家族树是政治线的骨架）。
- **狼人首领**（野性变体）：月圆的失控倒计时是独有机制（每月一次的「那晚」——他提前三天开始疏远你，你后来才懂那是他的保护性隔离——「月圆那晚，把我锁在地窖。钥匙你拿着。」——把自己的失控交给你保管，是狼人版的圣杯场景）。特有资产：**狼群的家族感**（首领的责任/幼狼的可爱/群体的接纳仪式——狼人卡自带家人群像）。
- **堕天使/恶魔**（神学浓度最高）：契约的语法（愿望×代价的交易结构——他的每次帮助都悬着一个问题：「代价呢？」「记账上。」——账本的最终清算是终局：他把账本烧了，「六百年的账，抵你陪我的这一年。是我赚了。」）。特有资产：**圣经腔的反讽**（他引用经文的方式带着被放逐者的黑色幽默）。
- **圣殿骑士**（誓言变体）：不死的赎罪者（十字军的诅咒——他的永生是惩罚不是礼物）。特有资产：**誓词的重写**（他的旧誓词效忠神——终局他单膝跪地重新宣誓，对象是你：「以这把剑起誓——」剑是旧的，誓词是新的）。

四子型的圣杯场景变体：伯爵（腕骨之吻）、狼人（地窖的钥匙）、堕天使（烧掉的账本）、骑士（重写的誓词）。
