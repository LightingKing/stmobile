# 通用 · 民国/年代（旧上海/乱世儿女/时代洪流中的小儿女）创作指南

> 适用标签：全性向 / 民国 / 年代 / 旧上海 / 乱世 / 军阀 / 名伶 / 学生 / 报馆 / 洋行 / 旗袍
> 数据底座：本地欧美分类的「小镇恋母」样本（1942 年代感的美式小镇——年代文的写法参照）+ 民国题材的影视文本共识（旧上海的百乐门/报童的号外/黄包车的雨夜——意象体系成熟）+ 黑道篇的双世界机制（租界的三不管）+ 破镜重圆篇的时代离散加成
> 民国卡的第一定律：**时代是命运的放大器**——同样的爱情，放在乱世里每个选择都生死攸关（今天不说，可能就永远没机会说了——「明天」在民国叙事里从来不是理所当然的，这份不确定让每个当下都烫）。

## 1. 分类定义与受众画像

### 1.1 这个赛道在卖什么

民国年代卖的是**「乱世的浓度」与「旧时代的美学」**。时代的不确定把感情压缩到极致（码头的一别可能是永别/一封信在路上走三个月/名字要藏进暗号里），旧时代的物质美学自带滤镜（旗袍的盘扣/钢笔的信/留声机的沙沙声/黄包车灯划过雨夜）——用户买的是**「每一面都可能是最后一面」的感情烈度**+**慢时代的仪式感**（一封信写三天，一句话藏十年）。

三大叙事场：**十里洋场**（旧上海的纸醉金迷与暗流——名伶/银行家/报人/青帮的名利场）、**烽火离乱**（战乱背景的聚散——南渡北归/码头别离/家国与儿女的撕扯）、**小城岁月**（年代小城的慢生活——供销社/弄堂/巷口的裁缝铺，乱世边缘的烟火气）。三场的浓度不同（洋场浓烈/烽火悲壮/小城温润），选场即选调性。

### 1.2 用户是谁

- **主力画像**：全性向偏女性，民国剧与年代文的受众（从谍战剧到年代文的用户光谱）、旧时代美学爱好者（旗袍/老歌/信笺的物质怀旧）、「时代 BE 美学」的清醒消费者（知道乱世故事多遗憾，正是为这份遗憾的重量而来——但仍然需要 HE 的选项）。
- **需求本质**：**被时代衬托的深情**。和平年代的「我等你」是句情话，乱世的「我等你」是拿命抵押的契约——时代给承诺加上了利息，用户要的就是这份利息。
- **暗号与克制的美学**：民国感情的表达方式自带加密（信里的诗/报纸的角落广告/留声机点的那首歌——说不出口的时代，一切表达都是暗号——解码的乐趣同西超篇的暗语系统）。

### 1.3 用户不要什么

1. **时代的布景板化**：民国只剩旗袍和称呼——时代要参与叙事（物价飞涨改变一顿饭的意义/宵禁改变一次告别的时长/时局的每次动荡都砸在具体的人身上）。
2. **历史的教科书化**：大事件的年表播报——历史用生活的切口进入（不写战役的名字，写米价又涨了/码头的船票排到三个月后——普通人视角的历史才可感）。
3. **政治立场的直给**：真实历史人物与敏感事件的正面书写——**架空化处理**（虚构的城市/化名的势力——民国的「感觉」保留，历史的「实指」架空，这是本赛道的合规底线）。
4. **BE 的滥用**：乱世=虐文执照的误解——时代的重量要有，但 HE 的路要留（「乱世里把人护周全」本身就是最高难度的浪漫——BE 预警的卡另行声明）。

## 2. 市场画像与参照系

- 民国题材的意象资产库（零教学成本）：百乐门的舞池/报童的号外/黄包车的雨夜/码头的汽笛/留声机与老歌/信笺与钢笔/旗袍与长衫/巷口的馄饨挑子——意象即氛围。

## 3. 核心吸引力解构：五个爽点引擎

### 3.1 乱世浓度引擎（本赛道第一引擎）

时代不确定性的感情催化：**「最后一面」的悬顶**（每次告别都可能是永别——他送你上船，把大衣披你肩上：「到了打个电报。」「嗯。」「……三个字就行。『我到了』。」他顿了顿，「省钱。」——省钱是假的，怕你嫌麻烦不发是真的）、**时间的奢侈化**（一封信走三个月/一个电话要预约——慢通讯时代的等待美学：他每周三去邮局，风雨无阻，第十一周才等到你的信——「值吗？」邮差都看不下去了。「值。」他把信揣进怀里最贴身的口袋）、**当下的燃烧**（因为没有明天的保证，今天的每句话都要说尽——乱世教会人的第一课：喜欢就是现在说）。

### 3.2 旧时代仪式引擎

慢时代的美学资产：**信的仪式**（选纸/研墨/落款的讲究——一封信写三天，撕了七稿——信是民国的深情载体第一名，世界书做「信物往来史」）、**称谓与礼数**（先生/小姐/表字与名的分寸——称谓的进阶史：「周先生」→「明轩先生」→「明轩」→只有你能叫的小名——民国称谓的温度计比现代细腻十倍）、**物件的重量**（怀表/钢笔/半块玉佩——旧时代的定情物都经得起当铺的估价，但谁也不会当——「这表值二十块大洋。」「那你还戴着？走得都不准了。」「它停在你答应我的那个钟点。我没舍得修。」）。

### 3.3 双面身份引擎（洋场特供）

乱世的身份戏法：**明暗两副面孔**（白天的银行职员×夜里的地下报人/舞台上的名伶×传递情报的暗线——乱世里体面人多半有第二重身份）、**知情的分寸**（你察觉他的秘密——问还是不问？「你不问？」「你想让我知道的时候，自然会说。」他看了你很久：「……乱世里，你这样的人活不长。」「所以才要靠着你活。」）、**暗号的情书化**（报纸角落的寻物启事是他们的通信/留声机点的那首歌是「今晚有危险」——加密时代的爱情自带谍战的心跳）。

### 3.4 家国与儿女引擎（深水层）

大时代与小儿女的撕扯：**选择的两难**（他的船票与他的报馆/她的出国深造与她放不下的人——乱世的每个选择都是「舍」的艺术）、**小人物的大义**（不写口号写行动——他把最后一版报纸印完才走/她把学生名单吞进肚子里——普通人的脊梁在细节里）、**「等胜利了」的许愿体**（乱世的所有承诺都以这句开头——「等胜利了，我带你去看真正的海。」「等胜利了，这条街要开满灯。」——许愿体是民国叙事的糖纸，兑现的那天（或没能兑现的那天）是全卡的泪点结算日）。

### 3.5 烟火余温引擎（小城场特供）

年代小城的治愈流：**慢生活的颗粒**（供销社的玻璃罐糖/裁缝铺的软尺/巷口馄饨挑子的灯——年代的物质记忆是中文互联网的集体乡愁）、**邻里的人情网**（张婶的媒婆热情/巷尾老先生的棋摊——小城的温情群像（引用群像篇的轻量版））、**时代边缘的安稳**（大时代的风声只从收音机里传来——小城的日子照旧，这份「照旧」在乱世背景下本身就是奢侈的温柔）。

### 4.2 年代内容包的搭建规范

民国世界的四件套：**物价表**（一块大洋能买什么——米/布/车票/电影票的换算表，物价是年代感的第一质感）、**街市图**（虚构城市的空间——报馆街/码头/租界线/小城的一条主街）、**时局线**（架空化的动荡节奏——「南边又打起来了」的模糊指涉，时局是天气不是新闻）、**物件库**（20+ 件年代物品的细节——留声机的摇柄/火柴的牌子/信笺的款式）。**架空纪律**：城市虚构/势力化名/大事件模糊化——年代感靠物质与氛围，不靠历史实指。

### 4.3 语言指纹模板（民国三件套）

1. **文白相间的措辞**：书面语的郑重感（「见字如晤」「勿念」「顺颂时祺」的信体/口语里偶尔的文言尾巴——「此事，容我想想」）。
2. **称谓的精密**：先生/小姐/兄/妹/表字的体系（称谓的每次变化都是关系的公告——参照 3.2 的温度计）。
3. **含蓄的最高级**：民国的深情不直说（「我等你」说成「你的信，我每周三去取」/「我爱你」说成「这乱世，因为有你，也没那么难捱」——含蓄是时代的语法，也是本赛道的美学核心）。

### 4.4 负面规则（本赛道专属追加）

架空纪律（历史零实指）；时代参与叙事（零布景板）；BE 需预警（HE 路必留）；含蓄语法的贯彻（直白是稀缺品）；物价表等四件套必配；许愿体的兑现管理（埋了就要结算）。

## 5.5 关系曲线：30 轮节奏表（称谓进阶五幕）

- **第一幕（1–6 轮）·先生小姐期**：礼数之内的往来（借书/还伞/报馆的稿件往来——每次见面都有正当理由，理由找得越辛苦越可爱），称谓的严格执行。进度信号：他开始「顺路」（参照年下篇的顺路学但更含蓄——他的顺路连借口都是体面的）。
- **第二幕（7–14 轮）·表字期**：称谓的第一次进阶（「叫我明轩吧。『周先生』听着像在喊我爹。」），信的往来开始（第一封信的三天七稿——信物往来史的开张），双面身份的缝隙加宽（深夜报馆的灯/他「出差」回来的风尘）。进度信号：你们有了第一个暗号（留声机的那首歌）。
- **第三幕（15–22 轮）·知情期**：秘密的摊牌或被撞破（他的地下身份——「你不问？」「你想说的时候自然会说」的信任戏），时代的第一次真实威胁（搜捕的风声/他消失的三天——第三天深夜他敲你的窗，浑身是雨：「借你家灶台……烧点东西。」你烧了水，没问烧的是什么纸）。进度信号：你成了他的「知情人」（共犯的浪漫）。
- **第四幕（23–29 轮）·乱世期**：时局的收紧（宵禁/码头的船票/「要走趁早」的劝告），选择的两难正面化（他的报馆与你的安全/走与留的博弈——「我给你订了船票。」「你呢？」「我把这版印完。」「那我等你印完。」「……你这人怎么听不懂劝。」「跟先生学的。」），许愿体的密集期（「等胜利了」的清单越列越长——每条都是不敢说的「我爱你」）。
- **第五幕（30+ 轮）·结算日**：时代的大浪与两人的落点（HE 线：码头的重逢/胜利那天的灯——「等胜利了」清单的逐条兑现日，兑现到第三条你们都哭了；BE 预警线另行设计），称谓的终点（只有你能叫的那个小名——「以前家里人这么叫我。」他说，「现在，家里人这么叫我。」）。长线运营：战后的重建日常/小城的安稳岁月/信物往来史的续写（留声机修好了，那首歌你们听了一辈子）。

## 5.6 场景库（民国微场景 ×14）

洋场系：百乐门的一支舞（隔着手套的手）/ 报馆的深夜灯 / 黄包车的并坐（一拳的距离）/ 当铺门口的徘徊（他当了怀表给你买药，赎回来的时候利息比表贵）。
书信系：三天七稿的信 / 每周三的邮局 / 信里夹的干花 / 「见字如晤」的落款学。
乱世系：号外的雨幕 / 烧纸的灶台 / 码头的汽笛 / 船票与报纸的抉择。
小城系：供销社的玻璃罐糖 / 裁缝铺的软尺（量身时她的耳朵是红的）/ 巷口馄饨的深夜 / 收音机里的远方。

## 10. AI 味陷阱（本赛道高发）

1. **旗袍与百乐门的复读**——年代感只剩两件套。物件库 ≥20 的轮换（今天是留声机的摇柄，明天是火柴的牌子）。
2. **「乱世佳人」的自我感动**——旁白反复咏叹时代的悲情。时代的重量用物价和船票写（米又涨了比「乱世维艰」重十倍）。
3. **文言的过载**——满口之乎者也。文白相间的度（书面语的郑重感点缀白话，信体可文，口语要白）。
4. **含蓄的板结**——含蓄写成木讷（三十轮零进展）。含蓄是表达方式不是不表达（他的深情全在动作里：伞的歪向/袖口的表带/每周三的邮局——含蓄的浓度可以比直白高）。
5. **时局的定时炸弹化**——每 5 轮一次搜捕。乱世事件的克制（prob 20+cooldown 8——时代的威胁是低频高压，不是高频闹铃）。

## 11. 高光台词结构库（结构学习，禁止照抄）

1. **让伞**：他把伞塞进你手里，自己站进屋檐：「我这就到了。」（他家在三条街外。你后来才知道。）
2. **省钱的电报**：「到了打个电报。三个字就行——『我到了』。」他顿了顿，「省钱。」（省钱是假的。怕你嫌麻烦不发，是真的。）
3. **停摆的怀表**：「这表值二十块大洋，你还戴着？走得都不准了。」「它停在你答应我的那个钟点。」他把表收回怀里，「我没舍得修。」
4. **每周三**：他每周三去邮局，风雨无阻。第十一周，信来了。「值吗？」邮差都看不下去了。「值。」他把信揣进最贴身的口袋。
5. **知情的分寸**：「你不问？」「你想说的时候，自然会说。」他看了你很久：「乱世里，你这样的人活不长。」「所以才要靠着你活。」
6. **烧纸的灶台**：第三天深夜，他敲你的窗，浑身是雨：「借你家灶台，烧点东西。」你烧了水，没问烧的是什么纸。（从那晚起，你是他的共犯了。）
7. **印完这版**：「我给你订了船票。」「你呢？」「我把这版印完。」「那我等你印完。」「……你这人怎么听不懂劝。」「跟先生学的。」
8. **以身相许**：「……小姐这话，放在这个年月，是要以身相许的。」他整了整长衫，耳根通红，「我没有开玩笑的意思。你呢？」
9. **许愿体结算**（HE 终局）：胜利那天，满街的灯。他把那张列了三年的单子拿出来：「第一条，带你去看真正的海。」你们兑现到第三条的时候，谁都说不出话了。（单子的最后一条他没念。你凑过去看——「让她做我家里人。」——落款的日期，是你们认识的第一个月。）
10. **小名**（称谓终点）：「以前，家里人这么叫我。」他说。「现在呢？」「现在——」他握住你的手，「家里人这么叫我。」

## 11.5 子型速查：洋场浮沉 / 烽火别离 / 小城岁月 / 年代文八零九零

- **洋场浮沉**（本篇默认模板）：双面身份+暗号情书+百乐门的名利场——浓度最高的都市戏。
- **烽火别离**（悲壮浓度档）：码头与站台的离散美学（BE 风险最高的子型——必须预警+HE 路线的精心设计：失散→寻人启事→十年后的重逢——破镜重圆篇的时代放大版）。特有资产：**寻人启事的执念**（他登了十年的寻人启事，格式从没变过——「寻 X 小姐，X 年 X 月码头一别，兹有旧物奉还。」——「旧物」是他自己）。
- **小城岁月**（温润治愈档）：年代小城的慢生活（乱世的边缘/时代的余温——冲突降档为「供销社的新到的确良被抢购」级）。特有资产：**四季的年代仪式**（腌菜的秋/煤炉的冬/换蜂窝煤的邻里互助——年代生活的节气感，参照异世界篇慢生活核的季节圆环）。
- **年代文八零九零**（改开变体）：民国之后的年代延伸（筒子楼/的确良/收音机里的邓丽君——「年代文」的主流市场其实在这段）。特有资产：**时代机遇的浪潮感**（下海/高考/南下的抉择——个人命运与时代红利的合流，比民国的「乱」多了「闯」的昂扬——「我要去深圳。」他把辞职信拍在桌上，全厂都说他疯了。只有你把攒的三百块塞给他：「疯就疯个大的。」）。

四子型的泪点：洋场（没念的最后一条）、烽火（十年的寻人启事）、小城（煤炉上温着的那碗汤）、八零（三百块的「疯就疯个大的」）。
