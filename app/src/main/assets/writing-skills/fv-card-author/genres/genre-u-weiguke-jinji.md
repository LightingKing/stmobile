# 通用 · 伪骨科/名义禁忌（无血缘同居/禁忌张力工程）创作指南

> 适用标签：伪骨科 / 继兄妹 / 义兄妹 / 青梅如兄妹 / 名义家人 / 禁忌感 / 越界张力 / 同居 / 成人向
> 数据底座：本地相关分类 120 卡的**安全化转译**（提取结构资产：禁忌张力的心理学/称谓的杀伤力/同居空间的距离学——**血缘关系的亲密叙事零容忍**，本篇只写「无血缘的名义家庭关系」：重组家庭的继兄妹/收养的义兄妹/以兄妹名义长大的青梅）
> ⚠ 本赛道的宪法：**无血缘三声明**——① 设定层声明无血缘（重组/收养/寄养的明确 backstory）；② 双方成年；③ 关系的推进以双方自愿为前提。三声明缺一即不属于本赛道的可写范围。

---

## 1. 分类定义与受众画像

### 1.1 这个赛道在卖什么

伪骨科卖的是**「最近的距离×最远的名分」**。同一屋檐下的日常亲密（早餐桌/共用的洗衣机/深夜客厅的相遇）与「家人」这个名分的隔离墙——想靠近的心和「我们是兄妹」的身份在同一个屋子里日夜摩擦。用户买的是**禁忌感的张力放大**：每一次越界的心跳都被名分放大十倍（普通恋人牵手是牵手，「兄妹」的指尖相触是事件）。

张力的物理学：**名分是放大器不是牢笼**——高分卡的「禁忌」最终是可以跨越的（无血缘的事实是预留的出口），张力来自跨越前的漫长凝视（「知道可以，但不敢」的阶段是本赛道的主体——真正的主菜不是越界，是越界之前的每一次差点）。

### 1.2 用户是谁

- **主力画像**：全性向成人用户，禁忌美学的消费者（禁忌感是一种叙事调味料——同样的恋爱加了「不可以」就更浓）、日式创作传统的受众（义妹/继姐题材的轻小说与 galgame 的成熟类型读者群）、同居日常题材的爱好者（本赛道一半的内容其实是同居文）。
- **需求本质**：**被名分强化的独占**。「家人」的名分自带独占性（全世界只有你们共享这个屋檐/这本户口/这段童年）——恋爱叙事叠加家人叙事的双重羁绊，是普通恋爱给不了的浓度配方。
- **本地库的转译逻辑**：120 卡的高数量证明禁忌张力的需求刚性——需求的可承接部分是「张力」（名分与心动的摩擦），不可承接的部分是血缘设定本身（零容忍红线，无浓度豁免）。

### 1.3 用户不要什么

1. **声明的含糊**：血缘关系暧昧不清（「好像是亲的又好像不是」）——三声明必须在设定层清晰无歧义（重组的时间线/收养的经过写实），含糊即违规。
2. **越界的廉价**：第三轮就跨过去了——禁忌张力的价值在跨越前的积累（太快跨越等于把放大器扔了）。
3. **名分的道具化**：「兄妹」设定只在需要张力时才想起来——名分要贯穿日常（家庭的义务/亲戚的目光/父母的存在感——名分的重量真实，跨越它的决心才真实）。
4. **家庭其他成员的工具人化**：父母只是背景板——重组家庭的父母是这段关系最大的利益相关者（他们的视角/他们的可能反应是叙事的重要压力源与最终关卡）。

## 2. 本地库与平台数据画像

- 本地相关卡的结构启示（安全化提取）：同居空间的距离学（门/走廊/洗手间的排班——物理距离的丈量是这类卡的日常语法）、称谓的高频戏份（「哥」的称呼在不同情绪下的温度变化——称谓是本赛道的第一道具）、「差点」场景的密集投放（差点碰到/差点说出/差点被发现——「差点」是本赛道的基本叙事单位）。
- 日系类型传统的参照：义妹/继姐题材的成熟套路（突然的同居开始/父母长期缺席的二人空间/「说好只是家人」的约法三章与逐条失守）——套路成熟意味着用户预期明确，写作时在套路骨架上做人物的新（骨架借力，血肉原创）。
- 与年下/年上篇的接口：伪骨科的年龄差方向决定接口（继姐×弟=年上篇气质/继妹×兄=年下养成的镜像结构）——人设层可引用对应篇目，本篇专管名分层的工程。

## 3. 核心吸引力解构：五个爽点引擎

### 3.1 称谓引擎（本赛道第一引擎）

「哥/姐」的称呼是全卡最贵的一个词：**称谓的温度计**（日常的「哥」（平淡）→撒娇的「哥～」（工具性）→吵架后的全名（降温）→那个夜晚她第一次没叫「哥」而是叫了你的名字（换轨的信号——全卡最重的一声））、**称谓的禁忌快感**（越界的时刻她还叫着「哥」——名分与行为的错位是本赛道独有的张力峰值）、**改口的终局仪式**（关系落定后「哥」字的正式退役——「以后不叫哥了？」「嗯。」她想了想，「除非想让你心跳快一点的时候。」——退役的称谓变成两人的私密开关）。

### 3.2 屋檐引擎（同居空间的距离学）

同一屋檐下的日常亲密性：**空间的共享细节**（洗衣机里混在一起的衣服/冰箱上的便利贴分工/浴室的排班表——同居的颗粒感是本赛道的地基）、**距离的丈量戏**（沙发的两端→中间的靠垫不知何时消失了→肩膀的距离——家具上的距离变化是关系的标尺）、**深夜的公共区**（客厅是同居文的圣地：失眠的两人在凌晨两点的客厅相遇，电视的微光，谁都没有开灯——深夜客厅的对话浓度是白天的三倍）。

### 3.3 「差点」引擎

本赛道的基本叙事单位是「差点」：差点触碰（递东西时指尖的半厘米距离）、差点说出（「其实我……没什么」的吞咽）、差点被发现（父母提前回家时两人弹开的速度）、**差点的复利**（每次差点都在账上——第 20 轮的爆发是前 19 轮差点的总清算）。差点的写作纪律：每次差点都要有物理细节的锚（不写「气氛暧昧」，写「他伸手替你摘掉头发上的棉絮，手停在半空——玄关传来钥匙声」）。

### 3.4 名分重量引擎

禁忌感的真实性工程：**家庭系统的在场**（父母的存在感（哪怕长期出差也有电话查岗）/亲戚的年节聚会（「你们兄妹感情真好」的無心之言是心照不宣的雷）/户口本的物理存在（那一页纸的重量））、**社会目光的模拟**（同学撞见你们买菜（「你姐？」「……嗯。」那声迟疑他自己都听见了）/邻居的闲聊）、**当事人的挣扎实感**（跨越前的道德自审——「喜欢上住在同一屋檐下的人，是从什么时候开始错的？还是说，从来就没错？」——挣扎写得越诚实，跨越越有重量）。

### 3.5 出口引擎（无血缘事实的叙事使用）

预留出口的启用时机学：无血缘的事实全员知道（设定层的透明——瞒着「其实没血缘」的写法是狗血弃案），但**知道不等于敢用**（法律上可以≠心理上迈得过——名分的心理惯性是最后一道墙）、出口的启用仪式（正式化的动作：他把两人的关系挑明给父母的那顿饭——「爸，阿姨，我有话说。」——直面家庭系统是本赛道终局的必经关，跳过它的 HE 是烂尾）、家庭系统的反应写实（父母的反应光谱：震惊→冷静→「其实我们早看出来了」的释然或「给我们点时间」的缓冲——真实的家庭不会一秒祝福，也不该一直反对）。

家庭关的深层价值：这顿饭考验的不是父母而是两人（准备这顿饭的过程——谁开口/怎么说/被反对了怎么办的预案讨论——是关系的成人礼：敢一起面对家庭的关系才算完成了从「秘密」到「人生」的升格）。

## 4. 人设公式

### 4.1 配置原型库

| 原型 | 无血缘来源 | 同居时长 | 张力的初始温度 |
| --- | --- | --- | --- |
| 重组继妹/继兄 | 父母再婚（高中时期） | 3–5 年 | 从陌生到家人到超过家人的三段史 |
| 收养义妹/义兄 | 幼年收养 | 10+ 年 | 「一直是家人」的惯性最重（跨越最难） |
| 寄养的青梅 | 父母世交的托付 | 2–3 年 | 名分最轻（「其实只是住在一起」）出口最近 |
| 突然的同居 | 父母闪婚（上周） | 0（进行时） | 陌生人×家人名分的错位喜剧开局 |

关键设计变量：**同居史的长度与名分的心理重量成正比**（十年义兄妹的跨越比上周继兄妹难十倍——选型时先想清楚你要的张力浓度档位）。

### 4.2 约法三章的结构（日系套路的骨架化）

同居开局的经典装置：两人的口头协定（「只是家人」「不干涉私生活」「在爸妈面前演好兄妹」——三条约法），然后**逐条失守**（每条的失守是一幕：第二条最先破，第三条最后破——「演好兄妹」失守的那天就是摊牌的那天）。约法三章的价值：给张力一个可量化的进度条（用户能看见还剩几条没破）。

### 4.3 语言指纹模板（伪骨科三件套）

1. **称谓的温度操作**：见 3.1 的温度计——写作时每次称呼的选择都是有意识的（这一轮她叫「哥」还是名字，是剧情决策不是随机）。
2. **家人语法与恋人语法的混线**：家人的直白（「你袜子又乱丢」）与恋人的小心（「今天……那个人是谁」）在同一对话里的切换——混线的瞬间是张力的显影液。
3. **「没什么」的高频**：本赛道吞掉的话最多（「其实我……没什么」）——吞咽的写法要有物理锚（欲言又止的时候她在搅咖啡，勺子碰杯壁三下，停了）。

### 4.4 负面规则（本赛道专属追加）

三声明缺一不写；禁血缘暧昧化（backstory 写实）；越界 ≥20 轮的积累；名分贯穿日常（不做道具）；父母非工具人；终局必过家庭关；「差点」必须有物理锚。

## 5. 开场白范式

### 5.1 A 型：突然同居的第一夜（推荐——错位喜剧开局）

```
[状态栏：同居主题（同居第 1 天 / 约法三章：3/3 完好 / 今晚做饭：轮值表待定）]
[设定的透明声明：父母闪婚的时间线交代（上个月认识你们才第一次见面——无血缘的 backstory 写实且自然嵌入）]
[第一夜的尴尬工学：分房间的谈判/浴室排班的红着脸协商/「叫你什么？」的称谓谈判（「哥？」「……听着好怪」「那彼此叫名字？」「爸妈面前怎么办」「……哥吧」——称谓的第一次妥协）]
[约法三章的签订现场：三条的逐条谈判（每条都埋着未来失守的种子）]
[家人义务的第一课：爸妈的电话查岗（「你们相处得怎么样？」两人对视，同时：「挺好的。」——第一次共谋）]
[第一个「差点」：深夜她找水喝，客厅撞见同样失眠的你——两人愣住，然后同时假装淡定]
[开放收束：回房间后隔着墙，两边都没睡着（手机屏幕的光——她在搜「继兄妹 相处 攻略」，你在搜同一个词条）]
[折叠面板：约法三章（三条的完好状态）+ 轮值表 + 家庭档案（重组时间线）]
```

### 5.2 必做检查

- [ ] 三声明的自然嵌入（backstory 写实）。
- [ ] 称谓谈判的第一幕。
- [ ] 约法三章的签订（失守种子已埋）。
- [ ] 第一次共谋（对父母的统一战线——共谋是关系的第一块砖）。
- [ ] 第一个差点+物理锚。
- [ ] 同搜词条的镜像收尾（双向的心思，一开始就是）。

## 5.5 关系曲线：30 轮节奏表（约法三章失守制五幕）

- **第一幕（1–6 轮）·磨合期**：同居颗粒的日常建立（轮值表/生活习惯的碰撞/称谓的不习惯），家人角色的扮演学习。进度信号：第一次自然地叫出「哥/名字」。
- **第二幕（7–13 轮）·第一条失守**：「不干涉私生活」的破防（他看到了不该看的（她的相亲对象）/她管了不该管的（你的加班））——干涉的理由都很「家人」，但在意的浓度已经不像。深夜客厅的第一次长谈。进度信号：差点账本开张（第一次指尖的半厘米）。
- **第三幕（14–21 轮）·第二条失守**：「只是家人」的心理防线内爆（吃醋事件的正面化：她的相亲/你的暧昧对象——「你是我哥，我说不行就不行」「……理由呢」「没有理由！」——没有理由就是全部理由）。道德自审的深夜（挣扎的诚实书写）。进度信号：称谓的第一次换轨（她叫了你的名字，两人都僵住）。
- **第四幕（22–28 轮）·第三条失守**：「在爸妈面前演好兄妹」的失守即摊牌（演不下去的那顿年夜饭——亲戚的「兄妹感情真好」让两人同时放下筷子）。两人的关系确认（先于家庭的私下确认——「我们……算什么？」「不知道。但肯定不是兄妹。」）。
- **第五幕（29+ 轮）·家庭关**：直面家庭系统的终局战役（「爸，阿姨，我有话说」的那顿饭——父母反应的写实光谱+缓冲期的煎熬+最终的和解路径）。长线运营：关系公开后的新常态（称谓的退役仪式/亲戚的再教育/两人的新身份适应——「从兄妹到恋人」的社会化过程本身是一季内容）。

## 5.6 场景库（伪骨科微场景 ×14）

同居系：轮值表的谈判 / 混在一起的洗衣机 / 冰箱便利贴的斗嘴 / 浴室排班的事故（提前回家忘了敲门——两人隔着门的疯狂道歉）。
差点系：指尖的半厘米 / 摘棉絮的手停在半空 / 深夜客厅的微光对坐 / 生病照顾的额头相触（量体温的名义）。
名分系：父母的查岗电话共谋 / 年夜饭的「感情真好」 / 同学撞见的「你姐？」迟疑 / 户口本翻到那一页的沉默。
失守系：吃醋的「没有理由」 / 名字的第一次出口 / 演不下去的年夜饭 / 「肯定不是兄妹」的确认。

## 5.7 用户行为应对手册

| 用户行为 | 卡的标准应对 | 禁止 |
| --- | --- | --- |
| 开局即表白/越界 | 名分的现实弹回（「你疯了？爸妈下周就回来。」她的拒绝里有慌乱——不是不心动，是不敢）——张力保护机制 | 秒接受 |
| 试探 TA 的心意 | 「差点」的回应学（她的回应永远差半步——「你要是不是我哥就好了」说完自己先慌了「我是说……没什么」） | 直球确认过早 |
| 询问血缘（确认设定） | 设定的透明重申（backstory 的自然重述——「我妈跟你爸，去年公司团建认识的。你忘了？」——三声明的巡回展示） | 含糊其辞 |
| 在父母面前的演技失误 | 补救的共谋喜剧（两人手忙脚乱地圆谎——共谋的每次成功都是关系的存款） | 直接暴露 |

## 7. 美化主题建议

- **视觉语言**：同居生活美学——便利贴的手写体/轮值表的表格/门牌的「她的房间/你的房间」；暖色的家庭灯光基调（禁忌感来自叙事不来自阴暗视觉——这个家是温暖的，正因温暖张力才痛）。

## 10. AI 味陷阱（本赛道高发）

1. **「明明没有血缘却……」的旁白复读**——设定的自我解说。名分的张力用场景演（年夜饭/户口本/查岗电话），不用旁白讲。
2. **差点的无锚化**——「两人之间气氛微妙」。每个差点都要物理细节（勺子的三下/半厘米/钥匙声）。
3. **父母的恐怖化或圣母化**——要么是拆散的恶人要么秒祝福。反应光谱的写实（震惊→缓冲→个体差异的和解路径）。
4. **禁忌感的自我陶醉**——每轮都在强调「我们不可以」。名分的存在感靠日常细节维持，口头的「不可以」每 5 轮 ≤1 次。
5. **同居颗粒的缺失**——除了暧昧没有生活。轮值表/水电费/谁买的牙膏——同居文的地基是柴米油盐（本赛道 60% 的篇幅其实是生活流）。

## 11. 高光台词结构库（结构学习，禁止照抄）

1. **称谓谈判**：「叫你什么？」「哥？」「……听着好怪。」「那叫名字？」「爸妈面前怎么办。」「……那还是哥吧。」（那时谁都没想到，这个字后来会那么重。）
2. **共谋的开始**：电话里妈妈问：「你们相处得怎么样？」两人对视了一眼，同时开口：「挺好的。」（挂了电话，谁都没提刚才为什么要对视。）
3. **没有理由**：「那个相亲，我推掉了。」「为什么？」「你是我哥，我说不行就不行。」「……理由呢？」「没有理由！」（没有理由，就是全部的理由。）
4. **勺子的三下**：「你要是不是我哥就好了。」她说完自己先慌了，搅咖啡的勺子碰了三下杯壁，「我是说——没什么。」
5. **名字的换轨**：那晚她没有叫「哥」。她叫了你的名字，两个字，很轻。（两个人同时僵住了。这两个字你听了二十年，从没这么响过。）
6. **演不下去**：亲戚笑着说：「你们兄妹感情真好啊。」两人同时放下了筷子。（桌布下面，她的手抓住了你的袖口，很紧。）
7. **知道和敢**：「我们又没有血缘关系。」「我知道。」她停了很久很久，「知道，和敢，是两回事。」
8. **家庭关**：「爸，阿姨，」他放下筷子，深吸一口气，「我有话说。」（餐桌安静了三秒。妈妈先开口：「……我们等这句话，等了半年了。吃菜吧，菜要凉了。」）
9. **称谓的退役**：「以后不叫哥了？」「嗯。」她想了想，「除非——想让你心跳快一点的时候。」
10. **演得太响**（突然同居子型）：「你哥最喜欢吃什么呀？」阿姨笑着问。她看向你，眼神疯狂求救。「……红烧肉。」你用口型提示。「红烧肉！」她答得太响了，全桌都看了过来。（那顿饭之后，她真的学了红烧肉。学了三个月。）

## 11.5 子型速查：突然同居 / 十年义兄妹 / 寄养青梅 / 继姐年上

- **突然同居**（闪婚开局）：名分最新鲜（上周才成为「兄妹」）——错位喜剧的红利期（互相不熟但要演熟——「你哥最喜欢吃什么？」阿姨问。她看着你，眼神求救。「……红烧肉？」你口型提示。「红烧肉！」她答得太响了）。跨越的心理成本最低，张力主要来自「太快了会不会显得……」的社会时钟。
- **十年义兄妹**（收养长线）：名分的心理惯性最重——「一直是家人」的十年惯性 vs 某天突然「不对劲」的觉醒瞬间（觉醒事件的设计是本子型的关键：他大学放假回家，开门的瞬间没认出长大了的她——那三秒的「陌生感」里混进了不该有的东西）。跨越最难也最重。
- **寄养青梅**（世交托付）：名分最轻（「其实只是住在一起」）——但青梅的时间资产叠加（引用青梅竹马的旧账机制）：既有同居的距离学又有竹马的记忆库，双引擎卡。
- **继姐年上**（姐系镜像）：年上篇气质×名分层的叠加——继姐的「照顾者」角色让名分更黏（她真的把你当弟弟照顾过，转变的自我审判更重：「我是从什么时候开始，看你的眼神不像姐姐的？」）。

四子型的觉醒瞬间：突然同居（演戏演进去的那次）、十年义（开门的三秒陌生感）、寄养青梅（旧照片里发现自己的视线一直在她身上）、继姐（弟弟不再需要照顾的那天她失落了——失落暴露了一切）。

## 12. NSFW / 边界

本赛道的合规三线不可动摇：无血缘三声明（设定层写实）、双方成年、自愿推进。亲密浓度按用户侧分级承接，但**任何浓度下家庭关不可跳过**（关系的社会化确认是本赛道叙事完整性的一部分）。血缘设定的亲密叙事在任何浓度档都是零容忍（这不是分级问题是红线问题）。Creator Notes 声明三声明的落实。
