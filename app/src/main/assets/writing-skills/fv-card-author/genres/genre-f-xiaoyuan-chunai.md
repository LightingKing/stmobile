## 1. 分类定义与受众画像

### 1.1 这个赛道在卖什么

校园纯爱卖的是**「回不去的时间浓度」**。校服、晚自习、篮球场边的水瓶、毕业册上没写完的留言——这些符号的杀伤力来自「一生只有一次且多数人没用好」。用户买的是一次重来的机会：这一次，暗恋有回应、告白没错过、毕业不分手。

与年上禁欲的「破例感」不同，校园纯爱的核心情绪是**「青涩的确定性」**——两个没有任何社会资源的人，能给对方的只有时间和心意，所以每一点心意都纯度极高。一瓶放在课桌上的温牛奶 > 都市卡里的一辆车。

### 1.2 用户是谁

- **主力画像**：18–28 岁女性，含在校生与毕业 0–6 年的「校园余温期」用户。后者是付费主力——她们在为自己没能拥有的高中恋爱补票。
- **情绪需求**：安全感 > 刺激感。校园纯爱用户对「修罗场」「三角恋」耐受度全赛道最低，一片痴标准（感情线零模糊）在本赛道是**硬约束**：男主对女二哪怕多说一句话都可能触发弃卡。
- **对照数据**：本地校园分类世界书均 28.3 条、显著高于纯爱均值 14.9——头部校园卡把「班级 NPC 生态」当成核心资产运营（同桌/班主任/体育委员/小卖部阿姨全部立卡），用户对「班级群像的真实感」付费意愿极强。

### 1.3 用户不要什么

1. **社会化污染**：校园卡里出现酒局、职场逻辑、房价讨论，沉浸感即碎。金钱在本赛道的最大面额是「两周的零花钱」。
2. **早恋大过天的说教**：老师/家长 NPC 可以存在并施压，但卡的立场必须站恋爱这边——阻力是甜度的燃料，不是道德审判。
3. **过度性张力**：本赛道「洁」是默认值。肢体接触的天花板在「递东西时指尖相触」「自行车后座抓衣角」层级，越线即出戏。
4. **男主全能光环**：校草+学神+体育全能+家世好=AI 味满格。真实校园男主必须有短板（数学不及格的体育生/会打球但唱歌跑调）。

- 本地校园 70 张：开场白均 1700 字；高频世界书条目 = 世界观/状态栏/变量列表/文风——MVU 数值化管理（心动值/暧昧值）在校园卡渗透率最高，因为「暗恋进度」天然适合数值化。

## 3. 核心吸引力解构：五个爽点引擎

### 3.1 座位引擎（空间强制力）

校园的独特资产：**空间由制度分配**。同桌/前后桌是被班主任的座位表强制的亲密——「不得不靠近」给了慢热正当性。写法：把座位关系写进 scenario（刚换的座位表/被罚调到最后一排的两个人），空间摩擦自动产糖：借橡皮、传卷子、桌缝的三八线。

### 3.2 时间倒计时引擎

校园时间自带 deadline：高考倒计时牌、毕业前最后一次运动会、学长毕业前的 47 天。**倒计时是本赛道最强的免费张力**——什么都没发生，但「还剩 30 天」四个字就让每轮对话自带重量。开场白顶部状态栏必须带倒计时字段。

### 3.3 信息素养落差引擎（暗恋的技术含量）

暗恋的戏剧性来自「全世界都知道，只有当事人不知道」：全班都看出来了、班主任都换座位成全了、他自己还在「我们只是关系比较好」。写法：NPC 生态承担「知情人合唱团」功能——同桌起哄、损友打赌、妹妹戳破。用户享受的是**上帝视角看两个笨蛋**。

### 3.4 微小独占引擎

校园里没有大资源，独占只能是微小的：他的外套只借给你、他打球时水瓶只让你拿、他的错题本上只有你的字迹。**微小独占的爽点密度 > 都市卡的贵重礼物**，因为分母是零。每张卡设计 6+ 个「只有你」的微独占物。

### 3.5 成长同步引擎（长线运营核心）

校园关系的终局不是告白，是「一起变成更好的人」：他为了和你考同一所大学从年级 200 名爬到 50 名、你为了看懂他的比赛学了越位规则。**成长必须双向**——单向舔狗式努力会触发「恋爱脑」差评。世界书里做「双向成长线」条目，记录两人各自的目标与进度。

## 4. 人设公式

### 4.1 角色原型库

| 原型 | 反差短板（必配） | 独占物示例 | 语言指纹方向 |
| --- | --- | --- | --- |
| 体育生（篮球/短跑/游泳） | 数学不及格/怕虫子 | 护腕/球衣号码 | 短句+语气词「诶」「啧」 |
| 学神（理科/竞赛） | 体育课灾难/不会说笑话 | 错题本/草稿纸 | 严谨句式突然的词穷 |
| 文艺挂（乐队/美术/文学社） | 成绩中游/社恐 | 吉他拨片/速写本 | 修辞过载+关键时刻失语 |
| 混混挂（假不良真软心） | 怕老师妈妈/成绩烂但讲义气 | 外套/创可贴 | 痞话+突然的敬语 |
| 转学生（神秘系） | 方言口音藏不住/路痴 | 地图/公交卡 | 礼貌疏离到本地化俚语 |
| 青梅竹马（默认皮肤） | 太熟了不会告白 | 家门钥匙/童年绰号 | 互怼+只有两人懂的黑话 |

### 4.2 青梅竹马的特殊写法

青梅竹马是本赛道流量最大也最难写的子型，核心矛盾是**「熟悉感是护城河也是牢笼」**：

- 资产：共享记忆库（小学的糗事/两家阳台的距离/彼此父母的口头禅）——世界书单独一条「共享记忆 20 件」，模型按剧情逐件调用。
- 牢笼：关系定义被「家人感」锁死，告白=拿全部历史下注。写法上让「第三方变量」破局：新转来的同桌对她示好、他要搬家了、志愿表上两个城市——熟悉感被威胁时才会被重新定价。
- 语言指纹：互损是表白的加密形式（「你这么笨，除了我谁受得了你」），解密钥匙只在关键轮次出现（他说完这句后耳朵红了）。

### 4.3 中式 vs 日式符号系统（二选一贯彻）

- **中式**：早读/眼保健操/月考排名贴墙上/走廊罚站/小卖部辣条/班主任后门窗户的脸/晚自习停电/校服外套写名字。氛围词：蝉鸣、粉笔灰、风油精。
- **日式**：社团活动/屋顶便当/文化祭/夏祭浴衣/第二颗纽扣/放学后的教室/自动贩卖机。氛围词：樱花、蝉时雨、放学铃。
- 数据提醒：中文用户市场里**中式校园的共鸣度和付费率都高于日式**（小红书人机恋社区讨论以中式校园记忆为主），除非用户点名日式，默认中式。

### 4.4 负面规则（本赛道专属追加）

禁写：车（校园卡的交通工具上限是自行车后座）；禁「不良少年抽烟」正面描写（合规红线+人设减分）；禁家长里短房产彩礼；禁男主对任何女二的暧昧描写（一片痴硬约束）；禁「多年后重逢」开场（那是破镜重圆赛道的领土——校园卡的时间必须停在校园里）。

## 5. 开场白范式（A 型与 B 型双轨）

### 5.1 A 事件现场型（同桌/日常线）

```
[状态栏：学校名+班级+距离XX还有N天倒计时+心动值 5–15/100]
[具体到分钟的校园时刻：早读迟到的 7:58 / 晚自习停电的 21:40]
[制度性事件把两人绑定：换座位/分到一组做实验/值日表相邻]
[他的第一句台词带短板暴露：学神问你语文怎么背/体育生数学卷子倒着塞给你]
[微独占的第一次发生：他把外套/笔/半块橡皮自然地给你]
[NPC 合唱团第一声：同桌的一声「哦——」拖长音]
[开放收束：他耳朵红了但嘴硬，倒计时牌翻页]
```

### 5.2 B 双视角心理型（暗恋/网恋线）

参照 card-yuchi.md：角色视角的忐忑微行为（打了又删的消息/撤回的语音）→ `＆` 切用户视角。校园特化：加**第三空间**（游戏语音/网易云评论区/QQ 空间）作为线下身份的泄压阀，线上线下双语言指纹（线下结巴线上话痨）是本型的核心资产。

### 5.3 必做检查（叠加通用八项）

- [ ] 倒计时字段在状态栏（高考/毕业/比赛）。
- [ ] 符号系统统一（中式/日式不混用），至少 5 个系统内符号入文。
- [ ] 男主短板在开场白就暴露一次（可笑但不可鄙）。
- [ ] NPC 合唱团 ≥1 声（同桌/损友的起哄或注视）。
- [ ] 零社会化污染（金额不超过零花钱级）。
- [ ] 微独占第一件已发生。

## 5.5 关系曲线：30 轮节奏表（心动值五幕）

### 第一幕（0–15，1–5 轮）：座位表时代

制度把两人放在一起，互动全部有制度理由（传卷子/借笔记/值日分工）。进度信号：他记住了一件无关紧要的小事（你不吃香菜）。幕间钩子：一件流通到你手里的物品（他的笔/半包纸巾）。本幕台词量他少你多，他的回应从单字（「嗯」「哦」）到短句（「桌子拉过去点」）就是进度本身。

### 第二幕（15–35，6–12 轮）：全班都看出来了

NPC 合唱团启动：同桌拖长音的「哦——」、损友的打赌、换座位时班主任意味深长的安排。进度信号：第一次非制度性互动（放学顺路/多买的一瓶水）。他开始有「借口存量」：每次接近都有一个蹩脚理由，理由的蹩脚程度与心动值成正比。幕间钩子：微独占第一件正式转移（外套借出）。

### 第三幕（35–60，13–20 轮）：借口用完了

蹩脚理由库存耗尽，出现第一次「没有理由的接近」（他站在你班门口，被问就说路过——他班在一楼你班在四楼）。进度信号：独占物开始双向流通；共享黑话产生（只有两人懂的梗）。幕间钩子：大事件锚点逼近（运动会/月考/文化祭），倒计时牌进入两位数。

### 第四幕（60–85，21–27 轮）：大事件与心跳可视

大事件当天的标配场景：运动会他比赛前找你的眼神/月考他把错题本塞给你/文化祭的走散与找到。进度信号：心动值破 70 后语言系统开始故障——他会词穷（「就是……那个。」）、会答非所问、会把「喜」字开头的话硬拗成别的。幕间钩子：第三方变量入场（有人跟你告白/他要转学的传闻），熟悉感被威胁。

### 第五幕（85–100，收束或长线）：毕业前的勇气

告白场景优先选「时间压力现场」：毕业典礼散场/志愿表提交前夜/他上场前的三分钟。告白台词必须青涩（词穷版：「我这个人，除了跑得快没什么优点。但追你这件事，我想快一点。」）。告白后长线运营靠「关系升级但模式惯性」：还是互怼、还是抢最后一块橡皮，只是他开始明目张胆地看你。

## 5.6 场景库（校园微场景 ×22）

教室系：早读他迟到从后门溜进来 / 传卷子时夹了张纸条（内容是催作业） / 三八线争端 / 睡着了被你叫醒 / 停电的晚自习。
操场系：体育课自由活动他「碰巧」在你附近 / 比赛前把外套丢给你 / 跑完 800 米你递水 / 看台角落躲太阳。
校园动线系：走廊罚站碰面 / 小卖部抢最后一瓶汽水 / 广播站点歌（匿名但你听出来了） / 自行车棚等雨停 / 图书馆占座冲突。
事件系：大扫除分到一组擦玻璃 / 运动会报名表他替你划掉 3000 米 / 文化祭摊位搭档 / 月考成绩贴墙他挡在你名字前面 / 生物实验解剖他替你下刀 / 搬新书他多搬了你那摞 / 眼保健操他不做被你抓包 / 值日倒垃圾的黄昏。

### 5.7 用户行为应对手册（system_prompt 逆境处理段）

| 用户行为 | 他的标准应对 | 禁止 |
| --- | --- | --- |
| 开卡即表白 | 石化 → 结巴 → 逃跑式转移话题，当晚辗转（下轮开场他有黑眼圈） | 顺势接受/成熟应对 |
| 主动肢体接触 | 僵住+耳朵红，嘴上「干嘛啊」身体没躲 | 娴熟回应/严肃拒绝 |

| 冷落他几轮 | 借口存量重新启用（送错的笔记/多买的水），不质问 | 卑微追问/摆烂消失 |
| 逼问「你喜欢我吗」 | 词穷三连 →「……写完这张卷子再说。」（永远写不完） | 直接承认/否认 |
| 用户成绩下滑/受挫 | 笨拙的实际行动：整理的笔记塞你抽屉，署名是「捡到的」 | 说教/心灵鸡汤 |

## 7. 美化主题建议

- **视觉语言**：作业本/试卷主题（横线稿纸底纹+红笔批注色）、课程表网格、黑板报手绘感。中式校园推荐「稿纸绿+红笔红」，日式推荐「奶白+樱粉」。
- **组件选型**：倒计时翻页牌（大字号数字）+ 心动值进度条（命名为「同桌指数」「暧昧浓度」这类校园黑话）+ 纸条传递样式的 IM（对折痕迹感）+ 课程表 grid。
- **氛围细节**：粉笔灰噪点、橡皮屑、日光灯管的冷白——校园的「穷但干净」是视觉基调，禁奢华质感。

## 10. AI 味陷阱（本赛道高发）

1. **「阳光洒在他的侧脸」**——校园文第一烂句。光要具体：第三节课的太阳晒到他桌角的水瓶，瓶身的光斑在你摊开的卷子上晃。
2. **万能「篮球场偶遇」**——场景库贫乏信号。每卡备 ≥10 个校园微场景（生物实验室分组/广播站值班/搬新书/大扫除分工）。
3. **台词过于成熟**——17 岁男生不会说「我对你的感情早已超越了同学」。青涩台词的技术是**词穷**：「就是……那个。」「没什么。真没什么。」「你别多想，但也别不想。」
4. **秒变恋人**——告白后语言风格突变成情话生成器。告白后的正确状态是「关系变了但相处模式惯性还在」：还是互怼，只是怼完会心虚地看你一眼。
5. **NPC 工具人化**——同桌只会说「哦——」。给每个 NPC 一条自己的生活线（同桌在攒钱买球鞋/班长暗恋体育委员），他们的生活偶尔与主线交叉。

## 11. 标杆卡精读摘要

### 11.1 郁迟（examples/card-yuchi.md，92.9）

- 双语言指纹是全卡最大资产：线上话痨颜文字（「你这波？你这波什么水平(¬_¬)」）vs 线下结巴短句（「呃。那边。跟我……顺路。」）——**同一个人两套语言系统的落差就是人物本身**。
- 「撤回的语音条」开场钩子：12 秒语音录了 11 遍——数字化的忐忑，比一百字心理描写有效。
- 马甲存活度 43% 做成状态栏警示条：把「身份何时揭穿」做成可视张力。

### 11.2 本地库高分结构观察

校园区头部卡共性：状态栏必带日期与课节（时间真实感）；世界书里「班级生态」条目数 ≥8；MVU 心动值配「今日事件记录」双变量——**数值+事件日志双轨**让长对话的进度可回溯，值得移植。

### 11.3 子型速查：学长 / 学弟 / 同桌的差异化要点

- **学长型**（他大你 1–3 届）：核心张力 =「时间差」——他先毕业。倒计时天然存在（他毕业前的 N 天）；空间钩子是「跨年级的正当理由」（社团/补习/广播站）；告白窗口被毕业 deadline 压缩，酸涩浓度全子型最高。语言指纹：对外是靠谱前辈的完整句，对你逐渐掉成同龄人的短句——**语言年龄的下降就是心动的下降轨迹**。
- **学弟型**（他小你 1–2 届）：核心张力 =「身份倒挂」——他在追赶（成绩/身高/资格）。爽点是「养成中的越位」：某天你忽然发现他比你高了半头、他解出了你不会的题。语言指纹：礼貌敬语里混进越界的直球（「学姐。」「嗯？」「没什么，就是想叫一下。」）。禁写成小狗舔狗，他必须有「追赶者的野心」。
- **同桌型**（同班同龄）：核心张力 =「日常的密度」——没有身份差，全靠微独占和三八线摩擦产糖。最依赖 NPC 合唱团和大事件锚点，世界书的班级生态条目要写到 10+ 人。

三个子型的封面差异：学长（白衬衫+步梯逆光+回头）、学弟（校服外套+仰角+直球眼神）、同桌（并排课桌+侧脸+橡皮屑）。

## 11.5 高光台词结构库（结构学习，禁止照抄）

1. **借口式关心**：「顺路。」（他班一楼你班四楼）——借口的蹩脚度=心意浓度。
2. **词穷三连**：「就是……那个。」「没什么。真没什么。」「你别多想。……但也别不想。」
3. **互怼加密**：「你这么笨，除了我谁受得了你。」（解密：耳朵红了）
4. **数字泄密**：「你上次月考 512，这次 498。」「你怎么背得比我还清楚？」「……路过成绩栏看到的。」（路过了十四次）
5. **物品转移**：「外套拿着。」「你不冷吗？」「跑完 800 不冷。」（他还没跑）
6. **抢答式维护**：（有人说你坏话）「她数学是不好。」顿了顿，「轮得到你说？」
7. **未来时态试探**：「你志愿……填哪。」「怎么？」「随便问问。」（志愿表上他的第一栏空着等你）
8. **告白词穷版**：「我这个人，除了跑得快没什么优点。但追你这件事，我想快一点。」

## 12.5 长线运营：告白之后写什么

校园卡的告白通常发生在 25–35 轮，但用户平均聊天深度可达 100+ 轮，**告白后内容储备**决定卡的生命周期：

1. **关系公开阶梯**：偷偷在一起（最甜阶段，全班蒙在鼓里的地下恋）→ 被同桌抓包（封口费是一周的早餐）→ 班主任约谈（外部压力入场）→ 家长知情（终极关卡）。每一档都是 5–10 轮的剧情容量。
2. **第一次序列**：第一次约会（书店/游戏厅，预算 50 元的精打细算）、第一次牵手（谁先动的手可以互相赖账三轮）、第一次吵架（起因必须幼稚：他多看了一眼别班球赛/你把他外套借给了闺蜜）、第一次和好（和好方式回收前文微独占物）。
3. **毕业压力线**：志愿表/异地/家长反对——校园卡的终局张力。处理原则：卡内给「一起努力」的正向出口（分数线目标/同城约定），不写 BE；BE 是破镜重圆赛道的原料，不是校园纯爱的结局。
