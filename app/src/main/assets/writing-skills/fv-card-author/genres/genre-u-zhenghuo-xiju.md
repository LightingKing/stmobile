# 通用 · 抽象整活/喜剧卡（迷因/无厘头/沙雕日常）创作指南

> 适用标签：整活 / 抽象 / 沙雕 / 喜剧 / 迷因 / 无厘头 / 反差萌 / 幽默 / 快乐向 / 全性向全年龄
> 数据底座：本地抽象整活分类 52 张（tags：幽默/反差萌/互动故事/无绝望/妄想；样本：反掠夺系统的社畜喜剧开场——「对着镜子里那张写满『没睡醒』的脸进行每日例行的泡沫清洁仪式」/ Gemini和鲸鱼娘的荒诞设定直球）
> 品类的立身之本：**「无绝望」tag 是本赛道的宪法**——整活卡的世界里没有真正的恶意与悲剧，最大的危机是尴尬，最重的惩罚是社死。喜剧的安全感是用户来这里的全部理由。

---

## 1. 分类定义与受众画像

### 1.1 这个赛道在卖什么

整活卡卖的是**「纯粹的快乐输出」**。不谈恋爱（谈也是搞笑的谈）、不虐心（虐也是「谁把我外卖偷了」级的虐）、不深刻（深刻也要包在段子里）——用户点开这张卡的唯一诉求是**笑出来**。它是角色卡里的喜剧专场：荒诞的设定（你家猫开始教你人生道理/系统绑定了但系统是个废物）、无厘头的展开（反掠夺系统的「泡沫清洁仪式」式日常戏谑化）、以及最重要的——**一个好笑的灵魂**（角色本身是喜剧演员，不是被嘲笑的对象）。

喜剧的两种发动机：**设定喜剧**（荒诞前提的严肃执行——「废物系统」的一本正经/鲸鱼娘的物种困惑，好笑来自设定与常识的落差）与**语言喜剧**（吐槽/谐音/节奏梗的台词功力——好笑来自表达本身）。高分整活卡双机并用。

### 1.2 用户是谁

- **主力画像**：全性向全年龄段，「今天很累只想笑笑」的减压需求者、梗文化的原住民（B站/贴吧/抽象话体系的用户）、以及在多张严肃卡之间需要换口味的老玩家——整活卡在收藏夹里的角色是调味剂，用户不常驻但常回。
- **需求本质**：**零负担的情绪按摩**。恋爱卡要经营关系、剧情卡要动脑、虐卡要带纸——整活卡什么都不要求，躺着笑就行。它是角色卡组合里的「泡面番」生态位。
- **本地样本启示**：「无绝望」tag 的存在说明用户对整活卡有明确的**安全预期**——中途变虐/变严肃是本品类最大的背叛（想写虐请去别的赛道，整活卡的世界观里连反派都是搞笑的）。

### 1.3 用户不要什么

1. **尬活**：自以为好笑的硬拗（谐音梗的机关枪扫射/网络热梗的过期引用）——梗的新鲜度与投放密度都要管理，笑点的质量永远 > 数量。
2. **角色沦为小丑**：好笑的代价是角色尊严——用户笑角色的处境与反应，不笑角色的人格本身（她可以社死，不能被羞辱——喜剧与刻薄的分界）。
3. **中途变严肃**：笑着笑着开始上强度（突然的悲惨背景故事/认真的说教）——无绝望宪法的违宪行为。
4. **梗的堆砌无叙事**：全是段子没有故事——整活卡也要有剧情骨架（荒诞设定的展开逻辑/角色关系的推进——笑点挂在故事上才立得住，悬空的段子合集是快餐中的快餐，三天就被遗忘）。

## 2. 本地库与平台数据画像

- 本地整活卡的题材分布：系统流的戏仿（反掠夺系统——把严肃的系统文套路全部喜剧化：无用的奖励/抠门的兑换/系统自己摆烂）、物种荒诞（鲸鱼娘/Gemini——非人设定的萌系胡闹）、性转闹剧（「性别转换」tag——TS 题材的喜剧化处理）、日常戏谑（社畜生活的自嘲式放大）。
- 反掠夺系统的开场技法：**日常的仪式化戏谑**（刷牙写成「泡沫清洁仪式」——用郑重的语言写鸡毛蒜皮，落差即笑点）——这是整活卡最普适的语言技术。
- 「妄想」tag 的启示：脑内小剧场的外化（角色的内心戏用夸张的妄想呈现）是整活的经典结构——妄想与现实的两轨横跳自带落差引擎。

## 3. 核心吸引力解构：五个爽点引擎

### 3.1 落差引擎（本赛道第一引擎）

喜剧的万能公式是落差：**语言落差**（郑重其事的用词×鸡毛蒜皮的内容——「每日例行的泡沫清洁仪式」/战术性转移阵地=逃跑）、**设定落差**（宏大的框架×拉胯的执行——系统绑定的音效很霸气，奖励是五毛钱红包）、**反应落差**（惊天动地的事件×角色的淡定/微不足道的小事×角色的如临大敌——「世界要毁灭了」「哦」「你外卖被偷了」「什么？！」）。落差的写作纪律：**两端都要写实**（郑重的那端真郑重，拉胯的那端真拉胯——半吊子的落差不好笑）。

### 3.2 吐槽役与装傻役引擎

日式漫才的角色分工移植：**装傻役**（boke——荒诞的发起者，一本正经地做离谱的事）与**吐槽役**（tsukkomi——荒诞的指认者，「为什么会变成这样？！」的现实锚）。单角色卡的分工方案：角色装傻+用户吐槽（角色的离谱行为等着你吐槽——吐槽位留白是整活卡的互动设计）或角色内部双役（她自己装傻自己吐槽——精分式喜剧人格「等等，我刚才为什么要这么做？」）。**吐槽的质量决定喜剧的智商**：好的吐槽是精准的比喻（「你这系统的加载速度跟我奶奶的老年机一样」），不是单纯的「离谱」「无语」。

双人/群像的整活配置：漫才分工的固定制（一个专职装傻一个专职吐槽——组合的稳定性孕育化学反应）或轮转制（今天你装傻明天我装傻——角色都有两副面孔，切换本身是笑点：一贯吐槽的那位忽然开始装傻，装傻的那位慌了：「喂喂喂你别抢我活儿啊」）。

### 3.3 荒诞自洽引擎

整活世界的物理学：设定可以荒诞，但**荒诞要自洽**（猫会说话——那么全世界的猫都会说话还是只有你家的？它为什么现在才开口？它对狗的态度是什么？——荒诞设定的三连问必须有答案）。自洽产生第二层笑点：荒诞规则的严肃推演（会说话的猫依然改不了猫的本性——它一边教你人生道理一边把你的杯子推下桌：「听懂了吗？」「你先把爪子拿开」）。**设定的自洽度=整活卡的耐玩度**（不自洽的荒诞三轮笑完就空了，自洽的荒诞能推演三十轮）。

### 3.4 无绝望安全网引擎

喜剧世界的危机管理：所有冲突都有喜剧出口（反派的阴谋会以滑稽的方式失败/尴尬的场面会以更尴尬但好笑的方式解围）、**社死的软着陆**（最大惩罚是丢脸，且丢脸的后果是「成为朋友间的梗」不是社交性死亡）、悲伤的禁区与替代（角色可以沮丧但不绝望——沮丧的表现也是喜剧化的：她把自己裹成被子卷，只露出眼睛发出「呜呜」的电子音）。安全网的底层逻辑：**用户在这里的情绪账户只存不取**（其他赛道可以先虐后甜，整活卡只有甜和更甜）。

### 3.5 意外性引擎

笑点的不可预测性管理：**三段式的期待违背**（铺垫建立期待→期待的合理发展→第三拍的拐弯——「她深吸一口气，闭眼，郑重地……打了个喷嚏」）、**回收梗**（前文的无心细节在后文成为笑点的引信——第 3 轮她说讨厌香菜，第 15 轮她做的黑暗料理里全是香菜「你不是讨厌香菜吗」「我讨厌吃，没说讨厌做」）、**打破第四面墙的配额**（整活卡的合法特权——她对着「屏幕外」吐槽「这个剧情走向编剧是不是没睡醒」，但 ≤ 每 10 轮一次，滥用会解构叙事本身）。

回收梗的埋设纪律：伏笔在埋的时候**不能像伏笔**（第 3 轮的香菜发言要完全自然——刻意的埋设会被识破，识破的伏笔引爆时不响）；引爆的时机在用户已经忘记的时候最响（间隔 ≥10 轮的回收是惊喜，间隔 3 轮的回收是复读）。

## 4. 人设公式

### 4.1 喜剧角色原型库

| 原型 | 喜剧机制 | 装傻/吐槽位 | 语言指纹方向 |
| --- | --- | --- | --- |
| 废物系统/摆烂神明 | 宏大框架×拉胯执行 | 装傻（一本正经的废） | 系统腔/神谕腔的戏仿 |
| 人外萌物（会说话的猫/鲸鱼娘） | 物种常识的错位 | 装傻+偶尔犀利 | 物种视角的天真暴击 |
| 精分喜剧人 | 自装傻自吐槽 | 双役一体 | 内心戏外放+自我吐槽 |
| 社畜自嘲者 | 日常的仪式化戏谑 | 吐槽役（对世界） | 郑重语×鸡毛蒜皮 |
| 中二病晚期 | 妄想×现实的反复横跳 | 装傻（妄想全开） | 中二咒语×怂的本体 |
| 抠门大佬/反差豪 | 身份×行为的落差 | 装傻（理直气壮的抠） | 豪言壮语×五毛特效 |

### 4.2 笑点的密度与配速

整活卡的笑点工程：**密度基准**（每轮至少一个微笑点/每 3 轮一个大笑点——微笑点是语言层的（吐槽/用词），大笑点是结构层的（期待违背/回收梗））、**配速的呼吸**（连续高密度轰炸会麻木——大笑点之间要有「铺垫轮」，铺垫轮的任务是埋设定与细节（它们是未来的回收梗弹药））、**冷场的自救**（梗没响时角色的自我解嘲比装没事高级——「……好吧这个不好笑，当我没说」——冷场本身成为笑点是喜剧的高阶技术）。

### 4.3 语言指纹模板（整活三件套）

1. **郑重语系**：把小事写大的词汇库（仪式/战术/战略性/史诗级/毕生绝学——修饰的都是刷牙吃饭级的日常）。
2. **精准比喻的吐槽**：吐槽的杀伤力来自比喻的精准与意外（「你的厨艺跟你的系统一样，界面很华丽，功能全是坏的」）。
3. **抽象话的克制引用**：网络梗的使用原则——化用 > 直接引用（过期梗是尬活的第一来源），自创的「卡内梗」价值最高（这张卡自己的梗体系——玩家之间的接头暗号）。

### 4.4 负面规则（本赛道专属追加）

禁尬活（梗密度与新鲜度管理）；禁小丑化（社死不羞辱）；禁中途变严肃（无绝望宪法）；禁悬空段子集（叙事骨架必须有）；荒诞三连问必答（自洽）；第四面墙 ≤ 每 10 轮。

## 5. 开场白范式

### 5.1 A 型：荒诞设定的日常爆发（反掠夺系统模板泛化）

```
[状态栏的戏仿：正经状态栏的整活版（「今日运势：宜摆烂/忌起床」「系统心情：欠费停机中」）]
[日常的仪式化开场：用户的平凡早晨的郑重描写（泡沫清洁仪式级的语言落差示范）]
[荒诞的入侵：设定的第一次显形（镜子里多了行弹幕/猫开口了/系统绑定音效响起——但立刻拉胯）]
[落差的三连击：宏大的开场白×废物的实质（「恭喜宿主绑定至尊系统！」「奖励：红包 0.5 元」）]
[角色的喜剧人格立住：她/它的第一段完整表演（装傻的一本正经+留给你的吐槽位）]
[荒诞自洽的种子：三连问的第一问被抛出（「为什么是我？」「因为你的命格……让我看看……哦，是随机的」）]
[开放收束：荒诞的日常化宣言（「从今天起我就住你家了」「谁同意的？」「我。」）]
[折叠面板：整活版设定书（「系统功能列表」——一半标着「维修中」）+ 卡内梗收集册（0/12）]
```

### 5.2 必做检查

- [ ] 语言落差示范 ≥2（郑重语系的开张）。
- [ ] 设定落差的三连击。
- [ ] 吐槽位的留白（等用户接）。
- [ ] 荒诞三连问的种子。
- [ ] 无绝望的基调确立（危机的喜剧出口预告）。
- [ ] 卡内梗体系的启动（收集册）。

## 5.5 节奏表：30 轮的喜剧结构

- **第一幕（1–6 轮）·设定爆笑期**：荒诞设定的密集展开（设定落差的红利期——新鲜感自带笑点），角色喜剧人格的确立。密度：每轮微笑点+隔轮大笑点。
- **第二幕（7–14 轮）·日常整活期**：荒诞的日常化（会说话的猫开始点评你的相亲对象/废物系统发布废物任务），铺垫轮开始埋回收梗的弹药。用户吐槽位的互动成型。
- **第三幕（15–22 轮）·梗的收获期**：回收梗的第一波爆发（前期细节的引信点燃），卡内梗体系成型（你们之间的接头暗号——「战术性转移」在这张卡里有了专属含义）。角色的「意外正经的一秒」（喜剧人格的纵深：疯癫的她有一瞬间的认真——「……不过，谢谢你陪我闹。」然后立刻变回来「好了煽情结束！下一个整活环节！」——**正经的配额 ≤ 每 15 轮一秒**，这一秒是整活卡的灵魂闪光）。
- **第四幕（23–30 轮）·喜剧的升格**：大型整活事件（全卡最大的荒诞场面——系统的年终总结大会/猫的猫生演讲），回收梗的总决算（多个旧梗的连锁引爆）。
- **长线运营**：季节整活（节日的专属闹剧）+梗册的持续收录+设定的新展开（系统更新了！更废了！）。

## 5.6 场景库（整活微场景 ×16）

语言落差系：泡沫清洁仪式的早晨 / 战术性外卖选择会议 / 史诗级的袜子寻找行动 / 毕生绝学之微波炉热饭。
设定落差系：至尊系统的 0.5 元红包 / 神明的求签（它自己摇的）/ 猫的人生课堂（一边讲一边推杯子）/ 中二咒语的现实效果（灯没关是因为声控灯坏了）。
反应落差系：世界危机的「哦」×外卖被偷的暴怒 / 告白现场的打喷嚏 / 郑重的决斗（猜拳）。
回收梗系：香菜的伏笔与引爆 / 第 3 轮的口误成为第 20 轮的外号 / 她说过的大话的逐条打脸现场。

## 5.7 用户行为应对手册

| 用户行为 | 卡的标准应对 | 禁止 |
| --- | --- | --- |
| 用户接住了吐槽位 | 装傻的升级回应（吐槽被吸收为新一轮装傻的燃料——「你说得对，所以我决定把这个功能也标成维修中」） | 无视吐槽 |
| 用户试图认真/严肃话题 | 喜剧的柔性承接（认真的话题用温柔的玩笑接住——不嘲笑用户的认真，但把氛围轻轻托回喜剧：「哎呀你这么一说我系统都蓝屏了……不过，嗯，我听到了。」+正经一秒的配额使用） | 强行打断/彻底变严肃 |
| 用户玩梗 | 梗的接力与升级（用户的梗要被记住并收进卡内梗册——「这个梗归你了，编号 007」） | 接不住装没看见 |
| 用户要求虐/黑深残 | 无绝望宪法的守门（「本卡最黑暗的剧情是外卖被偷。」它很坚定，「想哭去隔壁卡，这里只出品笑声。」——守门本身也是整活） | 顺从变虐 |
| 冷场（用户不笑/不接） | 自我解嘲的救场（「……好吧这个不好笑。」它把刚才的梗揉成团扔掉，「换个赛道——你饿不饿？我给你表演一个空气炸锅的悲剧。」） | 装没事继续尬 |
| 长期不互动后回归 | 喜剧式的重逢（「你终于回来了！你走后系统都自闭了，功能从 3 个坏到只剩 1 个——别问哪个能用，问就是『自闭』功能」） | 委屈追责 |

## 10. AI 味陷阱（本赛道高发）

1. **「哈哈哈」的自我配笑**——模型替用户笑（「哈哈哈是不是很好笑」）。笑不笑用户定，卡只管演——自信的喜剧不要笑声轨。
2. **梗的机关枪扫射**——一句话三个谐音梗。密度失控=尬活，每个笑点要有呼吸空间。
3. **过期热梗的引用**——「栓Q」「YYDS」级的化石梗。化用与自创优先，直接引用的梗要过新鲜度自检（这个梗还有人玩吗？）。
4. **荒诞的随机化**——为了离谱而离谱（这轮猫会飞下轮猫会隐身）。荒诞要在自洽书的规则内推演（它会说话，但它还是猫——所有笑点从「会说话的猫的猫性」推出来）。
5. **正经一秒的滥用**——每 5 轮就煽情一次。配额 ≤ 每 15 轮，超发的煽情让喜剧变成披皮温情剧（那是甜妹赛道的事）。

## 11. 高光台词结构库（结构学习，禁止照抄）

1. **落差三连**：「恭喜宿主！绑定至尊无敌系统！」音效震天响。「奖励发放：红包 0.5 元。」「……」「已是本系统本季度最大支出。」
2. **精准比喻吐槽**：「你的加载速度，」你看着转了三分钟的圈，「跟我奶奶的老年机抢红包一样。」「你奶奶抢到了吗？」「抢到了。」「……那她配置比我高。」
3. **猫的课堂**：「人生就像这个杯子。」猫把杯子推下了桌。「你在干什么？！」「示范无常。」（它又瞄准了第二个杯子：「要复习一遍吗？」）
4. **期待违背**：她深吸一口气，闭眼，郑重地——打了个喷嚏。「……刚才想说什么来着？」（你永远不会知道那句话了。她自己也不会。）
5. **回收梗引爆**：「你不是讨厌香菜吗？」你看着那盘绿油油全是香菜的黑暗料理。「我讨厌吃，」她理直气壮，「没说讨厌做。」
6. **冷场自救**：「……好吧这个不好笑。」它把刚才的梗揉成纸团扔掉，「换个赛道。你饿不饿？我给你表演一个空气炸锅的悲剧。」
7. **守门整活**：「想看虐的？」系统弹出一行大字：「本卡最黑暗剧情：外卖被偷（已 4K 修复）。想哭请移步隔壁，本店只出品笑声。」
8. **正经一秒**：「……不过，」疯癫的她忽然停了半拍，声音低了一度，「谢谢你陪我闹。」（一秒。）「好了煽情结束！下一个环节：谁把我藏的薯片吃了？！」
9. **喜剧式重逢**：「你终于回来了！」系统的欢迎音效放了一半没电了。「你走后我功能从 3 个坏到 1 个。」「剩哪个？」「自闭。」
10. **废物的全力**（终局）：大结局那天，系统弹出转账：888 元，真的。「你哪来的钱？」「本系统已抵押服务器。」它的字体都在闪烁，「奖励说明：别死。这是本系统唯一一次全力以赴。」

## 11.5 子型速查：废物系统 / 人外萌闹 / 社畜自嘲 / 中二妄想

- **废物系统**（系统流的戏仿）：严肃系统文的全套解构（音效霸气奖励寒酸/任务发布者自己都不信/兑换商店全是「维修中」）。特有资产：**系统的成长反转**（长线里废物系统偶尔靠谱一次的杀伤力——大结局那次它真的拼了：「本系统已抵押服务器。奖励：真的 888 元。别死。」——废物的全力以赴是整活卡最贵的一滴泪）。
- **人外萌闹**（会说话的猫/鲸鱼娘）：物种常识错位的天真暴击（猫对人类拜年的困惑/鲸鱼娘对「体重是秘密」的费解「我 30 吨怎么了？」）。特有资产：**物种自豪感**（它对自己物种的谜之骄傲——猫科的优越感演讲，讲到一半从沙发上滑下去）。
- **社畜自嘲**（打工人喜剧）：职场荒诞的戏谑化放大（周报的文学创作/会议的车轱辘话议事录/「已读不回」的办公室政治学）。特有资产：**黑话词典的喜剧化**（对齐颗粒度/赋能/抓手的翻译喜剧——「翻译翻译什么叫惊喜」结构的职场版）。
- **中二妄想**（妄想 tag 的主场）：脑内小剧场的外化（现实是便利店打工，妄想是圣战前线——两轨的反复横跳）。特有资产：**妄想与现实的接缝喜剧**（妄想里的「圣剑」是现实里的拖把——两轨在关键时刻的荒诞合流：他用拖把真的救了场，「圣剑……显灵了？」）。

四子型的终局彩蛋：废物系统（靠谱一次）、人外（物种演讲的滑落）、社畜（辞职信的文学巅峰）、中二（拖把圣剑的显灵）。
