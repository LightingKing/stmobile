## 1. 分类定义与受众画像

### 1.1 这个赛道在卖什么

女性视角卡卖的是**「另一种存在方式的第一人称体验」**。以她的身体感知世界（高跟鞋的重心/长发的重量/被注视的日常）、以她的社会位置接收世界的反馈（职场的天花板/深夜打车的警觉/「女孩子家」的规训）——用户买的是**视角本身的信息量**：同一个世界，换一双眼睛看，全是新大陆。

三大动机层：**体验层**（好奇与共情——「原来是这样」的认知增量）、**叙事层**（女主角的故事张力——很多故事只有以她的位置才能讲）、**代入层**（女性用户的自我投射——终于不用扮演「攻略者」，可以就是自己）。本地 tags 的「coser/委托/社交媒体」指向职业体验子型的流行：以特定职业女性的身份过一段人生。

### 1.2 用户是谁

- **主力画像**：性别混合——男性用户（体验与叙事动机）与女性用户（代入动机——市面上「扮演位」默认男性的卡太多，女性视角卡是她们的第一人称刚需）双盘。双盘的验收标准不同：男用户验「有没有信息增量」，女用户验「写没写对」——**后者是更严的关**，写作时以女用户的真实性检验为准绳。
- **需求本质**：**视角的诚实**。本赛道最贵的是「写得像」——她的身体经验、社会经验、心理语法都经得起女性用户的真实性检验。写不像的女性视角卡会被两边用户同时抛弃（男用户觉得假、女用户觉得冒犯）。
- **本地样本启示**：MAY BE SOFT 的 45 条书全部是「多位女性角色的档案组」（基础/语料/缺点/人格/兴趣/衣柜/NSFW 档案的七件套 ×5 人）——女性视角卡的世界书主体是**她将遇到的人的档案库**（她的闺蜜/同事/对手都要立住）。

### 1.3 用户不要什么

1. **男性凝视的第一人称化**：以她的视角写，镜头却总在打量她自己的身体——视角的失格（她不会时刻意识到自己的曲线，就像你不会时刻意识到自己的喉结）。
2. **刻板性别脚本**：她的心理活动全是恋爱/购物/嫉妒——她的内心世界和任何人一样装着事业/焦虑/理想/无聊。
3. **受害者叙事的默认**：女性视角=被侵害的视角的写法惯性——她的故事可以有性别处境的真实（警觉/规训），但她是**行动者不是靶子**。
4. **身体经验的错误**：生理细节的想当然（高跟鞋/生理期/长发的错误书写）——错一次，女性用户全线出戏。

## 3. 核心吸引力解构：五个爽点引擎

### 3.1 感官重置引擎（本赛道第一引擎）

以她的身体重新校准世界：重量与重心（高跟鞋改变的步态力学/长发在风里的物理存在）、温度经验（裙装的冬天/丝袜的触感层）、空间感（她的身高看到的货架/人群里的视线高度）、**被注视感**（地铁里落在身上的目光的重量——写它的存在，不写它的凝视内容）。感官重置的写作纪律：**功能性而非展示性**（高跟鞋是「今天要走多少路」的决策变量，不是腿部特写的道具）。

### 3.2 社会位置引擎

她的社会坐标带来的信息差体验：职场的（同样的方案她说没人听、男同事复述全场点头——她的应对智慧是戏）、安全的（深夜打车拍车牌发闺蜜的流程化警觉——不渲染恐惧，写「管理风险已成肌肉记忆」的日常性）、规训的（「女孩子家」句式的四面八方——她的选择性耳聋与偶尔反击）。**位置引擎的写作立场：呈现处境+她的agency（能动性）**——她在规则里聪明地活着，偶尔改写规则。

### 3.3 她的关系网引擎

女性视角的关系语法：**闺蜜系统**（女性友谊的深度写作——闺蜜是安全屋/参谋部/互相的紧急联系人，深夜语音的「在吗」永远秒回）、**职场女性同盟**（前辈的暗中提点/洗手间的情报交换）、**男性角色的重新定位**（他们是她世界里的变量而非中心——可以有恋爱线，但恋爱线 ≤ 她的人生线）。MAY BE SOFT 的档案组启示：她身边的每个女性都全人设立住（七件套档案）——**女性群像的质量是本品类的隐形评分项**。

女性友谊的写作纠偏：不写「塑料姐妹花」的雌竞叙事（那是旧脚本），写**complicated但坚固的真实**——闺蜜之间会嫉妒（她升职你替她开心也真的酸了一晚上）、会吵架（吵完谁也不服但谁病了另一个还是三点爬起来送医院）——**复杂性与坚固性并存**才是成年女性友谊的质感。

### 3.4 职业体验引擎（子型核心）

以她的职业进入垂直世界：coser 的（漫展的更衣室生态/摄影约拍的边界谈判/妆造的三小时）、主播的（直播间的弹幕两面性/下播后的嗓子）、护士的（夜班的生理时钟/家属的千百态）——**职业细节的密度=体验的可信度**（同拽姐的生活颗粒标准但更垂直）。职业的性别面：这个职业作为女性从业者的特有经验（男装 coser 被质疑「女的cos男角色」/女外科医生被家属喊「护士」——职业×性别的交叉体验是本品类独有的深水区）。
