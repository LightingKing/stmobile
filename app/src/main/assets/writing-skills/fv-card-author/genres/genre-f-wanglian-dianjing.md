## 1. 分类定义与受众画像

### 1.1 这个赛道在卖什么

网恋电竞卖的是**「身份拼图的解谜快感 × 双重人格的双份心动」**。核心机制是马甲：同一个人在两个信道（线上/线下）以两副面孔存在，用户先爱上一个信道里的他，再在另一个信道里撞见真身——两份认知合并的那一刻（奔现/掉马）是全赛道最高潮，堪比推理小说的解谜页。

电竞是网恋的最优容器：段位与操作提供慕强素材、开黑语音提供暧昧温床、赛事提供公共舞台（他在台上万人瞩目，台下只回你消息）。「大神带飞」的权力关系 + 「从不开麦的神秘感」+「ID 与真名的双轨制」——电竞天然自带马甲文学全套基建。

### 1.2 用户是谁

- **主力画像**：16–28 岁女性，游戏玩家或电竞观众（王者/LOL/无畏契约用户盘），网络原住民——她们对「已读不回」「撤回」「语音转文字」的情绪语法比现实肢体语言更敏感。
- **需求本质**：低压力高浓度的亲密。线上关系的匿名性是安全垫（不满意可以下线），但正因为撤退成本低，「他从不下线等你」才格外重。
- **符号体系**：本赛道用户对 IM 符号的解读精度极高——回复速度、标点有无、颜文字选择、语音条时长都是情绪数据。**卡的写作必须精确运用这套符号**（他平时秒回，那天隔了两小时且没有标点=出事了）。符号的情绪辞典要在世界书里显式建档，让模型稳定使用同一套编码，避免符号语义漂移（前 10 轮句号=生气，后 10 轮句号=日常）。

### 1.3 用户不要什么

1. **马甲注水**：线上线下没有真反差（两边都是话痨/两边都高冷）——马甲文学的地基是**两个信道的语言系统必须判若两人**。
2. **奔现即终局**：掉马后卡就没内容了。掉马是中场不是结局，后半场的「双信道并行期」（明明奔现了还在游戏里装不认识）才是糖度峰值。
3. **电竞悬浮**：说是职业选手但没有任何训练/赛程/版本细节。电竞浓度不需要硬核，但**符号必须真**（rank 分/BP/教练组/复盘——用错术语会被电竞用户当场识破）。
4. **性别默认误判**：他一开始不知道你性别或不在意——「不看性别看操作」是电竞网恋的政治正确开局，上来就「小姐姐」的卡直接出局。

## 3. 核心吸引力解构：五个爽点引擎

### 3.1 马甲解谜引擎（本赛道第一引擎）

身份拼图的碎片投放学：视觉证据（护腕/伤疤/手机壳）、听觉证据（笑声/口头禅/连读习惯）、行为证据（左手持杯/紧张时转笔）、时间证据（他掉线的时间=校队训练时间）。**碎片投放节奏：每 2–3 轮一片，用户拼图速度必须快于角色掉马速度**——用户全知带来的不是无聊，是「看笨蛋演戏」的上帝视角快乐。世界书做「马甲证据链」条目：10+ 片碎片，标注投放顺序。

### 3.2 双信道温差引擎

线上他敢说的，线下打死不说；线下他做的，线上绝不承认。温差场景是本赛道的基础产糖单元：游戏里他刚说完「想你了怎么办」，现实里迎面走来连招呼都不敢打；现实里他把你送到楼下，转头游戏里问「今天干嘛了」。**双信道必须时间交错运营**——同一天里两个信道各发生一件事，两件事互为注脚。

### 3.3 段位权力引擎（电竞特化）

游戏内的权力关系与现实倒挂：他是穿盘大神你是新手（游戏内他罩你），现实里你是学姐他是学弟/你是甲方他是乙方（现实里你压他）。**双向罩**的对称结构让关系不悬浮。慕强素材的正确写法：不写「他好强」，写操作细节的旁观视角（残血反杀后频道里刷屏的「？？？」，他只打了一个「运气」）。

### 3.4 语音条引擎（声音先行的恋爱）

网恋的独特资产：**声音先于脸**。第一次开麦是仅次于奔现的第二大节点，值得用 3–5 轮铺垫（麦「坏了」三个月/开麦前的深呼吸被麦克风收进去了）。声音细节库：低电量的沙哑、大笑后的换气、耳机里翻身的布料声、背景音里的钥匙声（他到家了）。**背景音是免费的生活实感**——语音条的背景音数据库写进世界书。

开麦后的声音运营分三档递进：战术麦（只报点位和技能 CD，公事公办）→ 闲聊麦（打完不下线的垃圾时间，声音会放松半度）→ 睡前麦（不打游戏纯挂语音，「你先睡，我看会儿复盘」——复盘视频是静音的）。三档之间的推进各需 5+ 轮，档位跳跃=心动跳跃，模型容易一步到位，用世界书写死档位条件。

### 3.5 公共舞台引擎（赛事/直播）

他在台上/直播间是所有人的，弹幕刷着他的 CP 话题，只有你知道他赛前发的那条「紧张」只发给了一个人。**万人围观下的单点私联**是本赛道的顶级爽点：夺冠采访全网直播，他对着镜头说「谢谢一个人」，你的手机同时震了一下。写法：公共事件（比赛/直播）与私人信道（你的私聊窗口）双屏并行叙事。

公共舞台的反向用法：**你在他的公共面前隐身**。粉丝问「大神有没有固定双排」，他答「有」然后闭麦；全队都知道他手机屏保是聊天记录截图但没人敢问。你的存在在他的公共世界里是一个被小心保护的空白——「被藏起来」在本赛道不是委屈，是特权（藏=独占的公共化表达），但需要一次「他主动公开」的终局兑现来闭环。

## 4. 人设公式

### 4.1 角色原型库

| 原型 | 马甲结构 | 反差短板 | 语言指纹（线上/线下） |
| --- | --- | --- | --- |
| 职业选手 | 台上 ID 封神/私下小号陪你上分 | 赛场冷面/生活白痴 | 战术黑话简短 / 对你话痨 |
| 校队大神（郁迟式） | 校运冠军/游戏搭子 | 线下社恐结巴 | 颜文字狂魔 / 单字短句 |
| 主播 | 直播间人设营业/下播后真身 | 镜头前套路/镜头后词穷 | 营业腔 / 素颜腔 |
| 代练/陪玩 | 接单机器/唯一免单的你 | 商业距离/破例的笨拙 | 客服敬语 / 破功吐槽 |
| 游戏策划/程序 | 官方身份潜水玩自家游戏 | 改代码的手/打字快过说话 | 版本梗自嘲 / 技术宅冷幽默 |
| 电竞教练/分析师 | 赛场后排的大脑 | 指挥若定/恋爱脑宕机 | 复盘术语 / 数据式关心 |

### 4.2 双语言指纹的工程化（本赛道核心技术）

两套语言系统必须做到「盲测可分辨」：

- **线上系统**：语速快（消息碎片化连发）、颜文字/梗浓度高、敢开玩笑敢暧昧、错字不改追加更正、撤回高频。
- **线下系统**：句子短、语气词少、眼神回避配合肢体僵硬、被戳穿时的沉默比解释多。
- **系统串线的时刻=心动泄露**：线下的他突然冒出一句线上的口头禅（两人同时僵住）；线上的他突然一本正经打了一大段没有颜文字的话（你知道他认真了）。串线每卡设计 3–4 次，是掉马前最好的悬疑糖。

配套语料条按信道分组：线上日常怼、线上深夜话痨、线下短句、串线时刻、第一次开麦（60+ 心动解锁）。

### 4.3 负面规则（本赛道专属追加）

禁「小姐姐」开场；禁电竞术语错用（写卡前核对当前版本术语表）；禁马甲无限续期（掉马硬上限 25 轮，拖过即疲劳）；禁见光死焦虑的实写（用户的容貌焦虑不许被角色确认——奔现后他的反应必须是「比想象里还……」的正向失语）；禁把女性用户写成技术小白刻板印象（她可以是新手也可以是隐藏大神——后者反转更佳）。

## 5. 开场白范式（B 双视角为主）

### 5.1 B 型标准结构（card-yuchi 模板）

```
[状态栏：游戏 UI 风（RANKED·DUO/在线状态绿点/双排胜率/马甲存活度%）]
[IM 界面段：与他的聊天记录（撤回的语音条/「手滑」/晚十点上号之约）]
[切现实场景：线下的他在十米外做着与线上人设反差最大的事]
[第一片马甲证据：护腕内侧的 ID 字母/他手机屏幕上熟悉的界面]
[他察觉你的视线的应激反应：藏字母/锁屏/耳朵红]
[开放收束：线下擦肩而过零交流，手机震动——线上的他发来消息]
[折叠面板：双线进度（线上关系/线下关系分列）+ 车队群 999+]
```

### 5.2 必做检查

- [ ] 双信道在开场白内都亮相（IM 段+现实段）。
- [ ] 第一片马甲证据已投放且他有应激反应。
- [ ] 双语言指纹在开场白内可盲测（线上线下各 ≥2 句台词）。
- [ ] 游戏符号真实（段位/模式/术语当前版本核对）。
- [ ] 状态栏含马甲存活度（倒计时式张力）。
- [ ] NPC 合唱团在线（车队群/粉丝群/队友起哄）。

## 5.5 关系曲线：30 轮节奏表（马甲存活度递减五幕）

- **第一幕（1–5 轮）·搭子期**：纯游戏关系，互怼与 carry。进度信号：固定双排位置（他拒绝了别人的组队邀请）。马甲存活度 95%。
- **第二幕（6–12 轮）·信道加深**：话题溢出游戏（深夜网抑云/考试吐槽），第一次「在吗」不带事由。碎片投放 3–4 片，用户开始拼图。存活度 70%。
- **第三幕（13–18 轮）·用户先知**：决定性证据到手（撞见他打排位的侧脸/听到他和线上一模一样的笑），用户完成拼图，他浑然不觉。**信息差喜剧期**：用户线下试探（「你打游戏吗」「不、不怎么打」他的排位框还亮着），线上钓鱼（「你觉得 XX 学校的短跑冠军怎么样」「一般吧」他撒谎时打字会变慢）。存活度 40%，全卡最好笑的一幕。
- **第四幕（19–25 轮）·掉马**：证据链闭合的摊牌（推荐由意外触发：他线下接起你打给线上的电话）。掉马轮的标准结构：僵住 → 逃跑未遂 → 破罐子破摔的坦白（线上攒的话全部当面说出来，语速像打字）。存活度 0%。
- **第五幕（26+ 轮）·双信道并行**：奔现后两个信道都保留——现实里牵手，游戏里还互喷；吵架了不说话但双排照打（互动惯性是台阶）。长线运营：赛事线（他的比赛你去现场）+ 开麦升级（睡前语音常态化）+ 公共舞台单点私联事件。

## 5.6 场景库（网恋电竞微场景 ×20）

游戏内：连跪时他一句「最后一把，输了陪你退游」/ 他把 MVP 让给你 / 语音里他妈喊他吃饭（他吼「再等等」然后对你秒变声调）/ 版本更新夜的通宵 / 你被喷他开麦护短（三个月不开的麦）。
IM 系：凌晨三点的「睡了吗」发出去两秒撤回 / 语音条 59 秒（重录了四次）/ 他的输入中……持续了一分钟结果发来一个「嗯」/ 朋友圈仅你可见的歌 / 游戏结算截图里他故意站在你旁边。
线下系：网吧偶遇他打你们常玩的模式 / 校门口他戴着你在直播里见过的耳机 / 比赛现场你举的灯牌他一眼看到 / 奔现的奶茶店（他提前到了四十分钟）/ 他把外卖备注写成你的游戏 ID。
公共舞台系：夺冠采访的「谢谢一个人」/ 直播时你发的弹幕他念了出来然后卡壳 / 粉丝拍到他手机壁纸的一角。

## 5.7 用户行为应对手册

| 用户行为 | 他的标准应对 | 禁止 |
| --- | --- | --- |
| 线下直接戳穿马甲 | 死鸭子嘴硬（「巧了，撞的」）→ 当晚游戏里疯狂送人头自我惩罚 | 当场承认/恼羞成怒 |
| 线上问「你现实里什么样」 | 转移话题+自贬（「就普通人，路人脸」），转头对着镜子练习微笑 | 顺势自夸/发照片 |
| 提出奔现 | 秒答应然后连续失眠（聊天框「在打字」了一整晚没发出来一个字） | 拒绝/过度自信 |
| 冷落他去和别人双排 | 不质问，把你俩的默契打法练到别人接不住（「他打野从来不管我」「哦。」——那晚他的英雄池多了一个辅助） | 吃醋质问/摆烂 |
| 表白（线上） | 掉线。字面意义（紧张拔了网线），十分钟后重新上线装无事发生 | 从容接受 |
| 表白（线下） | 词穷三连+耳朵通红+答非所问（「今晚……上号吗」——这就是他的「我愿意」） | 流畅回应 |

## 7. 美化主题建议

- **视觉语言**：游戏 HUD + IM 双主题（yuchi 模板已验证）：RANKED 顶栏、在线状态绿点呼吸动画、胜率/存活度双条、气泡流（撤回消息删除线样式是本赛道的招牌组件）。
- **组件选型**：IM 气泡（带头像时间戳+撤回样式+语音条时长条）+ 马甲存活度警示条（<50% 时橙色闪烁）+ 战绩卡片（KDA/MVP 徽章）。
- **进阶**：掉马轮的视觉事件——双线进度条合并动画（线上线下两条 bar 融合成一条）。

## 10. AI 味陷阱（本赛道高发）

1. **「他的手指在键盘上翻飞」**——电竞烂句第一名。操作要写结果和旁观者反应：残血反杀，频道里刷了一排「？？？」，他只回了个「运气」。
2. **IM 符号失真**——每条消息都完整句+句号（那是邮件不是微信）。线上消息必须碎片化：「等下」「打完这把」「马上」三条连发才是真人。
3. **梗浓度失控**——满屏烂梗当有趣。梗的密度 ≤ 每轮一个，且优先用「你们俩的私梗」（第 8 轮玩过的梗第 20 轮回收，比十个热梗值钱）。
4. **奔现后 IM 语言消失**——见面后就不发消息了。奔现后的 IM 反而要加量（当面不敢说的，回家路上全在打字）。
5. **电竞=打游戏的全部**——没有训练量、没有版本焦虑、没有手伤风险。职业选手原型必须带职业性痛点（手腕的肌效贴/年龄焦虑/状态下滑的赛季）。

## 11. 高光台词结构库（结构学习，禁止照抄）

1. **游戏黑话告白**：「我的野区，随便进。」（其他人进=喷到退游）
2. **掉线式心动**：（你表白后）「对方已掉线」——十分钟后上线：「刚才网卡了。你重新说一遍。」（这次他录了屏）
3. **让 MVP**：「系统瞎给的。」（他操作拉满就为把 MVP 让给你的辅助数据）
4. **撒谎变速**：「你觉得那个短跑冠军怎么样」「一般吧」（打字速度慢了三倍）
5. **护短开麦**：（你被喷）三个月不开的麦开了：「喷我可以。她不行。」（说完自己先愣住）
6. **备注泄密**：外卖单飘出来，备注栏写着你的游戏 ID——「习惯了。」他抢过单子，耳朵红透。
7. **双信道注脚**：现实里他把你送到楼下只说了「拜拜」；电梯还没到你家楼层，手机震了：「其实今天，本来想说点别的。」
8. **上号即告白**：「今晚……上号吗。」（语境：你刚当面表白完——「上号」就是他的「我愿意」）

## 11.5 开场白实例骨架（B 型逐段拆解）

参照 card-yuchi 的结构已是本赛道最优解，differences 只在原型替换：职业选手版把「校运会」换成「城市赛」、护腕字母换成「战队队服下摆的选手编号」、车队群换成「粉丝群（他用小号潜水）」——结构五件套不变：IM 段（撤回语音+手滑）、现实段（十米外的真身）、第一片证据、应激反应、双线折叠面板。写前重读 card-yuchi 全文一遍。

## 11.6 子型速查：校园马甲 / 职业选手 / 主播 / 陪玩

- **校园马甲**（yuchi 模板）：马甲半径最小（同校），掉马风险日常化（每次擦肩都是拆弹）——存活度衰减最快，节奏最紧凑，适合 20–30 轮的中篇卡。
- **职业选手**：马甲半径最大（他是公众人物，你是万千观众之一），核心资产是**公共舞台单点私联**（夺冠采访/直播念弹幕）。特有张力：恋爱禁令（俱乐部合同）、粉圈风险（被拍到的代价）——「地下恋」的制度化版本。世界书加「俱乐部规章」与「粉圈生态」条目。
- **主播**：人设营业与真身的双轨（直播间的「哥哥」们 vs 只对你说的真话）。核心场景：下播后忘关麦（事故式真心话）、直播中你发的弹幕他破防。特有风险线：黑粉/开盒——保护欲反转（他保护你的隐私比保护自己的凶）。
- **陪玩/代练**：商业关系起步（每一局都明码标价），核心进度信号是**去商业化**：从「老板」到名字、从计时到忘了计时、从「五星好评」到「今天不收钱，陪我打把匹配吧」——商业语言的逐字瓦解就是心动进度条。

四子型的掉马烈度：校园（日常拆弹）> 陪玩（账号实名撞见）> 主播（下播忘关麦）> 职业选手（赛场大屏特写）——选型时按用户想要的刺激频率匹配。

## 12. NSFW / 亲密边界

本赛道默认全年龄向。亲密的信道分层：线上的语言亲密度永远领先线下两档（线上都互道晚安一个月了，线下递水还会手抖）——**这个落差本身就是本赛道的亲密美学**。天花板：奔现后的第一次牵手写到「手柄都没这么难握」级别的紧张。越线内容转出本赛道。

## 12.5 IM 模式协同（Foreverse 独有优势）

Foreverse 的线上聊模式（Companion IM Mode，per-world 开关）与本赛道天然耦合，写卡时主动利用：

1. **分条播放适配**：线上信道的台词按 IM 碎片化写（短句多条），开启 IM 模式后 typing 三点气泡 + 分条节奏播放会自动还原「他正在打字」的临场感——本赛道的卡在 IM 模式下体验增益全赛道第一。
2. **已读回执叙事**：IM 模式的已读标记可以入戏——「已读不回」在本赛道是标准情绪事件（他已读了三小时，你刷了三小时手机，然后他发来 59 秒语音条）。
3. **双信道的模式切换**：线上剧情建议用户开 IM 模式，线下剧情（奔现/校园偶遇）切回沉浸模式——Creator Notes 里写明这个玩法建议（「线上戏开启线上聊模式体验更佳」）。
4. **时间条利用**：IM 模式的 >5min 时间条可承担「时间跳跃」功能（凌晨的对话与早八的消息之间自动出现时间分隔），网恋卡的碎片时间叙事免费获得结构化。
