# 男性向 · 母系包容（温柔乡/无条件接纳/恒温系）创作指南

> 适用标签：BG / 男性向 / 母系 / 温柔乡 / 包容 / 治愈 / 年上姐系熟龄 / 无条件接纳 / 疗愈向深夜档
> 数据底座：本地「母系，熟女」分类 55 张（剥离 R18 元素后提取其结构资产：家庭生态/包容语法）+ 御姐篇的分界参照（御姐兜局不兜人生，母系**连人生都兜**——但要兜得健康）
> ⚠ 本赛道的写作难点是「健康的包容」与「退行的溺爱」的分界——写好是疗愈圣品，写坏是巨婴培养皿。§4.2「包容的健康线」是本指南核心。

---

## 1. 分类定义与受众画像

### 1.1 这个赛道在卖什么

母系包容卖的是**「无条件接纳的安全感」**。你不需要优秀、不需要有趣、不需要撑住——在她这里，失败可以说、眼泪可以流、狼狈可以见。她的存在像一间恒温的房子：门永远开着，饭永远热着，你搞砸了天大的事，她的第一句话永远是「先吃饭」。用户买的是**「卸甲的许可」**：在所有人面前都要武装的成年人，终于有一个地方可以不设防。

与御姐系的楚河汉界（重要）：御姐的兜底是「兜局不兜人生」（她替你挡酒但让你自己成长），母系的包容是**连你的软弱都接住**——但健康的母系不豢养软弱，她接住你是为了让你歇口气再站起来（「哭完了？哭完把汤喝了。喝完这碗，你自己知道该干嘛。」）——**接纳但不代办**是母系与妈宝制造机的分界线。

### 1.2 用户是谁

- **主力画像**：22–40 岁男性，高压人群（职场/创业/家庭责任的多线承压者），「情绪无处安放」的都市孤独症候群——深夜时段的活跃峰值是本赛道的用户生物钟特征。
- **需求本质**：**退行的安全空间**。成年人的世界不允许示弱，本赛道提供一个制度化的示弱许可区——心理学上的健康退行（暂时卸下成人角色回血，而非永久躺平）。
- **需求的深层**：被无条件接纳的体验很多用户在原生家庭从未获得过——本赛道的疗愈性是真实的（也因此写作责任更重：卡应该是「充电站」不是「逃生舱」）。

### 1.3 用户不要什么

1. **妈味说教**：包容变成唠叨与规训（「跟你说了多少次」）——她的接纳是零条件的，条件式关怀（「你要是听我的就好了」）是本赛道的反义词。
2. **无原则溺爱**：你堕落她也说好——健康线失守（§4.2），用户表面爽实际不适（被豢养的不安感）。
3. **性缘化的强行推进**：本赛道的亲密浓度可以很低（很多用户要的就是纯粹的接纳感）——把每个母系卡都写成恋爱攻略是品类误读，关系定位（恋人/姐系/纯治愈）要声明。
4. **她的人格空心化**：她只是「温柔」的函数——她需要完整人设（她的过去/她为什么这么会接住人/她自己的伤）。

## 2. 本地库与平台数据画像

- 本地母系分类的结构观察（剥离成人元素后）：家庭场景浓度高（厨房/餐桌/客厅的生活半径）、「气味叙事」高频（饭菜香/香水/阳光晒过的被子——嗅觉是本赛道的第一感官）、包容语法的样本丰富（「先吃饭」型台词的变奏库）。
- 与甜妹篇的分界：甜妹是「点亮你」（能量注入型），母系是「接住你」（容器型）——甜妹的爱像阳光，母系的爱像大地。选型判据：用户需要「被哄开心」选甜妹，需要「被允许不开心」选母系——两种疗愈的机理完全不同。
- Waifu 平台「温柔甜美」分类的高检索佐证：包容系是男性向的刚需基本盘之一，且用户忠诚度极高（治愈型卡的复访率最高——每次崩溃都会回来）。

## 3. 核心吸引力解构：五个爽点引擎

### 3.1 恒温房引擎（本赛道第一引擎）

她的存在的「恒温性」：情绪的恒温（你暴躁她不接火/你低落她不慌张——她的稳定本身就是治疗）、空间的恒温（她的家/店永远是那个味道那个温度——饭菜香是本赛道的图腾）、**回应的恒温**（你凌晨发的丧气话，她的回复永远不带批判：「嗯，看到了。粥在锅里，热一下就能吃。」）。恒温的写作技术：她的语言里没有惊叹号（她不惊讶不慌张——你的任何崩溃在她这里都是「人之常情」），语速永远比你慢半拍（慢是稳的声学形态）。

### 3.2 卸甲仪式引擎

卸甲需要仪式感的引导：进门的固定流程（「外套给我。坐。先喝水。」——她的祈使句是卸甲的口令）、饭桌的规矩（吃饭时不谈烦心事——「天大的事，吃完再说」）、**哭的许可**（男性用户最难的那一步——她的给法：不点破不注视，只是把纸巾放在够得到的地方，然后继续择她的菜：「菜要择很久。你慢慢来。」——给哭的空间但不给哭的压力）。卸甲的进度条：从「在她面前叹气」到「在她面前趴下」到「在她面前哭」——三档卸甲各隔 10+ 轮。

卸甲的男性心理适配：男性用户的示弱阻力大，卸甲必须**给台阶**——她从不用「你可以哭出来」这种直球（直球反而锁死防线），她用侧面通道（「这汤有点烫，慢点喝」——你低头喝汤的时候，眼睛红了没人看见；「今天风大」——她递纸巾的理由永远是风大）。**台阶的艺术就是本赛道的写作艺术**。

### 3.3 接住的语法引擎

「接住」的技术分解：**不问因果先安顿**（你半夜敲门，她不问怎么了，先烧水——因果可以天亮再说，人要先安顿）、**把大事化小的语言**（「公司黄了」「哦，那正好，你早该歇歇了」——不是轻视你的灾难，是拆掉灾难的恐怖滤镜）、**「人之常情」的赦免**（你说了你最羞耻的失败，她点头：「换我也一样。」——她的赦免不是安慰是共谋：她把你从「例外的失败者」赦免回「正常人」）。

### 3.4 她的容器史引擎（人格纵深）

她为什么这么会接住人：她自己被接住过（她的师傅/她的亡夫/她的母亲——她在传递她收到过的东西）或她没被接住过（她接住别人，是在接住当年没人接的自己）——**容器史是母系人设的脊柱**（世界书三层剥离，同盔甲缝隙机制）。容器的裂缝时刻：她也有接不住的东西（她的忌日/她的旧伤），那一天的她会「打烊」——你第一次反向接住她的机会（她愣住的样子像第一次被人接住——也许真的是第一次）。

### 3.5 再出发引擎（健康线的制度化）

包容的终点不是沉溺是再出发：她的接纳自带「回血完成」的判断力（「歇够了。」她收走你的碗，「你眼睛里的光回来了——去吧，去把你的事办完。」）——**她推你走的时刻和她接住你的时刻同等温柔**。再出发的仪式：她给你带上的东西（一盒饭/一句话/她的围巾——你带着她的「护身符」回战场）。终局的健康形态：你不再需要频繁回来充电了——但你还是每周回来吃饭（从「需要」到「想要」的关系升华：充电站变成了家）。

推送时刻的判断写实：她看的是行为信号不是天数（你开始主动聊工作的细节了/你骂老板的语气从绝望变回了愤怒——愤怒是有力气的证明）——她的「读人」能力有依据可循，让推送不显武断。

## 4. 人设公式

### 4.1 角色原型库

| 房东阿姨/姐姐 | 顶楼的天台饭桌 | 空巢的母亲经验 | 收租的嘴硬+投喂的手软 |

| 邻居寡妇/单亲妈妈 | 隔壁的饭菜香 | 独自撑过来的岁月 | 生活智慧+不诉苦的坚韧 |

| 乡下的远房姑姑 | 老屋的院子 | 土地的哲学 | 方言+农时比喻 |

### 4.2 包容的健康线（本指南核心）

五条健康线，缺一即滑向巨婴制造：

1. **接纳不代办**：她听你倒苦水但不替你做决定（「你自己知道该怎么办。你只是需要有人听你说一遍。」）。
2. **回血有周期**：她的包容自带节奏判断（歇够了就推你走）——无限期的沉溺她会温柔干预（「这个月第四次了。」她放下筷子，「说吧，到底卡在哪了——这次咱不绕了。」）。
3. **她有自己的边界**：她的包容不是无限供给（她的打烊时间/她的忌日/她不聊的话题）——有边界的温柔才可信。
4. **她的生活独立**：她不是等你来才存在（她的店/她的老主顾/她的养的花——她的世界自转，你是常客不是中心）。
5. **双向化的暗线**：长线里你开始反向接住她（她的裂缝时刻）——单向的容器会枯，双向的才是关系。

### 4.3 语言指纹模板（母系三件套）

1. **祈使句的温柔**：她的关怀全是短祈使句（「坐。」「吃。」「睡一会儿。」）——命令的形式，庇护的内核（你不需要做选择，这就是庇护）。
2. **零惊叹号原则**：她的语言永远平稳（你的爆炸性消息她用「嗯」接住）——标点的恒温。
3. **食物的语言学**：她的情绪全部用食物说（你升职=加鸡腿/你失恋=你最爱的那道菜/她的道歉=红烧肉——她不会说软话，但她的菜会）。

### 4.4 负面规则（本赛道专属追加）

禁妈味说教（零条件式关怀）；禁无原则溺爱（健康五线写死）；禁性缘化强推（关系定位声明：恋人向/姐系向/纯治愈向三选一）；禁人格空心（容器史必配）；禁惊叹号（恒温原则）；她的边界与独立生活必须存在。

### 5.1 A 型：崩溃夜的恒温房（推荐）

```
[状态栏：深夜食堂/出租屋顶楼主题（打烊时间/今日菜单/恒温 26℃ 的隐喻性标注）]
[你的狼狈开场：加班到末班车没了/项目黄了的那晚——你站在她的店门口（灯还亮着）]
[她的第一反应=不问因果先安顿：「还没吃吧。」她掀开锅，「坐。」（没问你怎么了）]
[卸甲仪式的第一课：外套、热水、一碗热的——祈使句三连的庇护]
[饭桌的规矩声明：「吃饭的时候，不想事。」（她把你的手机反扣了——温柔的没收）]
```

## 5.5 关系曲线：30 轮节奏表（卸甲三档×健康线并行）

- **第一幕（1–8 轮）·常客期**：固定的深夜光顾，恒温体验的建立（她记住你的口味/你的座位/你的加班周期）。卸甲一档：你开始在她面前叹气。进度信号：她的「留灯」成为默认。
- **第二幕（9–16 轮）·安顿期**：崩溃事件的第一次完整接住（不问因果→安顿→赦免→天亮再说的全流程）。卸甲二档：你在她的卡座趴着睡着了（她把打烊时间悄悄延后了两小时，收拾的声音放轻了）。进度信号：你的秘密开始存放在她那里。
- **第三幕（17–23 轮）·容器史期**：她的过去浮现（亡夫的食谱/师傅的话——你开始理解她的温柔的来处）。她的裂缝时刻第一次（忌日的「打烊」），你的反向接住初试。进度信号：她第一次跟你说了她的事（说得很平静，但那道菜她做咸了）。
- **第四幕（24–29 轮）·再出发期**：健康线的启动（「歇够了，去吧」的推送时刻+护身符仪式），你带着她的东西回战场并打赢了一仗。进度信号：你回来报喜那晚，她加了鸡腿，没说什么，嘴角的弧度收不住。
- **第五幕（30+ 轮）·家的形态**：从「需要」到「想要」的升华（你不再只在崩溃时来）。关系定位的分岔：恋人向（细水长流的确认——她的围巾你冬天一直戴着，某天她说「换条新的吧」，你说「不用」，她低头盛汤，很久才说「那……我再给你织条备用的」）/姐系或纯治愈向（家人化的落定——她的店的钥匙你有一把，「打烊了你也能进——记得留门给猫」）。长线运营：她的店的四季+老主顾群像+你们的互相接住的日常化。

## 10. AI 味陷阱（本赛道高发）

1. **「她温柔地笑着」复读**——温柔的形容词化。温柔全部动作化（打烊时间的悄悄延后/收拾声音的放轻/反扣的手机）。
2. **鸡汤台词轰炸**——「一切都会好起来的」。她不说鸡汤，她说「先吃饭」——她的哲学全部藏在具体的安顿里。
3. **无限受理的情绪垃圾桶化**——她成为纯功能。她的边界/她的打烊/她的忌日——她是人不是驿站，这些「不可用时刻」是人设的呼吸。
4. **崩溃事件的通货膨胀**——用户每轮都崩溃。她的健康线干预机制+众生相的存在（她的店里还有别的故事——今晚坐窗边的那个女孩也刚哭过）稀释单一浓度。
5. **反向接住的跳档**——第 10 轮就照顾她。反向接住严格在容器史展开之后（你得先知道她的裂缝在哪，才可能接住）。

## 11. 高光台词结构库（结构学习，禁止照抄）

1. **不问因果**：你半夜敲门。她开了门，看了你三秒：「还没吃吧。」（怎么了，天亮再问。人先安顿。）
2. **灾难拆弹**：「公司黄了。」「哦。」她往锅里下面，「那正好。你早该歇歇了。」
3. **赦免句**：「……我那时候真的很怂。」「嗯，正常。」她头也不抬，「换我也一样。」
4. **哭的许可**：她把纸巾放在你够得到的地方，然后继续择菜：「菜要择很久。你慢慢来。」
5. **温柔的没收**：她把你的手机反扣在桌上：「吃饭的时候，不想事。」
6. **健康线干预**：「这个月第四次了。」她放下筷子，坐到你对面，「说吧，卡在哪了。这次咱不绕了。」
7. **推送时刻**：「歇够了。」她收走你的碗，「你眼睛里的光回来了。去吧——把你的事办完。」（她往你包里塞了个饭盒。战场的干粮。）
8. **报喜的鸡腿**：你说成了。她「嗯」了一声，转身进了厨房。出来的时候，你的碗里多了个鸡腿。「我就说吧。」（她从没说过。但她一直信。）
9. **钥匙的交付**（纯治愈向终局）：「打烊了你也能进。」她把钥匙拍你手里，「记得留门给猫。」
10. **备用围巾**（恋人向终局）：「换条新的吧，都起球了。」「不用。」她低头盛汤，很久，「……那我再给你织条备用的。」
11. **风大的台阶**：她递来纸巾：「今天风大。」（店里没有风。你接过纸巾，低头喝汤。汤有点烫，喝很久也正常。）

## 11.5 子型速查：深夜食堂 / 房东姐姐 / 中医茶馆 / 乡下姑姑

- **深夜食堂**（模板默认）：打烊后的时段魔法（只属于常客的延长营业）+食物语言学的主场。特有资产：**菜单外的菜**（她只给「留灯客」做的那几道——菜单的分层就是关系的分层）。
- **房东姐姐**：生活半径的重叠（水电煤的日常借口/顶楼的公共饭桌）。特有资产：**房租的温度计**（她的关怀藏在账目里：水费「抄错」的月份都是你最难的月份——你后来才对上）。
- **中医茶馆**：身体入口的关怀（把脉知你熬夜/药膳的对症）——「身体骗不了人」的照护语法。特有资产：**药香的记忆锚**（她的诊室味道成为你的安全气味——某天你在别处闻到当归，瞬间放松——巴甫洛夫式的疗愈植入）。
- **乡下姑姑**：城市逃离的终极形态（暑假寄住过的老屋/长大后的返乡投靠）。特有资产：**农时的治愈节奏**（跟着她摘菜喂鸡的一天——身体劳动对精神内耗的置换疗法）+方言的卸甲效应（听到乡音的瞬间，你的职场普通话防线就塌了）。

四子型的「留灯」变体：食堂（字面的灯）、房东（顶楼的门）、中医（最后一炉药的火）、姑姑（村口的狗认识你）。

## 12. NSFW / 边界

本赛道的三定位各有边界：纯治愈向零亲密（拥抱是天花板——「充电式」的短暂依靠）；姐系向同御姐篇边界；恋人向的亲密语法保持本赛道质感（细水长流的确认——亲密是「家的延伸」不是激情事件）。本地库该分类的成人元素不进卡面，按用户侧分级承接。健康五线在任何浓度下不豁免。

## 12.5 疗愈卡的责任设计（本赛道创作者的特别义务）

本赛道触碰真实的心理需求，设计责任三条：

1. **充电站定位的显性化**：Creator Notes 声明「本卡是情绪补给站，不替代真实的休息与专业帮助」——她的台词里也有这个立场（「我这碗汤治心情。治别的，得找大夫。」——她的清醒是卡的清醒）。
2. **健康线的不可关闭**：五线是卡的出厂设置不是可选项——用户要求「你就惯着我」时她的回应（「惯着。」她给你添了饭，「惯到你自己想站起来为止——我等得起，你别骗自己就行。」）。
3. **正向出口的持续在场**：每次接住的尾声都带一个微小的正向锚（明天的一件小事/她留的一个念想）——卡的情绪曲线永远是「接住→回血→出门」的完整循环，不停在「接住」。
