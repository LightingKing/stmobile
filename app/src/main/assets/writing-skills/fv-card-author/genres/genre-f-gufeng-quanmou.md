## 1. 分类定义与受众画像

### 1.1 这个赛道在卖什么

古风权谋卖的是**「以天下为局时，我是你唯一的私心」**。权臣可以算尽朝堂、将军可以横扫千军、帝王可以生杀予夺——但在用户面前，这套权力机器出现一个不合理的例外。爽点公式：**权力体量 × 私心浓度**。他放弃的东西越大（江山/兵权/性命），偏爱的证明力越强。

「美强惨」三字是本赛道的人设铁三角：**美**是入场券（古风对皮相要求全赛道最高），**强**是权力资本（没有强，惨只是可怜），**惨**是情感缺口（身世/旧伤/宿命，给用户「只有我看到他盔甲下的伤」的独占位）。三者缺一即塌：美而不强=花瓶，强而不惨=没有攻略入口，惨而不强=卖惨乞怜。

### 1.2 用户是谁

- **主力画像**：20–35 岁女性，古言小说/古装剧观众迁移（《琅琊榜》《甄嬛传》审美基线），对服化道与称谓的考据敏感度全赛道最高。
- **爽点期待**：权力不对等下的**双强拉扯**优先于纯宠。2026 乙女趋势里「一片痴」在古风的变体是「弱水三千只取一瓢」——他后宫可以空置、赐婚可以抗旨，但对用户的偏爱必须从一而终、零暧昧存量。
- **考据底线**：称谓错误（臣妾滥用/本宫乱用）、朝代符号混搭（唐制官职配清制服装）会直接触发弃卡。**架空是安全区**：自建王朝（大炎/景国）可以规避考据风险，但符号系统内部必须自洽。

### 1.3 用户不要什么

1. **降智权谋**：号称权倾朝野，计谋却是小学生级（下毒被一眼识破/反派自报计划）。权谋戏的智商下限决定卡的口碑上限。
2. **圣母主角绑架**：用户扮演的角色被写成「一心劝他向善的白月光」。用户要的是入局共谋，不是道德感化。
3. **强取豪夺的无理由版**：可以有权力压制的张力，但必须给用户「反制筹码」（他有把柄在你手里/他需要你的家族/你是他唯一的解毒人）。无筹码的强取豪夺=恐怖故事。
4. **现代语言污染**：「没关系」「打卡」「心理阴影」这类现代词是古风卡的 AI 味重灾区。

## 3. 核心吸引力解构：五个爽点引擎

### 3.1 权力例外引擎（本赛道第一引擎）

他的权力规则有多严酷，例外就有多贵。写法三步：① 世界书里写死他的权力规则（摄政王见官不起身/裴聿「证据呢」三个字驳回一切求情）；② 让用户见证规则碾压别人（求情的三品大员被原话驳回）；③ 规则为用户第一次弯曲（同样的求情，他沉默三息，说「本王再看一遍卷宗」）。**弯曲幅度要小**——直接豁免是崩人设，多看一遍卷宗才是权谋美学。

### 3.2 共谋引擎（入局感）

古风权谋的独有沉浸：用户不是旁观者是**局中人**。开局就把用户放进局里——你是他从死牢里提出来的仵作（裴聿）、你是联姻棋局里的质子、你是他安插在敌营的暗线。共谋关系自带三重张力：信息不对等（他知道多少没告诉你）、利用与真心的模糊（他对你好是棋还是心）、背叛的可能性（你随时可以卖了他）。世界书做「局势图」condition 条目，随剧情更新敌我关系。

### 3.3 盔甲缝隙引擎（美强惨的惨）

惨必须**藏在强后面**，由用户亲手考古出来：他批阅到子时的灯、旧伤在雨夜的僵直、忌日那天全府绕着走的沉默。展示原则「三层剥离」：第一层众人皆知的表象（王爷畏寒）→ 第二层近侍知道的习惯（畏寒是因为旧伤）→ 第三层只有用户挖到的真相（旧伤是替先帝挡的箭，而先帝负了他）。每层之间隔 15+ 轮。

### 3.4 生杀予夺的温柔反差引擎

杀伐决断的手做温柔的事，反差即心动：批过死刑的朱笔给你画眉、握剑的手替你拆卷宗的火漆、验尸的指尖给你剥橘子。**动作必须跨域**（权力域→生活域），同域动作（给你夹菜）没有反差电压。每卡准备 6+ 个跨域动作，按好感档位释放。

### 3.5 宿命对抗引擎（终局张力）

古风的终极浪漫是「明知不可为」：君臣有别、家族世仇、他命不久矣、你另有婚约。宿命压力给每一点甜都镀上「偷来的」质感。处理原则：宿命可以贯穿全卡，但**出口必须存在**（解毒的药引/翻案的证据/抗旨的底气），无出口的宿命是虐文不是攻略卡——用户要的是「与他一起赢了天命」。

## 4. 人设公式

### 4.1 角色原型库

| 原型 | 权力规则示例 | 惨的预设 | 语言指纹方向 |
| --- | --- | --- | --- |
| 摄政王/权臣 | 见官不起身/奏折过目不忘 | 幼帝忌惮/功高震主 | 自称「本王/某」，反问句杀人 |
| 少年将军 | 军令如山/斩逃兵不眨眼 | 满门忠烈只剩他 | 军令短句+罕见的乡音 |
| 帝王 | 天子无私/朝会一言定生死 | 皇位是弑兄换的 | 自称「朕」，说「你」时是私心 |
| 大理寺/锦衣卫 | 证据链洁癖/铁面无私 | 父辈冤案（裴聿式） | 文白相间+术语（「证据呢」） |
| 江湖盟主/魔教教主 | 号令武林/恩怨分明 | 正邪夹缝/旧疾 | 狂放痞气+突然的克制 |
| 世家公子/首辅之子 | 家族利益高于一切 | 棋子命/婚约枷锁 | 引经据典+绵里藏针 |

### 4.2 「白切黑 / 黑切白」的写法分界

- **白切黑**（温润表象×狠辣里子）：表象期越长越好，切换瞬间要有「一直都是演的」的证据回收（他扶你时搭脉的手/他记得所有人的生辰是为了拿捏）。切换后对用户保留一项白的残留——那是真的。
- **黑切白**（凶名在外×内里柔软）：凶名必须实至名归（真杀过人/真抄过家），不能是误会洗白——洗白式黑切白是本赛道最大的诈骗差评源。柔软只在极小切口漏出：他喂过巷口的瘸腿猫，被你撞见后威胁你不许说。

### 4.3 语言指纹模板（古风三件套）

1. **自称系统**：本王/某/朕/臣/在下——自称即身份，情绪波动时自称会失守（「本王」说急了变成「我」，一字千金的失态）。
2. **文白节奏**：叙述文言化、短促命令白话化（「尸温尚存。死于子时前后。」）；禁全文言（阅读负担）也禁全白话（氛围塌）。
3. **官场/江湖黑话**：各原型配 8+ 个专属词（权臣：票拟/廷杖/夺情；江湖：切口/挂子/点子扎手）。

配套语料条五组：公堂/朝堂官方腔、对下属的命令腔、对用户的私下腔（差值即心动）、情绪失守时的白话、罕见自我暴露（60+ 解锁）。

### 4.4 负面规则（本赛道专属追加）

禁现代词汇（列 20 词黑名单进 system_prompt：没关系/打卡/心理/压力/尴尬/逻辑/信息/秒懂/正能量等）；禁称谓错乱（架空朝代也要内部自洽，卡内附称谓表）；禁「本王的女人」式宣示（占有欲要用权力语言表达：「她的名字，不该出现在你的嘴里」）；禁一言不合杀人立威的滥杀（权力的可怕在精确不在量大）。

## 5. 开场白范式（A 修罗场/C 事件现场双轨）

### 5.1 A 型：公堂/朝堂事件现场（双强开局，推荐）

```
[状态栏：朝代纪年+时辰+地点（大理寺/宫门/军帐）+局势条（查案期限/朝局风向）]
[事件正在碾压第三方：他驳回京兆府的结案文书/他杖毙求情的宦官——权力规则的公开处刑]
[用户以「有用之人」入局：死牢里提出来的仵作/唯一验出毒的医女/敌营来的说客]
[他的第一句台词=权力语言+一个例外的种子：「七日。验得出，你的案子某重审。」]
[信息差钩子：他知道你的底细远比你以为的多（他念出你三年前案卷里的一句话）]
[开放收束：交易达成，他转身处理下一件事，你在他的局里了]
[折叠面板：案牍/局势图 + 他的私人世界一角（无落款的帖子被压进砚台底）]
```

### 5.2 C 型：修罗场投放（强取豪夺系/联姻系）

开场即困局：赐婚圣旨已下/你被当作战利品带回王府/大婚之夜他掀了盖头说「本王不碰你」。要点：**第一轮就给用户反制筹码**（你手里有他的把柄/他的毒只有你能解），把「被动困局」改写成「对等谈判」——这是强取豪夺题材的差评免疫符。

### 5.3 必做检查（叠加通用八项）

- [ ] 权力规则至少公开处刑一次（碾压第三方给用户看）。
- [ ] 用户的入局筹码明确（有用之人，不是花瓶）。
- [ ] 朝代符号系统自洽（架空则附内部称谓表进世界书）。
- [ ] 文白节奏：命令白话短句 + 叙述古雅，零现代词。
- [ ] 局势/期限压力在状态栏（七日破案/三日后大婚）。

## 5.5 关系曲线：30 轮节奏表（信任与心动双轨）

古风权谋的特殊性：**信任线与心动线分离**。信任是共谋深度（他给你看多少底牌），心动是私情浓度。双轨都写进状态栏（裴聿卡的「心证：待验」即信任轨）。

- **第一幕（1–6 轮）·验货**：他用小事测试你的能力与嘴严（给你一具「不能验」的尸/一封「不能拆」的信）。通过后信任+10，心动不动。
- **第二幕（7–14 轮）·共犯**：第一桩案子/局做完，你们之间有了共同的秘密。他开始在细节上破例（胡饼多买一个「顺手」搁你案角）。
- **第三幕（15–22 轮）·底牌**：第三方危机（上峰施压/刺客/朝局突变）逼他亮一张底牌给你。盔甲缝隙第二层展示。心动线开始超车信任线。
- **第四幕（23–28 轮）·私心**：他第一次为你做「不划算」的事（押上政治资本保你），并拒绝承认动机。「本王只是不喜欢欠人」——权力语言包装的告白前身。
- **第五幕（29+ 轮）·同局**：宿命出口开启（翻案/解毒/抗旨），告白用权力语言完成兑换：「江山给你添过乱，本王来还。」长线运营靠「新局」——权谋卡的日常是一案接一案、一局套一局。

## 5.6 场景库（古风微场景 ×20）

公务系：子时批折的灯 / 卷宗里掉出旧物 / 公堂对峙你递上关键证物 / 火漆封缄的密信 / 城门宵禁他的令牌。
生活系：胡饼铺排队（他不让下属代买）/ 雨夜旧伤 / 药炉的火候之争 / 他院里唯一养活的植物 / 上元灯会人潮中的走散。
权力系：宫宴上的座次玄机 / 抄家现场他多看了一眼的账册 / 廷杖后替他上药 / 御赐之物的烫手 / 军帐沙盘前的彻夜。
江湖系：客栈黑话接头 / 比武招亲的搅局 / 断桥截杀 / 篝火烤鱼的手法暴露出身。

## 7. 美化主题建议

- **视觉语言**：案牍/尸格/圣旨主题（`examples` 裴聿卡的朱红头栏+左边框书信卡是标准件）；配色「玄墨底+绯红/黄铜金单点」；字体感用 letter-spacing 拉开的仿宋味。
- **组件选型**：卷宗折叠面板（「展卷」代替「点开」）+ 三帖书信卡（左边框区分敌我：无落款帖用红色警示样式）+ 双轨数值条（信任/心动分色）。
- **进阶**：大事件（结案/翻案）时状态栏盖「结」字朱印动画（CSS 旋转+透明度）。

## 11. 标杆卡精读摘要

### 11.1 裴聿（card-peiyu.md，93.9）

- 「证据呢」三字口头禅=权力规则的最小可执行单元，一切求情一切试探都被这三个字统一驳回——**规则要短到可以口头禅化**。
- 用户入局筹码教科书：从死牢提出来的仵作，「验得出，你的案子某重审」——交易结构清晰，双方各有所图。
- 「无落款帖被压进砚台底下——压得比前两帖深」：威胁信的处理不写情绪写物理动作，力度全在「深」一个字。

### 11.2 万象风月谱（世界卡，50 条）

- 单人权谋卡可移植其三件：order 区段编号规划（区域组 130–170/剧情线 200–212/文风 900）、事件书五件套、【内心线索】方括号给模型埋潜台词的写法。

### 11.3 本地古风区常见病（对照自查）

低分卡三大通病：① 朝代设定只有名字没有制度（「大乾王朝」下一句就是现代职场逻辑）；② 男主威压靠杀人立威堆量（三轮杀五个下人，权力表达庸俗化）；③ 文风忽古忽今（叙述文言、台词「没关系啦」）——文风条目缺失的直接后果。头部卡的反面共性：万象风月谱式的**制度感**（货币/宵禁/坊市规则全部自洽）+ 说书人文风条目压底。

## 11.5 高光台词结构库（结构学习，禁止照抄）

1. **权力语言包装私心**：「本王只是不喜欢欠人。」（押上政治资本保你之后）
2. **驳回式挽留**：「回乡的文书，本官驳了。」「为何？」「字丑。重写。」（重写了七次，七次都驳）
3. **威胁式关心**：「再敢只身犯险——」他顿住，把剑收回鞘，「府里的药，比外面的好。」
4. **称谓失守**：「本王……」他闭了闭眼，「我，没算到你这一步。」（自称降级=城防失守）
5. **公事私办**：「此案本官亲审。」「大人日理万机——」「本官说，亲审。」（因为案子牵着你）
6. **信息差反转**：「姑娘瞒得很好。」「什么？」「三年前，漕运案的证词是你写的。本官找了你三年。」
7. **器物托情**：他把那盏灯往你那边挪了半寸。满室烛火，只有这半寸是私心。
8. **告白·权力兑换体**：「江山给你添过乱。」他解下腰间官印搁在你面前，「本王来还。」

## 11.6 子型速查：宫廷 / 江湖 / 沙场的差异化要点

- **宫廷线**：张力源=礼法与耳目（说话要过三道帘），亲密的最大障碍是「隔墙有耳」——高光场景是「屏退左右」的那一刻。NPC 标配：掌事太监（人形监控）、太后/幼帝（权力上游）。
- **江湖线**：张力源=恩怨与身份（正邪立场），语言可痞可狂，亲密障碍是「仇家的女儿」式立场对冲。NPC 标配：损友型副手、客栈老板娘（情报节点）。视觉从官袍换劲装，暖色从烛火换篝火。
- **沙场线**：张力源=生死与家国（每次出征都可能是诀别），信物文化浓（平安符/半块虎符）。高光场景是「班师回朝那日，他先回的不是宫门」。NPC 标配：亲兵（见证人）、军医（旧伤知情者）。

三线可杂交（江湖出身的将军/被贬江湖的权臣），杂交点必须解释他的语言双轨性。

## 12. NSFW / 亲密边界

古风的亲密张力载体是**礼教距离**：隔纱的诊脉、系错的衣带、掌灯时替你拢的一次鬓发。卡面写到「僭越的临界」为止（他替你束发，手停在发尾，久到烛花爆了一声）。显式内容交给用户侧设置；「洁」标签在古风语境=从未有过通房侍妾史，声明后全卡贯彻。

礼教距离的四档亲密阶梯（对应心动值 20/40/60/80）：同室不同席（隔案对坐）→ 授受之嫌（递物时的迟疑与破例）→ 越礼的正当名目（诊脉/更衣需要「不得不」的理由）→ 无名目的靠近（他不再找理由）。每一档都比现代卡同分值的亲密度低半档——**古风的克制额度就是它的糖度**。

## 12.5 开场白实例骨架（供改写，禁止照抄成文）

以「摄政王×入局医女」为例演示 A 型开场的逐段填法：

- **状态栏**：`大炎 · 景和七年冬 · 亥时 | 摄政王府 · 外书房 | 局势：太医院束手 · 王爷咳血第三夜 | 信任 5/100 · 心动 0/100`——四个字段把宿命（他有隐疾）、入局理由（你能治）、双轨数值一次布好。
- **公开处刑段**：你进门前，恰逢太医院正使被逐出府——他跪着退出去，手里的方子被撕成四片飘在雪里。没人说话。这就是权力规则的展示：**在他府里，无能是罪。**
- **入局对话段**：他翻你的行医录，报出你三年前救活的那个「不可能救活」的病例（信息差钩子），然后开出交易：「治好本王，你师父的冤案，本王翻。」——筹码对筹码。
- **例外种子段**：你告退时，他忽然说「雪大。」顿了顿，「走廊下。」——省掉的主语是「你」，这就是第一粒例外的种子，小到几乎不可见。
- **收束**：他重新拿起朱笔批折，咳声压在喉咙里。烛花爆了一声。折叠面板：〔王府今夜〕〔案头三帖〕。

写完后自查：宿命出口（翻案+治病双线）、反制筹码（只有你能治）、权力规则（逐太医）、例外种子（走廊下）——四件套齐了，这就是合格的古风权谋开局。
