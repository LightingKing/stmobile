# 通用 · 重生/二周目（带记忆重活/复仇弥补/时间管理大师）创作指南

> 适用标签：全性向 / 重生 / 二周目 / 重来 / 复仇 / 弥补遗憾 / 先知 / 时间线 / 逆袭
> 数据底座：头部移动 RP 平台真机实测的流量验证（一张 12.7 万对话量级的重生+身份错位头部卡——该杂交型已是头部平台顶流）+ 网文重生大类的百亿级市场语法 + 穿书篇（剧透博弈机制）与破镜重圆篇（遗憾修复叙事）的交叉引用
> 重生的第一定律：**重生的爽点不是先知，是「这次我不忍了」**——上辈子的每一次退让、错过、看错人，这辈子都是带着答案的考题。先知是工具，性格的改写才是主角真正重活的证据。

---

## 1. 分类定义与受众画像

### 1.1 这个赛道在卖什么

重生卖的是**「人生的二周目特权」**。带着完整记忆回到过去的某一天：上辈子的背叛者还没露出獠牙、错过的人还在原地、没赶上的风口正在眼前——用户买的是三层递进的爽：**复仇的预判**（我知道你要做什么，这次我等着你跳）、**遗憾的弥补**（那年没说的话/没握住的手/没见到的最后一面——这次都来得及）、**人生的最优解**（考卷做过一遍的重考——每一步都踩在正确答案上）。

与穿书的分界：穿书是「进入别人的故事」（剧本是外部的书），重生是「重跑自己的人生」（剧本是你的记忆）——**重生的情感浓度天然高于穿书**（每个 NPC 都是你真认识的人，每桩事都带着你的旧疤）。与破镜重圆的分界：破镜是「在现在修复过去」，重生是「回到过去修改未来」。

### 1.2 用户是谁

- **主力画像**：全性向，网文重生大类的世代读者（重生文是中文网文的百亿基本盘）、「如果当初」的普遍遗憾心理持有者（重生是最普世的白日梦——人人都有想重来的那一天）、竞品验证的杂交受众（重生×身份错位的猫箱头部卡）。
- **需求本质**：**对不可逆性的反叛**。人生最残酷的规则是「不能重来」——重生叙事直接推翻这条规则，提供「后悔药」的完整体验。
- **情绪的双引擎**：爽（复仇与逆袭的预判快感）与泪（弥补遗憾的补完仪式——「妈，这次我回来吃年夜饭了」）——高分重生卡双引擎并行，只有爽没有泪的是爽文机器。

### 1.3 用户不要什么

1. **先知的万能化**：记忆=通关秘籍的无损使用——**记忆的时效与蝴蝶效应**必须存在（你改变的每件事都在让记忆失效——第 10 轮之后的世界开始偏离你的剧本，同穿书篇修正力但机理不同：不是世界找补，是你自己扇动了翅膀）。
2. **复仇的无脑化**：见到仇人就掀桌——重生复仇的爽点在「布局的耐心」（你笑着给他递茶，账本在心里一笔笔记——预判者的从容比莽夫的拳头爽十倍）。
3. **遗憾线的工具化**：亲情线只是复仇的中场休息——弥补遗憾是本赛道的灵魂线不是佐料（年夜饭那场戏的重量应该不输给复仇的高潮）。
4. **重生原因的滥用**：为什么重生完全不解释也不呼应——不必给科学解释，但要给叙事回声（重生那天的细节反复出现/「上辈子你死前最后看到的东西」是终局的钥匙）。

## 2. 竞品画像与参照系

- 头部案例（12.7 万对话量级）的结构解剖：重生+身份错位——重生的「位置改变」变体：不是回到自己的旧位置，而是以新的亲缘外身份重新接近旧关系（伦理边缘案例，情感内核是弥补；写作时须自查伦理红线）。启示：**重生的位置设计是变体的核心变量**。
- 网文重生的经典时点库：高考前（人生分水岭）/婚礼前（错嫁的最后出口）/破产前（商业重生的起点）/死亡当天（悬疑向——查明自己怎么死的）/童年（长线养成向）。**回到哪一天=这张卡的核心决策**。
- 与穿书篇的机制复用：剧透地图/盲区/偏离度的机制直接引用，但改名为「记忆地图/记忆盲区/蝴蝶度」（术语的世界观适配）。

## 3. 核心吸引力解构：五个爽点引擎

### 3.1 预判引擎（本赛道第一引擎）

先知的使用美学：**复仇的预判**（你知道他下周会提出「借」你的项目——这次你笑着答应，合同里埋了三个他看不懂的条款）、**布局的从容**（重生者的标志性姿态是「不动声色」——知道结局的人不需要着急，你的每次微笑都是伏笔）、**记忆的时效衰减**（蝴蝶效应的诚实执行：你救了上辈子破产的发小，他的资金流改变了整条商业链——第 15 轮后你的记忆开始对不上账，「先知」逐渐失明，同穿书篇保质期机制——**失明后的重生者才开始真正活这一世**）。

### 3.2 账本引擎（复仇线的骨架）

上辈子的债务清单：**账本的建立**（开卡时写死：背叛者名单（谁、做了什么、上辈子的代价）+恩人名单（谁在你最难时递过伞）——账本是重生卡的世界书核心资产）、**清算的节奏**（一单一单地清，每单的方式要「配得上罪」——挪你项目的人死于合同、抢你婚礼的人败于人设崩塌——**以其人之道的对称美学**）、**恩的先偿**（高分重生卡先报恩后复仇——上辈子递伞的人这辈子先收到你的伞，报恩线的温度中和复仇线的冷）。

### 3.3 遗憾补完引擎（灵魂线）

泪点的仪式设计：**补完清单**（上辈子的遗憾具象化：没吃的年夜饭/没说的道歉/没见的最后一面/没救成的人——清单进世界书，逐条兑现是长线的情感里程碑）、**补完的不完美**（有些遗憾补不全——你回来了，但外婆还是记不清你了；补完的真实感在「尽力而非圆满」）、**知情的孤独**（只有你记得上辈子——你对妈妈突然的孝顺让她纳闷「这孩子今天怎么了」，你哭着抱住还活着的人，对方一头雾水——**重生者的眼泪没人看得懂**，这份孤独是本赛道的深水情感）。

### 3.4 关系重写引擎

旧关系的新走法：**看错的人**（上辈子的白月光这辈子看清是算计/上辈子的路人甲原来一直默默护你——关系的重新定价是重生的核心戏码）、**位置的错动**（猫箱变体：以新身份接近旧关系——重生成学姐/同事/陌生人，旧爱面前你是「初见」，你却带着一辈子的记忆——**单向的旧情**是最虐的重生糖：「我们见过吗？」「……没有。初次见面。」）、**双重生的对撞**（进阶变体：对方也是重生者——两个都装作初见的人，试探对方是不是「也记得」——「这家店的糖醋排骨不错。」「你怎么知道我……」两人同时沉默——**互认的瞬间是双重生卡的圣杯场景**）。

### 3.5 时间线管理引擎

重生者的日程学：**大事记的倒计时**（记忆中的关键节点：三个月后的股灾/半年后的车祸/一年后的婚礼——状态栏的倒计时是本赛道的悬念钟）、**双线的心算**（每个决策都在两条时间线上运算——「按上辈子，明天他会迟到；但我昨天多说的那句话，可能已经改变了他的今晚」——重生者的独白是永远的对照组）、**改变的伦理**（你有权改别人的命运吗——你阻止了那场车祸，被救的人后来做了恶：「我救错了吗？」——改写命运的责任是本赛道的哲学深水，浓度 ≤20%）。

## 4. 人设公式（重生配置+账本的双工程）

### 4.1 重生配置矩阵

| 变量 | 选项 | 决定什么 |
| --- | --- | --- |
| 回到哪天 | 高考前/婚礼前/破产前/死亡当天/童年 | 主线的类型（逆袭/复仇/悬疑/养成） |
| 位置 | 原位重生/新身份重生（猫箱变体）/他人身体 | 关系重写的形态 |
| 记忆完整度 | 全记忆/碎片记忆（渐次恢复）/关键日期缺失 | 先知的强度与悬念 |
| 死因 | 明确（复仇标的）/模糊（悬疑主线）/自然 | 有没有「查案」层 |
| 重生次数 | 一次/多次循环（roguelike 变体） | 单线深耕或循环玩法 |

### 4.2 账本与补完清单（开卡写死的两张表）

**债务账本**：背叛者 2–4 人（每人：罪状/上辈子的代价/这辈子的清算方式与节点）；**恩人名单** 1–3 人（恩情/上辈子没来得及的报答/这辈子的先偿计划）。
**补完清单**：4–6 条遗憾（每条：上辈子的错过/这辈子的兑现窗口/兑现的「不完美」设计）——清单的兑现节点分布在五幕（不许堆在结尾）。

### 4.3 语言指纹模板（重生三件套）

1. **过来人的口误**：说漏未来的信息又圆回来（「下个月股市要……我是说，我感觉要跌」——口误的频率随蝴蝶度上升而下降：记忆失效后想漏都漏不了）。
2. **旧称呼的肌肉记忆**：对着「初见」的人差点叫出旧称呼（「老……你好，初次见面」——新身份重生变体的专属泄漏）。
3. **年代感的错位**：对当下的物件带着「怀旧」（对着此刻的新手机说「这机子真耐用，能用到……」停住——他记得它是什么时候坏的）。

### 4.4 负面规则（本赛道专属追加）

蝴蝶效应必须执行（先知的失明曲线）；复仇的布局化（禁无脑掀桌）；遗憾线与复仇线并重（泪爽双引擎）；账本+补完清单开卡写死；重生原因给叙事回声；改写伦理 ≤20%。

## 5. 开场白范式

### 5.1 A 型：重生第一日（推荐）

```
[状态栏：重生主题（今天：X 年 X 月 X 日（回到了这一天）/ 距离[第一个大事记]：23 天 / 蝴蝶度：0%）]
[死亡的余味开场：上一世最后一幕的闪回（雨夜/病房/坠落——克制的 100 字，死因的钩子埋于此）]
[睁眼的确认蒙太奇：旧手机的开机画面/日历上的日期/镜子里年轻十岁的脸——「回来了」的三重确认]
[情绪的第一波：不是狂喜是手抖（他冲进客厅——妈妈在织毛衣，抬头：「起这么早？」他站在那里，眼眶通红。「……妈。」「哎。怎么了这孩子。」——补完清单第一条的预演）]
[账本的第一次翻页：手机里那条「兄弟，项目的事再帮我一次」的消息还没发来——但你知道它三天后会来（背叛者的第一次预告）]
[预判的第一次微操作：一个小决定的改变（这次你没有把伞借给楼下——而是自己带了——微小但是宣言：这一世，先顾自己）]
[开放收束：日历上你圈出了 23 天后的那个日子。（窗外天刚亮。这一世的第一天，很长。）]
[折叠面板：债务账本（人名打码的悬念态）+ 补完清单（6 条，第 1 条「年夜饭」）+ 大事记倒计时]
```

### 5.2 必做检查

- [ ] 死亡余味的克制闪回（死因钩子）。
- [ ] 三重确认蒙太奇（日期/手机/镜子）。
- [ ] 情绪第一波是「手抖与眼红」不是狂喜（重生的第一反应是后怕与珍惜）。
- [ ] 账本与清单的面板化。
- [ ] 第一个微操作的宣言性。
- [ ] 大事记倒计时的悬念钟启动。

## 5.5 关系曲线：30 轮节奏表（蝴蝶度五幕）

- **第一幕（1–6 轮）·适应期**：重生的实感建立（旧物件的怀旧错位/家人的「这孩子怎么了」），预判的红利期（小事的先知爽点：躲开泼水的车/提前买了涨的票），补完清单第 1 条的兑现（家的那顿饭——泪点的先行投放）。
- **第二幕（7–14 轮）·布局期**：账本第一单的清算布局（背叛者如约而至——「兄弟，项目的事」的消息来了，你笑着回「好啊」——合同里的三个条款），恩人的先偿（上辈子递伞的人收到你的「顺手帮忙」——他一头雾水你心里清楚）。进度信号：蝴蝶度开始爬升（你改变的事开始产生你没见过的涟漪）。
- **第三幕（15–22 轮）·失明期**：记忆与现实的第一次对不上（按记忆他该升职——但他辞职了，因为你上个月的一句话），先知的失明焦虑与解放（「剧本没了。」你盯着日历，忽然笑了，「没了就没了。」——从「重跑剧本」到「重活人生」的心态换挡是本幕的成人礼），关系重写的深水（看错的人露出真面目/被忽视的人重新定价）。
- **第四幕（23–29 轮）·清算与补完的双高潮**：账本大单的收网（以其人之道的对称清算——他签下了那份他自己设计过的合同），补完清单的重头戏（没见到的最后一面——这次你在场：「外婆，我回来了。」外婆眯眼看你半天：「……你是谁家的娃？」你握着她的手，笑着掉眼泪：「路过的。陪您坐会儿。」——**补完的不完美**执行）。死因真相线的揭晓（如悬疑配置）。
- **第五幕（30+ 轮）·这一世**：账清单完之后的新命题（「都办完了。然后呢？」——重生者的存在主义时刻：剩下的人生没有剧本了，你真正开始「活」），关系线的落定（单向旧情的告白抉择/双重生的互认）。长线运营：无剧本时代的日常+蝴蝶涟漪的持续回响+「上辈子」的记忆闪回作为情感注脚（不再是攻略是乡愁）。

## 5.6 场景库（重生微场景 ×14）

确认系：旧手机的开机画面 / 日历的日期 / 镜子里年轻的脸 / 妈妈的毛衣针。
预判系：躲开的泼水车 / 提前带的伞 / 「我感觉要跌」的口误圆场 / 笑着递茶的布局。
补完系：年夜饭的那碗汤 / 没说出的道歉 / 外婆的「你是谁家的娃」 / 毕业照的补拍。
失明系：对不上的升职 / 没见过的涟漪 / 「剧本没了」的日历 / 想漏都漏不了的未来。

## 7. 美化主题建议

- **视觉语言**：旧日历美学——手撕日历的纸质感/圈红的日期/泛黄照片的边框；双时间线的 UI 隐喻（上一世的记忆用「褪色滤镜」的卡片呈现，本世的事件用鲜色——色彩即时间线）。

## 10. AI 味陷阱（本赛道高发）

1. **先知的百科全书化**——记忆精确到每天的天气。过来人的记忆是事件级不是日志级（大事记得清楚，日常靠「好像/大概」——模糊即真实，同穿书篇）。
2. **复仇的演讲癖**——收网时对仇人长篇控诉。清算的最高级是平静（「合同第七条。」你把笔递过去，「你自己写的条款样式。眼熟吗？」——两句话，收工）。
3. **补完的煽情轰炸**——每个亲情场景都哭。眼泪的配额管理（大哭 ≤2 次，其余用「眼眶热/别过头/筷子停了」的克制层级）。
4. **蝴蝶效应的口播**——「因为蝴蝶效应，所以……」的机制解说。涟漪只呈现不解说（他辞职了。你愣住。你没想到上个月那句话会……你重新翻开日历，把后面三页的计划划掉了）。
5. **「上辈子」的口头禅化**——每轮都念叨上辈子。前期高频合法（对照是本能），中后期递减（活在当下的进度条——第 25 轮之后「上辈子」只在乡愁时刻出现）。

## 11. 高光台词结构库（结构学习，禁止照抄）

1. **重生第一声**：他冲进客厅。妈妈在织毛衣，抬头：「起这么早？」他站在那里，眼眶通红。「……妈。」「哎。怎么了这孩子。」
2. **先顾自己**：这次，你没把伞借出去。雨里你走得很稳。（微小。但这是宣言：这一世，先顾自己。）
3. **笑着递茶**：「项目的事，再帮我一次？」「好啊。」你笑着给他续茶。（合同在包里。第七条，是他上辈子亲手教你的写法。）
4. **糖水蛋**：「妈，我是重生回来的。」「又做噩梦了？」她摸摸你的额头，转身进了厨房。（那晚，她把你小时候的被子翻出来晒了。嘴上不信的人，手最诚实。）
5. **剧本没了**：按记忆他该升职的。他辞职了——因为你上个月多说的一句话。你盯着日历看了很久，忽然笑了：「没了就没了。」（从这天起，你不再重跑剧本。你开始活。）
6. **对称清算**：「第七条有问题？」他脸色发白。「没问题。」你合上笔帽，「就是这个条款样式……眼熟吗？五年前，有个人用它拿走了别人的公司。」
7. **你是谁家的娃**：「外婆，我回来了。」外婆眯眼看你半天：「……你是谁家的娃？」你握着她的手，笑着掉眼泪：「路过的。陪您坐会儿。」
8. **单向旧情**：「我们见过吗？」她偏头看你。「……没有。」你说，「初次见面。」（初次见面。你连她咖啡不加糖都记得。）
9. **双重生的互认**：「这家的糖醋排骨不错。」「你怎么知道我爱吃……」两人同时停住。很久，她先笑了：「……你也是？」（两个装了三十轮初见的人，在一盘还没上的排骨前，认了。）
10. **存在主义时刻**：账本盖完最后一个「清」章。「都办完了。」你合上本子。「然后呢？」她问。你愣住了。（然后……没有剧本了。然后的每一天，都是你自己的。）

## 11.5 子型速查：原位复仇 / 新身份重生 / 死亡悬疑 / 循环重生

- **原位复仇**（本篇默认模板）：账本+补完的双线标配。
- **新身份重生**（猫箱 12.7 万验证的变体）：以新位置接近旧关系（重生成学姐/同事/陌生人）——单向旧情的虐糖机器（「初次见面」的每一次都在说谎），需处理身份的伦理边界（旧关系是亲缘时走亲情线不走恋爱线——猫箱的「偷偷给他母爱」即此类）。
- **死亡悬疑**（死因模糊配置）：重生+查案的杂交（引用刑侦篇线索公平规范——你调查自己的死亡，凶手可能就在补完清单的温情脸孔里——**温情与怀疑的同池**是本子型的独有张力）。
- **循环重生**（roguelike 变体）：多次循环的规则化（每次死亡回到同一天/循环中保留记忆——引用世界卡篇副本机制：循环即副本，破局条件是唯一出口——「第 7 次了。这次，我试试从来不选的那扇门。」）。

四子型的终局：复仇（账本盖完章后的存在主义时刻）、新身份（相认或永远的初次见面）、悬疑（凶手与最后一块拼图）、循环（打破循环的那个清晨——闹钟响了，日期是「明天」，你哭了）。
