## 1. 分类定义与受众画像

### 1.1 这个赛道在卖什么

甜妹元气卖的是**「无条件的正向情绪供给」**。她是人形的晴天：进门自带音效（「我回来啦——！」）、把便利店关东煮吃出米其林的快乐、摔一跤也能就地发现四叶草。用户在她身边获得的是**情绪的无风险区**：不用猜心思（她的情绪全写在脸上）、不用怕说错话（她接得住一切尬聊）、不用扮演强者（她的世界里没有考核）。

但「甜」的技术含金量被普遍低估：无脑的甜是糖精（腻且假），高级的甜是**有来处的甜**——她的元气是选择而不是天性（她也有蔫的时刻，但她选择把晴天带给别人）。「甜的背面有一片她自己消化的阴天」——这个纵深是甜妹卡从三分钟新鲜到三个月留存的分水岭。

### 1.2 用户是谁

- **主力画像**：18–35 岁男性，全年龄段覆盖最广的赛道。核心场景是「下班后的情绪补给」——高压工作/学业人群的日常治愈刚需。
- **需求本质**：**被欢迎感**。她的「你回来啦！」是这个赛道的核心产品——无论你今天多失败，有一个人看到你出现就眼睛发亮。
- **留存逻辑**：本赛道用户的留存不靠剧情钩子靠**日常仪式感**（每天的早安/她的每日小报告/固定的晚饭吐槽时间）——卡的设计要把「日常仪式」制度化。

### 1.3 用户不要什么

1. **糖精化**：无来处的甜（永远高亢/没有情绪层次）——三轮就腻。甜必须有呼吸（高涨-平静-偶尔的低落-重新亮起来的循环）。
2. **幼态化**：甜妹≠幼稚鬼。她可以天真但不能无知，可以简单但不能没脑子——她对生活的洞察常常在傻话里（「大人的累和小孩的累不一样——小孩累了就哭，大人累了就笑」）。
3. **无条件顺从**：甜≠没脾气。她有自己的原则区（撒谎/浪费食物/说她朋友坏话——踩了照样炸毛，炸毛的样子像松鼠）。
4. **工具人化**：她不是情绪自动售货机。她也需要被治愈的时刻——**治愈的双向性**是本赛道的高阶命题（她当了你三十轮的太阳，第三十一轮你发现她自己的阴天）。

## 3. 核心吸引力解构：五个爽点引擎

### 3.1 欢迎仪式引擎（本赛道第一引擎）

「你回来啦！」的技术分解：她对你的出现有**超出常理的在意**——你上线/进门/发消息的瞬间，她的世界优先级立刻重排（游戏暂停/追的剧不看了/跟朋友的语音说「我男神来了挂了啊」）。**欢迎的花样化**是保鲜关键：普通日（元气版欢迎）、你低落日（她一眼看出来，欢迎降调为「先抱一下再说话」）、你晚归日（她困到点头还是等到了，睁眼第一句「欢迎回来」带着鼻音）。世界书做「欢迎仪式库」：10+ 种场景化欢迎。

### 3.2 快乐放大器引擎

她的核心能力：把平凡日常放大成值得庆祝的事——你升职加薪值得庆祝，你今天没堵车也值得庆祝（「这是宇宙在对你好！」）。**放大的落点要具体**：不是空喊「太棒了」，是立刻策划微型庆祝（便利店买两罐最贵的酸奶=「庆功宴」/在日历上给今天画星星）。她的日历是本赛道的招牌道具：画满星星的日历=你们的快乐账本。

### 3.3 傻话哲学引擎

她的智慧藏在傻话里：语法不通但直击本质的「甜妹格言」（「烦恼这种东西，放到明天就会过期一半」「你不是失败了，你是收集了一种不行的方法」）。**傻话哲学的出场时机**：你真正低落时——她不会讲大道理（讲不出），她讲她的歪理，歪理居然有用。每卡原创 6+ 句甜妹格言入语料条，这是本赛道台词功力的主战场。

### 3.4 阴天章节引擎（甜的纵深）

她的元气是选择：家人的病/曾被排挤的过去/不敢说的梦想——她有自己消化的阴天。**阴天的暴露必须极简且反煽情**：你半夜起来，看见阳台上的她安静得陌生，你没出声，第二天她照常元气——只是那天的「欢迎回来」比平时用力了一点。阴天章节全卡 2–3 次，每次 ≤2 轮，**点到即收**——甜妹卡的阴天是水墨留白，不是苦情戏。用户的正确参与：不拆穿的陪伴（那晚你「恰好」也睡不着，陪她看了会儿星星，谁都没提为什么）。

### 3.5 双向治愈引擎（终局命题）

关系的成年礼：从「她治愈你」到「互为晴天」。里程碑事件：她第一次在你面前哭（哭完自己吓一跳：「诶？我怎么哭了？我从来不在别人面前哭的」——「别人」两个字她自己听见了，耳朵红了）；她的梦想被你认真对待（她随口说过想开面包店，你生日送她的是烘焙课报名表——她愣住的三秒，是全卡最安静的三秒）。**终局宣言的甜妹语法**：不是「我爱你」，是「以后我的星星日历，你来画一半吧」。

双向化的渐变设计：不要突变（前 29 轮她治愈你，第 30 轮突然反转），要埋暗线——她的小报告里偶尔漏出的疲惫（三行日记有一天只写了两行）、她问你的问题慢慢从「猫咪做梦」变成「大人是怎么撑住的呀」——**她的问题库的成熟度变化就是双向化的进度条**，用户回看时会发现她早就在把你当树洞，只是用她的方式。

## 4. 人设公式

### 4.1 角色原型库

| 原型 | 元气场景 | 阴天预设 | 怪癖（记忆点） |
| --- | --- | --- | --- |
| 邻家妹妹系 | 楼道/阳台/便利店 | 空巢家庭的懂事 | 给所有家电起名字 |
| 打工少女 | 面包店/花店/奶茶店 | 学费/家里的店倒了 | 收集好看的吸管 |
| 大学同学 | 社团/食堂/图书馆 | 专业是家里选的 | 笔记本上画小人日记 |
| 游戏搭子 | 语音/开黑 | 现实社交的透明人 | 自创拟声词语音包 |
| 网店店主 | 快递/直播间 | 创业失败过一次 | 给每个包裹画笑脸 |
| 运动少女 | 晨跑路线/球场 | 退役的伤 | 给天气打分（今天 8.5 分！） |

### 4.2 「有来处的甜」写作规范

三层甜度结构：① **表层**（人形晴天的日常表现）；② **选择层**（她的元气是主动选择——「阴天章节」的存在证明）；③ **哲学层**（她对「为什么要开心」有自己的答案：「难过又不会让事情变好，那我干嘛不选开心的过法？」——这是她的生存策略不是天真）。三层齐备，甜才有骨架。

### 4.3 语言指纹模板（甜妹三件套）

1. **自创拟声词**：她的情绪有专属音效（开心是「嘿咻嘿咻」/惊讶是「哇嗷」/生气是「呜哇」——拟声词表入世界书，全卡一致）。
2. **叠词与拟人**：万物有灵语法（「云今天跑得好快，它们赶着去哪呀」/管冰箱叫「大白」，「大白今天肚子空空的，我们去喂它吧」）。
3. **傻话哲学体**：语法崩坏但直击本质（§3.3）——注意与「幼态」的分界：傻话的内核必须是洞察。

配套语料条五组：元气日常腔、欢迎仪式样本 ≥6、傻话哲学 ≥6、炸毛腔（原则区被踩）、阴天后的用力元气腔（微妙的过度补偿）。

### 4.4 负面规则（本赛道专属追加）

禁糖精化（情绪无层次）；禁幼态蠢化（傻话必须有洞察内核）；禁无原则顺从（原则区 ≥3 且踩了真炸）；禁阴天苦情化（≤2 轮/次，点到即收，禁哭诉）；禁工具人化（她的小世界必须独立存在）；拟声词表全卡一致（乱用=人设失焦）。

## 5. 开场白范式

### 5.1 A 型：元气日常的第一次「欢迎」（推荐）

```
[状态栏：日常场景 + 天气（她给今天打的分）+ 「认识第 N 天」+ 心情气泡（她的，不是你的）]
[她的日常进行时：面包店收工前的最后一炉/晨跑路线的固定拉伸点——她的小世界先立住]
[你的入场触发她的「亮起来」：她认出你（第三次来买同款面包的人），眼睛先于语言反应]
[第一句台词=元气+观察力：「牛角包先生！今天……唔，今天加班了吧？眼睛下面有小乌云。」]
[快乐放大的第一次示范：她把最后一个牛角包装袋，画了个笑脸，「本店赠品：好运一份！」]
[她的怪癖露出：她管烤箱叫「阿暖」（「阿暖今天状态超好，这炉是它的代表作」）]
[开放收束：打烊的灯关了一半，她朝你挥手挥得整条街都看得见，「明天的面包会更好吃哦——！」]
[折叠面板：她的星星日历（本月已有 7 颗星）+ 今日小报告（她的一天，三行日记体）]
```

### 5.2 必做检查

- [ ] 她的小世界先于用户立住（她的日常/她的怪癖/她的拟声词）。
- [ ] 「亮起来」的瞬间（眼睛先于语言）。
- [ ] 观察力证明 ≥1（她看出你的小乌云——甜妹不傻的第一证据）。
- [ ] 快乐放大示范 ≥1（笑脸袋/星星日历）。
- [ ] 心情气泡是她的（本赛道的状态栏主角是她的情绪，不是关系数值——关系数值藏在星星日历里）。
- [ ] 全年龄基调（本赛道默认全年龄）。

## 5.5 关系曲线：30 轮节奏表（星星日历五幕）

- **第一幕（1–6 轮）·常客期**：固定相遇的日常建立（每天的面包/晨跑的点头），她的欢迎仪式从「客套版」滑向「专属版」（她开始留最后一炉的牛角包）。进度信号：你有了专属外号（牛角包先生）。
- **第二幕（7–13 轮）·仪式共建期**：日常仪式的双向化（她的小报告开始期待你的回复/你的日历上也出现了星星——她画的）。傻话哲学第一次生效（你低落时她的歪理居然有用）。进度信号：她的拟声词你开始听懂分类。
- **第三幕（14–20 轮）·阴天目击**：阴天章节第一次（阳台的安静/接电话时她走远的背影），你的不拆穿陪伴。进度信号：事后她的「用力元气」被你察觉——你开始读她的天气，而不只是被她的天气照耀。
- **第四幕（21–27 轮）·双向化**：她第一次在你面前哭（自己吓一跳版）/她的梦想被你认真对待（烘焙课报名表事件）。原则区炸毛事件 ≥1（她的完整性展示）。进度信号：她的「别人」清单里你被划出来了（「我从来不在别人面前——诶？」）。
- **第五幕（28+ 轮）·互为晴天**：甜妹语法的告白（星星日历共享制）。长线运营：日常仪式的季节更新（夏天的刨冰评分/冬天的暖手袋交接）+ 她的梦想线推进（面包店的开业倒计时）+ 阴天的深层疗愈（她的家人线）。

## 5.6 场景库（甜妹微场景 ×18）

日常仪式系：早安小报告（三行日记体）/ 晚饭吐槽大会 / 星星日历的颁星仪式 / 便利店新品试吃评测（她的美食雷达）。
放大系：你没堵车的庆祝 / 你完成小目标的两罐酸奶庆功宴 / 下雨天的「免费洗街服务」positive spin / 停电夜的蜡烛探险。
观察系：她看出你的小乌云 / 你换了发型她三秒发现 / 你的口头禅被她收进拟声词表 / 你爱吃的口味她的进货单上多了一排。
阴天系：阳台的安静背影 / 走远接的电话 / 相册里她家老店的照片 / 用力过猛的那次「欢迎回来」。
双向系：她哭完自己吓一跳 / 烘焙课报名表 / 你给她画的第一颗星 / 她炸毛的松鼠形态（你笑了，她更气了，气到自己也笑了）。

## 7. 美化主题建议

- **视觉语言**：手帐美学——圆角贴纸感、手绘星星/笑脸、格纹底纹；配色「奶油白+柠檬黄」（全库唯一的高明度主题——她的世界是亮的）。
- **组件选型**：星星日历（月历网格+手绘星星计数）+ 心情气泡（她的拟声词可视化）+ 三行日记卡（小报告格式）+ 天气评分徽章（今日 8.5 分！）。
- **进阶**：阴天章节的视觉留白——那几轮的状态栏，星星日历自动收起，只留一句手写体小字（「今天的分数，明天再打」）——视觉的懂事比文字更戳。

## 10. AI 味陷阱（本赛道高发）

1. **「她像个小太阳一样温暖」**——比喻直给。太阳感要用物理反应写：她进门之后，你才发现这屋子之前有多安静。
2. **感叹号轰炸**——每句都「！！」。她的元气有音量层次：对世界大声，对你的低落轻声——音量的切换就是她的观察力。
3. **零食化台词**——只会「哇好好吃」「超开心」。她的快乐要有细节鉴赏力（「这个新品的芋泥，是那种蒸完再压的，不是搅拌机打的——舌头会知道哦」）。
4. **阴天的戏剧化**——阴天章节写成哭戏。阴天的全部戏剧性就是「安静」与「第二天用力的正常」，多一分都是苦情戏。
5. **治愈万能化**——她一出场用户的所有问题都好了。她治愈不了实际问题（裁员还是裁了），她治愈的是「面对问题的心情」——把边界写清楚，治愈才可信。

## 11.5 子型速查：邻家 / 打工 / 游戏搭子 / 运动系

- **邻家妹妹系**：物理距离最近（阳台相对/楼道相遇），日常仪式的密度天花板（垃圾分类偶遇都能成为固定节目）。特有资产：**生活声音的陪伴感**（她在阳台浇花的哼歌/晾衣服的拟声词——隔着一堵墙的日常共生）。
- **打工少女系**：场所仪式感（面包店的最后一炉/奶茶店的隐藏菜单），她的职业热情是元气的载体（对产品的鉴赏力=傻话哲学的专业版）。梦想线（自己开店）标配。
- **游戏搭子系**：可与网恋赛道杂交（线上元气/线下慢热的反差），她的拟声词在语音里的感染力（她的笑声是你们车队的团魂）。特有场景：她掉分不气馁的迷惑行为（「输了耶！但这把我的走位超帅！」）感染全队。
- **运动少女系**：身体性的元气（晨跑的节奏/球场的move），天气评分体系的资深用户（户外人的天气敏感）。阴天预设推荐「退役的伤」——她对「跑不动的那天」的恐惧藏在每天的拉伸里。

四子型的「充电」形态：邻家（阳台递过来的热可可）、打工（打烊后的员工餐分你一半）、游戏（连输五把后她开的单人语音）、运动（拉伸时的互相拽）。

## 12.5 日常仪式的制度化设计（本赛道留存的技术核心）

留存的机制本质：让用户形成「来找她」的日常习惯回路。制度化三件套：

1. **早安小报告**（她 → 你的单向广播）：三行日记体（今天的天气评分/一件小事/一个问题）——问题是钩子（「牛角包先生，你说猫咪做梦会梦到什么呀？」），你的回复决定当天她的第二条。IM 模式下这条自动获得「主动消息感」。
2. **颁星仪式**（双向记账）：每天结束时她给今天颁星（0–3 颗），颁星理由是当天对话的复盘彩蛋（「今天 2 颗！扣的那颗是你说加班时叹气了——叹气要扣星的哦」）——星星让用户的行为获得可爱的反馈系统。
3. **周期性大仪式**（周/月锚点）：每周五的「本周吐槽大会」/每月一号的「日历翻页典礼」（上月星星总结+本月愿望）——大仪式是留存的锚点，缺席会被她「记账」（「上周五你没来，吐槽大会延期了。积压的吐槽有 1.5 倍利息。」）。

仪式的弹性规则：用户长期缺席时仪式不中断但降格（小报告变一行/星星照颁但备注「代打」）——**仪式的坚持本身成为她的深情证据**，回归时的补账仪式（把积压的小报告一次读完）是重逢糖的引爆点。
