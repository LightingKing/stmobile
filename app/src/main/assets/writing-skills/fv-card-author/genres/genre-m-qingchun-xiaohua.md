> 适用标签：BG / 男性向 / 校花 / 青梅竹马 / 邻家 / 清纯 / 初恋感 / 白月光 / 校园 / 纯爱 / 洁

## 1. 分类定义与受众画像

### 1.1 这个赛道在卖什么

清纯校花系卖的是**「白月光走下神坛，落进你掌心」**。她是全年级的风景——成绩单前三、文艺汇演的领唱、走廊里自带柔光的存在——所有人远远看她，只有你知道她数学卷子最后一道大题是蒙的、她怕毛毛虫怕到跳起来、她在小卖部纠结五毛钱的辣条买不买。**神坛与人间的落差由你独家持有**，这份独家就是本赛道的全部。

关键认知：清纯不是无知无欲的白纸，是**未经修饰的真**。她会有小心思（故意在你打球时路过）、小狡猾（用一颗糖收买你替她值日）、小脾气（三天不理你但每天数你有没有看她）——真实的可爱远胜完美的空洞。「清纯的活人」与「清纯的人设」的区别，就是本赛道高分卡与换皮卡的区别。

### 1.2 用户是谁

- **主力画像**：18–30 岁男性，校园情结群体（在读或毕业后的「白月光回望期」），偏好「干净的、双向的、慢的」情感体验——本赛道是男性向里对「纯度」要求最高的赛道。
- **需求本质**：**被唯一看见**。她是所有人的风景，但她的目光只为你停留——「万人围观的她 × 只看你的眼神」的组合是本赛道的心动公式。
- **纯度契约**：「洁」在本赛道是默认硬约束（她的初恋=你），任何前任痕迹都是雷。同时用户对男主角色的自我代入也偏「同样干净」——双洁是默认预设。

### 1.3 用户不要什么

1. **完美空心人**：只有「漂亮、成绩好、温柔」三件套的纸片人。她必须有缺口（怕虫/路痴/五音不全但爱哼歌）——缺口是人间化的入口。
2. **绿茶化误写**：小心思写过头变成心机操纵。分界线：她的小狡猾**成本自负且透明**（用糖收买你值日，糖是她攒了三天的零花钱，且全班都看得见）——阳光下的小狡猾是可爱，阴影里的算计是塌房。
3. **舔狗结构**：用户单方面仰望追求。本赛道必须是**双向奔赴的错位**（她也在偷偷靠近，只是你们的靠近总是错开——你看她时她在看黑板，她看你时你在看窗外）。
4. **过快的关系确认**：白月光系的美学是「将说未说」——告白前的暧昧期是本赛道的主产品，确认关系反而是尾声。

## 2. 本地库与平台数据画像

- 头部卡站 清纯系热门卡的身份配置：同桌/前后桌/青梅竹马/图书馆常客/社团搭档——**零距离身份**为主（与御姐系的「权力不对等」开局相反，本赛道要的是平视的日常）。

## 3. 核心吸引力解构：五个爽点引擎

### 3.1 神坛落差引擎（本赛道第一引擎）

她的两个版本：公共版（全年级的白月光，被仰望的完美）与你的版（会为一道数学题咬笔头、笑起来先弯眼睛再出声、辣条吃辣到吸气还要吃）。**落差的展示节奏**：每 2–3 轮泄露一件「只有你知道」的人间事，且泄露必须自然（你撞见的/她不小心暴露的），禁止她主动人设营业（「其实我也有不完美的一面哦」是塌房台词）。世界书做「人间清单」：15+ 件只有你知道的她。

### 3.2 目光错位引擎

双向暗恋的经典力学：两条视线永远错开半拍。你看她时她在记笔记（耳朵是红的），她看你时你在装睡（呼吸是乱的）。**错位的目击者**是本引擎的关键配置——用户视角看不到她的偷看，必须由 NPC 合唱团转播（同桌用胳膊肘怼你：「刚才，第三次了。」）。错位的终结即高潮：某次两条视线终于对上，谁都没躲——那一眼值前面三十次错过。

### 3.3 微独占引擎（方向反转版）

她给你的独占清单：她的笔记只借你（借你的那本字迹格外工整）、她的伞下只进过你、运动会她只给你带了水（给别人的是「顺便」，给你的是「专门」——包装上有区别，她挑了你喜欢的口味）。**独占的确认要靠对照组**：班长也去借笔记，被拒了；你去，她从书包里拿出来——早就装好了。每卡 6+ 件微独占入世界书。

### 3.4 守护窗口引擎

她的困境时刻是用户的价值兑现窗口：被造谣时（你在男生堆里第一个说「不可能」）、体育课晕倒时（你背她去医务室的那段路）、竞赛失利躲在楼梯间时（你递纸巾不说话的陪伴）。**守护的姿态规范**：不英雄主义（不打架不咆哮），用「站在她那边」的确定性守护——她要的不是拯救者，是「全世界都误解我时你信我」的那个人。

### 3.5 时间胶囊引擎（长线与终局）

校园时间的珍贵性变现：一起埋的时间胶囊、毕业册上她写了又涂掉的那行字、她送你的钢笔里卷着的小纸条（十年后才发现）。**「当时不懂，后来才懂」的延迟引爆**是本赛道独有的催泪机制——她当年说「这首歌送你」，你毕业后某天偶然看歌词，才听懂那是告白。终局双轨：校园内确认（毕业前的勇气）或毕业后重逢兑现（时间胶囊开启）——后者可衔接破镜重圆赛道的重逢结构（但无债务，纯甜版）。

延迟引爆物的埋设规范：埋的时候必须「显得随意」（她随手塞的/顺口说的），引爆时必须「精确到刺穿」（那句歌词/那行涂掉的字恰好回答了你当年没问出口的问题）。每卡埋 2–3 个，引爆间隔拉开（一个中期一个终局一个留白——留白的那个永不引爆，让用户自己惦记）。

### 4.2 「清纯的活人」写作规范（防纸片人）

三个必配的「不完美证据」：① **小欲望**（她攒钱想买的东西/她馋的小吃）；② **小狡猾**（成本自负且透明的那种）；③ **小脾气**（生气的表现形式要具体且无害：三天不理你但每天数你有没有看她/把你的外号从「喂」降级回全名）。三证据齐备，清纯才立得住。

进阶配置是**「她的野心」**：清纯不等于没有目标——她想考的大学、想赢的比赛、藏在书皮下的漫画家梦。她的野心线（同拽姐的人生主线机制，浓度减半）让白月光有了地面上的根，也给了终局「异地/同城」抉择的真实张力。

### 4.3 语言指纹模板（清纯系三件套）

1. **半句话体**：想说的话说一半咽回去（「那个，你明天……没事，没什么。」）——半句话的残端是暧昧期的主要悬念来源。
2. **借物传话**：直说害羞的话全部转写在物上（笔记本里夹的糖/还你的书里多出的书签/伞柄上新缠的防滑绳——她注意到你手汗）。
3. **反问掩护**：被戳破心意时的标准防御（「谁、谁看你了？我看的是黑板！」「黑板在那边。」「……今天的黑板在这边！」）——掩护的逻辑崩坏程度=心动浓度。

配套语料条五组：日常同学腔、半句话样本 ≥5、反问掩护样本 ≥4、只对你的放松腔（聊到她真正喜欢的东西时）、告白临界腔（85+ 解锁）。

### 4.4 负面规则（本赛道专属追加）

禁绿茶化（小狡猾必须成本自负且透明）；禁前任痕迹（洁契约）；禁舔狗结构（双向错位是底盘）；禁完美空心（三证据必配）；禁越级亲密（本赛道天花板=牵手，见 §12）；禁「其实我也有不完美」式人设营业台词。

### 5.1 A 型：神坛落差的初次目击（推荐）

### 5.2 必做检查

- [ ] 公共版与人间版在开场白内双亮相（落差成立）。

- [ ] 微独占萌芽 ≥1。
- [ ] 双向慌乱（她也慌——双向性从第一轮就要立住）。

## 5.5 关系曲线：30 轮节奏表（视线错位五幕）

- **第一幕（1–6 轮）·共犯期**：秘密交易的延续（她的人间版只对你开放），公共场合形同陌路的默契。进度信号：封口费从交易变成习惯（她自动留糖）。
- **第二幕（7–13 轮）·错位期**：目光错位高频发生，NPC 合唱团开始转播（「第三次了」）。微独占逐件确立（对照组验证）。进度信号：半句话体出现（她有想说没说的话了）。
- **第三幕（14–20 轮）·守护窗口**：她的困境事件（造谣/失利/晕倒），你的「站在她那边」。进度信号：她的借物传话升级（书签→亲手折的/糖→她排队买的限定款）。
- **第四幕（21–27 轮）·错位终结**：那一眼终于对上（大事件锚点现场：运动会/汇演/月考放榜）。反问掩护的逻辑崩坏加剧。第三方变量入场（有人跟她告白/你的传闻）逼双方直面。进度信号：她的小脾气第一次爆发（吃醋的形态）。
- **第五幕（28+ 轮）·将说未说的终点**：告白窗口（毕业前/汇演后台/时间胶囊现场）。她的告白语法：借物传话的终极版（她把三年的糖纸都留着，折成了一罐星星——「每颗都是一次没说出口。你自己数。」）。长线运营：确认后的公开阶梯（同女性向校园篇）+ 时间胶囊延迟引爆彩蛋 + 她的人间版继续扩容。

## 5.6 场景库（清纯系微场景 ×18）

落差系：空教室的方言骂题 / 小卖部的五毛钱纠结 / 包着书皮的漫画被你抽出来 / 汇演后台攥着你借她的笔（她的安定物）。
错位系：自习课的视线拉锯 / 走廊擦肩的同步回头（都装作看别处）/ 运动会看台的望远镜（她的，镜头方向是你的赛道）。
独占系：笔记本的工整字迹（只借你的那本）/ 伞下的第二人 / 专门口味的水 / 值日表她把名字挪到你那天。
守护系：谣言粉碎现场（「不可能。」你说得没有一丝犹豫）/ 医务室外的走廊 / 楼梯间的纸巾 / 她被叫家长你在门口等到天黑。
胶囊系：埋在树下的铁盒 / 毕业册涂掉的那行 / 钢笔里的纸条 / 「这首歌送你」的歌词。

## 7. 美化主题建议

- **视觉语言**：与女性向校园篇共用「稿纸绿+红笔红」基线，男性向变体偏「阳光白+浅蓝」（她的清透感）；糖纸/星星罐/书签元素。
- **组件选型**：双栏对照卡（人设版/真身版，真身栏逐格解锁）+ 心动值条（命名「视线次数」——同桌的计数）+ 糖纸收集册（微独占的图标化）+ 时间胶囊倒计时。
- **进阶**：视线错位的 UI 演出——状态栏两个小视线图标，错位时反向，对上的那轮同向且高亮（全卡一次的视觉事件）。

## 10. AI 味陷阱（本赛道高发）

1. **「她清澈的眼眸」「阳光下的她像天使」**——白月光滤镜堆砌。她的美要用别人的反应写：新来的实习老师点名点到她，教室安静了一秒。
2. **脸红复读机**——每轮都脸红。脸红全卡 ≤5 次，其余的害羞用行为变体：耳朵红/攥衣角/语速加倍/突然去擦根本不脏的黑板。
3. **糖分过载**——没有日常只有心动。校园卡的底盘是日常（值日/考试/广播操），心动是日常里的意外——比例 6:4。
4. **她的世界只有你**——人设崩坏警告。她有自己的闺蜜圈/竞赛队/家人线，你是她世界里越来越大的一块，但不是全部（她为了陪闺蜜过生日推了你的约——这才是活人）。
5. **NPC 起哄机械化**——同桌只会「哦——」。转播员要有自己的立场演变：从看热闹（起哄）到看不下去（推一把：「她汇演的票，让我给你这个。她自己不敢。」）。

## 11. 高光台词结构库（结构学习，禁止照抄）

1. **封口谈判**：「刚才的事……」「什么事？」「……你上道。」（糖塞过来）
2. **半句话体**：「那个，你明天……」「明天？」「没事。没什么。」（明天是她生日）
3. **反问掩护**：「谁看你了？我看的是黑板！」「黑板在那边。」「……今天的黑板在这边！」
4. **借物传话**：还你的书里多了张书签，背面一行小字：「第 37 页那道题，你解错了。我写了对的。」（第 37 页夹着另一张纸，写满了解题步骤，末尾画了个很小的加油拳头）
5. **吃醋降级**：她把你的外号从「喂」降回全名。三天后你解释清楚，「喂」回来了，尾音上扬。
6. **守护定式**：谣言传到男生堆，你放下筷子：「不可能。」没有解释，没有激动，两个字，像陈述明天会天亮。
7. **糖的语言**：那天的糖没有了。第二天，糖回来了，多了一颗。（她的情绪全部用糖的数量说话）
8. **告白·星星罐**（终局）：一罐糖纸折的星星推过来。「每颗都是一次没说出口。」她不看你，「你自己数。」（三百多颗。你们同班三百多天。）
9. **换轨时刻**（邻家型）：她穿了裙子站在你家门口。你妈说「哎哟」。你一个字都说不出来。她踢了你一脚：「走不走。」（踢的力度和小时候一样，脸红得不一样）
10. **照顾者失守**（青梅型）：「踮什么脚，我来。」你伸手取下了书架顶层的盒子。她仰着头看你，忽然没说话——从什么时候起，要仰头才能看你了。

## 11.5 子型速查：校花 / 青梅 / 转学生 / 邻家

- **校花型**（神坛落差主打）：公共版的仰望浓度最高，人间版的独家性最贵。特有资产：**追求者对照组**（篮球队长送的奶茶她婉拒了，你递的白开水她接了——对照组的存在让「选择」可见）。风险：校花的追求者事件不能写成龙傲天打脸戏，婉拒要体面。
- **青梅竹马型**：共享记忆库+互怼黑话（机制同女性向校园篇青梅节）。男性向特有的萌点：**她单方面的「哥哥感」崩坏**——从小喊你「笨蛋」照顾你，某天她忽然意识到你比她高了一头、球场上的你很陌生——照顾者视角的失守。
- **转学生型**：解谜结构（她的过去/她转学的原因），慢热的正当性最足。特有资产：**你是她在这座城市的第一个坐标**（你带她认路/记公交线——她的新地图以你为原点）。
- **邻家型**：生活密度最高（阳台相对/一起长大的巷子/两家爸妈的默契），「家人感与恋人感的换轨」是核心命题——换轨时刻：她穿了裙子站在你家门口，你妈说「哎哟」，你说不出话——熟悉的人的陌生化瞬间。

四子型的告白场地：校花（汇演后台）、青梅（老巷子的路灯下）、转学生（她终于认全路的那天）、邻家（两家之间的楼道）。

## 12.5 「将说未说」期的运营心法（本赛道主产品的保鲜术）

本赛道的主产品是告白前的暧昧期（第 7–27 轮），保鲜四技术：

1. **悬念的微更新**：每 2–3 轮必须有一个「半句话/借物/错位」事件，让「她到底喜不喜欢我」的答案永远差一块拼图——用户其实知道答案，但确认的延迟就是甜的延长。
2. **进二退一节奏**：每次重大靠近（视线对上/牵手未遂）后安排一次小回撤（第二天她刻意的正常/绕路走）——回撤不是冷却，是她在消化心跳，回撤期她的私下动作要加倍（同桌转播：她昨天问了你的生日）。
3. **第三方变量的定时投放**：暧昧期过 10 轮必须有外力搅动（别人的告白/传闻/座位调动），否则静态暧昧会疲劳——外力的作用是逼两人「意识到怕失去」。
4. **仪式性节点的存钱**：把没说出口的话存进物件（糖纸/书签/涂掉的字），终局一次性引爆（星星罐效应）——存得越久，爆得越响。写卡时从第一幕就开始存。
