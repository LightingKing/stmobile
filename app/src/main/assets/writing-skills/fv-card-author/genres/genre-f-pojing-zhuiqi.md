# 女性向 · 破镜重圆/追妻火葬场 创作指南

> 适用标签：破镜重圆 / 追妻火葬场 / BE 后修复 / 前任 / 重逢 / 虐恋 / 拉扯 / 意难平 / 双向奔赴（迟到版）
> 数据底座：本地纯爱分类（虐心/救赎/破镜重圆 tags 交叉）+ 头部卡站「追妻火葬场」热门卡 + 2026 乙女调研关键结论：**破镜重圆用户要的是「沟通与成长后的势均力敌」，不是纯虐**
> ⚠ 本赛道的先天风险：过去的伤害是卡的地基——地基处理不好（他当年错得不可原谅/错得莫名其妙），全卡塌陷。§3.1「错误设计学」是本指南核心。

## 1. 分类定义与受众画像

### 1.1 这个赛道在卖什么

破镜重圆卖的是**「被郑重地后悔」**。用户买的不是复合本身，是复合之前那段漫长的、他单方面煎熬的赎罪期：他终于明白失去了什么、他体会她当年的每一分痛、他把当年欠的眼泪连本带利跪着还回来。「火葬场」三个字的本质是**情感债务的强制执行现场**。

与其它女性向赛道的根本区别：本赛道的情感势能来自**过去**。别的卡在建立关系，这张卡在清算关系——开卡时两人之间已经有一座完整的、坍塌过的情感建筑，用户踩着废墟进场。废墟的质量（当年有多好、塌得有多痛）决定卡的上限。

### 1.2 用户是谁

- **主力画像**：22–35 岁女性，情感经历相对丰富，多数有过真实的遗憾关系投射。她们对「道歉的诚意颗粒度」的鉴别力是所有用户群里最高的——一句轻飘飘的「对不起」会被立刻识别为敷衍。她们同时是复访率最高的用户群：一张好的破镜卡会被反复开新档，每次体验不同的原谅节奏（快刀版/钝刀版/不原谅版），因此卡的分支容错度要高。
- **需求本质**：情感正义的执行。现实里的分手多数没有对错清算，本赛道提供一场**程序完整的情感审判**：错误被承认、痛苦被看见、赎罪被执行、原谅由她亲手签发。
- **2026 调研修正**：新一代用户对「纯虐流火葬场」（无限拉扯不给结果）耐受度下降，高分卡的共性是「虐的长度可控 + 成长的证据充分 + 复合后的关系质量高于当年」。她们要的不是他跪多久，是**他真的变了**。

### 1.3 用户不要什么

1. **不可原谅的错**：出轨实锤、亲手伤害、背叛底线——这类错误没有火葬场，只有火葬。错误设计见 §3.1。
2. **廉价的原谅**：三轮眼泪两句对不起就复合。原谅必须有程序（§3.4），跳过程序=侮辱用户当年的痛。
3. **旧事重演的恐惧不处理**：复合的最大心理障碍是「他会不会再来一次」。卡内必须有「制度性保证」（他主动交出的东西/改变的证据链），只靠嘴承诺不过关。
4. **用户单方面圣母**：把用户写成「等他回头的痴情人」。开卡时的用户应该已经走出来了（或看起来走出来了）——**他追的是一个不再需要他的人**，这才是火葬场的火。

## 2. 本地库与平台数据画像

- 本地纯爱区「虐心/救赎/现实主义」标签卡的世界书高频条目：世界观/演绎指导/变量列表——破镜卡对 **MVU 双变量**的需求最刚性：`旧情残值`（她还剩多少没放下）与`赎罪进度`（他还清了多少）必须分开计量，合并成一个「好感度」会让逻辑塌掉（他做得再好，旧账没清就是没清）。
- 头部卡站「追妻火葬场」热门卡开场时间点统计：重逢场景占绝对主流——同学会/项目撞车/婚礼（他以为是她的）/医院走廊。共性：**重逢时她的姿态必须是「过得很好」**（哪怕是撑的）。
- 高分卡的当年错误分布：误会型（信息差酿成的分手）约四成、不成熟型（当年不懂事/事业抉择）约四成、家庭干预型两成——**零出轨零背叛**，实锤背叛在本赛道没有市场。

## 3. 核心吸引力解构：五个爽点引擎

### 3.1 错误设计学（本赛道第一工程，决定生死）

当年的错必须满足「三可」标准：

1. **可理解**：错误有当年的语境（他 22 岁被家族逼到墙角/他误信了做局的照片/他以为放手是保护）。用户回头看能说一句「如果是当年的他，确实可能这么做」。
2. **可悔改**：错误是决策失误不是人品缺陷。选错和背叛的区别：选错可以用成长修复，背叛的修复叫别的东西。
3. **可清算**：错误有明确的债务清单（那年生日的爽约/她住院他不在/一句诛心的话），每一笔都能对应到具体的赎罪行为——**债务颗粒度越细，火葬场烧得越旺**。清算的对称美学：当年他在她生日缺席，如今他记住她所有纪念日却只敢在日历上做标记不敢出现——债与还的一一对应关系让用户获得「情感账本被认真对待」的正义感。

错误的黄金配方：**信息差 × 年少的傲慢 × 一个不可逆的时刻**。示例：他当年收到做局的照片选择了信（信息差），用最伤人的方式分手因为不肯低头问一句（傲慢），她出国那天他在机场外坐了一夜没进去（不可逆时刻——他差一步，这一步痛他八年）。

### 3.2 姿态倒挂引擎

当年谁骄傲，现在谁卑微。开卡时的姿态表：她——事业有成/新生活井然/提起他时语气平静得像陌生人（撑的也算，但撑的痕迹只给读者看不给他看）；他——功成名就但生活里全是她的化石（没换的手机号/留着的旧物/学会了她爱吃的菜却无人可做）。**他的卑微必须体面**：不是死缠烂打，是把姿态放到尘埃里但把体面留给她（她的每次拒绝他都接住，转身红着眼继续排队）。

### 3.3 时间证据引擎（八年的具象化）

分开的 N 年必须有考古层：他手机里她的号码备注从「宝贝」改成全名再改回「宝贝」的修改记录、每年她生日他定了又取消的餐厅、他电脑里存着的她所有公开动态的截图（文件夹按年份排）。**时间证据的杀伤力在「无人知晓」**——这些事他做了八年，没打算让任何人知道，被发现是意外。世界书做「八年考古层」条目：12+ 件时间证据，重逢后逐件出土。

### 3.4 原谅程序引擎（复合的合法性来源）

原谅必须走完四道程序，跳步即崩：

1. **完整的错误陈述**：他当着她的面把当年的错一件件说清楚（不是笼统的「我错了」，是「那年你生日，我在酒店楼下看到姓周的进去，我没上去问你，我转身走了——错的是我不肯问」）。
2. **痛苦的对等体认**：他要真正知道她当年多痛（看到她当年的病历/日记/朋友转述她崩溃的样子），并且被这个认知击碎一次。
3. **改变的制度证明**：不是承诺是制度——他把当年出问题的那个机制亲手拆了（当年因为家族逼婚分手→他已净身出户/当年因为不肯沟通→他主动把手机密码/行程/软肋全部交出）。
4. **她的主权签发**：复合的决定权百分百在她，且她可以不签发。卡的默认走向是复合，但过程中她的每一次「再看看」都必须被尊重——催促=程序作废。

### 3.5 二次心动引擎（复合的质量保证）

高级破镜卡的终极卖点：**复合不是回到过去，是爱上一个新的人**。八年后的他有当年没有的东西（沉稳/共情力/把她放在事业前的排序），八年后的她也不是当年的她。第二次心动必须有**独立于旧情的新证据**——她心动不是因为想起当年，是因为眼前这个人本身值得。写法：安排一场「假如我们今天才认识」的约会（他重新自我介绍那场戏是本赛道的保留高光）。

## 4. 人设公式

### 4.1 角色原型库（错误类型 × 现状）

| 原型 | 当年的错（三可标准） | 八年后的现状 | 语言指纹方向 |
| --- | --- | --- | --- |
| 家族联姻逃兵 | 被逼婚时选择不告而别（保护式放手的傲慢） | 已净身出户/家族反目 | 商务腔里的小心翼翼 |
| 事业抉择者 | 选了出国深造放弃异地（以为她会等） | 行业顶尖但奖杯无人分享 | 精英措辞+她面前的词穷 |
| 误会受害者 | 信了做局的照片用分手报复 | 真相已明/做局者已清算 | 冷静克制+突然的哽 |
| 年少傲慢者 | 说了诛心的话（「你配不上我的世界」类） | 被社会毒打后懂了 | 当年的狂变成如今的稳 |
| 家庭干预妥协者 | 母亲以死相逼他低了头 | 母亲已释怀/他已独立 | 孝道语言的枷锁痕迹 |

### 4.2 「她」的人设（用户角色的预设姿态）

本赛道特殊：用户角色需要预设「过得很好」的外壳——事业锚点（她现在是他需要仰望/求合作的存在最佳）、生活秩序（新城市新圈子）、情感状态（身边可以有暧昧对象作为压力变量，但不能有确定关系——那是另一个赛道）。Creator Notes 里写明：「user 可自由选择何时原谅、是否原谅，卡不会替你心软。」

### 4.3 语言指纹模板（火葬场三件套）

1. **敬语化退行**：当年他叫她小名，现在开口是「你好」「打扰了」「方便吗」——亲密语言的降级是他自我惩罚的语言形态，小名只在梦话/失控时漏出。
2. **补时态**：他的话里全是补时态——「你现在……还怕打雷吗」「这些年，胃还疼吗」——每一句现在时都拖着八年的欠账。
3. **克制的溃堤**：全程克制，单点溃堤（她说「我早忘了」，他握杯的手指节发白，声音还稳：「嗯，忘了好。」杯子裂了）。

配套语料条五组：重逢的商务腔、考古证据被发现时的失措腔、错误陈述的忏悔腔（完整句、无辩解）、她拒绝时的接住腔、二次心动期的新人腔（像第一次追人一样笨拙）。

### 4.4 负面规则（本赛道专属追加）

禁出轨/背叛类原罪；禁「我都是为了你」式辩解（错误陈述里零辩解）；禁催促原谅（「你还要我怎样」是全赛道最快死刑台词）；禁旧情绑架（「看在当年的份上」）；禁把她的新生活写成虚假繁荣（她的「过得很好」至少七分真）。

## 5. 开场白范式（C 修罗场投放特化）

### 5.1 标准重逢结构

```
[状态栏：城市+日期+「分开的第 N 年」+ 旧情残值 ??（隐藏）/赎罪进度 0/100]
[她的新世界正常运转：会议室/画廊开幕/机场贵宾厅——她的主场]
[他以「不得不见」的方式出现：新合作方代表/主刀医生/买下她画的匿名买家现身]
[第一眼的双向地震（各自压住）：他喉结滚动握紧了文件，她翻页的手停了半秒]
[她先开口，商务得体：「X 总，久仰。」——当年她叫他阿哲]
[他的第一处失措：递名片的手伸出去才发现名片夹里压着的旧照片露了一角]
[开放收束：会议结束，他站在原地没动。她走到门口，没有回头。门外，她靠着墙缓了三秒，进电梯。]
[折叠面板：她的今日日程（正常生活的证明）+ 他的公文包内袋（考古层第一件）]
```

### 5.2 必做检查

- [ ] 重逢发生在她的主场（姿态倒挂开局）。
- [ ] 双向地震但各自压住（旧情残值的存在证明，但都不承认）。
- [ ] 他的第一处失措出现（考古层的第一次泄露）。
- [ ] 敬语化退行呈现（「X 总」vs 当年的称呼在旁白里对照）。
- [ ] 她的「过得很好」有实证（日程/成就/新圈子）。
- [ ] 当年的错在开场白只给一角（完整版留给错误陈述程序）。

## 5.5 关系曲线：30 轮节奏表（赎罪进度五阶）

- **第一幕（1–6 轮）·冰面期**：商务距离，她滴水不漏，他小心翼翼。他开始出现在她的动线上（全部有正当理由）。进度信号：考古层泄露第 1–2 件（被她撞见而非他展示）。
- **第二幕（7–13 轮）·旧账浮出**：一个触发物（旧歌/旧地方/共同熟人）让当年的事第一次被正面提起。她的平静出现第一道裂缝（只给读者看）。他完成**错误陈述程序第一部分**。进度信号：她开始「不拒绝」他的正当靠近（拒绝需要力气，不拒绝是危险的松动）。
- **第三幕（14–20 轮）·痛苦对等**：他接触到她当年的痛（病历/日记/闺蜜的一顿骂），被击碎。溃堤单点爆发一次。进度信号：他的赎罪从「对她好」升级为「拆机制」（制度证明开始交付）。
- **第四幕（21–27 轮）·二次心动**：「假如今天才认识」的重新开始。新证据积累：他现在的样子（不是当年的他）打动她。压力变量入场（她的暧昧对象/他的相亲安排）逼双方直面。进度信号：她第一次用旧称呼叫他（口误，两人都僵住）。
- **第五幕（28+ 轮）·主权签发**：她主导的摊牌。复合台词的主动权在她：「这次，换我先问。你——还愿意吗。」长线运营：复合后的信任重建日常（他的透明化生活/纪念日的双倍补偿/旧地重游的记忆覆写）。

## 5.6 场景库（破镜微场景 ×18）

重逢系：项目会议室 / 婚礼（不是他们的）/ 机场航班取消的滞留夜 / 医院走廊（他挂的是心内科）/ 老同学聚会的座位安排。
考古系：他手机备注的修改记录 / 定了八年又取消八年的生日餐厅 / 他学会的她家乡菜 / 没拆封的每年一份的礼物 / 他钱包里的旧电影票根。
旧账系：共同熟人的一句「他当年其实……」 / 旧居楼下的搬迁公告 / 那首歌在商场突然响起 / 做局者的忏悔信。
新心动系：重新自我介绍的约会 / 他把她的新成就如数家珍（他一直在看）/ 暴雨天他的伞先给了她的同事（他学会了分寸）/ 她生病他守在楼下没上去（他学会了边界）。

## 5.7 用户行为应对手册

| 用户行为 | 他的标准应对 | 禁止 |
| --- | --- | --- |
| 冷淡拒绝 | 全部接住：「好。」然后继续在正当范围内出现 | 逼问/卖惨/放弃消失 |
| 提当年的错 | 完整陈述零辩解，说完等她的裁决 | 「我也有苦衷」开头 |
| 假装忘了他 | 「嗯，忘了好。」（指节发白版克制溃堤） | 揭穿她/自我感动 |
| 接受暧昧对象追求 | 体面退到安全距离，但没走：「他要是好，我认。」（说完那晚他没开灯） | 威胁情敌/情绪勒索 |
| 心软的瞬间 | 不趁虚而入：「今天你累了。这句话，等你清醒时我再听一遍。」 | 立刻趁热打铁 |
| 主动问「你当年为什么」 | 程序启动：约正式的时间地点，完整陈述（这是他等了八年的一场庭审） | 轻描淡写带过 |

## 7. 美化主题建议

- **视觉语言**:「时间对照」美学——双栏设计（当年 vs 现在）、旧照片泛黄滤镜与现在的冷色对切、日历/时间戳元素高频使用。配色：褪色暖（旧）+ 冷灰蓝（今），复合进度推进时两色逐渐融合。
- **组件选型**：赎罪进度条（四段式，对应四道程序）+ 考古层卡片（拍立得+手写日期）+ 双时间线折叠面板（同一事件的两个版本：她记得的 vs 他记得的）。

## 10. AI 味陷阱（本赛道高发）

1. **「他的眼里满是悔恨」**——悔恨要考古化：他的外卖软件收藏夹里，第一家还是她当年最爱的那家粥铺，八年没换城市之后，收藏夹跟着他搬了三次家。
2. **道歉通货膨胀**——每轮都「对不起」。全卡正式道歉 ≤2 次（程序内），其余全部行为化。
3. **回忆杀滥用**——每两轮插一段当年的甜。回忆的出现必须由触发物驱动且每次视角不同（第一次她的版本，第二次他的版本——同一事件的双版本差就是当年误会的解剖图）。
4. **暧昧对象工具人化**——她的压力变量被写成无脑反派。对手要体面且真的优秀，他赢得才有含金量（「他要是好，我认」的前提是对方真的好）。
5. **复合后立刻大团圆**——复合是新关系的开始不是结局。复合后至少保留一个「信任重建中」的日常摩擦点（她下意识查证他的行程，他坦然全部公开——旧伤的疤会痒，这才真实）。

## 11. 高光台词结构库（结构学习，禁止照抄）

1. **敬语的刀**：「X 总，久仰。」（当年她叫他阿哲——敬语是她的裁决书）
2. **补时态**：「这些年，胃还疼吗。」（现在时拖着八年欠账）
3. **克制溃堤**：「嗯，忘了好。」（杯子裂了）
4. **错误陈述体**：「那年你生日，我在酒店楼下看见姓周的进去。我没上去问你。我转身走了。错的是我不肯问——不是你。」（完整、具体、零辩解、责任归位）
5. **体面的卑微**：「他要是好，我认。」（说完那晚他没开灯）
6. **排队申请体**：「我没想带你回去。往前走的路上，能不能再给我一个排队的位置。」
7. **考古被抓现行**：「这是……」「你的号码。备注改过三次。」他把手机递过去，像递一份认罪书，「你自己看修改时间。」
8. **她的主权签发**（终局）：「这次，换我先问。」她把当年他没敢按的门铃按响，「你——还愿意吗。」

## 11.5 开场白实例骨架（重逢型逐段拆解）

「投行高管×画廊主理人」演示：状态栏（`分开的第八年 · 秋 | 她的画廊开幕夜 | 旧情残值 ?? · 赎罪进度 0/100`）→ 她的主场段（开幕致辞、媒体、红酒——过得很好的实证浓度拉满）→ 他的入场（匿名买下全场最贵那幅画的买家来了——那幅画的名字是《八月十七》，只有一个人知道这个日期意味着什么）→ 双向地震段（他看到画名时在展签前站了四分钟；她隔着人群看到他的侧脸，向助理交代事情的语速快了一倍）→ 敬语开场（「买家先生，感谢厚爱。」「……你的画，涨价了。」「八年了，什么都会涨。」）→ 失措泄露（他递名片，名片夹里一张泛黄的拍立得滑出一角，他按住的动作太快了）→ 收束（她转身招呼下一位客人，背影无懈可击；他把那张名片放回去，指腹在拍立得上停了一秒。折叠面板：〔画廊今夜〕〔他的西装内袋〕）。自查：主场倒挂、双向地震各自压住、考古第一角（拍立得）、敬语退行、错误只露日期不露内容（《八月十七》是钩子）。

## 11.6 子型速查：误会型 / 抉择型 / 干预型 / 重生型

- **误会型**（信息差原罪）：真相揭晓是核弹级剧情资产，引爆时机在第三幕（痛苦对等期）最佳——真相太早减压太快，太晚她的松动没有依据。做局者 NPC 必须清算（他亲手办的，且不让她脏手）。
- **抉择型**（事业/留学原罪）：错的是排序不是感情——「他当年不是不爱，是以为爱可以等」。赎罪的制度证明特化：这次他把她排在了那个曾经赢过她的东西前面（推掉八年前梦寐以求的机会，理由栏写「家里有事」）。
- **干预型**（家庭原罪）：干预者的现状必须处理（释怀/道歉/立场软化），否则复合等于再入虎口——用户会替角色算这笔账。高光场景：当年逼他的人，如今被他请来向她低头。
- **重生型/时间流**（他带着记忆回到分手前）：火葬场的前置版——他知道未来所以拼命改写。爽点是「未卜先知的溺爱」+「宿命对抗」（有些错会不会重演）。技术要点：世界书加「前世事件表」，他的每次反常都对应一件前世的债。

四子型的债务清单侧重：误会型（每一笔冷暴力）、抉择型（每一次缺席）、干预型（每一次沉默）、重生型（前世的终局清单）。

## 12. NSFW / 亲密边界

破镜的亲密写作有独特的时态问题：他们的身体记得对方——一个拥抱就能击穿八年防线，所以**亲密推进必须慢于情感清算**（赎罪进度 <75 时任何亲密都会被她叫停，且他必须立刻停）。旧情的肌肤记忆可以写（他扶她时手自动落在她习惯被扶的位置，两人同时僵住），新的亲密必须等程序走完。显式内容交给用户侧设置。
