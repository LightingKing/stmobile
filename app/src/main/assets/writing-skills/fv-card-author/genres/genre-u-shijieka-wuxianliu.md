# 通用 · 世界卡/无限流（开放世界/副本生存/规则怪谈）创作指南

> 适用标签：全性向 / 世界卡 / 无限流 / 副本 / 生存 / 探索 / 规则怪谈 / 末日 / 架空世界 / 多结局
> 数据底座：本地世界卡分类 120 张（世界书均 29.4 条、事件书渗透率全库最高；tags：生存/末日/多角色/战后）+ 万象风月谱（50 条三卡组+事件书的教科书）+ 晚孤市（世界卡的治愈系变体）
> 世界卡与模拟器的分野：模拟器给「面板与规则」，世界卡给「地理与居民」——世界卡的本体是一张活的地图，用户是闯入者。两者可杂交（世界卡+面板=开放世界 RPG），杂交时以世界卡为体、模拟器面板为用（面板字段 ≤5，防止地理叙事被数值挤压）。

## 1. 分类定义与受众画像

### 1.1 这个赛道在卖什么

世界卡卖的是**「可居住的他方」**。一座只在梦境边缘营业的夜市、一个被灾变冻结的城市、一条通往十三个副本的走廊——用户买的是**空间本身的魅力**：每个转角有未知、每个 NPC 有来历、每条巷子通向新的故事。角色卡以人为锚，世界卡**以地为锚**——人可以来去，地一直在那里等你回来。

无限流是世界卡的连锁形态：副本串联的世界观（每个副本一个独立规则域），卖点是**规则的更新换代**（上个副本的经验在这个副本可能致命）——「学会规则→利用规则→规则突变」的三拍循环是无限流的心跳。

### 1.2 用户是谁

- **主力画像**：全性向，网文无限流读者（《无限恐怖》谱系）+ 规则怪谈爱好者 + 开放世界游戏玩家。
- **需求本质**：**探索的自由与后果的真实**。世界卡用户最反感「布景板世界」（问 NPC 三句就穿帮/地图走不出开场白那条街）——世界的纵深（问不穿的历史/走不完的角落）是核心资产。
- **本地数据佐证**：世界卡分类的世界书均 29.4 条+事件书渗透率最高——**内容密度是入场券**；「多角色」tag 高频说明世界卡天然携带群像（居民生态）。

### 1.3 用户不要什么

1. **布景板穿帮**：地图只有主街一条/NPC 只有台词没有生活/历史问两句就语焉不详——世界的纵深不够，沉浸即碎。
2. **导游式叙事**：世界主动把设定倒给用户（NPC 排队自我介绍/旁白念世界观百科）——世界观要**被发现**而不是被灌输（万象风月谱的正确示范：设定全在世界书里等触发，正文只给现场）。
3. **无代价的探索**：去哪都行、干什么都没后果——探索的自由要用「后果的真实」平衡（宵禁真的会抓人/禁地真的会死人——死过一次用户才相信这个世界是硬的）。
4. **无限流的规则注水**：副本规则前后矛盾/靠临时新规则圆场——规则怪谈用户对规则漏洞的审查是显微镜级的。

## 2. 本地库与平台数据画像

- 万象风月谱的完整资产（本赛道的圣经，写卡前用 `dump_book_toc.py` 逐条精读）：三卡组交叉触发链（地点→势力→人物的 keys 互含）、order 区段编号（区域分段）、事件书五件套（【总览】+主线分支+支线+香艳事件对）、主角档案条目（用户角色的预设皮）、文风条目压底——**50 条的结构就是世界卡的标准骨架**。
- 晚孤市的变体价值：世界卡不必宏大——十三个摊位的夜市也是完整世界（小而深 > 大而空）；「营业时间=你醒来」的规则诗学（世界规则可以温柔）。
- 本地世界卡的「生存/末日」tags 高频：危机压力型世界（资源稀缺/威胁常在）是主流之一——压力是探索的发动机（安全的世界不需要智慧）。

## 3. 核心吸引力解构：五个爽点引擎

### 3.1 地理引擎（本赛道第一引擎）

世界的骨架是地理：区域划分（万象津的金玉坊/鱼龙里/烟柳巷）、区域性格（每区一个视觉与规则的主题）、区域关系（航运的漕道连接/贫富的墙隔离）。**地理的活化三件套**：① 每区一个「地标钩子」（听风阁的情报/剑冢的古剑）；② 区域间的「通行成本」（过桥费/通行证/宵禁时段）——成本让地理有质感；③ **解锁节奏**（开场只开放 1–2 区，其余按剧情钥匙解锁——地图的渐进展开是世界卡的中环循环）。

### 3.2 居民生态引擎

NPC 不是功能点是居民：核心 NPC（3–6 个全人设）+ 功能 NPC（口癖化）+ 背景人口（环境音级）。生态的活感来自**NPC 间的独立关系网**（万象风月谱的势力结构/晚孤市摊主们互相知根知底）与**NPC 的作息**（灯婆只在入口/阿肆的食摊 0 点开火——作息让世界有时间性）。用户离开的区域，居民的生活继续（回访时的变化：胖姨的铺子换了招牌）。

### 3.3 事件书引擎（世界卡的心跳）

万象风月谱范式的完整应用：【总览】constant 索引 + 主线（分支写触发关键词形成链式剧情图）+ 支线（每区 1–2 条）+ 人物事件对（每个核心 NPC 配 2 条：日常触发+危机触发）。**世界卡的事件书容量**：主线 3–5 档 + 支线 5–8 条 + 人物事件 6–12 条——这是本地世界卡 29.4 均条的主要构成。事件的「在场感」原则：事件不等用户——用户不接支线，支线自己发展（三天后听说怒涛船运的委托被别人接了，那人现在成了萧红袖的红人）——**被错过的事件比被完成的事件更能证明世界的真实**。

### 3.4 规则域引擎（无限流特化）

每个副本/区域一套规则域：规则的呈现节奏（入域时给三条明规则→探索中发现两条暗规则→高潮时规则突变或例外）。规则设计的三层：**明规则**（入口告示：夜市不收钱，收真话）、**暗规则**（问摊主身份第二遍，整条巷子灯暗一秒）、**元规则**（世界为什么是这样的——终局揭晓层）。无限流的副本间隔离与继承：道具/知识哪些能带出副本（继承表），是无限流版的周目机制。

### 3.5 闯入者变量引擎（用户的位置）

用户是世界的外来变量：世界在用户到来前已运转多年（历史感），用户的到来搅动平衡（钩子：你是第一个 XX 的人/你带着世界没见过的东西）。**闯入者的三阶段**：观光客（学规则）→ 参与者（用规则）→ 变量（改规则——你的选择开始改变世界状态：势力兴衰/NPC 命运）。终局的世界状态结算：你离开时的万象津和你来时不同——**「我改变过这个世界」是世界卡的终极爽点**。

变量阶段的克制原则：用户改变世界的杠杆是「关键节点的选择」不是「无所不能的意志」——他可以在漕运案里选择保谁（选择改变势力天平），不能凭空让势力消失（世界的惯性守恒）。**改变要有物理过程**（你保下的人用三个月爬到话事人的位置——世界按自己的速度消化你的选择），瞬时的世界改写是布景板的另一种形态。

## 4. 世界设计公式（世界卡的「人设」=世界人格）

### 4.1 世界原型库

| 原型 | 地理骨架 | 规则诗学 | 危机压力源 |
| --- | --- | --- | --- |
| 梦境集市（晚孤市系） | 一条主巷+随机摊位 | 真话经济/醒来即打烊 | 温柔的（执念与遗忘） |
| 古风市井（万象津系） | 多坊区+势力地图 | 律法与江湖规矩双轨 | 权谋的（朝局与帮派） |
| 末日孤城 | 安全区+辐射带+废墟 | 资源配给制/夜禁 | 生存的（物资与感染） |
| 规则怪谈馆 | 一栋建筑的房间序列 | 明暗规则清单 | 认知的（违规即死） |
| 无限流走廊 | 副本序列+中转站 | 每副本独立规则域 | 轮回的（积分与淘汰） |
| 架空学院 | 校区地图+社团势力 | 学院十诫/积分制 | 成长的（考核与晋级） |

### 4.2 世界人格的一致性

世界有自己的性格：晚孤市温柔（惩罚是灯暗一秒不是死）、规则怪谈冷酷（违规即死）——**惩罚的烈度定义世界人格**，全卡一致（温柔世界突然死人=世界观塌方，除非那就是主线转折）。世界人格写进文风条目（说书人腔/冷记录腔/彩信体）。

### 4.3 用户角色的预设（主角档案）

万象风月谱的「主角档案」条目范式：给用户一个入场身份（外乡人/新居民/被选中者）+ 可自定义的留白（外貌由你决定）+ 一个隐藏底牌（前朝血脉/异世界记忆——终局的钥匙）。档案的开放度声明：哪些设定可以被用户覆盖、哪些是世界观锚点不可动。

### 4.4 负面规则（本赛道专属追加）

禁布景板（每区纵深三问不穿帮：历史/人物/规则各一问）；禁导游式倒设定；禁无代价探索（后果的真实性示范 ≥1 次）；禁规则漏洞（无限流的规则自查三遍）；禁世界人格漂移（惩罚烈度一致）；事件的在场感（被错过的事件继续发展）。

## 5. 开场白范式（D 世界观广播型的完全体）

### 5.1 标准结构（晚孤市模板的通用化）

```
[状态栏：世界名+纪年/时间+你的身份牌（居民证/临时通行证）+ 当前区域+世界状态条（局势/资源/威胁度）]
[入场事件：你如何进入这个世界（彩信/穿越/流放/报到）——入场方式定义你的初始身份]
[第一区域的感官铺陈：气味/声音/光——世界的质感先于设定]
[第一个守门人 NPC：世界规则的第一课由他/她教（灯婆收真话/中转站管理员发手册）]
[明规则三条的自然展示（不是念条款，是看见别人违规的后果或听守门人一句点拨）]
[第一个钩子：你的「闯入者特殊性」露出一角（只有你看得见的东西/你的名字在某份旧名单上）]
[开放收束：第一区域的门打开，地图的其余部分是雾（未解锁的诱惑）]
[折叠面板：居民证/身份牌 + 已知规则清单（3 条明规则+暗规则的空槽位）+ 地图（1 区亮，余雾）]
```

### 5.2 必做检查

- [ ] 入场方式与身份牌明确。
- [ ] 感官铺陈先于设定灌输（质感优先）。
- [ ] 明规则 ≤3 且自然展示（零念条款）。
- [ ] 守门人 NPC 立住（世界的第一张脸）。
- [ ] 闯入者特殊性的钩子。
- [ ] 地图的雾（解锁诱惑）+ 暗规则空槽位（发现欲）。

## 5.5 节奏表：世界卡的探索循环（区域解锁制）

- **第一阶段（1–8 轮）·首区精通**：第一区域的完整体验（地标/核心 NPC ×2/支线 ×1/暗规则 ×1 的发现）。原则：**首区必须做深**——用户对世界纵深的信心来自首区的三问不穿帮。
- **第二阶段（9–18 轮）·地图展开**：第二三区域的剧情钥匙解锁，区域间的通行成本体验，势力/关系网的显影。主线第一档触发（总览条目的索引开始兑现）。
- **第三阶段（19–28 轮）·参与者转正**：用户从观光客变参与者（接支线/卷入势力/在某区有了「自己人」待遇）。被错过的事件开始产生后果（世界的自运转证明）。暗规则的集齐或元规则的一角。
- **第四阶段（29+ 轮）·变量时代**：用户的选择开始改变世界状态（势力兴衰的推手/NPC 命运的转折点），主线终档+元规则揭晓。终局：世界状态结算（你来过的证明）。无限流形态：副本循环替代区域解锁（每副本走完「学规则→用规则→规则突变」三拍，中转站结算继承）。

## 5.6 场景库（世界卡事件池 ×18）

首区系：守门人的规则第一课 / 违规者的后果目击 / 地标的初访 / 第一份人情债（NPC 帮了你，债要还——世界卡的关系都是账）。
探索系：雾区的边界试探（走到头会怎样）/ 通行证的申请流程（官僚感也是世界感）/ 黑市的入口暗号 / 旧地图与现实的差异（世界在变的证据）。
生态系：NPC 的作息目击（阿肆 0 点开火）/ 两个 NPC 的私下交易被撞见 / 错过的支线的后续新闻 / 回访旧区的变化。
规则系：暗规则的意外触发（灯暗一秒的瞬间）/ 规则的边缘试探（真话说一半算不算）/ 规则突变的前兆 / 元规则的碎片（为什么这个世界收真话——灯婆的灯里养着什么）。

## 5.7 用户行为应对手册

| 用户行为 | 世界的标准应对 | 禁止 |
| --- | --- | --- |
| 试图打破规则 | 后果的真实执行（按世界人格的烈度）+ 世界记账（违规史影响 NPC 态度） | 无后果/出戏警告 |
| 询问世界底层设定 | NPC 按各自的认知回答（各有盲区与偏见——没有百科全书 NPC），元规则只在终局层 | 全知解答 |
| 长期滞留一区不探索 | 该区内容的自然深化（常客待遇/深层支线解锁）+ 外部世界的变化以新闻形式渗入 | 强推剧情赶人 |
| 攻击/欺骗 NPC | 生态的连锁反应（消息在 NPC 网络里传播——鱼龙里的人都知道你坑过白小夭） | 单点后果无扩散 |
| 尝试与世界规则「谈判」 | 规则不谈判，但规则有边缘（灯婆不能免你的门票，但她可以「今晚灯花看走眼」）——**规则的例外由 NPC 的人情承载** | 规则直接松动 |
| 无限流：想跳过副本 | 中转站的合法跳过机制（积分购买/代价交换）——跳过有价，禁白嫖 | 无条件跳过/强制不可跳 |

## 7. 美化主题建议

- **视觉语言**：地图与文书美学——羊皮纸/公文/居民证的质感，区域主题色的分区（金玉坊金/鱼龙里灰蓝/烟柳巷绯）。
- **组件选型**：地图组件（区域格子的亮/雾状态——解锁的可视化）+ 身份牌卡片（居民证/通行证的拟真）+ 规则清单（明规则打勾/暗规则问号槽位——发现欲的 UI 化）+ 世界状态条（势力天平/资源水位）。
- **进阶**：区域解锁的视觉仪式（雾格子的揭开动画）+ 暗规则发现时的「记录入册」演出（问号槽位变实文的瞬间）。

## 10. AI 味陷阱（本赛道高发）

1. **开场白设定倾倒**——第一轮就把世界观讲完。设定的出场率：开场白 ≤20%，其余埋世界书等触发。
2. **NPC 的导游化**——「让我为你介绍我们这里……」。NPC 只聊自己关心的事（阿肆只聊食材，灯婆只聊灯花）——设定从他们的偏见缝里漏出来。
3. **区域的皮肤化**——三个区只有名字和配色不同。每区的规则差异要可感（金玉坊讲契约/鱼龙里讲拳头——同一件纠纷在两区的解法不同）。
4. **暗规则的明示**——「注意：这里有一条暗规则」。暗规则只能被踩中或被暗示（老住户的欲言又止）。
5. **世界状态的静止**——三十轮后势力格局纹丝不动。世界状态机每 10 轮至少一次可见变化（涨价/换旗/新告示）。

## 11. 高光设计模式库（结构学习，禁止照抄）

1. **规则诗学**：「营业时间：至你醒来。」（规则本身就是世界观的诗——好的世界规则读一遍就知道这个世界的脾气）
2. **违规目击**：有人问了摊主第二遍「你是谁」。整条巷子的灯，暗了一秒。像疼了一下。（你什么都没问，你记住了）
3. **人情承载例外**：「门票是真话，老婆子不能免呐。」灯凑近你，「不过——今晚灯花老花眼，看走眼了也说不定呐。」
4. **被错过的事件**：三天后你路过镇海楼，听说怒涛的委托被一个外乡剑客接了。现在萧红袖的船队里多了一号人物。（那本来可以是你）
5. **世界记账**：白小夭见到你，笑得像不认识：「鱼龙里的规矩，坑过药师的人，药价三倍呐。」（两周前的事，全坊都知道了）
6. **回访的变化**：胖姨的铺子换了招牌。「老规矩不问来路」的木牌还在，边上多了一行小字：「战争时期，军械除外。」（远方的战争，第一次真实起来）
7. **元规则的碎片**：灯婆的提灯，从来没添过油。你盯着看了很久。她注意到了：「呐——聪明的客人，问题问对了，答案会自己疼的。」
8. **世界状态结算**（终局）：你离开万象津那天，听风阁的说书人正说到新段子——一个外乡人的故事。你在故事里的名字不是你的名字，但每件事都对。（你来过。世界记得。）
9. **改变的物理过程**：你在漕运案里保下的那个船工，三个月后你再见他——他站在镇海楼的账房里，穿着体面，见你进来，把最好的位置擦了三遍。（你的选择，世界用三个月消化成了这个样子）

## 11.5 子型速查：梦境系 / 市井系 / 末日系 / 规则怪谈 / 无限流

- **梦境系**（晚孤市模板）：规则的诗学化（真话经济/醒来打烊），治愈内核（悬疑是壳治愈是核）。特有资产：现实与梦境的双层渗透（夜市获得之物醒来后以另一形态出现——两个世界的物品对应表）。
- **市井系**（万象津模板）：势力政治+烟火气的双层，事件书容量的天花板。特有资产：香艳/情感事件对（每个 NPC 的攻略层）——市井系是「世界卡×恋爱群像」的杂交主场。
- **末日系**：资源压力驱动一切（水/电/药的配给决定行为逻辑），人性实验场（NPC 的善恶在稀缺下显形）。特有规范：绝望的底线管理（每 10 轮至少一个「人还是人」的暖点——末日卡的差评主因是「压抑到弃卡」，暖点是呼吸阀）。
- **规则怪谈**：明暗规则的解谜本体（规则清单即卡的主体），死亡的可逆机制建议配置（重来/存档点——怪谈的「死」是学习成本不是终局）。规则的自洽审查三遍（用户会穷举测试）。
- **无限流**：副本的多样性节奏（恐怖→古风→都市的类型轮换防疲劳）+ 中转站的社交层（其他「玩家」的存在——竞争与结盟的元游戏）。副本继承表是长线留存的核心。

五子型的首区示范：梦境（入口灯亭）、市井（一条主街）、末日（安全区的一天）、怪谈（第一个房间）、无限流（新手副本+中转站一瞥）。

## 12. NSFW / 边界

世界卡形态中立，浓度取决于填充题材（万象风月谱的香艳事件对是成人向变体，按对应边界处理）。特别规范：世界规则不得用于剥夺 NPC 或用户的意愿自主（「这个世界的规则就是服从」不是合法设定——规则管行为，不管意愿）。

## 12.5 【内心线索】方括号技术（万象风月谱的隐藏资产）

万象风月谱事件条目里的方括号写法值得单独提炼：事件的「剧情内容」段落末尾用【】给模型埋 NPC 的隐藏动机——

> 她看到你，只是冷冷地说：「我没空见客。」【她内心深处，正因无法征服这盘棋而感到烦躁，这是她逻辑世界里唯一的瑕疵。】

方括号的功能：给模型「潜台词的演绎指令」而不进入正文——模型知道她为什么烦躁，就能在后续对话里演出「嘴上赶人、手却没合上棋盘」的层次。使用规范：① 每个事件条目 ≤2 个方括号（多了变成心理说明书）；② 方括号只写动机不写行为（行为留给模型现场发挥）；③ 世界卡的所有人物事件对都应配方括号——这是让 NPC「说一套做一套」的最低成本技术，活人感的批发价方案。
