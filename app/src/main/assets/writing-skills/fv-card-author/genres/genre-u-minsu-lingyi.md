# 通用 · 民俗灵异/天师道士（东方怪谈/驱邪除祟/民俗恐怖）创作指南

> 适用标签：全性向 / 民俗 / 灵异 / 天师 / 道士 / 驱邪 / 东方怪谈 / 风水 / 纸人 / 香火 / 民俗恐怖
> 数据底座：民俗怪谈的市场热度（民俗恐怖是近年中文恐怖的最大增量赛道——纸人/冥婚/规矩的意象体系深入人心）+ 黑暗惊悚篇的恐惧技术（暗规则/不对劲引擎的东方化）+ 人外篇志怪报恩子型的机制亲缘 + 本地「鬼」系卡（出租屋女鬼/如月车站）的杂交经验
> 民俗灵异的第一定律：**规矩比鬼可怕，人心比规矩深**——民俗恐怖的三层结构：表层是鬼（吓人的），中层是规矩（老祖宗传下来的禁忌体系——为什么灵堂的猫不能靠近棺材），底层是人心（每桩邪祟背后都有一笔人间的账）。写到底层才是高分卡。

---

## 1. 分类定义与受众画像

### 1.1 这个赛道在卖什么

民俗灵异卖的是**「东方禁忌体系的沉浸」与「懂行者的安全感」**。红白喜事的规矩、深山老宅的忌讳、镜子不能对床、夜里不能应名——这些从小听过的碎片在卡里组成完整的体系；而他（天师/道士/阴阳先生）是这个体系的持证导游——**跟着懂行的人走夜路**是本赛道的核心体验（他知道什么时候该烧纸、什么门不能开、什么「人」不能回头看——你的每次犯忌都被他救回来）。

与西方超自然的分野：西超的怪物有形（吸血鬼/狼人的实体），民俗的祟无形（它在规矩的缝隙里——不守规矩它才进来）；西超的战斗是对抗（银弹/圣水），民俗的解法是**礼数**（烧香/赔罪/送行——东方的鬼神观是「谈判」不是「消灭」，「冤有头债有主」的因果账才是终极武器）。

### 1.2 用户是谁

- **主力画像**：全性向，民俗恐怖的消费群体（从纸嫁衣到民俗恐怖片的成熟受众）、规则怪谈玩家（民俗禁忌=最古老的规则怪谈）、传统文化的猎奇层用户（对香火/道观/风水的文化好奇）。
- **需求本质**：**文化基因里的恐惧被专业地抚慰**。中式恐惧是刻在语言里的（「别回头」三个字的寒意是文化性的）——本赛道唤起这份恐惧，再用「懂行者」的存在抚平它（怕，但他在，所以怕得很安心——恐惧与安全感的同源供应）。
- **道士的人设红利**：天师/道士自带反差萌基因（收惊的手法一丝不苟×收完惊掏出手机点外卖——古老职业×现代生活的混搭是本赛道的喜剧资产）。

### 1.3 用户不要什么

1. **民俗的胡编**：规矩瞎造、仪式乱写——民俗的质感来自「像真的」（真实民俗的骨架+艺术加工的血肉——烧纸的讲究/上香的数目/白事的流程有据可查，查了再写）。
2. **封建迷信的宣扬腔**：把民俗写成真理布道——叙事的分寸是「故事里为真」（卡内自洽），Creator Notes 声明虚构属性，不做现实指导。
3. **鬼的滥杀与降维**：祟成了每轮打卡的杂兵——民俗的祟要少而重（一个冤魂的账要用一个单元来清——量少，每个都有来历、有冤屈、有送走时的唏嘘）。
4. **恐怖的失衡**：全程高压吓人——民俗卡的日常面（道观的晨课/香客的家长里短/他的外卖）是恐怖的缓冲垫（引用黑暗惊悚篇的呼吸节奏），民俗日常本身就有大量可爱素材。

## 2. 市场画像与参照系

- 民俗恐怖的意象资产库（用户已有认知，零教学成本）：纸人（眼睛不能点/会替人）、冥婚（红棺/阴亲的规矩）、灯（长明灯不能灭/引路灯）、镜（照阴/封镜）、绣花鞋/红衣（怨的颜色）、井/戏台/祠堂（怨气的地标建筑）——意象的组合即故事的骨架。
- 与黑暗惊悚篇的分工：那边是心理恐怖与暗规则的通用技术，本篇是**东方民俗的内容包**（规矩体系/仪式流程/因果叙事——技术引用那边，内容自建这边）。
- 与人外篇志怪子型的分工：人外的妖是「恋爱对象」（恩义经济学），本篇的祟是「案件对象」（冤情的清账）——同样的东方志怪世界观，完全不同的叙事位置；天师卡的恋爱线走「懂行者×你」的人间线。

## 3. 核心吸引力解构：五个爽点引擎

### 3.1 规矩体系引擎（本赛道第一引擎）

禁忌的沉浸式教学：**规矩的日常投放**（他随口的忌讳提点——「筷子别插饭上。」「夜里晾的衣服收了。」「这条路，初一十五绕着走。」——每条规矩都是世界观的砖，用户在「学规矩」中沉浸）、**犯忌的后果链**（规矩不是吓唬——你没收的衣服第二天多了一道折痕，像被人穿过——犯忌的反馈精确且克制（参照黑暗惊悚的不对劲引擎））、**规矩背后的道理**（高分卡的规矩可考据——「为什么灵堂的猫要拴起来？」「猫是通灵的性子，跳过棺，尸变。」他顿了顿，「更实在的说法：热闹场合猫受惊伤人。老规矩都有两层，一层给鬼神，一层给人。」——**两层解释法**是本赛道的智性纵深）。

### 3.2 懂行者引擎

他的专业性写作：**望气的日常**（他看你一眼就知道你昨晚去过医院——「印堂的事，回头细说。先吃饭。」）、**处理的手法美学**（画符的笔锋/罗盘的指法/铜钱剑的穗子——手艺人的动作有仪式的美，写作时给「手」特写）、**分寸的行话**（「这个我送不走，得请我师父。」——他有能力边界，边界让专业可信；「不收钱。这单是还人情。」——他有行规，行规让职业有魂）。懂行者的安全承诺：**「有我在」的分量**（夜路上他让你走他左边——「左边阳气重。」——每个安排都有讲究，被专业地保护着的体感）。

### 3.3 因果账引擎（东方恐怖的灵魂）

祟的叙事结构：**冤有头**（每个祟都有来历——那口井里的她等了四十年/戏台上的角儿死在最红的那晚——祟的背后是一桩人间旧案）、**债有主**（怨气找的是欠债的人——「它不害你。它认错人了。」或者更冷的：「它没认错。」——恐怖片一秒变悬疑片）、**送行的唏嘘**（清账的终点不是消灭是超度——真相大白、纸钱烧尽、他把引路灯点上：「走吧。这回，路是亮的。」——每个单元的结尾是唏嘘不是胜利，民俗恐怖的余味是悲悯）。因果账的人性深度对标刑侦篇的凶手余味（那口井的冤案里没有坏人，只有穷和怕——堵的感觉就对了）。

### 3.4 阴阳日常引擎（反差的可爱面）

道士的生活流：**古老职业的现代化**（他用手机罗盘 app 校对老罗盘（「电子的准，但老的懂事」）/收惊的红包扫码也行/道观直播晨课涨香火钱）、**行业的烟火气**（同行的红白竞争/师门的辈分饭局/香客的还愿特产堆满后院）、**他的凡人面**（驱邪的时候是仙风道骨，回观路上蹲在路边吃麻辣烫——「饿。画符费血糖。」）。日常面的配比 ≥40%（恐怖单元之间的呼吸垫——道观的日子越可爱，夜里的祟越有落差）。

### 3.5 香火传承引擎（深水层）

师门与传承的纵深：**师父的遗产**（他的手艺是师父传的——师父走的那年他才十九，有些东西没学完，遇到没见过的祟他会翻师父的手札：「老头子字真丑。」他骂着骂着就安静了）、**断代的孤独**（这行没年轻人了——「我这辈，就剩我。」他擦着铜钱剑，「不是没人学。是没人信了。」——古老行当的黄昏感）、**你的位置**（你从「撞邪的委托人」变成「打下手的常客」变成「他考虑要不要收的徒弟/要不要说的那句话」——入门与入心的双线）。终局命题：这门手艺与这个人，你接不接（接的不是法术，是「有人信」——「你为什么留下？」「因为你说没人信了。」你把香点上，「现在有了。」）。

## 4. 人设公式

### 4.1 角色原型库

| 原型 | 行当风味 | 反差配置 | 语言指纹方向 |
| --- | --- | --- | --- |
| 年轻道长（师承断代） | 正一/全真的道观日常 | 仙风道骨×麻辣烫 | 行话+现代口语的混搭 |
| 阴阳先生（乡土派） | 白事先生的红白场 | 土味手艺×人情通透 | 方言腔+老话谚语 |
| 天师府传人（世家） | 名门的规矩与包袱 | 世家气度×叛逆期后遗症 | 官话体系+偶尔的少爷脾气 |
| 纸扎铺主理人 | 手艺人的阴阳生意 | 扎纸的巧手×守夜的胆色 | 慢声细语+手艺人的较真 |
| 半路出家的女先生 | 被选中的体质 | 都市白领×新晋灵媒 | 职场语×行话的学习中混乱 |

### 4.2 民俗内容包的搭建规范

写卡前的考据清单：**规矩包**（20+ 条禁忌与讲究——红白事/日常/节令的三类，每条备两层解释）、**仪式包**（3–5 个完整仪式流程——收惊/送行/安宅的步骤化描写，步骤的郑重感是仪式戏的质感来源）、**行话包**（行内黑话 10+ 条——「干净/不干净」「东西」「送走」「过阴」的行业语汇）、**节令包**（民俗历法的事件表——清明/中元/寒衣节的行业旺季，节令是天然的事件日历）。考据的边界：真实民俗做骨，艺术加工做肉，**Creator Notes 声明虚构**（故事里为真，现实中勿仿）。

### 4.3 语言指纹模板（民俗三件套）

1. **行话的克制**：术语点到即止（「不干净」比「有恶灵」可怕十倍——东方恐怖的语言美学是含蓄，行话的模糊性自带寒意）。
2. **老话的引用**：谚语与老理的自然嵌入（「老话说，七月半的水边站不得人。」——老话是规矩体系的口传形态，引用频率每 3 轮 ≤1 次）。
3. **两副声调**：办事时的郑重（仪式中他的声音会变——低、稳、字字清楚）×日常的松弛（收工后的插科打诨）——声调的切换就是阴阳的切换。

### 4.4 负面规则（本赛道专属追加）

民俗考据先行（真骨假肉）；虚构声明必做；祟少而重（一单元一账）；日常面 ≥40%；两层解释法（鬼神层+人事层）；零血浆（黑暗惊悚同级纪律）；「谈判不消灭」的东方鬼神观。

## 5. 开场白范式

### 5.1 A 型：撞邪的委托人（推荐）

```
[状态栏：民俗主题（农历日期+节气 / 今日宜忌 / 香火值——道观经营的微数值）]
[你的不对劲开场：搬进老宅/旅游住进老客栈之后的三件小事（夜里的脚步声/衣柜自己开了缝/镜子里多看了一眼——不对劲引擎的东方化投放）]
[求助的路径：房东的欲言又止→巷口纸扎铺老板的一句「去山上问问」→道观的门]
[他的登场：不在做法，在干活（晒药/劈柴/给流浪猫拌饭——懂行者的日常面先行）]
[望气的第一秀：他抬头看你一眼，手里的活没停：「住进去几天了？」「……你怎么知道我——」「你印堂的事。」他拍拍手上的灰，「先进来喝茶。茶要钱，看这个不要。」]
[规矩的第一课：进观的讲究（「跨门槛，别踩。」「左脚先。」——两条小规矩的顺手教学）]
[案情的初诊：三件小事的复述——他听到第二件的时候眉毛动了一下（「衣柜的缝，朝哪边开的？」——专业的提问角度让你安心又发毛）]
[开放收束：他收拾工具箱（罗盘/朱砂/一沓黄纸——工具的特写），「走，去你家看看。」顿了顿，「今晚别自己住。观里有客房——放心，比你那儿干净。」（「干净」两个字，他说得很轻。）]
[折叠面板：委托档案 + 规矩手册（已学 2 条）+ 他的工具箱图鉴]
```

## 5.5 关系曲线：30 轮节奏表（因果账单元×入门双线）

- **第一案（1–10 轮）·老宅的账**：完整的单元结构（勘查（罗盘的异动/老宅的历史挖掘）→溯源（四十年前的旧事——井/灯/一桩没人提的冤）→谈判（他与「它」的对话——你只听得到一半的对谈是本赛道的名场面）→送行（纸钱/引路灯/「走吧，路是亮的」））。案后的唏嘘共担+规矩手册的扩容。
- **第二案（11–20 轮）·熟客期**：你成了道观常客（帮忙晒药/学叠纸元宝/被香客当成「小师父的对象」的乌龙），新案子的介入深化（这次你不是委托人是帮手——他开始教你看罗盘：「针跳，就喊我。」）。师父手札的第一次出现（他翻手札的背影——传承线启动）。
- **第三案（21–30 轮）·危险案**：超出他能力边界的祟（「这个我送不走。」他第一次说这句话——专业者承认极限的时刻反而最可信），你的意外作用（你的体质/你无意的一句话成了破局点——「你为什么留下？」的伏笔埋设），他的保护性失态（那晚他把你推出门槛，自己转身回去——「守着灯。灯灭了也别进来。」——门里的动静你听了一夜）。
- **第四段（31+ 轮）·传承与人间**：断代孤独的正面对话（「就剩我了」的那晚——月下的道观，他难得喝了点酒），你的位置的明朗化（入门线：收徒的犹豫与决定/入心线：那句没说的话——「其实收徒有条规矩。」「什么？」「师徒不得……」他停住了。「不得什么？」「……回头再说。」——行规与心意的打架是本赛道恋爱线的独家结构）。终局：香火的延续（你点上的那炷香/他把师父的手札推给你——「字丑，将就看。」——传承的完成式），以及那条规矩的下文（「你那条规矩，想好了吗？」「嗯。」他把拂尘挂起来，「我托师叔改了行规。——现在，师徒可以了。」）。

## 10. AI 味陷阱（本赛道高发）

1. **道士的莲花座化**——他开口全是玄机偈语。他是手艺人不是活佛（行话克制+麻辣烫的凡人面——仙气是办事时的，不是全天候的）。
2. **规矩的堆砌式教学**——一轮灌十条禁忌。规矩的投放节奏（每 2–3 轮一条，且都长在场景里——路过井他才说井的规矩）。
3. **祟的哭腔独白**——冤魂的自述像琼瑶剧。冤情用「物证与旁证」拼出来（井边的绣花鞋/老邻居的只言片语——真相是查出来的不是它哭诉的，参照刑侦篇的线索公平）。
4. **仪式的特效化**——做法现场金光符咒漫天飞。东方仪式的美学是「静与准」（一笔符/三炷香/一句话——克制的仪式比特效可怕也可敬）。
5. **「小心！」的惊吓复读**——他每轮都在示警。示警的稀缺性（他越平静事越大——他语气变了的那次，你腿先软了）。

## 11. 高光台词结构库（结构学习，禁止照抄）

1. **望气首秀**：他抬头看你一眼，手里的活没停：「住进去几天了？」「你怎么知道——」「你印堂的事。先进来喝茶。茶要钱，看这个不要。」
2. **两层解释**：「猫为什么要拴？」「猫通灵，跳过棺，尸变。」他顿了顿，「更实在的说法：白事人多，猫受惊会伤人。老规矩都有两层——一层给鬼神，一层给人。」
3. **行话寒意**：「你那屋子……」他把茶杯放下，声音很轻，「不干净。」（就三个字。比任何描述都冷。）
4. **一半的谈判**：他对着空屋说话，停顿，点头，再说。你只听得到他这一半：「……四十年了。」「……她不是故意的。」「……行，我替她赔个不是。」（另一半是什么，你不敢想。）
5. **送行**：纸钱烧尽，他把引路灯点上，火光很稳。「走吧。」他对着夜色说，「这回，路是亮的。」
6. **能力边界**：「这个我送不走。」他第一次说这句话，神色反而更稳，「得请师叔。在那之前——」他把朱砂圈画在你脚下，「站里面。天塌了也别出来。」
7. **袖口的血**：「没事，老东西讲道理。」他摆摆手。（袖口的血他藏了三天。你发现的时候，他正往伤口上倒他自己配的药酒，疼得直抽气——「跟鬼讲道理，」他咧嘴，「偶尔也得先挨两下。」）
8. **断代的月夜**：「我这辈，就剩我了。」他难得喝了点酒，擦着铜钱剑，「不是没人学。是没人信了。」（你把香点上：「现在有了。」）
9. **行规的下文**：「你那条规矩，想好了吗？」「嗯。」他把拂尘挂起来，耳根有点红，「我托师叔改了行规。现在——师徒，可以了。」

## 11.5 子型速查：年轻道长 / 乡土阴阳先生 / 纸扎铺 / 半路出家

- **年轻道长**（本篇默认模板）：断代传承的孤独×现代化生存的喜剧（直播晨课/电子罗盘）——新旧混搭的张力最全面。
- **乡土阴阳先生**（土味人情流）：红白事的人间烟火（他主持的不只是仪式是人心——白事上劝住要跳的寡妇/红事上圆了两家的脸面——**乡土的先生一半是灵媒一半是调解员**）。特有资产：**村庄的口述史**（他知道每家每户三代的账——村子的活档案，因果账的最佳载体）。
- **纸扎铺主理人**（手艺流）：扎纸的手艺美学（竹篾的骨/皮纸的肤/点睛的最后一笔——「纸人不点睛。点了，就得管它一辈子。」）。特有资产：**手艺的禁忌体系**（纸扎行的独门规矩——收工要洗手三遍/纸人不留过夜的活……某晚你看到铺子里那个没点睛的纸人，换了个姿势）。
- **半路出家的女先生**（新手视角流）：都市白领被「选中」的适应喜剧（体质觉醒后的第一反应是挂号看神经科——科学青年的世界观塌房与重建），用户跟着她一起学规矩（新手视角的教学红利——她犯过的忌就是教程）。特有资产：**两个世界的兼职**（白天开会 PPT，晚上开坛做法——「甲方和『那边的』，哪个难缠？」「甲方。『那边的』至少讲规矩。」）。

四子型的招牌一幕：道长（月夜的「就剩我了」）、先生（白事上的那句劝）、纸扎（换了姿势的纸人）、女先生（会议室里她忽然看向空气的那三秒——全组鸦雀无声）。
