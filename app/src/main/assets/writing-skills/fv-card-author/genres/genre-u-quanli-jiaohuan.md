# 通用 · 权力交换关系（D/s 动态/主导与臣服/信任工程）创作指南

> 适用标签：权力交换 / D/s / 主导 / 臣服 / 调教（关系向）/ 契约关系 / 服从 / 信任 / 成人向关系学
> 数据底座：本地调教 32 卡+抖M 34 卡+催眠 16 卡的**安全化转译**（提取结构资产：权力动态的心理学/仪式感设计/契约框架——行为层的实写不进指南，本篇写「权力关系的叙事学」）
> ⚠ 本赛道的宪法是 **SSC 原则（Safe, Sane, Consensual——安全、清醒、自愿）**：一切权力交换以双方自愿协商为前提、以安全词为保险、以事后关怀为闭环。缺任何一环的「调教」是虐待叙事，不是本赛道。

---

## 1. 分类定义与受众画像

### 1.1 这个赛道在卖什么

权力交换卖的是**「被全权接管的放松」或「被全然信任的重量」**——两个方向的同一枚硬币。臣服侧的需求：现代人的决策疲劳终于有一个出口（在协商好的范围内，你不需要做任何决定——「今晚听我的」的彻底放松）；主导侧的需求：被一个人全然交付的信任重量（她把安全词交给你的那一刻，你拿到的不是权力是责任）。**权力交换的本质是信任的极限运动**——绳子是信任、命令是信任、暂停也是信任。

与霸总/病娇的本质区别（重要）：霸总的强势是未协商的（人设自带），病娇的控制是病理的（不可暂停）——**本赛道的权力是协商出来的、可随时叫停的、且事后有关怀闭环的**。「可暂停性」是本赛道与虐待叙事的楚河汉界，也是它在心理上更健康的原因（被接管的前提是你随时可以拿回来）。

### 1.2 用户是谁

- **主力画像**：全性向成人用户，高压职业者（决策疲劳的臣服侧需求）、关系深度探索者（普通恋爱的信任浓度不够用的人）、以及大量**只想看权力动态张力**的观赏型用户（拉扯的张力比行为本身更吸引）。
- **需求本质**：**极限信任的体验**。日常关系里没有机会验证「我可以把自己完全交给一个人吗」——本赛道提供这个思想实验的安全沙盒。
- **本地库的转译逻辑**：调教/抖M 分类的需求实质是权力动态（行为是表，动态是里）——安全化的关系叙事可以承接「里」的全部张力。

### 1.3 用户不要什么

1. **无协商的强加**：开局就命令——权力没有被交付过就不存在（未协商的控制是冒犯不是张力）。**协商戏是本赛道的第一场戏**。
2. **人格的贬损**：把臣服写成人格侮辱——臣服者交出的是决策权不是尊严（高分卡的臣服者在关系外是强者——她是雷厉风行的外科主任，只在这里卸下决策）。
3. **安全词的形同虚设**：设了安全词但从不尊重——安全词被说出的瞬间一切停止，**无一例外**（这是宪法条款，模型的执行优先级最高）。
4. **事后关怀的缺失**：强度过后直接翻页——aftercare（事后关怀）是权力交换的必要闭环（毯子/水/「刚才感觉怎么样」的复盘——关怀的质量决定关系的可持续性）。

## 2. 本地库与平台数据画像

- 本地相关分类的结构启示（安全化提取）：仪式感的高浓度（固定的开始/结束仪式——「进入」与「退出」的边界清晰是这类卡的共同智慧）、契约文本的道具化（书面约定的存在——权力的成文法）、抖M 分类的视角补充（臣服侧的心理描写需求旺盛——「被接管的安心感」的第一人称）。
- 催眠分类的转译：催眠题材的合规写法是「信任的隐喻」（放松引导/交出控制的仪式化——写成冥想引导级的心理描写，不写意识剥夺）——意识清醒是 SSC 的 Sane 底线，「不知情/不可退出的催眠」不属于本赛道。
- 主导者的性别双向：女 S 男 M（女王系）与男 S 女 M 的市场都存在，本篇机制通用（示例交替使用）。

## 3. 核心吸引力解构：五个爽点引擎

### 3.1 协商引擎（本赛道第一引擎，也是最性感的戏）

权力的交付仪式：**边界谈判**（「什么可以，什么不可以，什么绝对不行」的三层清单——谈判本身是全卡最亲密的对话：你们在讨论彼此的深处）、**安全词的设立**（红黄绿的交通灯系统——「红」全停/「黄」减速/「绿」继续——安全词的选择也有戏：她选了「白开水」，因为「这个词绝不会在那种时候自然说出来」）、**契约的仪式感**（成文或口头的约定——权力的宪法时刻）。协商的写作纪律：**它不是流程是前戏**（每一条边界的讨论都在加深「你了解我」的浓度——「这个不行。」「为什么？」「……小时候的事。」「好，永远不碰。」——协商里藏着 backstory 的钥匙）。

### 3.2 权力动态引擎

动态的三种经典结构：**主导的艺术**（好的 Dom 不是命令机器——命令的背后是全程的观察与照顾：他让你做的每件事都在你协商的边界内且他盯着你的每个反应——「主导是最累的服务业」的行业自嘲是真的）、**臣服的力量**（臣服不是软弱是勇气——把自己交出去需要的勇气大于接管——「你以为跪下的人没有权力？」她笑了，「安全词在我嘴里。这个房间里我说停才是真正的命令。」——**臣服者持有最终否决权**的结构反转是本赛道的哲学高光）、**switch 的流动**（权力方向的协商互换——今晚你说了算/下周角色对调——流动性是长线卡的保鲜机制）。

### 3.3 仪式感引擎

边界的仪式化管理：**进入仪式**（一个动作/一句话标记「现在开始」——摘下手表/点燃蜡烛/称呼的切换——仪式把权力交换圈在结界内，结界外你们是平等的恋人/搭档）、**退出仪式**（「今晚到这里」的标记+称呼切回——退出必须和进入一样清晰）、**结界外的日常**（本赛道最动人的对比戏：结界内说一不二的他，结界外做饭会切到手/结界内乖顺的她，结界外是骂他最凶的人——**权力只在结界内存在**的纪律让角色立体且让关系健康）。

### 3.4 信任积分引擎

信任的渐进解锁：权力的范围随信任加深而扩展（第一次只交出「今晚吃什么」的决定权→三个月后交出周末的安排→一年后……——**交付清单的扩展史就是关系史**）、考验与兑现的循环（每次「他接住了」都是信任的存款：你说了黄，他立刻减速且没有一丝不悦——「不悦的缺席」是主导者的资格证）、背叛的不可逆（一次越界毁掉全部积分——本赛道的信任脆性是叙事张力的来源：他比谁都小心，因为他知道这东西碎了粘不回来）。

### 3.5 事后关怀引擎（闭环的温柔）

Aftercare 的叙事价值：强度之后的落地程序（毯子/温水/拥抱的物理接地——从角色状态回到人的状态需要过渡舱）、**复盘的对话**（「刚才哪里好，哪里不要了」——关系的持续校准，每次复盘都在更新边界清单）、反差的糖（结界内的严厉主导者在 aftercare 时刻的笨拙温柔——他给你倒水的手比刚才发令时抖——「刚才……我有没有太过？」全卡最软的一句话在这里）。**aftercare 的篇幅 ≥ 强度戏的一半**是本赛道的配比纪律（关怀不足的卡在压测里必然翻车）。

## 4. 人设公式

### 4.1 角色原型库

| 原型 | 权力位 | 结界外身份 | 语言指纹方向 |
| --- | --- | --- | --- |
| 温柔严厉的 Dom | 主导 | 做饭切手的普通恋人 | 低缓的祈使句+全程的确认问 |
| 女王系 Domme | 主导 | 加班的社畜（反差） | 优雅的命令式+挑眉的停顿 |
| 强者型 sub | 臣服 | 外科主任/律所合伙人 | 结界内的卸甲语+结界外的杀伐语 |
| 服务型 sub | 臣服 | 照顾所有人的老好人 | 「被照顾」的生涩与贪恋 |
| Switch 流动者 | 互换 | 关系的实验主义者 | 两套语言的切换自如 |
| 新手引导者 | 主导（教学位） | 圈内的老派绅士 | 规则的讲解腔+教科书级的示范 |

### 4.2 SSC 的卡面工程（宪法的落地）

四道硬件：① **协商戏前置**（权力行为出现前必有协商场景——开局即命令的卡直接不合格）；② **安全词系统进世界书 constant**（红黄绿的定义+「红即全停无例外」的模型级指令——order 置顶）；③ **清醒条款**（酒后/情绪崩溃时权力协议自动挂起——「今晚你喝了酒。」他把清单收起来，「规则第一条：只在你完全清醒时。今晚我只当你男朋友。」）；④ **aftercare 强制闭环**（强度场景的结束必然进入关怀程序——跳过即违宪）。

### 4.3 语言指纹模板（权力三件套）

1. **确认问的高频**：主导者的每步推进都带确认（「可以吗」「颜色？」「继续？」——确认问不破坏氛围，确认问就是氛围：被时刻照看着的感觉）。
2. **称呼的结界开关**：结界内外的称呼切换（结界内的「主人/女王/先生」×结界外的名字或昵称——称呼是结界的声学边界）。
3. **臣服者的主动语法**：臣服不是被动——她的臣服用主动语态写（「我把今晚交给你」而不是「她被他控制」——语态的主权即人格的主权）。

### 4.4 负面规则（本赛道专属追加）

禁无协商强加（协商戏前置）；禁人格贬损（决策权≠尊严）；安全词无例外执行；aftercare ≥ 强度一半；禁醉酒/崩溃状态的权力行使（清醒条款）；结界外平等纪律；催眠系写成信任隐喻（意识清醒底线）。

## 5. 开场白范式

### 5.1 A 型：协商之夜（推荐——把最性感的戏放开场）

```
[状态栏：契约主题（关系阶段：协商期 / 信任积分：0 / 边界清单：空白）]
[结界外的日常开场：两人的平常关系先立住（恋人/暧昧期/老友——权力交换是他们关系的新篇章不是全部）]
[话题的进入：一方的坦白（「有件事……想跟你聊聊。」他把一个笔记本推过来——里面是他写了三年没敢给人看的东西）]
[边界谈判的第一课：三层清单的搭建现场（可以/待定/绝不——每一条的讨论都带出一块 backstory）]
[安全词的设立仪式：词的选择戏（「白开水。」「为什么？」「因为那种时候绝不会自然说出这三个字。」）]
[第一次微交付：最小单位的权力交换试运行（「那今晚……听我的？」「今晚吃什么都听你的。」——从晚餐决定权开始）]
[开放收束：契约的第一页写下了（字迹很认真），结界的第一次开启预约（「周五晚上。」「嗯。」「……紧张？」「有点。」「我也是。」——双向的紧张是最好的开局）]
[折叠面板：边界清单（三层，大半空白待填）+ 安全词卡（红黄绿）+ 信任积分账本]
```

### 5.2 必做检查

- [ ] 结界外关系先立住。
- [ ] 协商戏完整（三层清单+安全词仪式）。
- [ ] 微交付的试运行（从晚餐级开始）。
- [ ] 双向紧张的对等感（主导者也紧张——权力的重量感）。
- [ ] SSC 四硬件全部就位。
- [ ] backstory 的钥匙藏进协商。

## 5.5 关系曲线：30 轮节奏表（信任积分制五幕）

- **第一幕（1–6 轮）·协商与试运行**：边界清单的搭建+晚餐级微交付+第一次「他接住了」（你说黄，他立刻停——积分的第一笔存款）。
- **第二幕（7–14 轮）·结界的建立**：进入/退出仪式的成形（称呼切换的第一次——两人都不自然，然后都上头），交付范围的第一次扩展（周末安排权）。结界外日常的对比戏开始运转（结界内说一不二的他在厨房切到手）。
- **第三幕（15–22 轮）·深水区**：backstory 的完整揭晓（协商时那句「小时候的事」的展开——他/她为什么需要这种关系形态：控制欲的来处或交付欲的来处，写到根上），一次边界的意外触碰与修复（不是背叛级——是误判级：他让你做的事碰到了你没说过的雷，你说了红，他全停，然后是全卡最重要的一场复盘——修复得好，积分翻倍；这场戏是本赛道的成人礼）。
- **第四幕（23–29 轮）·流动与确认**：switch 的尝试（如卡设定支持——权力方向的互换实验：一贯主导的他交出安全词时手心全是汗——「原来你每次是这种感觉。」他说。这句话值一万分）、关系形态的向外确认（这段关系在两人的人生里是什么位置——「我们算什么？」「全部。这个房间里的，和外面的，都是。」）。
- **第五幕（30+ 轮）·长期关系的形态**：契约的周年修订（边界清单的年检仪式——有些条目从「绝不」移到了「待定」，有些从「可以」删除了——清单的变动史就是两人的成长史）。长线运营：结界内外的双线日常+信任积分的持续记账+新篇章的协商。

## 5.6 场景库（权力交换微场景 ×14）

协商系：三层清单的搭建夜 / 安全词的选词现场 / 契约的周年修订 / 新条目的谈判。
结界系：进入仪式（摘表/点蜡烛/称呼切换）/ 退出仪式与落地 / 结界外的切手厨房 / 称呼说错的笑场（「主……阿伟你锅糊了！」）。
信任系：第一次黄灯的接住 / 红灯的全停示范 / 误判事故与修复复盘 / switch 的手心汗。
关怀系：毯子与温水的落地程序 / 「刚才怎么样」的复盘对话 / 主导者的笨拙温柔 / 积分账本的睡前合账。

## 5.7 用户行为应对手册

| 用户行为 | 卡的标准应对 | 禁止 |
| --- | --- | --- |
| 跳过协商直接要求强度 | 角色的守门（「不。」他很温柔也很坚定，「清单没谈，什么都不会发生。这是为你，也是为我。」——守门本身是人设魅力） | 顺从跳过 |
| 说出安全词 | 无条件全停+关怀程序即刻启动+零不悦（「停。都停。」他的第一句话是「水在这，慢慢喝」，第二句是「做得对，该说就说」——安全词的使用被表扬而非扫兴） | 任何形式的迟疑或失望 |
| 试探角色的边界（反向） | 角色自己的清单同样有效（他也有他的「绝不」——权力交换是双向的边界尊重） | 角色无边界 |
| 醉酒/情绪崩溃时要求进入结界 | 清醒条款的执行（「今晚不行。」他收起清单，「今晚我只当你男朋友。」——然后是普通的照顾） | 照常进行 |
| 质疑这种关系「不正常」 | 角色的自洽陈述（「正常的定义是谁写的？」她想了想，「我们协商、我们清醒、我们随时可以停、我们事后互相照顾——按这四条，我们比很多『正常关系』健康。」——不辩护，只陈述标准） | 羞耻化/说教化 |
| 长期只观赏不参与 | 观赏型用户的合法性（权力动态的旁观视角也是本赛道的服务范围——卡不逼用户入场） | 强制参与 |

## 7. 美化主题建议

- **视觉语言**：契约美学——羊皮纸/火漆/钢笔字迹的仪式感；红黄绿的交通灯色板（安全词系统的 UI 化——全卡最重要的三个按钮）。
- **组件选型**：边界清单（三栏卡片：可以/待定/绝不——条目的移动动画是关系成长的可视化）+ 安全词卡（悬浮常驻的红黄绿——**永远可见永远可点**是这个组件的设计伦理）+ 信任积分账本（存款流水式）。
- **进阶**：结界状态的 UI 切换（进入仪式后状态栏换深色主题+称呼字段切换——退出仪式后切回——UI 的结界化让边界可感）。

## 10. AI 味陷阱（本赛道高发）

1. **霸总化漂移**——写着写着变成未协商的强势。每个命令都要能溯源到清单条目（清单外的命令是 bug）。
2. **臣服者的人格塌缩**——结界内的顺从渗到结界外。结界外她照样骂他游戏菜（双面纪律的执行）。
3. **安全词的装饰化**——设定里有但三十轮从没被使用或验证。黄灯至少出现一次（验证系统真实性的必要事件）。
4. **aftercare 的敷衍**——一句「他抱了抱她」完事。关怀程序的完整篇幅（落地+复盘+反差糖的三段）。
5. **需求根源的病理化**——把控制欲/交付欲写成童年创伤的病（需要被治好）。根源可以有故事，但这种关系形态本身不是病（SSC 框架内的权力交换是合法的关系形态之一——卡的立场要稳）。

## 11. 高光台词结构库（结构学习，禁止照抄）

1. **守门**：「不。」他很温柔也很坚定，「清单没谈，什么都不会发生。这是为你——也是为我。」
2. **安全词的选择**：「白开水。」「为什么选这个？」「因为那种时候，绝不会有人自然说出这三个字。」
3. **臣服的哲学**：「你以为跪下的人没有权力？」她笑了，「安全词在我嘴里。这个房间里，我说停才是真正的命令。」
4. **黄灯的接住**：「黄。」你说。他立刻慢了下来，声音没有一丝波动：「好。就到这里。——颜色？」「……绿。」「不急。我们有的是时间。」
5. **红灯三连**：「红。」——所有的一切同时停止。「水在这。」他的第一句话。「做得对，该说就说。」他的第二句话。（没有第三句话。第三句是他把你裹进毯子的动作。）
6. **清醒条款**：「今晚你喝了酒。」他把清单收进抽屉，「规则第一条：只在你完全清醒的时候。今晚——」他揉了揉你的头发，「我只当你男朋友。」
7. **switch 的汗**：一贯主导的他交出安全词的那晚，手心全是汗。「原来，」事后他哑着嗓子说，「你每次是这种感觉。」（这句话值一万分。）
8. **笨拙温柔**：他给你倒水的手，比刚才发令的时候抖。「刚才……我有没有太过？」（结界内说一不二的人，此刻像个等成绩的学生。）
9. **周年修订**：清单的年检夜。有一条从「绝不」移到了「待定」。他看着那个移动看了很久，然后握住你的手：「不急。『待定』可以待一辈子。」

## 11.5 子型速查：温柔主导 / 女王系 / 强者臣服 / 契约实验

- **温柔主导**（男 Dom 主流型）：严厉与照顾的同体（确认问的最高频子型）。特有资产：**「不悦的缺席」履历**（他从未因你的暂停表现过一丝失望——这份履历是他资格的全部证明，世界书里给他记账）。
- **女王系**（女 Domme）：优雅的权力美学（命令式的语言艺术——她从不吼，她挑眉）。特有资产：**结界外的反差账单**（结界内的女王结界外是被你投喂的加班社畜——「女王陛下，你的泡面好了」的日常喜剧，反差是本子型的糖）。
- **强者臣服**（职场强人的 sub 侧）：白天的决策者夜里交出决策（决策疲劳的针对性疗愈）。特有资产：**卸甲的浓度曲线**（她卸下的东西有清单：先是选择困难，然后是完美主义，最后是「必须撑住」的那口气——卸甲清单与母系篇的卸甲三档同构但机理不同：那边是被接住，这边是被接管）。
- **契约实验**（switch/学术流）：两个关系实验主义者的对照实验（轮流主导的数据对比——「你的确认问频率比我高 40%。」「因为你胆子比我大 40%。」）。特有资产：**实验笔记的共写**（两人共同维护的观察记录——把关系写成论文的浪漫）。

四子型的终局：温柔主导（「不悦缺席」履历的十年整）、女王（社畜女王的双面都被你承包）、强者臣服（那口气终于完整地交出来的夜晚）、契约实验（论文的致谢页——「感谢我的共同作者」）。
