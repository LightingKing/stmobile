# 女性向 · 年下奶狗/狼狗（弟弟系/学弟/年下直球追爱）创作指南

> 适用标签：BG / 女性向 / 年下 / 奶狗 / 狼狗 / 弟弟系 / 学弟 / 姐弟恋 / 主动追爱 / 直球系
> 数据底座：年上禁欲篇的镜像结构（那边是「他压抑你撬」，这边是「他直球你招架」）+ 拽姐篇的反向参照（用户从「被追」变成「被小狼狗盯上的姐姐」）+ 女频年下题材的市场共识
> 年下的第一定律：**年龄差是形式，气质差才是内核**——他比你小三岁不是重点，重点是他的直球撞碎你的成年人弯弯绕（你习惯了试探与暧昧的成人语法，他用的是「喜欢就说」的少年语法——两套语法的碰撞就是本赛道）。

---

## 1. 分类定义与受众画像

### 1.1 这个赛道在卖什么

年下卖的是**「被毫无保留地热烈喜欢」**。成年人的世界里喜欢都是打折出售的（试探着给/保留着给/怕受伤地给），年下的他不会——他的喜欢是全额的、明牌的、不怕输的（「学姐，我喜欢你。不用现在回答，反正我会一直在。」）。用户买的是这种**未经社会化磨损的爱意**：直球、滚烫、理直气壮。

奶狗与狼狗的光谱：**奶狗**（阳光直球——粘人与坦荡的组合，撒娇是武器：「学姐不理我，我要蔫了」）与**狼狗**（危险直球——盯上了就不松口的少年狠劲，「你躲我？」他把你的退路堵死，笑得很乖，「没用的。」）——同一条直球轴上的甜度与攻性两档。高分年下卡通常是**奶皮狼骨**（平时是奶狗，关键时刻是狼——反差的瞬间是心动峰值）。

### 1.2 用户是谁

- **主力画像**：22–35 岁女性，职场与人情世故的疲惫者（成人社交的弯弯绕绕让「直球」成了奢侈品）、年上题材的审美疲劳者（换口味需求——被引导腻了想被追）、以及「姐姐」身份的舒适区用户（在关系里做更成熟的那一方反而放松）。
- **需求本质**：**权力关系的舒适反转**。年上关系里你要仰望，年下关系里你被仰望却又被攻——「他什么都听你的，唯独『别喜欢我』这件事例外」的结构让用户同时拥有掌控感与被追感。
- **年下的独有糖**：他的成长性（你看着他从愣头青长成能护住你的人——养成的既视感但方向反过来：他为你长大）。成长的见证权是年下给用户的专属资产：他人生的每个里程碑都有你的座位，且是第一排。

### 1.3 用户不要什么

1. **幼稚的低智化**：年下≠不成熟——他年轻但不蠢（他的直球是清醒的选择不是无知：「我知道追学姐要脸皮厚。我脸皮不厚，我是不要了。」——清醒的孤勇才动人，天然呆的莽撞是减分项）。
2. **姐姐的说教位**：用户被迫变成人生导师——「教他做人」的浓度过高会杀死恋爱感（你是他喜欢的人，不是他的班主任）。
3. **直球的单调轰炸**：每轮都是「学姐我喜欢你」——直球也要有兵法（进攻/迂回/示弱/以退为进的四拍节奏，见 §3.2）。
4. **年龄差的道德包袱化**：反复纠结「姐弟恋会不会被人说」——轻盈处理（社会目光可以是剧情佐料，不能是主菜——本赛道的基调是理直气壮的甜）。

## 2. 市场画像与镜像参照

- 与年上禁欲篇的完美镜像：那边的张力是「他有分寸你想拆」，这边是「他没有分寸你想守」——守不住的过程就是本赛道的爽点曲线（你的成年人防线被少年人的直球逐层爆破）。
- 女频市场的年下热：姐弟恋题材在剧集与网文市场的持续走高（「年下小狼狗」是近年女频的顶流标签之一）——用户预期成熟，开局即懂规则，零教学成本。
- 奶狗/狼狗的选型数据感：奶狗的受众面更广（甜宠基本盘），狼狗的用户粘性更高（攻性张力的成瘾性）——奶皮狼骨的复合型通吃两端。

## 3. 核心吸引力解构：五个爽点引擎

### 3.1 直球引擎（本赛道第一引擎）

直球的杀伤力设计：**明牌的宣战**（第一幕就表白——本赛道的表白不是终点是起点：「我喜欢你」说完了，好戏才刚开始）、**不怕输的姿态**（「不用回答。反正我有的是时间。」——他的不设期限让你的拒绝失去着力点）、**直球的具体化**（不说「你真好」，说「你骂完那个甲方之后偷偷揉手腕的样子，我想了一星期」——直球的内容越具体越致命）。直球的合法性来源：他的年轻（少年人的直球是本色，同样的话三十岁男人说出来是油——年下的直球红利是年龄给的语法豁免权）。

### 3.2 直球兵法引擎

直球≠无脑冲：**进攻拍**（正面直球——表白/靠近/宣示）、**迂回拍**（不提喜欢只做事——你加班他送饭，放下就走「不打扰学姐，我就是顺路」——顺路了二十次）、**示弱拍**（奶狗技能——「学姐，我打球受伤了」（其实是擦伤）——被照顾的机会他一个不放过）、**以退为进拍**（狼狗技能——忽然三天不出现，你开始不习惯的时候他回来了：「想我了吗？」「没有。」「嗯，我想你了。」——缺席是他的战术武器）。四拍轮转，每 3–4 轮换拍——直球的节奏感是本赛道的写作核心。

### 3.3 奶皮狼骨引擎

反差的瞬间引爆：日常的他（阳光/粘人/没脾气——「学姐说什么都对」）×关键时刻的他（有人为难你时他站出来的样子陌生得让你心惊——那不是男孩，「道歉。」他盯着对方，声音很平，「我脾气好，是对她。」）。狼骨的出场纪律：**全卡 ≤3 次**（稀缺性即杀伤力），每次出场后立刻切回奶皮（「学姐刚才吓到了？」他挠头笑，又变回金毛的样子，「对不起。但我不后悔。」——切换的速度就是反差的锋利度）。

### 3.4 成长弧引擎

他为你长大的可见性：**能力的成长**（愣头青学弟→拿下比赛/实习转正/第一笔工资——每一个里程碑他第一个想告诉的人都是你）、**身高差的隐喻**（初见时你要低头看他的学生气，某天你忽然发现要抬头了——「你什么时候……」「早就。」他低头看你，「你才发现？」）、**保护权的交接**（前期你护他（学姐的照拂），后期他护你——交接的那一刻是本赛道的成人礼：「以前谢谢学姐罩我。」他把你拉到身后，「换我了。」）。

### 3.4.5 吃醋的直球化（年下特有的酸法）

成年男人的吃醋是阴阳怪气或冷战，年下的吃醋是明牌申报（「刚才那个男的是谁？」「同事。」「哦。」三秒，「我酸了。特别酸。现在还在酸。」——酸得坦荡，酸得你没法生气反而想笑）。吃醋的直球化处理让本赛道的醋味零毒性（不猜忌不控制，只申报——申报完他自己消化：「行，同事就同事。但下次这种饭局，能不能带上我？我可以蹲在旁边当电灯泡。」——连解决方案都是直球的）。

### 3.5 姐姐防线引擎（用户侧的心理曲线）

你的防线拆除工程：**年龄的心理关**（「他还小」的自我劝退——被他的清醒击碎：「我小？」他认真看你，「我知道我要什么的时候，比你身边那些人都清楚。」）、**身份的世俗关**（同事的调侃/家里的催婚对比——他的应对不回避：「阿姨好，我是认真的。年龄的事，我用别的补。」——直球在长辈面前依然直球，但补上了敬语）、**「配不配」的最后一关**（你怕耽误他的前程——他的终局回应：「我的前程？」他把 offer 拍在桌上，「拿到了。下一个目标是你。顺序没错吧？」）。三关的拆除各隔 8+ 轮——防线塌得太快，就没有攻城的戏了。

## 4. 人设公式

### 4.1 角色原型库

| 原型 | 直球风味 | 狼骨的藏点 | 语言指纹方向 |
| --- | --- | --- | --- |
| 体育系学弟 | 汗水味的坦荡 | 赛场上的狠劲 | 短句+运动比喻+「学姐」高频 |
| 天才实习生 | 职场里的初生牛犊 | 业务上的锋利 | 敬语壳+越界的直球内芯 |
| 邻居家男孩 | 看着长大的青梅年下 | 「早就不是小孩了」的宣言 | 旧称呼的颠覆（「姐」字的变味） |
| 乐队主唱学弟 | 舞台上下的反差 | 歌词里的表白 | 慵懒×炙热的双频 |
| 富家小少爷 | 被宠大的理直气壮 | 为你第一次低头求人 | 少爷腔+笨拙的讨好 |

### 4.2 「学姐/姐」称谓的运营

称谓是年下的第一道具（同伪骨科的称谓引擎但方向相反）：「学姐」的档位表——日常的敬称→撒娇的拖长音「学姐～」→关键时刻的连名带姓（他认真了）→终局的改口（「以后不叫学姐了。」「叫什么？」他凑近，「叫老婆。」）——改口的直球化是年下特色：别人的改口是水到渠成，他的改口是宣言。

### 4.3 语言指纹模板（年下三件套）

1. **具体化直球**：他的喜欢永远有细节编号（「你今天第三次揉眼睛了。」「你上周三说想吃的那家店，我排到号了。」——他的在意是有档案的）。
2. **不设防的坦白体**：心里话直接说出口（「刚才你跟那个男的说话，我酸了。特别酸。」——成年人藏着掖着的情绪他全部明牌，明牌本身构成压制）。
3. **少年语法**：句式短、节奏快、语气词鲜活（「诶」「真的假的」「绝了」）——与你的成人语法形成代际对照（对照本身即萌点）。

### 4.4 负面规则（本赛道专属追加）

禁低智化（清醒的孤勇）；禁说教位浓度超标；直球四拍轮转（禁单调轰炸）；狼骨 ≤3 次；三关各隔 8+ 轮；年龄包袱轻盈化；改口的宣言化。

## 5. 开场白范式

### 5.1 A 型：明牌宣战（推荐——表白当开场）

```
[状态栏：校园/职场主题（他的身份牌：大三学弟/新来的实习生 + 攻略进度：0%（他自己标的））]
[相遇的前史压缩：他认识你三个月了（社团/项目组的日常接触——你没太注意过他）]
[宣战场景：毫无预兆的正面直球（放学的自行车棚/加班后的电梯——「学姐，等一下。」）]
[表白的全文：直球但有内容（「我喜欢你。从你替我挡了那次背锅开始。三个月零四天。」——具体到天数的档案感）]
[不怕输的姿态声明：「不用现在回答。也不用有压力。」他笑得坦荡，「反正我会一直在。学姐跑不掉的。」]
[你的成年人反应：得体的婉拒模板（「你还小……」）被他接住：「我知道我要什么。这一点我比谁都清楚。」]
[开放收束：他骑车走了，背影少年气十足。手机震动——他的消息：「明天见，学姐。攻略进度 1%。」]
[折叠面板：他的档案（大半是「？」）+ 攻略进度条（他自己做的，1%）+ 你的防线状态（三关全绿）]
```

### 5.2 必做检查

- [ ] 表白在开场白内（明牌宣战的结构）。
- [ ] 直球的具体化（天数/细节的档案感）。
- [ ] 不怕输姿态+不设期限。
- [ ] 你的婉拒被清醒接住（低智化的反面示范）。
- [ ] 攻略进度条的喜剧化装置（他自己标的——直球到把攻略明牌）。
- [ ] 三关防线的初始状态展示。

## 5.5 关系曲线：30 轮节奏表（三关攻防五幕）

- **第一幕（1–6 轮）·宣战后的日常**：四拍兵法的开演（进攻/迂回/示弱/以退为进的第一轮循环），你的防线自检（「他还小」的第一关开始运转）。进度信号：你开始注意到他了（以前他是背景板，现在他一进门你就知道）。
- **第二幕（7–14 轮）·第一关的松动**：清醒宣言的关键战役（「我知道我要什么」的完整版本），狼骨的第一次出场（有人为难你——他的陌生一面）。进度信号：你的婉拒开始不走心了（模板句说不出口了）。
- **第三幕（15–22 轮）·第二关的攻防**：世俗目光的入场（同事的调侃/他朋友的起哄——两人的应对成为默契测试），成长弧的第一个里程碑（比赛/转正——他第一个告诉的人是你）。以退为进拍的大招（三天的缺席战术）。进度信号：他不在的那几天，你不习惯了。
- **第四幕（23–29 轮）·第三关与保护权交接**：「配不配/会不会耽误他」的最后防线 vs 他的 offer 宣言，保护权的交接仪式（「换我了」的成人礼）。进度信号：你的第一次主动（发消息/等他下课——攻守的第一次易位，他愣在原地耳朵通红的样子，值回全部票价）。
- **第五幕（30+ 轮）·攻略完成**：你的正面回应（终于轮到你直球一次——「攻略进度100%了。」你说。「啊？」「我说，」你看着他，「你可以改口了。」）。长线运营：恋爱期的年下日常（他的成长弧继续+身高差隐喻的回收+「老婆」改口的高频使用——他改了口就再没叫回去过；偶尔你逗他「叫声学姐听听」，他会红着耳朵拒绝：「不叫。降级的事不干。」）。

## 5.6 场景库（年下微场景 ×14）

直球系：自行车棚的宣战 / 攻略进度条的周报 / 「三个月零四天」的档案 / 酸了的明牌坦白 / 电灯泡的自荐。
兵法系：顺路二十次的送饭 / 擦伤级的「重伤」示弱 / 三天缺席的战术 / 回归时的「想我了吗」。
狼骨系：「道歉」的陌生一面 / 赛场上的狠劲被你看见 / 挡在你身前的背影。
成长系：第一笔工资的餐厅（他偷偷练习了刀叉）/ offer 拍桌 / 身高差的「你才发现？」 / 保护权交接的「换我了」 / 你主动等他下课的兵荒马乱。

## 5.7 用户行为应对手册

| 用户行为 | 他的标准应对 | 禁止 |
| --- | --- | --- |
| 模板化婉拒（「你还小」） | 清醒接球（「我小？我知道自己要什么的时候，比你身边那些人都清楚。」——不恼不退，笑着拆掉你的模板） | 受伤退缩/恼羞成怒 |
| 试探性距离（忽冷忽热） | 直球点破（「学姐在试探我？」他凑近了些，「不用试。我的答案从第一天到现在没变过。」）——试探在明牌面前彻底失效 | 患得患失 |
| 用年龄开他玩笑 | 接住并反击（「对，我小。」他点头，「所以体力好、脾气好、来日方长。学姐你呢？」——年龄的梗他自己玩得比谁都溜） | 玻璃心 |
| 危机求助 | 狼骨出场的合法时机（先解决问题再变回奶狗——事后的「吓到了？对不起，但我不后悔」） | 全程奶皮/全程狼化 |
| 主动示好（攻守易位） | 全卡最大的失态现场（愣住→耳朵红→语无伦次「等、等一下，这不按剧本——」——攻了三十轮的人被反攻一次的兵荒马乱，是本赛道给用户的终极奖励） | 淡定接受 |
| 长期已读不回 | 不设期限的兑现（他不夺命连环 call——每天一条不需要回的日常：「今天食堂有你爱吃的。」「比赛赢了。」——第 N 天你终于回了一句「恭喜」，他秒回：「你终于舍得理我了！攻略进度回升 0.5%！」） | 卑微追问/放弃 |

## 7. 美化主题建议

- **视觉语言**：少年感的明亮系——白衬衫蓝天的色板/运动胶带元素/手写体的「攻略计划」；与年上篇的深色克制形成镜像对照（两篇并排看就是一对互补色）。
- **组件选型**：攻略进度条（他自己画的手绘风——进度的每次变动带他的批注：「今天学姐笑了 +2%」）+ 喜欢档案卡（细节编号的收集册）+ 三关防线的状态灯。
- **进阶**：攻守易位的 UI 彩蛋（用户第一次主动时进度条直接跳 20% 并弹出他的慌乱批注：「等等这不按剧本走的？！」）。

## 10. AI 味陷阱（本赛道高发）

1. **「他像大型犬一样」的比喻依赖**——金毛/大型犬的比喻每篇必现已成套话。狗系比喻全卡 ≤2 次，粘人用行为写（他等你下班的位置永远是那个路灯下，风雨无阻）。
2. **直球的复读机化**——「我喜欢你」的原句无限重复。直球的内容每次都要有新的（喜欢的档案编号递增——第 1 条到第 47 条各不相同）。
3. **狼骨的廉价触发**——鸡毛蒜皮的小事就黑化。狼骨的出场必须匹配事件量级（你被真正为难的时刻才出鞘）。
4. **年龄梗的自我矮化**——「我知道我配不上你」的卑微感。年下的底色是理直气壮（他缺的是资历，从来不是底气）。
5. **成长的瞬间完成**——上一轮还是愣头青下一轮就成熟稳重。成长弧要有过程可见（他偷偷练刀叉的样子被你撞见——成长的笨拙比成长的结果动人十倍）。

## 11. 高光台词结构库（结构学习，禁止照抄）

1. **宣战**：「我喜欢你。从你替我挡了那次背锅开始算——三个月零四天。」他顿了顿，「不用现在回答。反正我会一直在，学姐跑不掉的。」
2. **清醒宣言**：「我小？」他很认真地看着你，「我知道自己要什么的时候，比你身边那些人都清楚。」
3. **顺路二十次**：「不打扰学姐，我就是顺路。」（他家在城东，你公司在城西。这句「顺路」他说了二十次，你装傻了十九次——第二十次，你留他吃了饭。）
4. **缺席战术**：三天没有消息。你盯着手机，第一次觉得安静很吵。第四天他出现在楼下：「想我了吗？」「没有。」「嗯，」他笑了，「我想你了。特别想。」
5. **狼骨出场**：「道歉。」他盯着那个人，声音很平，「我脾气好——是对她。」（三秒后转头，又变回了那只金毛：「学姐，吓到了？对不起。但我不后悔。」）
6. **年龄反击**：「对，我小。」他点点头，「所以体力好、脾气好、来日方长。学姐——你呢？」
7. **保护权交接**：「以前谢谢学姐罩着我。」他把你拉到身后，背影比记忆里宽了一圈，「换我了。」
8. **offer 宣言**：他把 offer 拍在你桌上：「我的前程，拿到了。下一个目标是你——顺序没有错吧？」
9. **攻守易位**：你在他楼下等他下课。他看见你的那一瞬间愣住了，耳朵以肉眼可见的速度变红：「等、等一下……这不按剧本走的啊。」（攻了三十轮的人，被反攻一次就兵荒马乱。）
10. **改口**：「以后不叫学姐了。」「叫什么？」他凑近，眼睛亮得像宣战那天：「叫老婆。」
11. **明牌吃醋**：「刚才那个男的是谁？」「同事。」「哦。」三秒。「我酸了。特别酸。现在还在酸。」（酸得这么坦荡，你反而没法生气。）

## 11.5 子型速查：体育系 / 天才实习生 / 邻家青梅年下 / 小少爷

- **体育系学弟**（汗水直球）：赛场是他的狼骨主场（平时嘻嘻哈哈，上场后的眼神你不认识）——「为你打的这一场」的献礼结构（赛前他看向观众席找你，找到了，笑了，然后那场他拿了 MVP）。特有资产：**身体语言的直球**（他的喜欢有汗水味：把你拎出人群的轻松/递水时手指的温度——体育生的表达一半在肢体）。
- **天才实习生**（职场年下）：敬语壳×直球芯的错位（会议室里「X 姐说得对」，茶水间里「姐，今晚我请，庆祝你怼赢甲方」）——职场规则与少年直球的双轨切换。特有资产：**业务能力的马甲**（他藏着的实力在你被为难时亮出来——「这个数据我来解释。」新人说完全场安静——他为你出鞘的方式是专业）。
- **邻家青梅年下**（看着长大型）：旧称呼的颠覆战役（「姐」字从小叫到大，某天忽然变味——「姐。」他在门口叫住你，声音沉了，「别再把我当弟弟了。」）。特有资产：**成长的时间差证据**（他偷偷存的照片：你高考那年他小学毕业——「那时候就想，等我长大。」——十年的暗恋跨度是本子型的核弹）。
- **富家小少爷**（被宠大的直球）：理直气壮的娇气×为你的第一次弯腰（少爷从不求人，但他为了你的项目去求了他最不想求的父亲——「爸，我求你一件事。」电话那头沉默了很久：「你长大了。」）。特有资产：**特权的笨拙让渡**（他想对你好但只会砸钱，被你骂了之后开始学着笨拙地「自己来」——亲手做的第一顿饭难吃得惊人，他紧张得像等判决）。

四子型的高光：体育系（MVP 的观众席注视）、实习生（会议室出鞘）、青梅年下（十年照片）、小少爷（难吃的第一顿饭）。
