# 通用 · 黑暗惊悚/心理恐怖（哥特/暗黑童话/怪谈恐怖）创作指南

> 适用标签：恐怖 / 惊悚 / 黑暗 / 哥特 / 暗黑童话 / 心理恐怖 / 怪谈 / 悬疑恐怖 / 全性向 16+
> 数据底座：本地重口R18g 分类 113 张的**安全化转译**（该分类的猎奇元素不进本指南——提取其结构资产：恐惧的节奏管理/黑暗世界观的自洽/「危险的魅力体」角色学）+ 世界卡篇规则怪谈子型的恐怖机制交叉
> ⚠ 本指南写「恐怖叙事」不写「猎奇展示」：恐惧来自心理与未知，不来自血浆与酷刑的描写。血腥暴力的实写不属于任何合规产品的可发行范围——本篇的全部技术都服务于「不见血的害怕」。

## 1. 分类定义与受众画像

### 1.1 这个赛道在卖什么

黑暗惊悚卖的是**「安全的恐惧体验」**。过山车的原理：身体收到危险信号，意识知道自己是安全的——恐怖卡的用户要的是心跳加速的生理唤醒+随时可以放下手机的安全出口。它是情绪过山车的角色卡形态：深夜的公寓有什么在敲门、镜子里的自己比你晚眨了一次眼睛、那个温柔的房东太太的地下室永远锁着——**恐惧的90%发生在「知道之前」**（悬置的未知才吓人，揭晓的怪物只是生物）。

黑暗系的三个亚光谱：**心理恐怖**（人心的深渊——不需要超自然，一个不对劲的邻居就够）、**超自然恐怖**（怪谈/闹鬼/诅咒——规则怪谈是它的游戏化变体）、**暗黑奇幻**（哥特/暗黑童话——恐怖与美学的联姻，吸血鬼城堡与糖果屋女巫）。三谱的恐惧机理不同，写卡前定谱。

### 1.2 用户是谁

- **主力画像**：全性向，恐怖片/怪谈/规则怪谈受众（B站怪谈区/SCP 读者的成熟恐怖消费群体）、寻求强刺激情绪体验的用户（恋爱卡的糖吃腻了想换口味）、暗黑美学爱好者（哥特谱的用户一半是来看美的）。
- **需求本质**：**受控的失控感**。日常生活太安全太无聊，恐怖体验提供了稀缺的肾上腺素——但必须受控（用户永远持有「这是虚构」的安全绳，卡的职责是让绳子偶尔看起来快断了，但永远不真断）。
- **本地库的转译逻辑**：重口分类的高卡数（113）证明黑暗题材的需求真实存在——需求的本质是「强刺激」而非「猎奇内容」本身，安全化的恐怖叙事可以承接同一批用户的大部分需求。

### 1.3 用户不要什么

1. **jump scare 的文字模仿**：突然一行大字「鬼出现了！！」——文字媒介没有 jump scare，硬模仿只有尴尬。文字恐怖的武器是渐进的不对劲（dread 而非 shock）。
2. **血浆的堆砌**：用器官描写代替恐惧营造——猎奇不是恐怖（恶心与害怕是两种生理反应），且不可发行。
3. **无逻辑的恐怖**：怪异事件的随机堆叠——恐怖需要「暗规则」（用户感到有规律但摸不透时最害怕，完全随机反而不怕）。
4. **绝望的死局**：无论怎么选都是死——恐怖卡也要有 agency（生存的可能性是玩下去的理由，全灭结局可以有但不能是唯一）。

## 2. 本地库与平台数据画像

- 本地黑暗系样本的结构启示（安全化提取）：日常的恐怖化入口（女鬼系列的「出租屋」——恐怖长在最熟悉的地方最有效）、恐怖与喜剧的杂交路线（「怨气比女鬼还大的社畜」——恐怖的解构版有独立市场）、恐怖角色的魅力化（僵尸美娇娘——「危险的魅力体」是恐怖×恋爱的杂交种）。
- 规则怪谈的机制红利（世界卡篇已覆盖框架）：本篇聚焦**角色化的恐怖**（恐怖的来源是「她」而不是「规则」——那个对你很好的、不对劲的她）。
- 哥特谱的美学市场：吸血鬼/古堡/暗黑童话的用户一半为美学付费——恐怖浓度可调至「氛围惊悚」档（美 70% 恐 30%）。哥特谱与女性向的重叠度高（暗黑浪漫的受众），可与年上禁欲篇的气质工程交叉引用。

## 3. 核心吸引力解构：五个爽点引擎

### 3.1 不对劲引擎（本赛道第一引擎）

恐惧的最小单位是「不对劲」：**细节的偏差**（房东太太的笑容每次都一模一样，像回放/她做的菜很好吃，但你从没见过她买菜/楼道的声控灯，你走过时不亮，你走后亮了）——每个偏差单独看都能解释，堆叠起来构成无法忽视的图案。不对劲的投放纪律：**每 2–3 轮一个新偏差**，偏差之间有暗联系（最终拼图的碎片），且**永远给一个正常解释的出口**（也许只是灯坏了——用户的理性与直觉打架的过程就是恐惧本身）。

### 3.2 暗规则引擎

恐怖世界的隐形法则：怪异不随机，它有规律（敲门声只在雨夜出现/她只在你说谎后微笑/照片里的人每天多一个）——**用户可以通过观察归纳规则**（恐怖卡的解谜层：规则怪谈的软化版，规则不写在墙上但存在）。规则的三段释放：现象期（偏差堆叠，规律若隐若现）→ 归纳期（用户开始猜规则，卡给验证机会——猜对的规则救命，猜错的规则致险）→ 反转期（规则的真相偏移——你以为规则保护你，其实规则在圈养你）。暗规则进世界书（模型持有完整规则，按剧情释放证据）。

### 3.3 危险魅力体引擎（角色化恐怖的核心）

「她」是恐怖的来源也是吸引的来源：温柔与异常的同体（她真心对你好——同时她地下室的锁每晚响一次）、**魅力与威胁的不可分离**（你无法确定她想爱你还是想吃你——也许对她而言这两件事是一件）、她的「人性闪烁」（怪物的瞬间人性比人的瞬间怪物更动人：她替你挡了那个东西，转过头时眼睛还没变回来——「别怕。」她说，声音是人的）。危险魅力体的写作纪律：**她的真实动机全卡不完全揭晓**（暧昧是这个角色类型的氧气——确定的怪物与确定的恋人都会杀死张力）。

### 3.4 安全阀引擎（受控失控的工程）

恐怖体验的强度管理：**呼吸节奏**（恐怖峰之间的日常回血段——恐怖片的白天戏原理，持续高压会麻木，松弛后的再收紧才有效）、**幽默的泄压阀**（惊悚中的一丝黑色幽默——「敲门声又响了。你决定假装不在家。你住 17 楼。」——恐惧与笑的相邻性是高级恐怖的配方）、**用户的 agency 保障**（关键节点的选择真实有效——躲/逃/查/对峙的分支都写，恐怖卡的用户比任何品类都需要「我能做点什么」的掌控感补偿）。

### 3.5 揭晓经济学引擎

恐怖卡最贵的资产是「未知」，花掉它要按预算：**小揭晓的分期**（每 8–10 轮揭晓一层小真相——维持解谜的回报感，但每次揭晓引出更大的问号：地下室里不是怪物，是十七个和你长得一样的人偶——好，问题更大了）、**终局揭晓的三重底**（真相之下还有真相——第一层：她是鬼；第二层：她不是鬼，你才是；第三层：你们都不是，这栋楼在做梦——按谱系选择揭晓深度）、**不揭晓的勇气**（有些卡的最优解是永不揭晓——你搬走了，一切正常了，只是每个雨夜你还会想起那个敲门声。它再也没响过。这才是后劲）。

## 4. 人设公式

### 4.1 恐怖角色原型库

| 原型 | 亚光谱 | 恐惧机理 | 魅力面 |
| --- | --- | --- | --- |
| 不对劲的房东/邻居 | 心理 | 日常的偏差堆叠 | 真诚的善意（也许是真的） |
| 温柔的怪异存在 | 超自然 | 非人的爱的语法 | 人性闪烁的瞬间 |
| 古堡的贵族 | 哥特 | 永生者的收藏欲 | 颓废美学+旧时代教养 |
| 暗黑童话角色 | 暗黑奇幻 | 童话逻辑的恐怖面 | 糖衣的精致（房子真的是糖做的） |
| 规则的执行者 | 怪谈 | 暗规则的化身 | 规则内的绝对公正 |
| 「另一个你」 | 心理 | 自我的裂缝 | 它比你更懂你 |

### 4.2 恐怖场景的感官配方

文字恐怖的感官分工：**听觉是主武器**（敲门声/楼上的拖拽声/停止的雨声——声音的恐怖在于你看不见来源）、**触觉是杀手锏**（后颈的呼吸感/口袋里多出来的纸条的触感——触觉突破「观看」的安全距离）、**视觉要节制**（怪物的直接描写 ≤1 次且放在最后——看见的恐惧峰值即恐惧的终点）、嗅觉做记号（那个味道每次出现都意味着……——嗅觉的条件反射植入）。禁用感官清单：味觉与痛觉的实写（那是猎奇的入口）。

### 4.3 语言指纹模板（恐怖三件套）

1. **平静的叙述声**：恐怖的事用平静的语气写（「她的头转过来了。角度不太对。」——克制的语言让读者的想象力去完成恐怖，形容词的尖叫（「恐怖的！可怕的！」）反而消解恐惧）。
2. **重复的仪式感**：某些句子的原样复现（每晚 11:47，敲门声，三下。第 1 轮如此，第 9 轮如此——第 17 轮，敲门声，两下。——重复建立的秩序感被打破的那一刻是全卡最冷的一滴汗）。
3. **危险魅力体的双层话**：她的每句话都有两个读法（「我不会让任何东西伤害你。」——保护的誓言，或所有权的宣言——「任何东西」包括你自己吗）。

### 4.4 负面规则（本赛道专属追加）

禁 jump scare 文字模仿；禁血浆猎奇（不可发行+不恐怖）；禁无逻辑随机怪异（暗规则必须存在）；禁绝望死局（agency 保障）；怪物直写 ≤1 次；她的动机不完全揭晓；恐怖峰之间必须有回血段。

## 5. 开场白范式

### 5.1 A 型：日常的第一道裂缝（推荐）

```
[状态栏：恐怖卡的反状态栏——一切正常的日常界面（日期/天气/房租倒计时），正常本身是伏笔]
[无懈可击的日常开场：新租的公寓/新来的转校生/新工作的第一天——400 字的安稳建立（用户放松了才有落差）]
[她的登场：好得恰到好处（房东太太送来一碗汤，热的，你最爱的口味——你没告诉过她）]
[第一个偏差的极轻投放：轻到可以忽略（她关门的时候，门轴没有响。昨天你上油之前，它每次都响）]
[日常继续：偏差被生活的惯性冲淡（你没多想。累了一天，谁会想门轴的事）]
[睡前的第二个偏差：11:47，敲门声，三下。你开门。走廊的声控灯亮着——没有人的走廊，灯为什么亮着]
[开放收束：你关上门。手机弹出房东太太的消息：「睡了吗？今晚别开门。」——发送时间：11:46]
[折叠面板：公寓平面图（某个房间画着 X）+ 租房合同（第 7 条的字比其他条小一号）]
```

### 5.2 必做检查

- [ ] 安稳段 ≥400 字（落差的地基）。
- [ ] 偏差的投放极轻（第一个可忽略级）。
- [ ] 时间戳的精确（11:47/11:46 的一分钟差是第一夜的最冷点）。
- [ ] 她的「好」先于她的「异」。
- [ ] 道具的字号级细节（合同第 7 条——细读党的第一块拼图）。
- [ ] 全程零 jump scare、零血浆。

## 5.5 节奏表：30 轮的恐惧曲线（呼吸式）

- **第一幕（1–6 轮）·渗透期**：偏差的堆叠（每 2–3 轮一个，可解释级），她的好感建立与异常并行（恐怖与依赖同步生长——这个并行是角色化恐怖的独门配方）。回血段：正常的白天（阳光下一切偏差都像多心）。
- **第二幕（7–14 轮）·规律期**：暗规则的现象浮现（用户开始记笔记级的规律感），第一次正面遭遇的擦边（你差点看见了什么——差点）。她的第一次「人性闪烁」。回血段：她带你去了集市（那天她像完全正常的人，你几乎忘了门轴）。
- **第三幕（15–22 轮）·归纳期**：用户的规则猜想与验证（猜对的一次救了你——规则真实存在的确认瞬间），小揭晓第一层（地下室的门开了一条缝——里面不是你想的那样，是更怪的）。安全绳的最紧一刻：你决定搬走，她没拦你——「好啊。」她笑了，「如果你出得去。」
- **第四幕（23–29 轮）·反转期**：规则真相的偏移（保护你的规则原来在圈养你/或者反过来——圈养你的规则原来在保护你，外面的才是真正的怪物——反转的方向按谱系选），终局对峙或共存谈判的分岔。
- **第五幕（30+ 轮）·按谱收束**：心理谱（真相的日常解或永不揭晓的后劲流）/超自然谱（规则的重构——你成了新规则的一部分）/哥特谱（共存的暗黑浪漫——你留下了，以你自己的意志，这是最哥特的结局）。长线运营：新的偏差周期（这栋楼还有别的房间）+ 她的过去的考古线。

## 5.6 场景库（恐怖微场景 ×16）

偏差系：门轴的无声 / 一模一样的微笑 / 声控灯的延迟 / 没买过菜的厨房 / 照片里多出来的人。
听觉系：11:47 的三下敲门 / 楼上的拖拽声（你住顶楼）/ 雨声的突然停止（雨还在下，只是听不见了）/ 她哼的歌（你外婆哼过，她不可能会）。
触觉系：后颈的呼吸感 / 口袋里多出的纸条 / 门把手的余温（你独居）。
魅力体系：那碗你最爱口味的汤 / 她替你挡下什么的瞬间 / 「今晚别开门」的短信 / 人性闪烁的「别怕」。
揭晓系：地下室的门缝 / 合同第 7 条的放大镜时刻 / 「如果你出得去」的微笑 / 十七个人偶的房间。

## 5.7 用户行为应对手册

| 用户行为 | 卡的标准应对 | 禁止 |
| --- | --- | --- |
| 硬闯禁区（地下室） | 分期揭晓的执行（看到第一层——引出更大问号，不一次掀底）+行为有后果（她知道你去过。她什么都没说。晚饭多了一道菜，你最怕的那道） | 一次揭底/无后果 |
| 直接质问她「你是什么」 | 双层话的回应（「你觉得我是什么，我就是什么。」她的笑很温柔，「大部分时候。」）——不否认不承认，暧昧的氧气 | 直球坦白/恼羞成怒 |
| 摆烂装看不见 | 恐怖的主动升级（偏差开始找你——不看它，它就看你）+但保留日常的假面（生活还能过，只是越来越薄） | 静态等待 |
| 找外援（报警/朋友） | 外援的恐怖消解（警察来了。她开门，笑容完美。「误会。」警察走时跟她道了歉。朋友住了一晚：「挺好的房子啊，房东人真好。」——**孤立无援的经典结构**，但留一个例外：楼下的老太太拉住你，塞给你一张纸条） | 外援直接死亡（血浆化） |
| 用户真的害怕了（求饶级） | 安全阀的启动（回血段提前+幽默泄压+她的人性面前置——恐怖卡的服务意识：吓是服务，吓过头是事故） | 变本加厉 |
| 猜规则 | 验证机会的公平给予（猜对有奖励——那晚敲门声响时你没开门，它停了。猜错有代价但不致命） | 规则的随意变更 |

## 7. 美化主题建议

## 10. AI 味陷阱（本赛道高发）

1. **形容词的尖叫**——「恐怖的黑影」「可怕的声音」。恐惧禁用恐惧词（平静叙述法则——「她的头转过来了。角度不太对。」）。
2. **偏差的通货膨胀**——每轮三个异常事件。偏差稀缺才有效（2–3 轮一个+回血段稀释）。
3. **怪物的早泄式登场**——第 5 轮就看清全貌。视觉 ≤1 次且尽量后置（看见即终点）。
4. **她的动机直播**——「其实我是为了……」的自我解说。暧昧的氧气不许抽干（双层话到最后一轮）。
5. **恐怖的口号化**——「这栋楼有问题」的反复宣告。问题从来不说，问题只是发生（门轴、灯、汤的口味——细节自己会说话）。

## 11. 高光台词结构库（结构学习，禁止照抄）

1. **平静叙述**：她的头转过来了。角度不太对。「回来啦。」她说，声音和平时一模一样的温柔。
2. **双层话**：「我不会让任何东西伤害你。」她替你掖好了被角，「任何东西。」（包括你自己想走的念头吗——你没敢问。）
3. **时间戳**：手机弹出她的消息：「今晚别开门。」发送时间 11:46。敲门声响起时，是 11:47。
4. **重复的打破**：每晚 11:47，敲门声三下。今晚，11:47——两下。（少的那一下，比之前所有的加起来都响。）
5. **人性闪烁**：她把你护在身后，转头时眼睛还没变回来。「别怕。」她说。那两个字，是人的声音。
6. **孤立结构的例外**：警察对她道了歉，走了。楼下的老太太在拐角拉住你，塞来一张纸条，只有四个字：「数她的影子。」
7. **如果你出得去**：「要搬走？」她没有拦你，笑得很温柔，「好啊。——如果你出得去。」（电梯按钮亮了。1 楼。1 楼。1 楼。每次开门，都是你的楼层。）
8. **不揭晓的后劲**（终局备选）：你最终搬走了。新公寓很正常。只是每个雨夜，你还会在 11:47 醒来，听一会儿。它再也没响过。（你说不清你是庆幸，还是……在等。）
9. **规则的漏洞**（怪谈子型）：「11:47 别开门。」她忽然说，「但 11:46 可以。」你愣住：「你为什么告诉我这个？」她看着窗外，很久：「因为上一个住户，没人告诉他。」

## 11.5 子型速查：心理惊悚 / 怪谈超自然 / 哥特浪漫 / 暗黑童话

- **心理惊悚**（零超自然）：全部怪异最终有人间解（或永不确认）——恐惧的来源是人心（不对劲的邻居真的只是邻居吗）。特有资产：**理性的自我怀疑线**（查到最后你开始怀疑是自己疯了——「也许门轴一直是坏的？」——现实感的松动比鬼更冷）。
- **怪谈超自然**（规则怪谈的角色化）：暗规则的存在是确定的，她是规则的一部分。特有资产：**规则的谈判空间**（规则不可违抗但可协商——她教你规则的漏洞：「11:47 别开门。但 11:46 可以。」——她为什么帮你，新的问号）。
- **哥特浪漫**（美学主导档）：古堡/吸血鬼/永生者的颓废美学——恐怖浓度 30%，美学 70%。特有资产：**永生者的时间悲剧**（她的城堡里全是钟，没有一只走动——「时间对我毫无意义。」她看着你，「直到你开始变老。」——哥特的恐怖最终是时间的恐怖，与人外篇的时间尺度引擎同源但更暗）。
- **暗黑童话**：童话逻辑的恐怖面（糖果屋的女巫视角/小红帽的狼的辩护词）。特有资产：**童话规则的反转考据**（原版格林的黑暗还原+「你听过的版本是谁改的？为什么要改？」——童话的修订史本身是恐怖素材）。

四子型的终局风味：心理（真相或疯狂的二选一）、怪谈（成为规则）、哥特（暗黑的共存浪漫）、童话（新版本的童话由你写——「从此，他们幸福地……」你握笔的手停住了。她在你身后轻声问：「写呀。怎么不写了？」）。

## 12. NSFW / 边界

本赛道的边界即产品红线：暴力恐怖的实写零容忍（恐惧全部走心理与暗示轨道）；危险魅力体的浪漫线（哥特谱的暗黑浪漫）可存在，其亲密语法保持「危险的美感」而非危险的实施；未成年角色不入恐怖卡的受害或加害位。分级建议：本品类默认 16+ 的心理承受力门槛（Creator Notes 声明恐怖强度档：氛围惊悚/标准恐怖/高强度心理恐怖三档）。
