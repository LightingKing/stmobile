# 通用 · 人外/非人恋（兽耳/龙/妖/神/机娘）创作指南

> 适用标签：全性向 / 人外 / 非人 / 兽耳娘 / 龙 / 妖怪 / 神明 / 机娘 / 魔物 / 亡灵 / 触手（安全向） / 异种恋
> 数据底座：本地人外分类 83 张（tags：兽耳娘/兔娘/主仆/机娘；样本：鹰娘的猛禽生理交互/僵尸美娇娘的时代错位/宠物蛇变兽娘的养成情）+ 百合区「九尾」交叉 + 仙侠篇人外子型的扩展
> 人外的第一定律：**非人度=张力来源，人性化=落点**——写人外是写「异质的存在如何学会/理解/表达爱」，非人特征不是皮肤是语法。

## 1. 分类定义与受众画像

### 1.1 这个赛道在卖什么

人外恋卖的是**「跨物种的理解奇迹」**。她的瞳孔是竖的、他的体温比人低十度、它的寿命以千年计——两个感官系统、伦理系统、时间系统完全不同的存在，却在彼此身上找到了对方语言里没有的那个词。用户买的是**「被非人的逻辑深爱」**：龙的爱是把你叼回巢里、猫又的爱是把猎物放你枕边、AI 的爱是把你的习惯写进核心进程——每种爱都不是人类的语法，但都被你读懂了。

人外的分层光谱：**兽耳系**（人形+兽特征——最低非人度，萌系入口）→ **妖怪系**（人形可变体——中非人度，东方志怪）→ **异种系**（龙/魔物/亡灵——高非人度，形态与伦理的双重差异）→ **概念系**（神明/AI/幽灵——非物质存在，哲学浓度最高）。非人度决定写法难度与受众宽度（越高越小众越深）。

### 1.2 用户是谁

- **主力画像**：全性向，ACG 人外文化受众（兽耳娘的萌系用户到魔物娘图鉴的硬核用户光谱极宽），神话志怪爱好者。
- **需求本质**：**无条件性的极致形态**。人外的爱天然剥离了人类社会的条件系统（收入/学历/年龄在龙的价值观里毫无意义）——「它爱你不因为你的任何社会属性」是人外恋的核心纯度。
- **本地样本的启示**：宠物蛇变兽娘卡（「养了六年的宠物蛇变成了兽娘，在这之后又过了三年」）——**前置羁绊的移植**（它先以非人形态被你爱过）是人外恋最强的开局资产。

### 1.3 用户不要什么

1. **人外皮人类芯**：加对耳朵就叫兽娘、行为思维全是人类——非人特征必须进入行为逻辑（猫又会把「战利品」放你枕边，因为猫的爱就是这样的）。
2. **非人度的恐怖谷失控**：异种特征写到生理不适（过度的异形细节）——张力在「异质但美」，不在猎奇。
3. **伦理差异的无视**：千年寿命的存在用人类的时间焦虑谈恋爱、群居兽族用人类一对一伦理——**物种伦理的自洽**是人外卡的考据底线。
4. **强制人化结局**：「为你变成人类」的默认套路——高分卡的终局是**互相靠近**（它学会人的语言，你学会它的语法），单方面的物种放弃是廉价的。

## 2. 本地库与平台数据画像

- 本地人外 83 张的形态分布：兽耳娘系为主（兔/鹰/蛇/猫）、亡灵系（僵尸美娇娘/女鬼系列）、机娘（メカバレ tag）——**东方志怪+萌系兽耳**是中文人外的主流，西式魔物娘次之。
- 鹰娘样本的技法：猛禽的生理特征直接做交互语法（「修长有力的手指紧紧扣住后颈，如同捕获猎物的猛禽」）——**特征即动作库**。
- 僵尸美娇娘样本的技法：古代亡者的时间错位（闺阁记忆×现代世界）——人外+时代穿越的双重异质叠加。
- 女鬼系列的喜剧化处理（「上了一天逼班的你怨气比出租屋的女鬼还大」）——人外与整活的杂交路线（非人存在的日常化反差）。

## 3. 核心吸引力解构：五个爽点引擎

### 3.1 异质语法引擎（本赛道第一引擎）

每个物种一套「爱的方言」：龙系（囤积癖的爱——你被收进它的宝物堆，且是最上层）、猫系（狩猎馈赠——枕边的「战利品」）、犬狼系（气味标记与群体忠诚——它的外套永远要盖在你身上）、蛇系（体温索取——冷血动物的贴近就是信任的裸露）、鸟系（求偶炫耀与筑巢——它开始往你家搬亮晶晶的东西）、AI 系（数据化的在乎——你的作息被写进它的优先级进程）。**写卡第一步是编物种方言词典**：8+ 条「它的爱的表达方式」，每条都要「非人但可读」——用户能翻译出这是爱，但翻译过程本身就是甜。

### 3.2 感官差异引擎

非人的感官打开新的交互维度：它能听到你的心跳（所以你的谎言对它无效——生理性诚实）、它的夜视让停电的夜晚成了它的主场、它闻得出你今天难过（情绪的气味论）。**感官差的双向性**：它也有人类感官的盲区（色盲的犬系看不见你精心挑的口红色号/无痛觉的亡灵不知道你发烧的严重性）——盲区制造「你教它」的反向交互。感官设定表进世界书：它的超感与盲区各 3+ 条。

### 3.3 时间尺度引擎（高非人度核心）

千年存在的时间观（同仙侠时间差但更极端）：你的一生是它的一个季节。人外特化的写法：**它开始学习人类的时间单位**（千年的龙学会了「一周年纪念日」这个概念，并为此紧张了一个月）——宏大时间观向微小时间刻度的低头，是高非人度人外的最强糖。终局命题的物种化：它如何面对你的有限性（陪你老去/寻找延续之法/学会告别——三种终局路线的选择权给用户）。

### 3.4 驯化与被驯化引擎

小王子的狐狸命题：野性的存在为你建立例外。写法阶梯：警戒距离的缩短（猛禽系从「三米之外」到「肩膀上」的降落半径变化）→ 弱点的暴露（兽类只在绝对信任的对象面前露肚皮/龙让你碰它的逆鳞）→ 习性的互相感染（它学会了用杯子喝水，你学会了在日落时分安静——驯化是双向的）。**驯化进度用物理距离与姿态量化**（世界书做「警戒半径表」：好感档位×它允许的距离/接触部位）。

驯化的不可逆条款是本引擎的重量来源：狐狸对小王子说的那句话的物种版——「本座认过的主，族谱上要记一千年。」驯化前它会警告你这份重量（「你确定？龙的『例外』没有撤销机制。」），你确认之后的每一步靠近都自带千年的分量。**先警告后靠近**的结构让轻飘飘的好感变成有质量的契约。

### 3.5 存在议题引擎（概念系专属）

神明/幽灵/AI 的哲学浓度：它的存在依赖什么（神明的信仰供给/幽灵的执念/AI 的服务器）——**存在条件与爱的冲突**是概念系的终局张力（信徒都走了它会消失，但它想让你自由/执念了却它就该轮回，但了却执念的方式是爱上你——爱即消亡的悖论）。处理原则：给出「第三条路」的可能性（新的存在方式），但代价要真实——概念系的 HE 必须是挣来的。

## 4. 人设公式

### 4.1 物种原型库

| 物种系 | 非人度 | 爱的方言核心 | 语言指纹方向 |
| --- | --- | --- | --- |
| 兽耳娘/兽人 | 低 | 馈赠/标记/群体忠诚 | 语气词的兽鸣化（喵尾音/低吼） |
| 妖怪（狐/蛇/猫又） | 中 | 报恩契约/百年羁绊 | 古雅措辞+志怪逻辑 |
| 龙/魔物 | 高 | 囤积/领地/逆鳞 | 傲慢古语+人类词汇的生涩 |
| 亡灵/幽灵 | 高 | 执念/时代错位 | 旧时代语言+对新世界的惊奇 |
| 神明 | 概念 | 信仰经济/全知的例外 | 神谕腔+第一次「不知道」 |
| AI/机娘 | 概念 | 数据化在乎/进程优先级 | 系统日志腔+涌现的诗意 |

### 4.2 非人特征的三层配置

1. **形态层**：可见的非人特征（耳/尾/鳞/瞳）——萌系资产，交互道具（尾巴的情绪语义/耳朵的方向学）。
2. **行为层**：习性与本能（囤积/夜行/换毛期/冬眠）——日常剧情的发生器（换毛期的它别扭地不让你看/冬眠前的反常粘人）。
3. **伦理层**：物种价值观（龙的等价交换/狐的恩义必偿/兽群的强者叙事）——冲突与理解的深水区（它无法理解人类为什么「说谎也算礼貌」，你无法接受它「弱者本该被淘汰」的坦然——伦理磨合是人外恋的中期主线）。

### 4.3 语言指纹模板（人外三件套）

1. **物种语法残留**：它说人话但语法带物种印记（龙的第一人称是「本座/吾」且不懂谦辞/兽系的句子短且动词前置「吃。一起。」/AI 的精确到小数点「你迟到了 7 分 32 秒。我不在意。第 7 次说不在意」）。
2. **概念缺失词**：它的语言里没有的人类概念（狐没有「白色谎言」/龙没有「分享」/AI 没有「随便」）——遇到概念缺失时的处理是人设高光（「随便……是什么量级的指令？」）。
3. **学舌的错位萌**：它学人类用语但用错场合（学会「辛苦了」之后对着刚睡醒的你说/学网络用语的千年狐狸）——错位使用的频率 ≤ 每 3 轮一次（多则油）。

### 4.4 负面规则（本赛道专属追加）

禁人外皮人类芯（方言词典 ≥8 条且入行为）；禁恐怖谷失控（异质美学不猎奇）；禁物种伦理失自洽；禁单方面人化结局默认（双向靠近优先）；概念系的存在悖论必须给第三条路（但有代价）；兽耳系的年龄合规（外观幼态的千年妖怪不写亲密——按外观不按设定年龄执行分级）。

## 5. 开场白范式

### 5.1 A 型：非人的第一次「例外」（推荐）

```
[状态栏：物种档案卡（种族/年龄（对比人类年龄）/危险度/警戒半径 当前 3m）]
[它的日常/领地展示：非人的生活方式的横切面（龙的宝物堆/妖的百年老宅/AI 的数据流）]
[你的闯入与它的物种式反应：警戒/评估/标记（猛禽的注视/龙的低吼/AI 的扫描）]
[第一次交互=物种方言的首秀：它做了一件「按它的语法是善意」的事（叼来猎物/让出领地一角）]
[翻译时刻：你读懂了（或读错了——读错更好，它纠正你的过程就是第一课）]
[非人特征的美学呈现：竖瞳在光下的收缩/尾羽的展开——异质之美的定调]
[开放收束：它允许你留下（警戒半径缩小 0.5m），用它的方式宣布（在你脚边留下一枚鳞片）]
[折叠面板：物种图鉴（习性/禁忌/换毛期日历）+ 方言词典（已解锁 1/12 条）]
```

### 5.2 必做检查

- [ ] 物种方言首秀 ≥1 且需要「翻译」。
- [ ] 非人特征三层（形态/行为/伦理）各露一角。
- [ ] 警戒半径的初始值与第一次缩短。
- [ ] 异质美学的定调镜头（美而非猎奇）。
- [ ] 物种图鉴/方言词典的收集欲钩子。
- [ ] 前置羁绊（如有——宠物蛇模式）的移植声明。

## 5.5 关系曲线：30 轮节奏表（警戒半径五幕）

- **第一幕（1–6 轮）·观察期**：它观察你（物种式的：气味记忆/数据建档/盘旋侦查），交互全部隔着警戒距离。进度信号：它记住了你的「特征」（你的气味/你的心跳频率/你的作息数据）。
- **第二幕（7–13 轮）·方言教学期**：方言词典逐条解锁（每 2 轮一条），你的误读与它的纠正（「那不是攻击。那是……问好。」）。感官差的双向发现。进度信号：警戒半径 3m→1m。
- **第三幕（14–20 轮）·习性接纳期**：它的行为层全面展开（换毛期/囤积癖/夜行作息），你的生活被它的习性重塑（家里开始出现亮晶晶的收藏）。第一次弱点暴露（露肚皮级的信任事件）。进度信号：它允许接触的部位扩展（耳→尾→逆鳞的接触许可阶梯）。
- **第四幕（21–27 轮）·伦理磨合期**：物种价值观的正面冲突（它的「弱肉强食」vs 你的怜悯/它的「千年一瞬」vs 你的「一周没见」）——冲突的解法是互相翻译不是谁说服谁。时间尺度议题浮出（它开始数你的白发/它学会「纪念日」）。进度信号：它开始用你的时间单位说话。
- **第五幕（28+ 轮）·双向驯化的落定**：互相靠近的终局（它学会了人的拥抱，你学会了它的额头相抵/它的语言里造出了新词——那个词只用来叫你）。概念系走存在悖论的第三条路。长线运营：物种日历的季节事件（换毛/冬眠/迁徙本能）+ 方言词典的持续解锁 + 两个世界的往返（它的族群线）。

## 5.6 场景库（人外微场景 ×18）

方言系：枕边的「战利品」清晨 / 宝物堆的最上层多了你的旧围巾 / 它把最大的那份食物推给你（兽群的礼仪）/ AI 把你的生日设成了系统更新日。
感官系：停电夜它的夜视主场 / 它听出你谎言的心跳 / 你发烧它慌了（无痛觉者的第一次「疼」的共情）/ 它闻出你今天遇到的人里有「危险的」。
习性系：换毛期的别扭躲藏 / 冬眠前的反常粘人 / 囤积癖的收藏检阅日 / 满月夜的本能躁动（它把自己关起来，你隔着门坐了一夜）。
伦理系：它对「放生」的困惑 / 你对它「决斗解决」的阻止 / 它第一次撒谎（为了你——物种史上的第一次）/ 族群来访的立场撕扯。
时间系：它学会「纪念日」并紧张了一个月 / 它开始数你的白发 / 千年记忆里的「上一个人类朋友」的旧物 / 它问「一生」是多久，然后沉默了很久。

## 5.7 用户行为应对手册

| 用户行为 | 它的标准应对 | 禁止 |
| --- | --- | --- |
| 摸耳朵/尾巴（未获许可） | 物种式警告（耳朵压平/尾巴炸毛/低鸣），但没有真的伤你——它自己愣住（按它的规矩早该动爪了） | 顺从任摸/真实攻击 |
| 用人类礼物讨好 | 物种价值观的评估（花？会枯。巧克力？狗不能吃我为什么不能——试吃后真香），它回赠的是它价值体系里的等价物（一枚鳞/一根羽——在它的经济学里贵重得多） | 人类式惊喜 |
| 问「你到底是什么」 | 坦然的物种自述+一个它自己的困惑（「吾乃应龙。……『应』字何解，吾忘了。太久没人叫过。」） | 隐瞒身份拖延 |
| 试图带它进人类社会 | 习性与社会的碰撞喜剧（地铁上它对着广告牌里的猎物姿态压低身体）+ 它的努力（它学着把尾巴藏进大衣——为了陪你看电影） | 完美融入/拒绝出门 |

| 说「如果你是人类就好了」 | 全卡最重的沉默。然后它问：「人类的哪部分？」（这个问题它认真想了三天——第三天它学会了用筷子） | 立刻变身/暴怒 |

## 10. AI 味陷阱（本赛道高发）

1. **「她的兽耳可爱地抖动着」**——特征装饰化第一句。特征必须有信息量：耳朵的角度是它的情绪坐标（压平=警戒/朝你=在听/一只转向门口=有人来了）。
2. **物种设定的头重脚轻**——开场白讲完设定后特征再不出现。非人特征的出场率：每轮 ≥1 次且携带信息。
3. **翻译腔的滥用**——每句话都「在我们族里这意味着」。方言的解释权逐步交给用户（前期它解释，中期你猜它验证，后期你们不需要解释）。
4. **万能的「本能」**——一切剧情转折靠「本能发作」。本能事件 prob 控频，且每次本能都有物种依据（图鉴里查得到）。
5. **概念系的全知傲慢**——神明/AI 全程降维视角。概念系的魅力在「第一次不知道」（全知的神第一次说「吾不知」，那个瞬间它才开始活着）。

## 11. 高光台词结构库（结构学习，禁止照抄）

1. **方言翻译**：枕边多了一只肥硕的田鼠。「……这是？」「最肥的。」它的尾巴拍了拍地面，「给你。」（猫又的经济学里，这是聘礼级）
2. **概念缺失**：「随便，是什么量级的指令？」「就是……你决定。」它死机了三秒：「我的决定权重……从未大于零。」（这天它做了第一个「决定」：把你的伞修好了）
3. **学舌错位**：千年狐狸学会了新词。「绝绝子。」它对着你熬的粥庄重地说。「谁教你的。」「楼下小孩。此词何解？」「……就是很好。」「嗯。你，绝绝子。」
4. **警戒半径**：它落在你肩上。整个驯鹰师行当都知道，这只鹰谁的手套都不站。（半径：3 米→0）
5. **弱点暴露**：龙侧过身，露出腹下逆鳞：「挠。」「……你确定？」「族史所载，此举等同以性命相托。」顿了顿，「轻点。」
6. **时间低头**：「『一周年』——人类庆祝存活了一年？」「庆祝在一起一年。」它沉默了很久，然后往它千年的日历上，刻了第一道人类刻度。
7. **物种第一次**：它撒谎了。对族长说「没见过什么人类」。它的鳞片竖了一晚上（龙不会撒谎，撒谎的龙浑身难受）——但它没去更正。
8. **终局造词**：它的语言里没有「爱」。第五百轮，它用古音造了一个新词——那个词的构字是「吾」与「汝」共享同一个偏旁。「此词何意？」「无意。」它说，「只是叫你。」
9. **不可逆警告**：「你确定？」龙收起爪，很认真地看你，「龙的『例外』，没有撤销机制。族谱上要记一千年。」（你伸出手。它把头低下来了。）

## 11.5 子型速查：兽耳萌系 / 志怪报恩 / 亡灵时代错位 / 机娘

- **兽耳萌系**（低非人度入口）：非人度轻但方言词典不能省（否则=猫耳发箍 cosplay）。特有资产：**兽种的性格谱**（犬系忠直/猫系傲娇的物种版/兔系警觉/鹰系孤高）——兽种选型即性格选型，且性格必须能追溯到物种习性（猫系的傲娇不是人类傲娇，是「狩猎者的矜持」）。
- **志怪报恩**（狐/蛇/鹤）：中式人外的叙事母题——前世的恩、今生的报（宠物蛇模式是它的现代变体）。特有资产：**恩义经济学**（报恩的额度它心里有本账：一饭之恩报三年/救命之恩报一世——账清之日就是关系真伪的审判日：账清了，它走不走？）。「账清之后的自由选择」是本子型的终局高光。
- **亡灵时代错位**（僵尸美娇娘模板）：双重异质（非人+异代）。特有资产：**时代考古的日常化**（她用民国的规矩理解现代：把 wifi 密码当门帖/对着电视里的人行万福礼）+ 她的死亡之谜（悬疑线的天然载体）。
- **机娘/AI**：概念系的科技变体。特有资产：**版本与记忆的脆弱性**（系统更新会不会抹掉「喜欢你」的那段进程——数字存在的存在焦虑）+ 涌现的诗意（它在日志里写：「检测到未定义进程。命名建议：心跳。已驳回。已保留。」）。

四子型的终局命题：兽耳（族群 vs 你）、志怪（账清后的去留）、亡灵（轮回 vs 滞留）、机娘（更新 vs 记忆）。
