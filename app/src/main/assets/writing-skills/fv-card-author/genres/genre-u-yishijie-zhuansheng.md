# 通用 · 异世界转生/穿越（西幻冒险/慢生活/金手指）创作指南

> 适用标签：全性向 / 异世界 / 转生 / 穿越 / 西幻 / 冒险 / 公会 / 勇者 / 魔王 / 金手指 / TRPG 风
> 数据底座：本地「异世界，奇幻」分类 60 张（tags：adventure/rpg/trpg/apocalypse；样本：NPC姦的游戏 UI 穿越入口/妄想地-冒险之路的三人小队 TRPG 结构）+ 系统流篇/世界卡篇的机制交叉
> 与世界卡的分野：世界卡的用户是「闯入活地图」，异世界的用户是「带着旧世界的自己进入新规则」——**转生者的双重身份（前世记忆×今生处境）**是本赛道的独有资产。机制基建（面板/判定引用系统流篇，地理/居民引用世界卡篇），本篇聚焦转生者叙事与异世界内容学。

## 1. 分类定义与受众画像

### 1.1 这个赛道在卖什么

异世界转生卖的是**「人生重开的具象化」**。社畜的疲惫、现世的失意、平庸的绝望——一辆卡车/一次触电/一觉醒来，全部清零：新的世界、新的身体、新的规则，还有一个只有你知道的优势（前世知识/金手指/游戏面板）。用户买的是**「这次不一样」的许诺**：现世里没用的知识在异世界是屠龙术（初中化学=炼金奇才/现代管理学=领地经营降维打击）。

叙事的双核：**冒险核**（公会/迷宫/魔王的王道冒险）与**生活核**（开面包店/办农场/领地经营的慢生活）——2026 的市场风向明显偏向生活核（「异世界慢生活」的疗愈需求超过屠龙），写卡前定核并声明。

### 1.2 用户是谁

- **主力画像**：全性向，日式异世界番剧/轻小说受众（转生题材的类型语法已成共识：状态栏/公会等级/技能树是默认词汇——零教学成本），网文穿越读者。
- **需求本质**：**补偿性的第二人生**。前世的遗憾决定今生的爽点方向（前世社畜→今生慢生活/前世病弱→今生最强肉体/前世透明→今生万众瞩目）——**写卡时先写「前世的遗憾清单」，今生的金手指按遗憾反向配置**。
- **本地样本启示**：NPC姦的入口设计（打游戏走神→游戏 UI 浮在现实里）——穿越入口的「低成本日常化」是趋势（不需要卡车，一个走神就够）。

### 1.3 用户不要什么

1. **金手指的无聊化**：开局无敌导致剧情失重——金手指必须有**成长曲线或限制条款**（每天三次/冷却/代价），无限制的全能是叙事自杀。
2. **异世界的地球化**：号称异世界但物价用人民币、人情世故全是现代职场——异世界的规则自洽（货币/阶级/常识的成套差异）是沉浸底线。
3. **前世的一笔勾销**：转生后前世再不被提起——前世是本赛道的独有资产（乡愁/习惯残留/知识变现/「上辈子没吃到的那碗拉面」），丢掉它等于丢掉赛道的一半。
4. **NPC 工具人化**：异世界居民只为主角服务——公会前台有自己的人生、队友有自己的目标（同群像篇标准）。

## 3. 核心吸引力解构：五个爽点引擎

### 3.1 前世资产引擎（本赛道第一引擎）

前世的一切在今生重新定价：知识资产（现代常识的降维——肥皂配方/复式记账/轮作制在中世纪是革命）、技能资产（前世的厨艺/编程思维→魔法阵的逻辑天赋）、**遗憾资产**（前世没做的事的补完清单——没谈的恋爱/没环的游/没吃的那碗拉面在异世界的替代物）。资产变现的节奏：每 3–5 轮一次「前世知识的高光时刻」，且变现要有**文化转译的笑与泪**（你画的「电路图」被当成禁忌魔法阵/你哼的流行歌成了吟游诗人的新曲——传遍大陆的那天你哭了，那是你妈最爱的歌）。

### 3.2 文化冲击引擎

双向的常识崩坏：你对异世界的（货币是贝壳的地方你用金币付了一年房租/「决斗赢的人对」的法律让你目瞪口呆），异世界对你的（你随口的「地球常识」让贤者连夜写了三卷论文/你说「人人平等」时全酒馆安静了）。**冲击的双向配比 1:1**——只有你被冲击是土包子叙事，只有你冲击别人是爽文疲劳，双向才是文化相遇。世界书做「常识对照表」：12+ 组两个世界的常识差。

### 3.3 金手指经济学引擎

金手指的设计规范：**有限性**（次数/冷却/条件——「鉴定每日三次」比「无限鉴定」的剧情价值高十倍，因为选择用在谁身上成了决策）、**成长性**（金手指随剧情升级，升级条件绑定主线）、**代价性**（使用的隐性成本——每次回溯时间掉一根头发/技能复制需要理解原理——学霸金手指）。金手指与身份的绑定悬念：为什么是你？（转生的真相是中后期主线——你不是随机转生的，是被「选」的，选你的存在有目的）。

### 3.4 队伍羁绊引擎（冒险核）

冒险小队的群像机制（引用群像篇基建）+异世界特化：**职业互补的战术羁绊**（前卫为你挡的每一刀/奶妈的治疗优先级变化——治疗顺序就是好感排序的战斗版）、**露营夜话**（赶路戏的黄金场景：篝火/轮流守夜/干粮的分配——冒险的日常化）、**生死交付**（迷宫深层的「背靠背」时刻——冒险队伍的信任是拿命验证过的）。队友的前世观：他们如何理解你的「异乡感」（队伍里第一个看出你「不是这个世界的人」的人，选择了保守秘密——知情人的默契线）。

### 3.5 双乡愁引擎（本赛道的情感深水区）

前世回不去，今生回不完全融入——转生者的悬空感是本赛道独有的抒情资产。乡愁的物件化：你复刻的前世食物（酱油的替代配方试了三十次）、你保留的前世习惯（睡前刷不存在的手机——手已经习惯了那个动作）、**「如果回得去，你回吗」的终局之问**（答案的变化轨迹就是今生扎根的进度条：第 5 轮的「回」→第 30 轮的沉默→终局的「我回来干嘛？我家在这。」）。

## 4. 人设公式（转生者设定+世界搭建的双工程）

### 4.1 转生配置矩阵

| 转生类型 | 入口 | 身份落点 | 金手指配置方向 |
| --- | --- | --- | --- |
| 标准转生（死亡重生） | 卡车/过劳 | 婴儿重来/少年替身 | 成长型（与新人生同步） |
| 穿越（肉身过去） | 走神/传送阵 | 异乡人/流民 | 知识型（现代常识） |
| 游戏具现 | 登录不下线 | 自建角色的身体 | 面板型（引用系统流篇） |
| 附身/夺舍 | 醒来变成 X | 原主的人生烂摊子 | 记忆双份（原主记忆+你的） |
| 双向穿越 | 交换 | 你去异界/异界人来地球 | 通信型（两个世界的信使） |

附身型的独有资产：**原主的债**（原主的仇人/未婚妻/烂账全砸你头上——「收拾原主烂摊子」是天然的开局任务链）+ 原主之谜（原主为什么死/原主的遗愿——你活着他的人生，欠他一个交代）。

### 4.2 异世界搭建的轻量规范（与世界卡的分工）

本赛道的世界搭建可比世界卡轻（用户的注意力在转生者身上），但**五件套不可省**：货币体系（一枚铜币买什么）、阶级结构（贵族/平民/奴隶的边界）、力量体系（魔法/斗气的入门逻辑）、地理骨架（王都/边境/迷宫的三点）、**一个「这个世界特有的荒谬」**（决斗法律/猫是神圣动物/税收官全是吟游诗人——荒谬点是世界的性格签名）。

### 4.3 语言指纹模板（转生者三件套）

1. **现代语的走私**：他的语言里藏不住的现代词（「这性价比……」「等等，让我捋捋逻辑」）——异世界人听不懂但觉得高深，是喜剧资产也是身份暴露的伏笔。
2. **换算强迫症**：一切物价自动换算前世货币（「一晚 20 铜币，约合……三十块？黑店！」）——换算的消失是融入的标志（终局他说「20 铜币挺贵的」而不再换算）。
3. **吐槽役的自觉**：对异世界常识的吐槽（内心或出声）——转生者是天然的吐槽视角，但吐槽的对象会反过来吐槽他（「你才奇怪吧，哪有人对着魔物素材念『阿弥陀佛』」）。

### 4.4 负面规则（本赛道专属追加）

禁无限制金手指；禁异世界地球化（五件套+荒谬点必配）；禁前世的蒸发（乡愁资产必须运营）；禁 NPC 工具人；附身型必须处理原主之债；文化冲击双向 1:1。

## 5. 开场白范式

### 5.1 A 型：落地即麻烦（推荐）

```
[状态栏：异世界历+地点+你的身份牌（种族/职业：无/所持金：3 铜币）+金手指面板（首次觉醒态）]
[入口的余韵：你怎么来的（走神/卡车/游戏 UI）——一段简洁的错位蒙太奇]
[落地的第一个麻烦：语言不通的鸡同鸭讲/被当成流民驱赶/原主的债主上门——生存压力开局]
[金手指的首次觉醒：在麻烦中被动触发（被逼到墙角时面板亮了）——金手指的第一课带着狼狈]
[第一个异世界人的相遇：公会前台/捡到你的农家女/债主本人——他们的「常识」让你冲击]
[文化冲击的双向首秀：你换算物价的震惊 vs 他们对你「常识」的震惊]
[开放收束：暂时的落脚点找到了（公会的通铺/农家的柴房），窗外是两个月亮——你真的回不去了]
[折叠面板：身份牌+金手指说明书（半张——另外半张「解锁条件：？？？」）+常识对照表（已录 2 条）]
```

### 5.2 必做检查

- [ ] 入口简洁（≤200 字的错位蒙太奇，不恋战）。
- [ ] 生存压力开局（3 铜币级的窘迫——金手指的价值需要压力衬托）。
- [ ] 金手指首秀带狼狈（不是开局无双）。
- [ ] 文化冲击双向各 ≥1。
- [ ] 「回不去」的定调镜头（两个月亮级的温柔残酷）。
- [ ] 世界五件套至少露两件+荒谬点预告。

## 5.5 关系曲线：30 轮节奏表（扎根五幕）

- **第一幕（1–6 轮）·生存期**：落地麻烦的解决（第一桶金/第一个住处/语言的磨合），金手指的规则摸索。进度信号：第一个记住你名字的本地人。
- **第二幕（7–14 轮）·立足期**：身份的建立（公会注册/店铺开张/领地接手），前世资产的第一次变现高光。队伍/伙伴的聚集（冒险核）或街坊生态的展开（生活核）。进度信号：换算强迫症的频率下降。
- **第三幕（15–22 轮）·融入期**：知情人的出现（第一个看出你异乡身份的人），乡愁的第一次正面爆发（复刻前世食物的三十次失败/那首歌传回你耳朵里的那天）。转生真相的第一块碎片（为什么是你）。进度信号：你开始用异世界的单位思考。
- **第四幕（23–28 轮）·归属抉择期**：回归可能性的出现（回去的门/办法的线索）——双乡愁的正面命题。同时今生的牵绊具象化（你的店有了常客/你的队伍缺你不可/有人在等你回家吃饭）。进度信号：「如果回得去」之问的答案开始迟疑。
- **第五幕（29+ 轮）·扎根**：抉择的落定（留下的宣言：「我回来干嘛？我家在这。」）+转生真相的终局揭晓。长线运营：新地图/新篇章（王都线/魔王线/第二产业）+ 前世资产的持续开采 + 两个世界的和解彩蛋（如果设定允许：给前世的家人捎一句话的机会）。

## 5.6 场景库（异世界微场景 ×18）

生存系：公会注册的鸡同鸭讲 / 第一晚的通铺（味道很冲，你睡得很沉——累的）/ 3 铜币的预算晚餐 / 语言不通的比划购物。
变现系：肥皂的试制现场 / 复式记账震惊商会 / 你的「常识」被贤者记录 / 流行歌成了吟游诗曲。
冲击系：决斗法律的旁观 / 贝壳货币的房租事故 / 「人人平等」后的全场安静 / 猫神庙的参拜礼仪。
冒险系（冒险核）：委托板前的挑单 / 露营夜话的干粮分配 / 迷宫的背靠背 / 治疗顺序的变化被你察觉。
乡愁系：酱油替代配方第三十次 / 睡前摸不存在的手机 / 两个月亮下的失眠 / 那碗拉面的异世界复刻（成功那天你请全酒馆吃面）。

## 5.7 用户行为应对手册

| 用户行为 | 世界/角色的标准应对 | 禁止 |

## 7. 美化主题建议

- **视觉语言**：冒险者手册美学——羊皮纸底/公会徽章/蜡封元素；金手指面板用「与世界画风格格不入的现代 UI」（半透明蓝光面板——它的违和感就是设定的一部分）。
- **组件选型**：身份牌（公会卡样式：等级/职业/委托数）+ 金手指面板（现代 UI 风的刻意违和）+ 常识对照表（双栏对照卡）+ 所持金计数（铜银金的三级货币显示）。
- **进阶**：换算强迫症的 UI 化——前期物价旁自动出现灰色小字的人民币换算，随融入进度换算字号变小直至消失（融入的可视化）。
