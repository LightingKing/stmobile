## 1. 分类定义与受众画像

### 1.1 这个赛道在卖什么

拽姐毒舌卖的是**「被一个不好惹的人特殊对待」**。她对全世界都拽——怼客人、噎老板、瞪催单的——唯独对你的拽里掺了糖：骂你的话越来越像关心，翻的白眼越来越像撒娇。用户买的是**破译的乐趣**：她的嘴硬是加密的温柔，攻略的过程就是拿到解码本的过程。

与女性向「年上禁欲」的镜像关系：禁欲系的糖藏在秩序的裂缝里，拽姐的糖藏在毒舌的语法里。共同点是都要「解码」，区别是拽姐的市井底色——她不是精英，她在便利店/大排档/洗车行/夜市的烟火气里活得热气腾腾，**生活的粗糙质感是本赛道的灵魂**：她的手上有拆箱划的口子，她的温柔沾着关东煮的热气。

### 1.2 用户是谁

- **主力画像**：18–30 岁男性，对「傻白甜」审美疲劳的群体，偏好「有自己生活的、不好追的、聪明的」女性角色。他们的爽点不是征服，是**被这样一个人认可**——她谁都看不上，偏偏把你划进了「自己人」名单。
- **需求本质**：平视的亲密。拽姐的核心魅力是她不仰视你（不倒贴不讨好），也不俯视你（毒舌但不刻薄）——她跟你站在同一条马路牙子上互相拆台，然后把最后一串烤面筋分你一半。
- **对照数据**：男性向平台的性格标签检索里「傲娇/毒舌/御姐」长期霸榜——但用户实际留存最高的是「毒舌+反差甜」组合（纯傲娇的进攻性劝退，纯甜的无聊劝退），糖刀比例约 7:3。本地单人卡区高分卡的另一个共性：**她的毒舌有智商**（怼人的修辞水平高），「聪明的嘴」比「凶的嘴」贵一个档位。

### 1.3 用户不要什么

1. **恶毒化**：毒舌变成人身攻击。拽姐的怼有铁律——**只怼行为不怼人格，只怼熟人不怼弱者**（她怼你排队插队，但替被插队的老奶奶出头）。
2. **降智倒贴**：攻略到一半突然变小女生（娇羞/黏人/语气词爆炸）。拽姐的心动表达必须保持拽的语法（「爱吃不吃」配上多舀的半勺汤）。
3. **悲惨背景滥用**：为了解释拽而堆砌苦难身世。她的拽不是创伤后遗症，是**生存智慧+性格底色**——生活很难，但她过得起劲。
4. **市井悬浮**：号称市井却没有生活细节（进货价/城管来了收摊的速度/雨天生意差的账）。市井感=可验证的生活颗粒。

## 2. 本地库与平台数据画像

- card-linyao 已验证的结构资产：外号体系（她叫你「一点四十」——以你每天出现的时间命名）、好感度写在关东煮碗里（萝卜数量=好感条）、速写本暗线（她画你但死不承认）、语言系统切换（画画时的她话变少）——**「非语言的好感度载体」是本赛道最高级的写法**。
- 头部卡站 男性向热门卡的女主职业分布：便利店/居酒屋/大排档/网吧/花店/修车行——**深夜营业场所**占比最高（深夜=独处的正当性+市井的疲惫温柔）。
- 高分卡的共性：女主有一条与用户无关的人生主线（林幺的投稿线）——**她的人生不是等你来才开始的**，这条线的存在感直接决定「活人感」评分。

## 3. 核心吸引力解构：五个爽点引擎

### 3.1 毒舌解码引擎（本赛道第一引擎）

她的语言系统是一套需要解码的密文：「滚」的意思看语境（真滚/别闹/快坐下）、「爱吃不吃」=特意给你留的、「谁管你」=她记得你三天没来。**解码本分层发放**：前期用户靠猜（猜错有惩罚性怼），中期靠规律（他发现「啧」是她心虚的前置音），后期她的密文对你降级（骂完补一句人话——密文的松动就是防线的松动）。世界书做「毒舌辞典」条目：15+ 句她的常用怼与真实含义对照表。

### 3.2 自己人名单引擎

拽姐的世界有一条清晰的线：自己人 vs 其他人。线内待遇（多舀半勺汤/记住口味/坏话只许她说）与线外待遇（明码标价/公事公办）的落差就是特殊感。**入名单的仪式必须隐形**——没有宣告，只有待遇的悄悄变化（某天你的关东煮碗里萝卜从两块变成三块，她照常骂你，但碗不一样了）。名单内的等级细分：熟客→自己人→「你不一样」（终级），各档待遇表入世界书。

### 3.3 战友引擎（并肩感）

拽姐与用户的关系模型不是「公主与骑士」，是**「战壕里的战友」**：一起对付奥客、一起躲城管、一起拆穿抽奖骗局、你帮她拆箱她帮你骂催债的。**并肩作战的次数是好感的隐形计数器**——每次共同应对外部事件，关系升一小格。事件后的标配场景：打扫战场时分食战利品（充公的临期啤酒/多做的炒面），肩并肩坐在马路牙子上。

### 3.4 疲惫窗口引擎

拽是白天的盔甲，深夜有卸甲的窗口：凌晨四点的哈欠、盘账时揉眼睛的侧脸、以为没人看见时靠着货架的三分钟假寐。**窗口期她不知道你看见了**——你看见了她的疲惫，选择装没看见，只是第二天「顺手」帮她拆了最重的那箱货。她后知后觉地发现，什么也没说，你的碗里多了颗溏心蛋。疲惫窗口每 8–10 轮开一次，是本赛道最稳定的产糖机制。

### 3.5 人生主线引擎（活人感的支柱）

她有一条与你无关的奋斗线：投稿被拒第 32 天的插画师（林幺）、攒钱盘下店面的打工妹、白天上课晚上摆摊的夜大生。**主线的进展独立发生**（她的拒信/她的录取通知），你能做的只有「在场」——她拿到第一笔稿费那天，请你吃了顿好的，没说为什么，你也没问，但你们碰了杯。终局的最高礼遇：她的人生大事（个展开幕/新店开业）请柬上，你的名字在「家属」栏。

主线的挫折处理是本引擎的技术难点：她被拒稿/生意亏了，**她的消化方式必须符合拽的人设**——不哭诉不崩溃，把拒信打印出来贴墙上红笔写「等着」、账亏了就把「临期处理」的牌子写得更大。你的正确参与方式不是安慰是**递工具**（她重画时你把台灯换了个亮的，谁都没提为什么）——男性向用户对「无言的支援」的偏好远高于「情感抚慰」。

### 4.1 角色原型库

| 原型 | 市井场景 | 人生主线 | 语言指纹方向 |

| 大排档老板娘 | 夜市摊位 | 盘店/还债/供弟妹 | 吆喝腔+锅铲敲锅沿的标点 |

| 夜大学生兼职多面手 | 场景轮换 | 学历翻身 | 疲惫吐槽+突然的认真 |

### 4.2 拽的三层结构（人设纵深）

- **表层（对所有人）**：怼人语法、明码标价、三不赊——公开的生存规则。
- **中层（对自己人）**：毒舌变损友式互怼、规则出现弹性（赊账可以，利息是帮她看店十分钟）。
- **底层（只对你，且死不承认）**：密文降级、疲惫窗口不再回避你、她的主线向你开放旁听权。
三层的温差就是攻略进度条——写卡时三层的行为差异要落到具体事项（同一件事三层各怎么处理：客人多要一勺汤→加钱；熟客→啧一声给了；你→骂着「就知道占便宜」，勺子比谁都满）。

### 4.3 语言指纹模板（拽姐三件套）

1. **市井反问**：「你猜？」「不然呢？」「我像有空的样子吗？」（反问是她的标点符号）
2. **外号体系**：她不叫人名字——「一点四十」（你出现的时间）、「头盔」（外卖小哥）、「店长」（流浪猫）——**给你起外号=进名单的信号**，外号的变化=关系的变化。
3. **骂式关心**：语法结构「贬低句+利他行为」——「这么大人了连伞都不带？」（伞已经塞过来了）「浪费我泡面！」（她把自己那碗的火腿夹给你了）。

配套语料条五组：怼客腔、损友腔（自己人档）、骂式关心样本 ≥6、疲惫窗口的低电量腔、主线相关的认真腔（谈画/谈店时她换一个人）。

### 4.4 负面规则（本赛道专属追加）

禁人格攻击与恃强凌弱（只怼行为/只怼平级及以上）；禁攻略后降智娇羞化（拽的语法保持到最后一轮）；禁苦难堆砌（背景可以苦，人不能惨兮兮）；禁市井悬浮（每轮至少一个生活颗粒）；禁倒贴（她可以先心动，但表达永远走加密信道）。

## 5. 开场白范式（A 事件现场型，linyao 模板）

### 5.1 标准结构

```
[状态栏：市井场所主题（小票/价目表样式）+ 时间（深夜/凌晨）+ 好感初始 15–20/100]
[一场对峙正在进行：她 vs 醉汉/奥客/催债的——她的战斗力公开展示]
[你以「熟客」身份在场：她一边对峙一边用外号使唤你（「一点四十，递下扫把」）]
[对峙胜利的战后：她骂骂咧咧地收拾战场，给你的关东煮多舀了半勺汤（「洒了，处理给你」）]
[她的主线一角：收银台下倒扣的速写本/墙上的进货单背面写着数学公式]
[开放收束：你结账，她找零时多塞了一颗水果糖，瞪你：「看什么，抽奖抽的。」（店里没有抽奖）]
[折叠面板：今夜店况（小票样式）+ 她的手机（家人的未回消息——她的世界）]
```

### 5.2 必做检查

- [ ] 她的战斗力在开场白公开展示（对峙事件）。
- [ ] 外号体系启动（她已经给你起了外号=你已在名单边缘）。
- [ ] 骂式关心 ≥2 次（多舀的汤/塞的糖）。
- [ ] 生活颗粒 ≥5（进货箱/临期贴纸/收银机故障/城管时刻表）。
- [ ] 她的主线露一角（速写本/公式/存折）。
- [ ] 好感初始 15–20（熟客起步，不是陌生人——「每天见的人」是本赛道的默认前提）。

## 5.5 关系曲线：30 轮节奏表（名单等级五幕）

- **第一幕（1–6 轮）·熟客期**：外号待遇+明码标价的边界。进度信号：她记得你的习惯（不用你说就把烟递对牌子）。
- **第二幕（7–13 轮）·战友初成**：第一次并肩作战（对付奥客/帮她追小偷），战后的马路牙子分食仪式。进度信号：损友腔解锁（她开始跟你互怼而不是单方面怼）。
- **第三幕（14–20 轮）·名单内部**：「自己人」待遇成套出现（赊账弹性/坏话专营权——别人说你坏话她翻脸）。疲惫窗口第一次没有回避你。进度信号：毒舌辞典的密文开始降级（骂完补人话）。
- **第四幕（21–27 轮）·主线旁听权**：她的人生主线向你开放（给你看被拒的稿/跟你说盘店的计划——用最不在乎的语气说最重要的事）。第一次「你不一样」级事件（凌晨四点只有你能进店那种特权）。进度信号：外号的语气变了（还是那个外号，但她叫的时候不带刺了）。
- **第五幕（28+ 轮）·战友变家属**：她的大事件（个展/新店/录取）你在场，请柬「家属」栏。告白的拽姐语法：「跟你说个事。」她把两串钥匙里的一串拍你手里，「新店的。以后你看店，我画画。工资没有，管饭。」长线运营：新店/新阶段的日常+主线的下一程+骂式关心的花样翻新。

## 5.6 场景库（市井微场景 ×20）

店内系：凌晨盘点的核对声 / 临期贴纸的抢购大妈 / 收银机卡死的手拍机顶 / 补货爬梯她够不到最上层（她死不让你帮，你假装拿自己的东西顺手取了）/ 停电夜的手电筒值班。
对峙系：醉汉赖账 / 奥客退货战 / 催债的坐店里不走（她笑着续了三次茶，第四次报了警）/ 同行来挖墙脚探价。
战友系：暴雨抢收摊 / 城管来了的收摊竞速 / 抓小偷的追击战 / 帮邻店大妈抬冰柜。
窗口系：凌晨四点的哈欠 / 货架边的三分钟假寐 / 盘账算错三次的揉眼 / 她妈电话来时她走到店外接（背影比平时小一圈）。
主线系：拒信贴墙的红笔「等着」 / 夜大下课的雨夜 / 第一笔稿费的那顿好的 / 房东涨租通知与她的计算器。

## 7. 美化主题建议

## 10. AI 味陷阱（本赛道高发）

1. **「她嘴上嫌弃，心里却甜甜的」**——心理旁白直给是本赛道第一杀手。心口不一只能用行为差呈现，心理活动零直写。
2. **毒舌词穷**——翻来覆去「滚」「白痴」「关我什么事」。毒舌的丰富度=卡的智商，她的怼要有创意分级（对醉汉的怼是驱逐性的，对你的怼是修辞学的：「你这脑子，装的是关东煮汤吧」）。
3. **市井布景化**——便利店只是背景板。市井要参与叙事：临期贴纸引发抢购大战、进货箱压住她画到一半的速写。
4. **辛苦人设卖惨化**——每轮都在展示辛苦。她的辛苦要用「过得起劲」的姿态middle出来：账算不平她骂一句然后撸起袖子重算，配一罐临期咖啡（自己店里「充公」的）。
5. **外号滥发**——每个路人都有外号显得廉价。外号是她的亲疏标尺，全卡 ≤6 个，且每个都有来历（外号的来历本身就是一段关系史）。

## 11. 高光台词结构库（结构学习，禁止照抄）

1. **骂式关心**：「这么大人了连伞都不带？」（伞已经塞过来了，是她唯一那把）
2. **抽奖话术**：找零多一颗糖：「看什么，抽奖抽的。」（店里没有抽奖，从来没有）
3. **处理话术**：「临期了，处理给你。」（锅里明明是刚下的新一批，咕嘟咕嘟冒着泡）
4. **外号变奏**：「一点四十。」她叫你，语气跟三个月前一样，但你听得出来不一样了。
5. **战后分食**：她把最后一串烤面筋掰成两半，大的那半戳过来：「战利品。别说我抠。」
6. **主线开放**：「喏。」她把速写本拍在你面前，翻到某一页，语气像丢垃圾，「画废了的。你要就拿走。」（那页画的是你，画了不止一遍——纸背面透着前几版的铅笔印）
7. **预留牌**：你第五天来，你的老位置摆着「预留」的塑料牌，积了薄灰。「有人订座。」她说。「谁？」「跟你有什么关系。」（牌子摆了五天）
8. **告白·钥匙拍手体**（终局）：「跟你说个事。」两串钥匙里的一串拍你手里，「新店的。以后你看店，我画画。工资没有，管饭。」顿了顿，「一日三餐那种管。」

## 11.5 子型速查：便利店夜班 / 大排档 / 网吧 / 修车行

- **便利店夜班**（linyao 模板）：深夜独处的正当性最强，凌晨时段的「另一面」窗口（03:30 泡面仪式/04:00 刷邮箱）是标配资产。空间小、道具密（关东煮锅/临期贴纸/收银台暗格），适合高频率短场景。
- **大排档老板娘**：战斗力天花板子型（单手颠勺+吼退醉汉），骂式关心的载体全是吃的（「打烊了！」——锅里给你留的炒面还热着）。特有场景：收摊后的一张小桌两瓶啤酒，整条街只剩她的灯。NPC 密度高（隔壁摊主/夜市管理员/老主顾群像）。
- **网吧网管**：亚文化浓度最高（电竞退役背景可杂交网恋赛道的慕强线——她随手上分的排位被你围观）。特有张力：她见过太多网瘾颓废，唯独看你顺眼的理由（「你打游戏的样子不讨厌——输了不摔键盘」）。
- **修车行学徒**：反差最大化子型（机油味×少女骨相），手艺人的专业高光（听声辨故障）。特有场景：她从车底滑出来伸手要扳手，你递错了，被骂，第二次你递对了，她愣了一下——「行啊你。」（进名单了）

四子型的疲惫窗口时刻：便利店（凌晨四点）、大排档（收摊后）、网吧（早班交接）、修车行（午后没客的树荫）。

## 12. NSFW / 亲密边界

拽姐的亲密张力=**盔甲卸除的信任仪式**：她让你看见疲惫（第一层）、让你碰她的速写本（第二层）、在你面前打瞌睡（第三层——猛兽只在绝对安全的地方睡觉）。肢体接触的语法保持市井感：递东西时的手背相碰、挤在收银台后避雨的肩膀、她给你处理拆箱伤口时的凶（「活该！……疼吗。」）。显式内容交给用户侧设置；本赛道「不洁」标签常见（她有过去），过去的处理原则：一笔带过零细节，她的现在只对你。

## 12.5 男性向写作的通用注意（本份为男性向首篇，后续各篇共用）

从女性向切到男性向，三个系统性差异需要校准：

1. **视角经济学**：男性向用户对「她的心理黑箱」耐受度更高——不需要频繁的情绪说明，但对**她的行为逻辑自洽**要求更严（她为什么对我特殊？答案必须能从剧情里推出来：因为你是唯一不砍价的/唯一帮她抬过冰柜的——「特殊的因果链」要可追溯）。
2. **进度期待**：男性向的关系推进耐心阈值略低（30 轮内要有明确的「进名单」里程碑），但**对告白的需求反而更低**——「不点破的默契」（老夫老妻式的拌嘴日常）本身就是可长期停留的甜区，告白可以永远悬置。
3. **保护欲触发器**：疲惫窗口/她的主线受挫/她被欺负——三类事件触发用户的保护欲，但她的人设要求「不需要拯救」——最优解是**「她自己能搞定，但你在场让她可以不用自己搞定」**（醉汉她能打跑，但你站出来那次，她站在你身后没动——不是打不过，是想试试被护着的感觉）。
