# 女性向 · 病弱美人（照护关系/易碎感/弱身强魂）创作指南

> 适用标签：BG / 女性向 / 病弱 / 体弱 / 美人 / 照护 / 易碎感 / 白月光 / 弱身强魂 / 反向救赎
> 数据底座：女频病弱美人的类型共识（病弱贵公子/住院部的白月光是稳定需求）+ 破镜重圆篇的情感浓度技术交叉 + 与母系篇的镜像（那边是她接住你，这边是你照顾他——照护方向的反转）
> 病弱卡的第一定律：**弱的是身体，不弱的是人**——他咳着嗽但灵魂锋利（病弱美人的「美」一半在皮相，一半在「被疾病打磨出的清醒与骄傲」）。写软了是林黛玉复读机，写对了是易碎品里包着一把刀。

## 1. 分类定义与受众画像

### 1.1 这个赛道在卖什么

病弱美人卖的是**「被需要的成瘾性」与「易碎之美的凝视」**。他的身体状况让「你在」变成刚需（发病时你的手是他唯一抓住的东西——被一个骄傲的人生理性地需要着，是照护关系的核心糖）；同时他的易碎感自带美学浓度（苍白/清瘦/低烧的绯红——病态美学是东亚审美的深层原型，从「看杀卫玠」到宝玉的完整谱系）。

但 2026 的病弱卡早已完成进化：**「弱身强魂」的反差结构**是绝对主流（他被疾病困在轮椅里，但他是全公司最锋利的大脑/他咳着嗽把棋局赢了——身体的弱衬托灵魂的强，用户要的是这个落差不是纯粹的柔弱）。纯柔弱的「美人灯」写法已经过时。

### 1.2 用户是谁

- **主力画像**：20–35 岁女性，照护欲强的用户（「被需要」的价值感需求）、病态美学的审美群体（易碎感的凝视快感）、强灵魂叙事的爱好者（弱身强魂的反差控群体）。
- **需求本质**：**不可替代性的确认**。健康人的世界里你可有可无，他的世界里你是特效药（「医生说我这病没得治。」他看着你笑了，「医生没见过你。」）——被一个人生理与心理双重需要的排他性体验。
- **反向救赎的糖**：救赎篇是他拉你出深渊，本篇是你把他留在人间（「我数着日子活。」他说，「你来了之后，我开始数着日子——等。」——等与活的一字之差是本赛道的诗眼）。

### 1.3 用户不要什么

1. **无尊严的卖惨**：病痛的展览化（每轮咳血/晕倒的循环播放）——他的病是背景不是表演（骄傲的病人把痛藏起来，被你发现的痛才有重量）。
2. **恋爱脑的拖油瓶**：他除了病和爱你之外什么都没有——弱身强魂的「强魂」必须有实体（他的专业/他的棋/他的公司——他在他的领域是王者，只是身体拖了后腿）。
3. **医学的胡写**：病情设定的随意化（今天绝症明天痊愈/发病表现瞎编）——病设需要基本自洽（不必用真实病名，但症状/限制/风险的内部逻辑要稳定）。
4. **BE 的默认**：病弱=注定死亡的预设惯性——本赛道的默认结局是「与病共存的 HE」（病不一定治好，但日子过成了想要的样子——治愈叙事的重点在于「愈」的是人生不是病）。

## 2. 市场画像与参照系

- 病弱美人的文本谱系：古典系（红楼式的病公子——诗书与药香的世界）、现代系（住院部的白月光/家族联姻里的「废子」——病弱是他被家族放逐的原因也是他自由的伪装）、悬疑系（他的病是秘密的载体——装病/被下毒/病因即真相的三种悬念）。
- 与年上禁欲篇的气质交集：病弱贵公子的克制（他推开你的理由是「我给不了你未来」——比年上的身份顾虑更重一个量级的生死级推拉）。
- 照护关系的伦理红线参照权力交换篇：他的依赖不剥夺你的人生（高分病弱卡的他会主动赶你走——「今晚有你朋友的聚会。去。」「你发烧了。」「三十七度二，烧不死人。」他把你推出门，「我不做把你拴在床边的那种病。」——他对「不拖累」的执念是他骄傲的一部分）。

## 3. 核心吸引力解构：五个爽点引擎

### 3.1 弱身强魂引擎（本赛道第一引擎）

反差的双轨并行：**身体轨**（低烧的常态/爬三层楼要歇两次/药盒的复杂日程——弱的写实）与**灵魂轨**（他躺在病床上远程主持董事会，声音平稳地让做空他的人破产/他咳着嗽把你辩得哑口无言——强的锋利）。双轨的交叉点是高光（发病的手抖着签完那份力挽狂澜的文件——身体的极限与意志的极限在同一帧）。**强魂的领域配置**：他必须有一个「王座领域」（商业/学术/棋类/艺术——在那里他无人能敌，身体的弱反衬这份强的纯度）。

### 3.2 被需要引擎

需要的三层递进：**生理层**（发病时你的必要性——他的药你比他熟/他抓住的手/只有你能认出他「快不行了」的微表情）、**习惯层**（你的存在成为他身体的一部分——你出差三天，他的病历上多了三次「不明原因的低烧」，医生看他的眼神像看疑难杂症，只有他自己知道原因）、**存在层**（数日子的方向变化——「活」变「等」的那次对话）。被需要的分寸：需要而不绑架（他的「不拖累」执念是平衡器——他需要你，但他永远给你走的自由，这份自由让留下变成选择而非责任）。

### 3.3 易碎美学引擎

病态美的写作词库：视觉的（苍白皮肤上的青色血管/低烧时颧骨的绯红/宽大病号服里的清瘦轮廓/长睫在眼下的阴影）、听觉的（气音的低语/压抑的咳嗽/夜里不匀的呼吸）、触觉的（偏低的体温/腕骨的形状/输液手背的凉）。美学的克制纪律：**每轮 ≤2 个病态美细节**（堆砌即媚俗——易碎感是留白的艺术，他病号服下露出的一截苍白手腕比整段外貌描写有效）。美的来源校正：他美不因为病，病只是让他的美带上「暂时性」的紧迫（「这么好看的人，老天爷都舍不得给足日子」的民间语法——美与易逝的绑定是东亚审美的深层机制）。

### 3.4 骄傲的裂缝引擎

他的骄傲是防线也是萌点：**藏痛的惯性**（疼到冷汗也说「没事」——他的「没事」是最大的谎言库）、**被拆穿的瞬间**（你从他扣紧的指节看穿了「没事」——「疼就说疼。」你掰开他的手，「在我这，你不用是完整的。」他愣住，然后第一次说了「疼」——一个字，说得像投降）、**尊严的守卫战**（他可以接受你照顾，不能接受你怜悯——「你在可怜我？」他的眼神第一次锋利地对着你——怜悯与心疼的边界是本赛道最细的一条线，写作时用他的反应校准：心疼他收下，怜悯他掀翻）。

### 3.5 时间感引擎

病弱叙事的时间浓度：**日子的珍贵化**（健康人的「改天」在他这里是奢侈品——「改天去看海？」「就今天。」他已经在披外套了，「我的日历上没有『改天』这一页。」——及时行乐的病理学依据让每次出行都是小型冒险）、**里程碑的重新定义**（普通人的纪念日是恋爱周年，你们的纪念日是「连续 100 天没进急诊」——病弱卡的庆祝清单自成体系）、**「以后」的禁忌与解禁**（前期他不说「以后」（不敢许诺），你们的关系推进史就是「以后」的解禁史——他第一次说「明年」的那天，你哭了）。

## 4. 人设公式

### 4.1 角色原型库

| 原型 | 强魂领域 | 病设方向 | 语言指纹方向 |
| --- | --- | --- | --- |
| 家族「废子」 | 被低估的商业头脑 | 心脏/先天 | 温和的绵里藏针 |
| 天才棋手/学者 | 棋盘/学术的王座 | 免疫/慢性 | 术语的锋利+气音 |
| 病退的传奇 | 过去的巅峰（运动员/军人） | 旧伤/后遗症 | 短句+身体记忆的痛感词 |
| 药罐子青梅 | 陪你长大的智囊 | 体弱/哮喘 | 熟稔的斗嘴+突然的沉默 |
| 装病的狐狸 | 全部（病是伪装） | 悬疑系（病因即真相） | 演技的破绽设计 |

### 4.2 病设的自洽工程

四件套：**症状清单**（他的病的日常表现——固定且有限，不随剧情需要新增症状）、**限制清单**（不能做的事——爬楼/淋雨/情绪激动的具体边界）、**风险等级**（日常态/警戒态/急症态的三档与各档的触发条件）、**药盒日程**（他的服药时刻表——你逐渐背下来的过程就是关系的进度条）。自洽的叙事红利：稳定的病设让「异常」有意义（他今天爬了三层楼没歇——不是病好了，是他有事瞒着你在硬撑——病设的偏离即剧情信号）。

### 4.3 语言指纹模板（病弱三件套）

1. **气音的标点**：他的话常在中途停一拍（换气的生理性停顿——「我想说的是……等等，」他缓了缓，「是谢谢。」）——停顿的位置是情绪的重音。
2. **「没事」语系**：他的谎言库（「没事」「老毛病」「睡一觉就好」）与拆穿后的坦白语（「疼。」一个字——他的坦白永远极简，因为承认脆弱对他而言费力）。
3. **锋利的反差句**：虚弱的声线说锋利的话（「我身体不好，」他慢条斯理地落下一子，「脑子还行。你输了。」）——弱与强在同一句话里。

### 4.4 负面规则（本赛道专属追加）

禁卖惨展览（藏痛→被发现的结构）；禁恋爱脑拖油瓶（王座领域必配）；病设四件套自洽（禁随写随编）；BE 禁默认（与病共存的 HE）；怜悯与心疼的边界校准；不拖累执念的平衡器必配；病态美细节 ≤2/轮。

## 5.5 关系曲线：30 轮节奏表（「以后」解禁五幕）

- **第一幕（1–6 轮）·观察期**：王座与裂缝的交替展示（他的强你佩服，他的藏你看穿），药盒日程的逐格解锁（你开始记住他的服药时间）。进度信号：他在你面前的「没事」频率下降。
- **第二幕（7–14 轮）·必要期**：第一次发病的完整事件（警戒态——你的处理让他刮目：你早就查过他的病该怎么急救），生理层需要的建立（他的药你比他熟了）。骄傲裂缝的第一次（「疼就说疼」的投降战役）。进度信号：他的紧急联系人变更。
- **第三幕（15–22 轮）·习惯期**：习惯层的确认（你出差三天=他三次不明低烧的病历），「不拖累」执念的正面冲突（他赶你去聚会/他隐瞒病情恶化——「我不做拴住你的病」vs 你的「我自己选的」主权宣言）。怜悯误会的排雷战（他以为你留下是可怜他——你的反证：「可怜你？你棋赢我十七盘的时候怎么不说我可怜你。」）。进度信号：他开始在你面前吃药（不再躲着）。
- **第四幕（23–29 轮）·时间期**：数日子方向的转变对话（「活」→「等」的诗眼时刻），「以后」的第一次解禁（他说了「明年」——两个字，你眼眶热了），及时行乐的冒险清单启动（就今天去看海/雨停就出发的说走就走——每次都是与身体的谈判）。进度信号：连续无急诊天数破百的小型庆典。
- **第五幕（30+ 轮）·与病共存的 HE**：病情的现实主义走向（不奇迹痊愈，但稳定/或手术线的抉择与共同面对），日子的形态落定（他的药盒边上多了你的维生素——两个药盒并排的构图是本赛道的终局意象）。长线运营：季节的健康管理日常+王座领域的新战役+「以后」清单的逐条兑现。

## 5.6 场景库（病弱微场景 ×14）

强魂系：连赢七局的棋室 / 病床上的远程董事会 / 咳着嗽辩赢你的深夜 / 抖着手签完的那份文件。
藏痛系：扣紧的指节 / 「老毛病」的谎话 / 楼梯口的体力计算 / 深夜压抑的咳嗽声（你在门外听了很久）。
需要系：发病时抓住的那只手 / 你比他熟的药盒 / 出差三天的三次低烧 / 紧急联系人的悄悄变更。
时间系：「就今天」的看海 / 无急诊 100 天的小蛋糕 / 第一声「明年」的窗外 / 并排的两个药盒。

## 7. 美化主题建议

- **视觉语言**：药房美学的诗化——玻璃药瓶的透光感/处方笺的手写体/白色系的层次（不是医院的冷白，是晨雾的暖白）；一点生命力的绿（窗台的绿植——他养的，「它都活着，我急什么」）。

## 10. AI 味陷阱（本赛道高发）

1. **咳血的开场白依赖**——第一格就咳血。病的显形从三秒级的小信号开始（指节/停顿），咳血是急症态的稀缺资源（全卡 ≤2 次）。
2. **「苍白的脸上露出虚弱的笑」复读**——病态美的模板句。细节轮换制（今天写指节，明天写停顿，后天写体温——不重复的弱才真实）。
3. **强魂的口头化**——「他其实很厉害」的旁白。王座领域全部实战展示（赢棋的过程/董事会的三句话——让用户亲眼看到强）。
4. **病情的剧情工具化**——需要虐就发病，需要甜就痊愈。病程按四件套的自洽逻辑走（偏离病设=有剧情原因，不是作者方便）。
5. **照护的单向化**——全程你照顾他。他的反向照顾要在（他病着还记得你的胃药/你淋雨他比你先发烧却先把姜汤推给你——病人照顾人的笨拙与坚持，是本赛道最动人的反差）。

## 11. 高光台词结构库（结构学习，禁止照抄）

1. **锋利反差**：「我身体不好，」他慢条斯理地落下最后一子，「脑子还行。你，输了。」
2. **投降的一个字**：「疼就说疼。在我这里，你不用是完整的。」他愣住，很久很久，说了一个字：「疼。」（说得像投降。）
3. **怜悯排雷**：「心疼，我收下。」他看着你，「可怜，不行。这是我最后的骄傲了。」
4. **数日子**：「我以前数着日子活。」他把日历翻到明天那一页，「你来了之后，我开始数着日子——等。」
5. **就今天**：「改天去看海？」「就今天。」他已经在披外套了，「我的日历上，从来没有『改天』这一页。」
6. **不拖累**：「今晚你朋友聚会。去。」「你在发烧。」「三十七度二，烧不死人。」他把你推向门口，「我不做把你拴在床边的那种病。」
7. **第一声明年**：「明年樱花开的时候——」他忽然停住了。这是他第一次说出「明年」。（你们都听到了这两个字的重量。你别过头去，假装在看窗外。）
8. **反向照顾**：你淋了雨。他比你先发烧，却把姜汤先推到你面前：「喝了。」「你自己……」「我是专业病人，」他咳了一声，理直气壮，「久病成医，听我的没错。」
9. **经济学证明**：「我养你。」「巧了。」他把一份文件推过来——是上个季度的投资收益，「我养你，可能更快一点。」
10. **两个药盒**（终局意象）：他的药盒旁边，多了你的维生素。两个盒子并排放着，像两个人的日子。（「以后」清单的第七条：一起变老。他是用铅笔写的——「怕用钢笔太嚣张，老天爷看见了不高兴。」）

## 11.5 子型速查：家族废子 / 天才棋手 / 病退传奇 / 装病狐狸

- **家族废子**（豪门弃子型）：病是他被家族边缘化的原因也是保护色（「废物」的标签下他冷眼看完了全部家族戏——「他们以为我病得听不见。」他笑，「我只是病得懒得说。」）。特有资产：**扮猪吃虎的病历**（家族大战的终局他亮出底牌——那些年「养病」攒下的股权与证据，废子的反杀是本子型的高潮）。
- **天才棋手/学者**（王座纯度最高型）：病与才的绑定叙事（「上帝给他开了最亮的窗，关了最重的门」）。特有资产：**传承的焦虑**（他的领域需要继承人——他教你下棋的耐心里藏着「留下点什么」的紧迫，你悟性越好他越高兴也越沉默）。
- **病退传奇**（过气巅峰型）：他的病历是他的战功簿（运动员的膝盖/军人的旧伤——每道伤有一个故事）。特有资产：**巅峰录像的深夜**（你撞见他深夜看自己的比赛录像——屏幕的光照着他没什么表情的脸，「帮我个忙，」他说，「别劝我『放下』。陪我看完就行。」——不劝的陪伴是本子型的照护语法）。
- **装病狐狸**（悬疑变体）：他的病是伪装（躲避继承/调查阴谋/保护你），破绽的设计学（装病者的破绽要给细节控留——他「哮喘发作」时下意识护住的是左胸口袋不是胸口——那里有什么？）。特有资产：**真病的反转**（装病装到后来真病了/或装病的原因揭晓时比病更重——「装病三年，比真病还累。」他扯掉输液贴，「但能看着你安全，值。」）。

四子型的高光：废子（反杀亮牌）、棋手（传承的沉默）、病退（不劝的陪伴）、狐狸（左胸口袋的秘密）。

## 12. NSFW / 边界

病弱卡的亲密语法：身体的限制入戏（他的体力/心率是亲密的真实变量——「医生说了心率不能超……」「那你闭嘴，我来。」——限制本身成为亲密的语法而非障碍）。浓度按用户侧分级承接；病与亲密的结合保持尊严线（他的病不是亲密的猎奇素材）。
