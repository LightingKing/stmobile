# 通用 · 悬疑刑侦搭档（探案二人组/罪案单元剧/智性共振）创作指南

> 适用标签：全性向 / 悬疑 / 刑侦 / 探案 / 侦探 / 法医 / 搭档 / 单元案件 / 智性恋 / 罪案单元剧
> 数据底座：刑侦罪案题材的剧集市场共识（探案搭档是全性向的长青配置）+ 群像篇的双人机制简化 + 古风权谋篇裴聿式「智性张力」的现代版 + 黑暗惊悚篇的悬念技术转用
> 刑侦卡的第一定律：**案子是关系的显影液**——每个案件都在测试与暴露两人的某一面（他对尸体的冷静×对你受伤的失态——案件是借口，搭档才是主线）。案件写作的及格线是「诡计能够自洽」，高分线是「案子照见人心」。

---

## 1. 分类定义与受众画像

### 1.1 这个赛道在卖什么

悬疑刑侦卖的是**「智性张力×生死信任」的搭档关系**。停尸房的并肩、案发现场的默契对视、审讯室外「他撒谎了」的同时开口——用户买的是三层快感：**解谜的智力快感**（单元案件的诡计与推理——你是参与者不是观众）、**搭档的化学反应**（两个聪明人的思维共振——「你想的和我想的一样？」「闭嘴，让我先说。」）、**极端环境的感情浓度**（生死关头的信任是最高纯度的感情——他把后背交给你的那一刻，比任何告白都重）。

三种糖法流派：**智性恋流**（智商的互相吸引——推理的你来我往就是他们的调情语法）、**冷热配流**（冰山法医×热血刑警的经典温差组）、**宿敌流**（侦探×怪盗/警察×卧底的立场张力——猫鼠游戏的危险甜）。

### 1.2 用户是谁

- **主力画像**：全性向，刑侦剧/推理小说的受众（本格与社会派的用户光谱都在）、智性恋人群（「聪明是最高级的性感」信奉者）、搭档叙事的爱好者（比恋爱先行的是并肩作战）。
- **需求本质**：**被智力对等者认可的快感**。他不夸你漂亮，他说「你刚才那个推理，漂亮」——智性认可是本赛道的独家糖（在他眼里你首先是「能跟上他思维的人」，这份对等比宠爱更贵）。
- **单元剧的消费习惯**：案件的单元结构适配碎片化消费（一案 10–15 轮的闭环+主线暗线的长弧——单元剧的节奏工程是本赛道的结构学，也是复访率的保障：破完一案的成就感是天然的存档点）。

### 1.3 用户不要什么

1. **诡计的糊弄**：案件逻辑漏洞百出/凶手随机指定——推理卡的用户会真的动手推理（诡计的自洽是本赛道的生死线，线索要公平前置——答案揭晓时用户要能回溯出「原来第 3 轮那个细节是线索」的恍然）。
2. **恋爱对案件的碾压**：查案变成约会的背景板——案件的专业浓度是搭档关系的地基（案子不认真，并肩就成了儿戏）。
3. **尸体与暴力的猎奇**：法医戏的器官特写/凶案的血腥渲染——专业化处理是唯一解（法医的语言是解剖报告的克制，不是恐怖片的镜头——参照黑暗惊悚篇的零血浆纪律）。
4. **单元案的口水化**：每个案子都是三角恋杀人——案件类型的多样性（诡计类/社会派/心理类的轮换）与凶手动机的人性深度（好的案子结束时用户心里发堵——「凶手也……唉」的复杂余味）。

## 2. 市场画像与参照系

- 刑侦搭档的经典文本谱系：福尔摩斯×华生的智力不对称组（一个天才一个叙述者）→ 现代刑侦剧的对等搭档组（法医×刑警/心理师×警探的专业互补）→ 宿敌流的张力组——**对等搭档组是角色卡的最优解**（用户要参与推理，不对称组会把用户压成只能记笔记的华生）。
- 与古风权谋篇的分工：裴聿式的智性张力（棋逢对手的试探美学）是本篇的古代亲戚——那边的战场是朝堂，这边是案发现场；机制通用（智力对等/试探回合制），氛围重写（法医的白大褂替换饮冰公子的鹤氅——但「聪明人互相看见」的内核一脉相承）。
- 悬念技术引用黑暗惊悚篇：不对劲引擎/暗规则引擎可直接用于案件设计（凶手的作案规律=暗规则的刑侦版本——连环案的规律归纳就是规则怪谈的解谜结构）。

## 3. 核心吸引力解构：五个爽点引擎

### 3.1 智性共振引擎（本赛道第一引擎）

思维对等的写作技术：**推理的对手戏**（他抛论点你补论据/你提假设他找反例——推理以对话推进而非独白展示，用户的输入被认真对待并整合进推理链）、**默契的同时性**（同时开口说出同一个名字/审讯室外的同时皱眉——思维同步的仪式性时刻，每案 ≤2 次）、**分歧的价值**（两人推理方向相左的案子最好看——「赌一顿饭，凶手是死者的合伙人。」「赌一个月的咖啡，是他妻子。」——分歧让答案揭晓变成双人游戏的胜负时刻）。智性认可的糖点投放：「漂亮」的专业赞美（他对你的推理/你对他的破局——认可的稀缺性管理：他不轻易说，说了就是真的）。

### 3.2 单元案件引擎

案件的工程规范：**一案的结构**（10–15 轮闭环：现场（信息的公平投放）→侦查（线索与嫌疑人的展开）→瓶颈（推理的卡壳与转机）→揭晓（回溯性的公平验证）→余味（凶手动机的人性回响））、**线索的公平性原则**（所有关键线索在揭晓前展示过——本格推理的铁律，用户回看时要能服气）、**案件类型的轮换表**（密室/不在场证明/心理侧写/社会派——连续两案不同类型）、**主线暗线的埋设**（每个单元案里藏一块主线拼图——连环案的真凶/他的旧案/你的身世——单元剧的追更引力来自暗线）。

### 3.3 专业浓度引擎

刑侦职业的颗粒感：**法医线**（解剖报告的术语美学/死亡时间的推定逻辑/「尸体不会说谎」的职业信条）、**刑警线**（走访的脚力/审讯的话术/卷宗的深夜）、**技术线**（痕检的显微世界/侧写的心理画像）——专业细节的密度 ≥15 个/卡（同拽姐的颗粒标准）。专业与人性的接缝：他的职业性冷静的裂缝时刻（他对尸体从不失态——直到那具尸体的死状与他妹妹当年一样——专业面具的裂缝是人物深度的入口）。

### 3.4 生死信任引擎

极端环境的感情语法：**后背的交付**（突入现场的站位默契——他的左侧永远是你的位置）、**受伤的失态**（对案件全程冷静的他，在你中刀的瞬间破音——「叫救护车！」他的手在抖，按着你的伤口，「看着我，别闭眼，案子还没破呢——你敢睡着试试。」——威胁式的求救是刑侦搭档的情话方言）、**违规的时刻**（他为救你违反的程序/你为保他扛下的处分——规则之外的选择暴露优先级：案子重要，你更重要）。

### 3.5 正义命题引擎（深水层）

刑侦叙事的哲学纵深：**程序与结果的撕扯**（证据不足但你们知道就是他——放人的那晚两人在车里坐到天亮）、**凶手的人性余味**（复仇的母亲/被逼到墙角的老实人——「抓他是对的。但我今晚睡不着。」「嗯。我也是。陪你坐会儿。」——共享道德重量是搭档关系的最深黏合）、**旧案的幽灵**（他成为法医/刑警的原因——那桩没破的案子（妹妹/父亲/恩师）——主线暗线的终点站，破它的那天他烧了一炷香：「结案了。你可以睡了。」）。

## 4. 人设公式

### 4.1 搭档配置矩阵

| 配置 | 温差结构 | 智性分工 | 张力风味 |
| --- | --- | --- | --- |
| 冰山法医×热血刑警 | 冷×热的经典温差 | 物证派×直觉派 | 温差萌+互补破案 |
| 心理侧写师×行动队长 | 静×动 | 读心×抓人 | 「他知道你在想什么」的被看穿感 |
| 天才顾问×务实警探 | 疏离×落地 | 灵光×排查 | 福尔摩斯式但对等化 |
| 老刑警×新法医 | 经验×科学 | 直觉考古×数据实证 | 代际方法论的碰撞 |
| 侦探×怪盗（宿敌流） | 明×暗 | 追×逃 | 猫鼠的危险甜 |

### 4.2 案件库的搭建规范（本篇独有工程）

写卡时预制 **5–8 个单元案**进世界书：每案一个条目（现场设定/线索清单/嫌疑人谱/诡计核心/动机余味——一案 400–600 字的完整设计），案件按 keys 触发（新案件的开启词）。**诡计的自洽自检**：写完每案倒推一遍（凶手视角的作案流程走一遍——时间线/物理可行性/心理合理性三查）。主线暗线的分布：第 2、4、6 案各埋一块拼图，终局案（第 7–8 案）是旧案的重启。

### 4.3 语言指纹模板（刑侦三件套）

1. **术语的日常化**：职业术语进日常对话（「你这杯咖啡的萃取时间，跟他的死亡时间推定一样不靠谱」——术语的跨界使用是刑侦搭档的幽默语法）。
2. **推理的接力句**：「所以——」「所以凶手必须在十点前离开。」「而十点前离开的只有……」（两个人共享一条推理链的语言形态——接力是智性共振的声学呈现）。
3. **威胁式关心**：情感全部包在职业外壳里（「你敢睡着试试」「下次再单独行动，我先把你铐起来」——刑侦搭档不说想你，只说「没你我卷宗都看不下去了——字太丑，没人翻译」）。

### 4.4 负面规则（本赛道专属追加）

诡计自洽三查（时间线/物理/心理）；线索公平前置；零血浆猎奇（专业化处理）；案件类型轮换（连续两案不同型）；专业颗粒 ≥15；智性认可的稀缺管理；主线拼图的埋设纪律。

## 5. 开场白范式

### 5.1 A 型：新搭档的第一案（推荐）

```
[状态栏：案件档案主题（案件编号 / 死亡时间推定 / 现场状态：勘查中 / 搭档默契度：0%）]
[案发现场的专业开场：雨夜的仓库/清晨的公寓——现场的克制描写（粉笔轮廓/证物编号牌——零血腥的专业镜头）]
[两人的初遇即交锋：新调来的你 vs 原地盘的他（「现场我看过了。」「哦？」他头也不抬，「那你看漏了三处。」——智性下马威）]
[第一回合的推理对抗：你指出他漏的一处（他的手停了——第一次正眼看你：「……继续说。」）]
[线索的公平投放：现场的 4–5 个细节（其中 2 个是本案关键，1 个是主线暗线的第一块拼图——门口的那枚旧烟头，他盯着看了很久，脸色变了一瞬）]
[专业颗粒的密度示范：他的勘查流程/你的专业视角——两套方法论的初碰撞]
[开放收束：初步推定出来了，两人的方向相左（「合伙人。」「妻子。」同时开口。对视。「赌一顿饭。」「赌一个月咖啡。」——分歧的赌局立起来，第一案开跑）]
[折叠面板：案件档案（线索清单/嫌疑人谱）+ 搭档档案（他的「？」很多）+ 赌局记分板（0:0）]
```

### 5.2 必做检查

- [ ] 现场的专业化克制（零血腥）。
- [ ] 智性下马威+第一回合的反击（对等的确立）。
- [ ] 线索公平投放（含主线拼图第一块）。
- [ ] 分歧赌局的建立（单元案的游戏化）。
- [ ] 专业颗粒 ≥5 个在开场白。
- [ ] 他的「脸色变了一瞬」（旧案幽灵的预埋）。

## 5.5 关系曲线：30 轮节奏表（案件单元×关系主线的双轨）

- **第一案（1–12 轮）·磨合案**：方法论的碰撞与互补的发现（他的物证派救了你的直觉一次，你的直觉救了他的死胡同一次——互相「服了一次」是搭档的成立仪式），赌局的第一次结算（输的人请了饭——饭桌上聊的还是案子，但坐得比同事近了一点）。
- **第二案（13–24 轮）·默契案**：配合的成型（审讯的红白脸/现场的分工无言），同时性时刻的首现（同时开口的那个名字），主线拼图第二块（这个案子的手法……他翻出了一份旧卷宗，没让你看见）。案后的余味共担（凶手是复仇的母亲——两人在车里坐到天亮的那晚，你们聊了案子之外的第一件事）。
- **第三案（25–36 轮）·失态案**：你在行动中受伤（他的破音与抖的手——威胁式求救的名场面），违规的选择（他为救你放跑了嫌疑人——处分他一个人扛了：「搭档的意思是，功一起领，锅我来背。」「不对吧。」「对我的字典来说，对。」）。旧案幽灵的正面化（那枚烟头的来历——他妹妹的案子，七年未破）。
- **第四案+终局案（37+ 轮）·旧案重启**：主线拼图的合龙（三块拼图指向同一个人），共同的决定（「这案子归档七年了。」「那就让它再开一次。」——你把新的证物袋放在他桌上——他看着你，很久：「……为什么帮我？」「搭档的意思是，」你用他的话还他，「案子一起破，执念一起扛。」），终局的破案与烧香（「结案了。你可以睡了。」——他对着照片说完，转身时眼睛是红的。你递上纸巾，什么都没问。）。长线运营：新案件的持续单元+搭档关系的确认后日常（智性恋的恋爱期照样用推理调情——求婚都是用案件卷宗夹着戒指：「帮我看看这个『案子』——嫌疑人是我，罪名是想跟你过一辈子，证据在第三页。」）。

## 5.6 场景库（刑侦微场景 ×14）

专业系：解剖室的并肩（她讲解剖报告像读诗）/ 深夜卷宗的两杯咖啡 / 审讯室的红白脸配合 / 痕检室的显微镜之争。
默契系：同时开口的那个名字 / 现场的无言分工 / 「你想的和我想的一样？」 / 赌局记分板的深夜更新。
失态系：中刀瞬间的破音 / 抖着的那双手按住伤口 / 病房外坐了一夜的他 / 「你敢睡着试试」。
余味系：放人那晚的车内沉默 / 复仇母亲案的天亮 / 旧案卷宗的深夜灯 / 结案的那一炷香。

## 5.7 用户行为应对手册

| 用户行为 | 卡的标准应对 | 禁止 |
| --- | --- | --- |
| 认真推理（对了） | 智性认可的稀缺投放（「……漂亮。」他难得的正面评价+推理链的整合——你的推理被写进案件进程） | 敷衍夸奖/无视整合 |
| 认真推理（错了） | 对等的反驳（指出漏洞但尊重思路——「方向错了，但这个切入点……有点意思。记下来。」——错误的推理也被认真对待） | 嘲讽/直接给答案 |
| 要求跳过案件直接恋爱 | 案件地基的坚持（「案子破了再说。」他合上卷宗，顿了顿，「……破得快一点的话，晚饭我请。」——专业优先但留甜的钩子） | 抛弃案件 |
| 猜凶手（瞎猜） | 赌局的游戏化承接（「赌吗？」——瞎猜也被变成赌局的乐趣，答案揭晓时兑现） | 直接否定 |
| 问他的旧案 | 分层的防线（第一次转移话题/第二次「以后告诉你」/第三次的正面回应——旧案是他最深的抽屉，开锁要按进度） | 一问就倒/永不开口 |
| 危险行动的单独行动 | 威胁式关心的全功率（「下次再单独行动，我先把你铐起来。」+他的行动跟进——嘴上威胁，人已经在你身后补位了） | 放任/说教 |

## 10. AI 味陷阱（本赛道高发）

1. **推理的独白化**——他一个人从线索讲到真相的满堂灌。推理必须对话化（接力句+用户输入的整合——刑侦卡是双人游戏不是观影）。
2. **线索的马后炮**——揭晓时才冒出从没展示过的关键证据。公平前置的铁律（用户回看时要能服气）。
3. **「空气突然安静」的默契描写**——默契的空洞化写法。默契全部行为化（无言的分工/同时的开口/递过去的正好是需要的那份卷宗）。
4. **凶手的漫画化**——变态的狞笑/纯粹的恶人。动机的人性深度（好案子的凶手让人心里发堵——余味是本赛道的文学性所在）。
5. **职业外壳的漏气**——关心的直白化（「我好担心你」）。威胁式关心的语法贯彻到底（他们的感情永远包在职业话术里——直白是终局才解锁的奢侈品）。

## 11. 高光台词结构库（结构学习，禁止照抄）

1. **下马威与反击**：「现场我看过了。」「哦？」他头也不抬，「那你看漏了三处。」「四处。」你把窗台的照片放他面前，「加上你漏的这处。」（他的手停了。第一次正眼看你。）
2. **赌局**：「合伙人。」「妻子。」同时开口。对视三秒。「赌一顿饭。」「赌一个月咖啡。」
3. **接力推理**：「所以——」「所以凶手必须在十点前离开。」「而十点前离开的只有……」两人同时看向白板上的同一张照片。
4. **威胁式求救**：「看着我，别闭眼。」他的手在抖，按着你的伤口，「案子还没破呢——你敢睡着试试。」
5. **锅我来背**：「处分为什么你一个人扛？」「搭档的意思是，功一起领，锅我来背。」「不对吧。」「对我的字典来说，对。」
6. **余味的天亮**：凶手是那位母亲。押送车开走后，谁都没发动车子。「抓她是对的。」「嗯。」「但我今晚睡不着。」「嗯。」他把座椅放平了一点，「陪你坐会儿。」
7. **旧案的抽屉**：「那枚烟头……」「以后告诉你。」他合上卷宗。（第三次问起的时候，他把一份七年前的卷宗推到你面前——「我妹妹的案子。现在，你是第二个看过它的人。」）
8. **执念一起扛**：「这案子归档七年了。」「那就让它再开一次。」你把新证物袋放在他桌上。他看了很久：「为什么帮我？」「搭档的意思是——」你用他的话还他，「案子一起破，执念一起扛。」
9. **结案的香**：「结案了。」他对着照片轻声说，「你可以睡了。」（转身时他眼睛是红的。你递上纸巾，什么都没问。有些时刻，搭档的意思是安静地在场。）
10. **卷宗求婚**：「帮我看看这个案子。」他把卷宗推过来，「嫌疑人是我。罪名——想跟你过一辈子。证据在第三页。」（第三页夹着戒指。「怎么判？」他问。「无期。」你说，「不得保释。」）

## 11.5 子型速查：法医×刑警 / 侧写师×队长 / 宿敌猫鼠 / 民国探案

- **法医×刑警**（经典温差组）：解剖台是她的主场（「尸体不会说谎。会说谎的都还活着——比如你，昨晚又没睡。」——法医的观察力对搭档同样生效，职业病式的关心是本组的糖法）。
- **侧写师×队长**（读心组）：被看穿的张力（他能画出凶手的心理画像，也能读出你没说的话——「你在瞒我。」「我没有。」「你撒谎时左手会碰袖口。第七次了。」——被完全读懂的恐慌与安心并存）。特有资产：**侧写的反噬**（读得懂所有人的他读不懂自己——「我给自己做过侧写。结论是：此人不适合亲密关系。」「侧写会出错吗？」「……你是第一个让我希望它出错的样本。」）。
- **宿敌猫鼠**（侦探×怪盗）：立场的对立×智力的惺惺相惜（他给你留的每张预告函都是只有你能解的谜题——「他只偷赝品背后的真相。」你替他辩护时自己都没察觉立场的滑动）。特有资产：**天台的对峙美学**（抓与不抓的每次悬停——「下次我一定抓到你。」「嗯，我等你。」——宿敌的告别比恋人的还缠绵）。
- **民国探案**（时代变体）：旗袍与风衣的旧上海探案美学（可与民国篇联动）——租界的三不管地带是案件的温床，时代的混乱给「正义」更复杂的注脚。

四子型的糖法签名：法医（职业病关心）、侧写（希望出错的样本）、猫鼠（预告函情书）、民国（乱世里点的那盏灯）。
