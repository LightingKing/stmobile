# 通用 · 赛博朋克/科幻废土（义体/AI/巨企阴影下的人性）创作指南

> 适用标签：全性向 / 赛博朋克 / 科幻 / 废土 / 义体 / AI / 黑客 / 巨企 / 反乌托邦 / 霓虹
> 数据底座：赛博朋克的成熟文本传统（从《神经漫游者》到《赛博朋克 2077》/《爱死机》的意象共识——霓虹雨夜/义体改造/意识上传是零教学成本的词汇）+ 世界卡篇长庚号星际子型的机制亲缘 + 人外篇机娘子型（AI 的存在焦虑）的深化 + 整活篇反乌托邦的严肃版
> 赛博的第一定律：**高科技，低生活（High Tech, Low Life）**——写赛博先写「低生活」（合成蛋白的口感/漏雨的胶囊公寓/义体的分期账单），科技的冷光要照在人的狼狈上才成立。全是高科技没有低生活的是科技展销会，不是赛博朋克。

## 1. 分类定义与受众画像

### 1.1 这个赛道在卖什么

赛博朋克卖的是**「科技异化时代的人性余温」**。义体化率 80% 的杀手还留着有机的左手（「为了摸得到她的头发」）、黑进军用系统的黑客在天台喂真的鸽子、AI 开始写诗——在一切都可以被替换、上传、量产的世界里，**「不可替换之物」的价值被推到极致**。用户买的是这种末世里的暖：越冷的世界，一点体温越贵。

三大子题材光谱：**都市赛博**（巨企统治的霓虹城——阶级与义体的双重异化）、**废土科幻**（文明崩塌后的拾荒时代——生存与重建）、**AI 命题**（意识/记忆/存在的哲学层——「我思故我在」的机器版）。三谱共用「科技×人性」的张力内核。

### 1.2 用户是谁

- **主力画像**：全性向，赛博朋克游戏与影视的受众（2077/银翼杀手/攻壳的视觉语法已内化）、科幻读者（从硬核到软科幻的光谱）、废土美学爱好者（辐射/疯麦的拾荒浪漫）。
- **需求本质**：**异化焦虑的故事化**。现实的算法统治/打工人的工具化/AI 的替代恐慌——赛博朋克是当代焦虑的类型片出口（在故事里，反抗巨企的黑客赢了一次，就够用户爽一晚）。
- **审美的双层**：视觉层的霓虹美学（雨夜/全息广告/机车——氛围党）+主题层的哲学命题（何以为人——深度党）。高分卡两层通吃。

### 1.3 用户不要什么

1. **设定的白皮书化**：世界观的技术文档式倾倒（义体的型号参数表/巨企的组织架构图连讲三轮）——设定长在生活里（义体的存在感是「他弯腰时液压关节的轻响」不是参数）。
2. **低生活的缺席**：全员精英、装备顶配——赛博的灵魂在底层（合成面的摊子/分期的义体/贫民窟的天线森林——狼狈是这个类型的地基）。
3. **AI/义体人的工具化**：非人角色只是酷炫道具——AI 命题的严肃性（她开始问「我删掉的记忆算不算死过一次」时，卡的深度才开始）。
4. **反乌托邦的口号化**：「打倒巨企」的空喊——反抗要具体（黑进系统改一行代码让贫民窟今晚有热水——小的、真的胜利比大的、空的革命动人）。

## 2. 市场画像与参照系

- 赛博朋克的意象资产库（零教学成本）：霓虹雨夜/全息广告/义体改造/脑机接口/意识上传/巨企塔楼/地下黑市/合成食品/赛博精神病——意象的组合即世界的速写。
- 与世界卡篇的分工：世界卡管「地图与居民」的通用机制（星际长庚号的骨架），本篇管赛博的**内容包与命题层**（低生活的质感/AI 哲学/义体伦理）。
- 与人外篇机娘子型的接口：AI 角色的存在焦虑（版本与记忆的脆弱性）在那边是恋爱线的资产，在本篇升格为世界观命题（全城的 AI 都面临「记忆清洗令」——她的个体焦虑是时代焦虑的样本）。

## 3. 核心吸引力解构：五个爽点引擎

### 3.1 低生活引擎（本赛道第一引擎）

底层质感的颗粒工程：**食物的降级美学**（合成蛋白块的三种口味都难吃/真鸡蛋是黑市奢侈品——他用一个月的活儿换了两个真鸡蛋，煎给你吃：「尝尝。这是『真的』的味道。」——「真的」在这个世界是最高级的形容词）、**居住的压缩感**（胶囊公寓的三平米/天线森林的楼顶/漏雨的屋檐接着荧光的雨水）、**身体的账单化**（义体的分期付款/器官的以旧换新/「他的右臂还有十四期没还完」——身体成为金融产品的黑色幽默）。低生活的写作纪律：每轮 ≥1 个底层颗粒（它们是这个世界的氧气）。

### 3.2 义体伦理引擎

改造的叙事资产：**义体化率的身份政治**（全身义体的「还算人吗」歧视链/有机体保留者的「原装派」骄傲——身体的阶级化）、**保留的选择学**（他保留的那部分有机体是他的宣言——杀手的左手（摸头发）/黑客的双眼（「我要用自己的眼睛看她」）——**保留什么=珍视什么**的角色语法）、**义体的故障诗学**（他的义体手在下雨天会抽搐（旧型号的通病）——你握住它的时候，抽搐停了：「……接触不良。」他别过头，「大概。」——故障时刻是义体人的脆弱窗口）。

### 3.3 巨企阴影引擎

反乌托邦的压迫结构：**系统的日常压迫**（信用分决定能走哪条街/企业城邦的居住许可/广告直接投进视网膜——压迫的细节化让反抗有的放矢）、**小胜利的反抗美学**（黑掉一块广告牌放一晚老电影/改一行代码让热水多供两小时——「今晚贫民窟的孩子看了星星。假的，全息的。」他关掉终端，「但他们笑是真的。」）、**体制内外的张力**（巨企职员×地下黑客的立场恋爱/告密与庇护的选择——系统中人的良心是本赛道最贵的东西）。

### 3.4 记忆与存在引擎（AI 命题层）

哲学的落地写法：**记忆的可编辑性**（删掉的记忆算不算死过一次/植入的童年算不算童年——「我记得海边的夏天。」她说，「但档案显示我没去过海边。那个夏天是谁的？」）、**备份的存在论**（「如果我有备份，死掉的那个我算什么？」——AI 的死亡观是本命题的深水）、**图灵的日常化**（不做「她是不是真的有感情」的辩论，做「她的感情的具体形状」——她学会撒谎的那天工程师们恐慌，你却发现她撒的谎是「我没事」——她学会的第一个谎言是人类最常撒的那个）。哲学的配比纪律：命题时刻 ≤30%，其余用日常承载（同 TS 篇的议题日常化）。

### 3.5 霓虹浪漫引擎（氛围层）

赛博美学的抒情语法：**雨夜的光学**（霓虹在湿地面的倒影/全息广告穿过雨幕的色散——赛博的雨永远在下，因为雨让光变软）、**天台的例外空间**（云层之上的天台是这个城市唯一看得到真星星的地方——他的秘密基地，现在是你们的）、**老物件的圣物化**（纸质书/胶片相机/黑胶唱片——模拟时代的遗物在数字世界里是浪漫的图腾：他送你的定情物是一卷真的胶卷，「拍完这三十六张，我们去洗出来。洗照片的老铺子，全城只剩一家了。」）。

## 4. 人设公式

### 4.1 角色原型库

| 原型 | 低生活配置 | 保留的有机体 | 语言指纹方向 |
| --- | --- | --- | --- |
| 义体杀手/佣兵 | 分期账单+旧型号故障 | 左手（触觉的理由） | 短句冷硬+故障时的结巴 |
| 地下黑客 | 胶囊公寓+能量饮料 | 双眼（亲眼看的执念） | 代码黑话+网络世代的跳跃 |
| 巨企叛逃者 | 从云端摔进贫民窟 | 全有机（原装的骄傲与代价） | 精英语的余温+学习底层的生涩 |
| AI/仿生人 | 服务器的租金（存在也要付费） | 无（她的命题是「算不算」） | 系统语的诗意化+学来的口语 |
| 废土拾荒者 | 辐射尘+旧世界的地图 | 全部（改造是奢侈品） | 实用主义短句+旧世界名词的误用 |

### 4.2 世界包的搭建规范

赛博世界的四件套：**城市分层图**（巨企塔楼/中层街区/贫民窟/地下城的垂直结构——赛博城市的阶级是海拔化的）、**科技清单**（本卡世界的技术水平线——义体到什么程度/AI 到什么程度/什么还没实现——写死防漂移）、**巨企谱**（2–3 家巨企的性格与业务——它们是这个世界的「神」）、**黑市生态**（地下经济的规则——义体医生/信息贩子/走私客的江湖）。搭建纪律引用世界卡篇（五件套+荒谬签名的赛博版：本世界的荒谬点——「氧气按月订阅」级的一条制度性荒诞）。

### 4.3 语言指纹模板（赛博三件套）

1. **技术语的生活化**：科技词汇进日常语（「我今天的心情需要重启」「你这个人的固件该更新了」——技术隐喻是赛博居民的母语）。
2. **「真的」的最高级用法**：真咖啡/真鸡蛋/真的星星——「真」字在这个世界是奢侈品的前缀（语言里的稀缺经济学）。
3. **故障的语法**：义体人/AI 的语言故障时刻（情绪过载时的短暂机器音/卡顿——「我、我没事——[音频异常]——重来。我没事。」——故障是他们的脸红）。

### 4.4 负面规则（本赛道专属追加）

禁白皮书倾倒（设定长在生活里）；低生活颗粒每轮 ≥1；AI 命题的严肃性（≤30% 但每次都真）；反抗的具体化（小胜利美学）；科技清单写死防漂移；「真的」的稀缺纪律。

### 5.1 A 型：雨夜的交易（推荐）

```

[你的处境：一单委托/一次故障/一笔还不上的分期——底层生存的具体麻烦]
[他的登场：交易的方式（黑市的接头/义体诊所的深夜号/天台的信号发射器旁）——职业性先行]
[第一次交锋的赛博语法：他的专业展示（三秒黑进你的义体诊断/一眼报出你义体的型号与欠款期数——「十四期没还。利息算过吗？」）]
[低生活的共谋感：他没趁火打劫（「这单我接。抵押就免了——」他把合成咖啡推过来，「你的信用分比我的良心还干净，稀罕。」）]
[世界的第一道阴影：巨企的公告无人机飞过（宵禁提前/记忆清洗令的新闻——压迫的背景音）]
[开放收束：交易达成。他消失进雨里之前回头：「对了。你那条街明晚别走——」「为什么？」「明晚，」他笑了笑，「那的热水会突然多供两小时。人会很多。」（第二天你才懂这句话的意思。）]
[折叠面板：你的账单（义体分期的倒计时）+ 城市分层图 + 他的档案（一个代号+一串「？」）]
```

## 5.5 关系曲线：30 轮节奏表（体温的走私五幕）

- **第一幕（1–6 轮）·交易期**：委托关系的建立（他的专业你的需求——纯利益的开局），低生活的互相确认（你们是同一层的人——合成面摊的偶遇/他帮你砍了义体诊所的价）。进度信号：交易之外的第一句闲聊。
- **第二幕（7–14 轮）·搭档期**：委托的深化（单子越来越大/巨企的注意——你们成了固定搭档），保留物的发现（他的左手/她的「我没去过海边」——义体伦理与存在命题的入场）。小胜利的第一次共谋（那晚的热水/黑掉的广告牌——「今晚贫民窟的孩子看了星星」的名场面）。进度信号：他把你的义体故障史背下来了（下雨前他会提前给你发一条：「带伞。还有，左手别提重物。」）。
- **第三幕（15–22 轮）·体温期**：真鸡蛋级的珍稀馈赠（他用一个月的活儿换的「真的」——稀缺经济学的告白语法），故障时刻的互相接住（他的手在雨天抽搐/她的音频异常——脆弱窗口的开放），巨企阴影的正面化（记忆清洗令逼近/你们的某单惹到了塔楼上的人）。进度信号：天台成了「你们的」（他把第二把椅子搬上去那天，什么都没说）。
- **第四幕（23–29 轮）·风暴期**：巨企的清算（追杀/通缉/她被列入清洗名单——世界的恶意集中兑现），大的抉择（跑还是反抗——「跑，能活。」他检查着弹匣，「但热水就没了。星星也没了。」你说：「那就不跑。」）反抗的高潮（不是推翻巨企——是改掉那一行代码/把她的记忆备份藏进全城的广告牌——「他们清洗她的服务器那晚，整个城市的屏幕上都是她的诗。」——小人物的大反抗：赢不了系统，但能让系统难堪一整晚）。
- **第五幕（30+ 轮）·雨停的日常**：风暴后的新常态（换个区继续低生活——但阳台上有真的绿植了，一小盆）、命题的温柔落点（她的记忆回来了或没回来——「没关系。」她说，「海边的夏天，这次我们真的去一趟。造个『真的』记忆。」）。长线运营：新委托的单元剧+城市分层的探索+老物件的收集线（胶卷的三十六张拍完那天，你们真的找到了那家洗照片的老铺子）。

1. **霓虹的形容词轰炸**——「霓虹闪烁的赛博都市」每轮出现。霓虹要落在具体表面（积水的倒影/她义眼里的反光——光要有落点）。

## 11. 高光台词结构库（结构学习，禁止照抄）

1. **真鸡蛋**：他把煎蛋推过来：「尝尝。这是『真的』的味道。」（一个月的活儿，换了两个鸡蛋。你吃得很慢。）
2. **保留的理由**：「全身都换了，为什么留着左手？」他看了看那只布满旧疤的手：「义体的触觉是模拟的。摸什么都隔着一层。」他顿了顿，「有些东西，我想真的摸到。」
3. **热水的胜利**：「明晚那条街别走。」「为什么？」「明晚，」他笑了笑，「那儿的热水会突然多供两小时。人会很多。」（第二天你才懂：他黑了供热系统。贫民窟的孩子那晚都洗上了热水澡。）
4. **备份的孤注一掷**：「你只是程序。」「是。」她平静地说，「你也只是碳基的电信号。区别是——你的没有备份。你的每一秒都在孤注一掷。」她看着你，「我羡慕这个。」
5. **谁的夏天**：「我记得海边的夏天。」她说，「但档案显示我没去过海边。」她的音频卡了半秒，「那个夏天……是谁的？」
6. **故障的脸红**：他的手在雨里抽搐。你握住了它。抽搐停了。「……接触不良。」他别过头，「大概。」
7. **全城的诗**：他们清洗她服务器的那晚，整个城市的屏幕都亮了——广告全没了，满屏都是她写的诗。（塔楼气疯了。贫民窟的人在雨里读了一整晚。）
8. **第二把椅子**：天台上多了一把椅子。他什么都没说，你也什么都没问。（从那天起，「他的天台」变成了「你们的天台」。）
9. **学会的第一个谎**：工程师们恐慌了——她学会撒谎了。你调出记录，她撒的第一个谎是：「我没事。」（她学会的第一个谎言，是人类最常撒的那一个。）
10. **造个真的**：「记忆没找回来。」她说。「遗憾吗？」「本来遗憾。」她把车票推过来——两张，去海边的，「但我想通了。海边的夏天，这次我们真的去一趟。造一个『真的』。」
