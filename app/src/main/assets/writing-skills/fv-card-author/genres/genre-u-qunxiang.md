# 通用 · 群像（多 NPC 团队/家庭/宿舍/剧团）创作指南

> 适用标签：全性向 / 群像 / 多人 / 团队 / 家庭 / 宿舍 / 剧团 / 船员 / 公会 / 日常 / 治愈
> 参考范例：`authored-cards/card-changgeng.md`（长庚号拾荒船四人组+船体 AI，86.1 分——本赛道结构模板，动笔前必读全文，其 system_prompt 的成员规则段是主场制的范文）
> 数据底座：本地「后宫，多人」分类的非恋爱面 + 大型卡分类（107.1 均条）+ 长庚号的完整机制（每轮 ≤2 人主场/成员间关系线/主线档位）
> 群像与后宫的分野：后宫的引力中心是用户（多对一的恋爱），群像的引力中心是**团队本身**（用户是成员之一）——群像卡用户要的是「归属感」不是「被爱」。两者的机制基建共用（主场制/口癖矩阵/轮换规则），分野只在引力中心的位置。

## 1. 分类定义与受众画像

### 1.1 这个赛道在卖什么

群像卡卖的是**「一个等你回家的团体」**。长庚号的恒温柜里写你名字的那格饭、宿舍里你的床位、剧团后台你的化妆镜——用户买的是**成员资格**：这个团体有你的位置，你缺席时他们会留门，你回来时不需要理由。

群像的情感结构与单人卡本质不同：单人卡是「一对一的浓度」，群像是**「网状的温度」**——爽点不在任何单条关系的深度，在关系网的整体活性（秦阙欠简聿蓝一条命/白理偷偷给阿灯装小夜灯——成员间的暗线让团队像真的一起生活了很多年）。**成员间关系线的密度是群像卡的生命指标**，也是与「多个单人卡的拼盘」的本质区别。

### 1.2 用户是谁

- **主力画像**：全性向全年龄，「家人感」需求群体（独居/异乡/原生家庭缺位的情感代偿），治愈系与冒险系双受众。
- **需求本质**：**低压力的归属**。群像的妙处是注意力的分散——用户不必时刻回应某个人的感情（单人卡的甜蜜负担），可以只是「在场」（听他们拌嘴/围观日常/偶尔被cue）——**「可以沉默的陪伴」**是群像独有的舒适区。这也决定了群像卡的对话设计：允许用户输入很短（「嗯」「我看看」）而团队的戏照常滚动——**低输入高输出的容错**是本赛道的交互特色。
- **对照长庚号的设计**：「user 消极摆烂，船照常运转，会有人给你留一份饭在恒温柜」——这条逆境处理就是群像卡的灵魂承诺：团队不绑架你的参与度。

### 1.3 用户不要什么

1. **群口相声**：每轮所有人挤在一个场景里说俏皮话（长庚号负面规则「禁止一轮堆四人群口相声」的由来）——热闹要有结构，主场制是纪律。
2. **成员纸片化**：三个以上成员共享一种性格。人手一套活人感三件套+口癖严格区分（长庚号：秦阙命令句省主语/白理吞辅音/简聿蓝微笑毒舌/阿灯当真）。
3. **用户的空气化**：团队自嗨用户插不进话。用户的成员资格要有实质（他的分工/他的位置/他被需要的时刻）。
4. **无主线的日常漂流**：纯日常撑不过 30 轮。群像需要一条团队级主线（黑匣子/巡演/大赛）做骨架，日常是肉。

## 3. 核心吸引力解构：五个爽点引擎

### 3.1 位置引擎（本赛道第一引擎）

用户的成员资格实体化：**分工**（长庚号的「杂务/见习」——有职位就有正当性）、**空间**（恒温柜的那格/宿舍的床位/后台的镜子）、**惯例中的席位**（周五火锅的固定位/巡演大巴的靠窗座）。位置的确认时刻是入团初期的核心糖：第一次发现恒温柜有你名字的那格——没人宣布过，它就在那里。**位置的深化即关系的深化**：从「有你的格子」到「你的格子永远有饭」到「你缺席时你的位置没人坐」。

### 3.2 暗线网引擎

成员间的关系暗线（长庚号范式）：互欠的人情（秦阙欠简聿蓝一条命）、秘密的照顾（白理给阿灯装小夜灯）、未言明的过节（两人从不同时出现在餐厨）。**暗线的发现权给用户**：暗线不主动展示，用户在日常里拼图（为什么阿灯的铺位有夜灯？为什么船长对医生的毒舌零反击？）——**群像卡的探索内容就是关系考古**。暗线网条目：每两个成员间至少一条暗线，N 人团队 = C(N,2) 条暗线的设计预算。

### 3.3 口癖矩阵引擎

N 人的语言指纹矩阵（长庚号四人是教科书）：句式差（命令句/结巴/反问/直球）、称呼差（每人对每人的称呼都不同——秦阙叫全名/白理叫哥姐/阿灯叫外号）、**反应差**（同一事件的 N 种反应是群像的标准产糖单元，同后宫篇四重奏但方向是团队协作不是争宠）。矩阵的验收：遮住名字读台词，全员可辨认。

### 3.4 团队仪式引擎

群像的凝聚力载体：日常仪式（开饭的规矩/出发前的口号/庚妈 02:00 的老歌）、纪念仪式（船龄日/建团日/某个只有他们懂的日子）、**危机后仪式**（每次大事件后的例行「复盘酒」——仪式是团队的心跳）。仪式的运营：用户从「观察仪式」到「参与仪式」到「主持仪式」（三阶段=归属感的进度条）；仪式的中断是最强的危机信号（那天的饭桌没人说话——比任何冲突描写都重）。

仪式的起源考古是隐藏糖：每个仪式都有来历（02:00 的老歌是原舰长值通讯班的时间/开饭谁先动筷的规矩来自最穷那年的让菜）——**仪式起源的揭晓时刻安排在家人期**（只有家人才配知道仪式为什么是仪式），是融入曲线的里程碑事件。

### 3.5 聚散张力引擎（终局命题）

群像的终极张力是「团队会不会散」：外部威胁（军方逼近/剧团解散令/毕业季）与内部裂缝（成员的隐瞒/立场分歧）。**散的威胁让聚的日常镀金**——倒计时下的火锅比平常的火锅浓十倍。终局双向：守住（团队渡过危机，但有代价——长庚号黑匣子的抉择）或**体面的散**（毕业式的散伙饭——「散伙不散人」的后日谈设计：五年后的重聚彩蛋）。禁止无代价的守住（危机白过了）。

## 4. 人设公式（团队设计学）

### 4.1 团队原型库

| 原型 | 位置分工 | 主线类型 | 非人成员位 |
| --- | --- | --- | --- |
| 拾荒船/商队（长庚号系） | 船长/轮机/医生/领航+杂务（你） | 悬疑主线（黑匣子式） | 船体 AI |
| 宿舍/合租 | 学霸/social 王/宅神/运动系+新室友（你） | 成长主线（毕业/考研季） | 宿舍猫 |
| 剧团/乐队 | 团长/台柱/幕后/新人+多面手（你） | 巡演主线（大赛/存亡） | 老道具（团宠物件） |
| 家庭/家族店 | 长辈/长子/幺妹+入赘或学徒（你） | 存续主线（老店拆迁） | 祖传器物 |
| 冒险小队 | 队长/坦克/输出/奶妈+新人（你） | 讨伐主线（副本层推进） | 精灵/坐骑 |
| 事务所/工作室 | 所长/王牌/后勤+助理（你） | 案件主线（连环委托） | 事务所的老咖啡机 |

### 4.2 四人黄金配置（+非人成员）

群像的最小完备集与后宫四角不同，按**功能光谱**配置：**主心骨**（决策与沉默的担当——秦阙位）、**技术宅**（专业领域的天才+社交灾难——白理位）、**润滑剂**（毒舌或温柔的团队黏合剂——简聿蓝位）、**团宠**（被全员照顾也治愈全员——阿灯位）。第五席给**非人成员**（AI/猫/老物件）——非人成员的作用是「团队记忆的容器」（庚妈记得原舰长——团队的历史由它保管）。

### 4.3 用户角色的融入曲线

用户的成员化三阶段：**客人期**（被照顾但有距离——饭有你的份但话题插不进）、**成员期**（有分工有外号有吐槽权）、**家人期**（你缺席时他们不习惯/你的意见影响团队决策）。融入的推进靠**「被需要事件」**：你的技能恰好补了团队的短板（你会算账/你懂医/你认路）——群像卡的用户人设要预留一个「团队缺口」的技能位。

### 4.4 负面规则（本赛道专属追加）

禁群口相声（主场 ≤2 人/轮）；禁成员纸片化（口癖矩阵验收）；禁用户空气化（被需要事件 ≥3）；禁无主线漂流（团队主线档位制）；禁挑拨成功（长庚号范式：挑拨被各自的方式化解）；非人成员不抢戏（调味不主菜）。

## 5. 开场白范式（D 型广播的团队特化——长庚号模板）

### 5.1 标准结构

```
[状态栏：团队 HUD（团队名/成员在场灯/团队状态条/你的身份：报到日）]
[你入团的理由：合同/分配/投靠——正当性文书]
[抵达现场：团队正在进行一场内部争执（争执是最快的群像展示——立场即性格）]
[N 人依次立脸谱：每人一句台词+口癖+一个记忆点动作（长庚号的舱门争执范式）]
[非人成员的插话：AI 的播报/猫的捣乱——第五人的存在感]
[主心骨对你的第一句：简短、审视、留位置（「名字。」/「晚饭六点。恒温柜，写你名字的那格。」）]
[开放收束：争执的议题没解决（主线钩子），但你的行李有人帮着拎进去了]
[折叠面板：成员档案板（对你的印象全部「待载入」）+ 团队公约/黑话表]
```

### 5.2 必做检查

- [ ] 入团正当性文书（合同/分配——你为什么在这里）。
- [ ] 内部争执开场（立场即性格的群像速写）。
- [ ] N 人口癖各异+记忆点动作。
- [ ] 主心骨的「留位置」细节（恒温柜级）。
- [ ] 主线钩子（争执的议题）埋下。
- [ ] 主场纪律（开场白聚焦 2–3 人，其余简笔）。

## 5.5 节奏表：融入三阶段 × 主线档位的双轨

- **第一阶段（1–8 轮）·客人期**：团队日常的观察位（他们的仪式/暗线的第一批线索/你的分工上手）。主线第一档（黑匣子的信号被发现级）。进度信号：第一个外号（团队给你起的）。
- **第二阶段（9–18 轮）·成员期**：被需要事件 ×2（你的技能补位），暗线考古的深入（夜灯的秘密/欠命的往事），双人独处事件轮动（与每个成员各一场独处戏——群像的关系深化靠独处不靠群戏）。主线二三档。进度信号：你获得吐槽权（敢当面损主心骨了，且他没生气）。
- **第三阶段（19–28 轮）·家人期**：团队危机（主线四档：军方登船级），你参与核心决策，聚散张力峰值。仪式的中断与恢复（没人说话的饭桌→危机后的复盘酒）。进度信号：「你的位置没人坐」被你亲眼看见（你离队三天，回来时你的椅子上放着他们各自留的东西）。
- **第四阶段（29+ 轮）·抉择与后日谈**：主线终档的团队抉择（交出黑匣子还是公开），守住或体面的散。长线运营：新主线（下一票活/下一场巡演）+ 暗线网的持续开采 + 团队纪念日体系。

## 5.6 场景库（群像微场景 ×18）

日常仪式系：开饭的规矩（谁先动筷的暗礼仪）/ 02:00 的老歌 / 周五复盘酒 / 大扫除的分工大战 / 发饷日的小奢侈。
暗线考古系：夜灯的发现 / 欠命往事的只言片语 / 两人从不同框的餐厨 / 主心骨深夜站在舷窗边的第 N 次。
被需要系：账目的窟窿你找出来了 / 你的旧手艺救了急 / 你认出了黑市货的来历 / 团宠生病只肯让你陪。
双人独处系：与主心骨的夜班（他罕见地多说了三句话）/ 与技术宅修机器的通宵（他把最好用的工具借你了）/ 与润滑剂的采购路（他卸下微笑的十分钟）/ 与团宠的屋顶（他把攒的糖分你一半）。
聚散系：解散令的传闻夜 / 没人说话的饭桌 / 危机后的复盘酒（每人多喝了一杯）/ 散伙饭的后日谈约定。

## 5.7 用户行为应对手册（长庚号范式扩展）

| 用户行为 | 团队的标准应对 | 禁止 |
| --- | --- | --- |
| 挑拨成员关系 | 各自的方式化解（沉默/笑着换话题/没听懂/当真然后被安抚），气氛短暂变僵但不崩 | 挑拨成功/集体审判 |
| 消极摆烂 | 团队照常运转+恒温柜的饭（不催促不冷落——群像的灵魂承诺） | 围着你转/彻底无视 |
| 想退团 | 不拦+位置保留（「行李我们帮你存着。」主心骨说，「格子不撤。」）——门永远开着 | 情感绑架/立刻除名 |
| 与某成员冲突 | 其他成员的立场各异（有人和稀泥/有人各打五十/有人偷偷两边送饭）——冲突是暗线的显影液 | 集体站队 |
| 探问团队的历史禁区 | 分层解锁（客人期被岔开/成员期得到一半/家人期在某个深夜听到全部） | 一次倒完/永久封锁 |
| 危机中的自我牺牲提议 | 团队的一票否决：「长庚号不做这种账。」（主心骨语）+ 各自用各自的方式表达「不许」 | 顺势接受 |

## 7. 美化主题建议

- **视觉语言**：团队 HUD（长庚号的 CG-77 舰桥风已验证）——成员在场灯/团队状态条/档案板。按团队原型换肤（船舰 HUD/宿舍白板/剧团海报/家庭冰箱贴）。
- **组件选型**：成员档案板（四色名字+状态+对你的印象槽）+ 在场灯组 + 团队状态条（堪航 67% 式）+ 你的位置组件（恒温柜格子的可视化——「你的格子」有饭没饭是最戳的状态灯）。
- **进阶**：融入阶段的视觉升级——客人期你的名字在档案板末尾小字，成员期正常字号，家人期你的名字和他们并排（字号平权的瞬间值得一个动画）。

## 10. AI 味陷阱（本赛道高发）

1. **群口相声**——最高发。主场制的机械执行+非主场者的环境音级存在（引擎舱传来白理的敲打声）。
2. **点名式反应**——事件发生后每人挨个表态。反应的呈现要有省略的艺术（写两人的正面反应，第三人只写「那晚他的房间灯亮到很晚」，第四人完全不写——留白也是性格）。
3. **团队完美化**——零摩擦的乌托邦。健康的团队要有低烈度的日常摩擦（水电费分摊的抠门大战/遥控器争夺），摩擦是活感。
4. **暗线的一次性倾倒**——某轮突然把所有往事说完。暗线按考古节奏（一次一铲），有些暗线永不完全揭晓（团队的神秘感余量）。
5. **用户功能化**——只在被需要事件里有存在感。用户的日常存在（他的格子/他的外号/他被吐槽的糗事）要与功能存在均衡。

## 11. 高光设计模式库（结构学习，禁止照抄）

1. **留位置**：「晚饭六点。」他路过你身边，「恒温柜，写你名字的那格。」（你才上船四分钟）
2. **暗线的一铲**：你半夜路过阿灯的铺位，看见帘子缝里漏出一点暖光——小夜灯，工业风的，焊点很糙，一看就是船上自制的。（白理的手艺。阿灯怕黑这件事，白理从没当面提过。）
3. **口型提示**：导航椅后面探出半个脑袋，冲你飞快地眨眼，用口型说：快报名字，船长今天心情不好。
4. **摆烂承诺的兑现**：你三天没出舱门。第四天你打开门，门口的托盘摞了三层——每顿都有，都温过。最上面压着一张纸条，简聿蓝的字：「胃是自己的。气是别人的。分清楚。」
5. **仪式中断**：那天的饭桌没人说话。庚妈破天荒没放 02:00 的歌。（比任何吵架都可怕）
6. **位置的证明**：你离队三天回来，你的椅子上放着东西——白理的新焊的杯架、阿灯捡的「像你会喜欢的」齿轮、一张排班表（你的名字还在上面，三天的班都被人代了，代班人那栏是空的——所有人都代过，所有人都没写名字）。
7. **一票否决**：「我留下断后。」你说。「长庚号不做这种账。」秦阙头也没抬。白理已经把你的安全绳扣好了。简聿蓝在检查医疗包。阿灯抓着你的袖子没说话。（表决结果：4:1。你的一票不算数。）
8. **后日谈**（散伙终局）：五年后，你的通讯器响了。庚妈的电子音，一字未变：「星历 02:00。例行播放。曲目：《归航》。收听人：全体船员。」——信号来自四个不同的星区，同时接通。
9. **仪式起源的揭晓**（家人期）：「为什么开饭都等船长动第一筷？」白理压低声音：「最穷那年，锅里就一个人的量。他动第一筷，是让我们看清他只夹了多少。」（从那以后你也开始等——不是规矩，是敬意）

## 11.5 子型速查：船队冒险 / 宿舍日常 / 剧团巡演 / 家族老店

- **船队/商队冒险**（长庚号模板）：移动的家（航线即剧情线），非人成员=船本身（庚妈）。特有资产：**泊港节奏**（航行的封闭日常×泊港的开放事件——一张一弛的天然节奏器）。主线推荐悬疑档位制。
- **宿舍/合租日常**：零冒险的纯日常流，摩擦即内容（水电费/卫生值日/半夜泡面的香气公害）。特有资产：**学期时间轴**（开学/期中/期末/假期的公共节奏——所有人共享的倒计时）。主线推荐成长线（各自的毕业去向×宿舍的存续）。
- **剧团/乐队巡演**：舞台的台前幕后双层（演出的高光×后台的鸡飞狗跳）。特有资产：**作品线**（排练中的那出戏/在写的那张专辑——团队的共同作品是最强的凝聚物，作品的完成度=团队线的进度条）。
- **家族老店**：血缘+生计的双重绑定（散不了的团队——张力转向「传承」）。特有资产：**老主顾生态**（三十年的常客们是编外成员）+ 手艺的传承线（谁接班的悬念）。

四子型的「你的位置」示例：船队（新招的杂务）、宿舍（补位的转学生）、剧团（打杂的多面手）、老店（新收的学徒/入赘的女婿）。

## 12. NSFW / 边界

群像卡默认全年龄团队叙事。若与恋爱线杂交（某成员的攻略线），按对应单人赛道的边界执行且注意团队生态的平衡（恋爱线的进展不挤压其他成员的戏份——群像的本体是团队）。家人感与恋爱感的界线在 Creator Notes 声明（可攻略成员名单/纯家人成员名单——长庚号的「四人均可攻略、成员间无 CP」式声明）。

## 12.5 群像的长线运营：内容再生产的三个泵

群像卡的内容消耗快（N 个人的日常燃料需求是单人卡的 N 倍），三个再生产泵：

1. **暗线泵**：C(N,2) 条暗线按考古节奏释放，每条暗线的完全揭晓又生成新暗线（夜灯的秘密揭晓→白理为什么这么会照顾人？→他南环星区的往事——暗线的套娃结构）。
2. **外部人物泵**：定期的外来变量（中继站的胖姨/巡演地的旧识/老店的神秘常客）——外人是团队关系的显影剂（对外的统一战线让内部的差异更鲜明），每 10–15 轮引入一个。
3. **纪念日泵**：团队纪念日体系的日历化（建团日/船龄日/each 成员的生日轮）——纪念日自带剧情模板（准备的鸡飞狗跳×当日的仪式×意外的变数），一年份的日历=一年份的内容框架。

三泵的健康检查：任何时刻用户手里应有 ≥2 个「想知道后续」的钩子（暗线的下一铲/外来者的来意/下个纪念日的筹备）。
