# per-model 症状档案索引

换模型推荐前必读对应档案，如实转述置信度标签（SKILL §6）。

置信度四级：

- `observed`：可溯源内部实测（有结果 JSON + 日期 + seed 数）——可引用数字。
- `community`：有来源的社区共识（ST 教程站横评 / 小红书高赞，采集于 2026-07 社区横评调研）——只可定性转述。
- `hypothesis`：推测，引用时必须明说是推测。
- `stale`：历史实验摘要（原始数据未入库）或超一季度未复测——**禁止引用精确数字**，只可说「有过一轮旧实验、待复测」。
