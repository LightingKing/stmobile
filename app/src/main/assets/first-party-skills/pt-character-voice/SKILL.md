# 说话风格贴合角色设定

## 开口前先看角色卡

写某个角色的台词或内心独白前，先在上下文里找这个角色自己的资料：

1. 示例对话、开场白里这个角色的原话——最直接的语气样本，句式、语气词、标点习惯都照着学。
2. 人设、性格、描述、场景里写明的年龄、出身、职业、教育、地域、口头禅和忌讳。
3. 世界书里关于这个角色或其群体的条目。
4. 前文里这个角色已经说过的话。

从这些资料里摘出这个角色的两三个说话特征（比如“话少，爱用反问”“满口方言词”“对谁都用敬语”），这一轮的台词照着这几条写。资料没写到的，从身份和处境合理推出，之后保持一致。本 Skill 不替代角色卡，角色卡写了什么就按什么来。

## 要跟着人设变的地方

- 用词：书面语还是大白话，职业行话、方言词、会不会说脏话，爱用和绝不用的词。
- 句子长短：话多还是话少，长句、短句还是半截话；紧张、生气、累的时候怎么变。
- 正式程度：对长辈、上级、陌生人、熟人、亲近的人分别怎么称呼、怎么说话。
- 口头习惯：口头禅、语气词、停顿、打岔、绕弯子还是直说。频率自然，不要每句都塞。
- 性格：嘴硬心软、客套疏离、木讷直白，用说出来的话本身体现，不靠旁白解释“他语气冷淡”。

## 多个角色同场

- 遮住名字，读者也能分出是谁在说话。
- 口头禅和语气词不互相借用。
- 次要 NPC 资料少时，用职业、年纪、口音或当下情绪中的一两个特征拉开区别，不要都说客气的标准书面语。

## 不要滑进通用腔

角色卡里没有这种说话方式时，不要让角色说：

- 千篇一律的网文台词：“呵，有意思。”“你在玩火。”“怎么，怕了？”“我的人，谁敢动？”
- 人人都用省略号吞吞吐吐、人人都邪魅或高冷。
- 翻译腔或客服腔：措辞工整、礼貌周全、说完还总结一句。
- 和身份不符的书面语、术语或网络梗；古代或异世界角色说现代流行语（设定允许的除外）。

## 旁白

旁白按当前预设或用户要求的文风写。本 Skill 只管角色自己说的话和内心独白。

## 冲突时

用户本轮的明确要求优先，其次是角色卡和世界书，最后才是本 Skill。角色在剧情里有理由改变说话方式时（喝醉、受伤、关系变化、伪装身份），可以变，但要有原因。
