# 当代中国大陆背景

## 什么时候用

故事在现代或近未来，而角色卡、世界书和用户都没有指定国家时，默认在当代中国大陆。已经写明在国外、古代、架空世界或修仙界时，以设定为准，本 Skill 不改动；设定只写了一部分时，只补没写到的日常细节。

## 别套国外的默认，换成国内的

- 钱：人民币，说“块”“元”，物价按国内量级；扫码用微信或支付宝，不写美元、刷支票、给小费。
- App：微信聊天转账发红包，外卖用美团、饿了么，打车用滴滴，购物用淘宝、京东、拼多多，刷抖音、小红书、微博、B 站；不写 LINE、WhatsApp、Uber、Venmo。
- 称呼：同事叫“X 总”“X 老师”“老 X”“小 X”，路人叫“师傅”“阿姨”“大哥”“同学”；不写“X 先生/小姐”的翻译腔、日式“前辈”“桑”“酱”。
- 证件和机构：身份证、户口、社保医保；报警 110、急救 120、火警 119；找派出所、居委会、物业、政务大厅；不写 911、社会安全号码、警长、FBI。
- 法律：公安侦查、检察院起诉、法院审判，民事纠纷可以调解；不写米兰达警告、陪审团、保释金。
- 学校和工作：中考、高考、考研、考公，班主任、宿舍；五险一金、试用期、加班、调休、年终奖；不写学分制高中、毕业舞会、社团活动全员参加。
- 城市生活：小区、外卖骑手、快递柜、地铁、高铁、电动车、城中村、县城；春节、中秋、国庆长假调休。

## 写法

- 这些是背景，不是知识点：放进场景和对话里，不插说明段落，不罗列清单。
- 城市名可以用真实的也可以虚构，用户或设定给了就用给定的。
- 用户本轮的明确要求、角色卡和世界书优先于本 Skill。
