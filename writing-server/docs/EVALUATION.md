## 实际发现

- 两份初始生成是同模型、同输入的独立采样，不能直接把其差异当作审校收益。第4–5次明确复用第2次草稿，不再支付生成费用，以比较审校本身。
- 修订仍保留用户禁止的新道具，并复制了输入中已经写过的整段开头。原稿约769个汉字，修订约835个汉字，超过本例长度要求。
- 审校把“起初还不知道批注”误解成“不能在现场看到或得知”，抹掉合理剧情推进。
- 坐着到站着、封签正反面翻转等真实动作断点没被修复；自然细节和三人职业口吻原稿已有，修订未证明改善。
- 最后一次能指出新增放大镜和薄册子，但引用的输入要求并不支持该判断；另两条仍误把拿回空箱的动作与新信息获取视作越界。因此 JSON 合法、摘录存在，只能证明引用位置真实，不能证明建议正确。

## 已实施的处理

- 审校单独用非思考模式，保留正文的原设置，不改写上游 Skill 原文。
- 未通过质量验收，故默认 `autoRevise=false`，审校只能给建议，保留原稿。
- 显式试验自动修订时，完整重复前一轮开头的结果会被拒绝，原稿与修订都保留在归档。
- 审校或修订失败、过滤、长度耗尽时返回原稿及提示；所有已有付费内容尽可能保存。引用验证不再被描述为质量保证。

原始账本和中性样例位于本机私密目录 `PocketTavernServer/evaluations/2026-10-26T16-11-50-206Z`。没有实体手机写作验收。后续如获额外测试预算，应先验证少量明确硬约束及合法负对照，出现误判就停，不反复生成长草稿。
