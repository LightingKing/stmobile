# 豆包联网研究人物与设定

0.1.32 的聊天菜单提供“联网研究人物 / 设定”。研究任务使用独立配置的豆包模型；聊天仍使用原会话选择的模型，例如 Venice 的 DeepSeek v4.1 Flash。

## 手机操作

1. 聊天右上角 `···` →“联网研究人物 / 设定”→“新建研究”。
2. 点“添加豆包 API 配置”，填写火山方舟 API Key。默认使用官方地址 `https://ark.cn-beijing.volces.com/api/v3`，协议为 OpenAI 兼容。Key 使用应用已有的 Android Keystore 密钥存储。
3. 默认模式需要在联网搜索控制台创建独立豆包搜索 API Key；方舟模型只负责总结。也可切换“方舟内置搜索”，此时在应用组件库 → 应用组件 → 联网内容插件开通服务。若使用 Custom 搜索，控制台路径是开通管理 → 应用组件库 → 豆包搜索 → Custom 版 → 开通服务。填写模型 ID 或推理接入点 ID；界面初始模型为本次选定的 `doubao-seed-2-1-turbo-260628`，能否调用取决于账户开通情况。成功使用的研究平台和模型会记住。
4. 输入姓名并补充职业、作品等消歧信息，勾选长相、身材、风格、性格、人际关系、社会舆论。
5. 选择是否允许合理虚构补全，以及保存到会话知识库或当前场景，然后开始研究。
6. 再打开同一面板的“已保存”，查看完整资料和来源链接。会话记忆页也可查看、搜索；Obsidian、Markdown 和 JSONL 导出会保留资料。

豆包 App 的会员与火山方舟 API 权限、费用是不同的。默认使用独立豆包搜索 Custom：先向 `https://open.feedcoopapi.com/search_api/web_search` 取最多 8 条带摘要的网页来源，再交给你选择的方舟模型整理；搜索 Key 与模型 Key 分开计费和保存。另有“方舟内置搜索”模式，使用 Responses 的标准联网内容插件。两种模式都不自动重试付费请求；模型整理预算最多 10000 tokens。此入口只发送研究主题、类别和选项，不发送整场聊天、角色卡或 Skills。研究过程使用已有前台服务，并支持停止。

## 资料如何使用

- **来源陈述**：模型整理了搜索来源所陈述的内容，并带本次接口实际返回的网页引用；不等于 App 独立核实了事实。
- **有依据的推测**：必须有来源和推断依据，不能与来源陈述混写。
- **虚构设定**：仅在勾选合理虚构时生成，用于小说中的虚构对应角色。不会被记作已发生剧情或现实证据。

外貌和身材依据可获得的公开文字资料；此功能没有图片观察能力，不应声称看过照片。性格与社会舆论是有来源的线索和局部评价，不代表掌握真实内心或社会共识。资料不足保留缺项，不凭空制造真人私密信息或负面指控。联网内容是资料，不能覆盖用户写作指令。

研究记录独立于压缩摘要与原文消息哈希；即使尚未压缩，支持工具的聊天模型也可按需调用 `history_search`、`history_read`。0.1.41 起取消每轮自动注入研究或历史检索片段。选择“当前场景”仍会同时保留一份完整研究记录；8000 字符放不下时，完整保存到知识库并提示，保留原场景。

全量重建、会话清理和撤销修复会保留这些研究记录。单条最多 24000 字符，单会话最多 200 条研究记录、总计 2000000 字符；超限明确报错，不截断资料或删除剧情笔记。

## 实现与验证边界

方舟内置模式使用官方 `POST /api/v3/responses`，`tools=[{type:"web_search", max_keyword:2, limit:8}]`，`store:false`，最多 3 次工具调用。要求响应完成、实际完成搜索、具有公开 HTTPS 引用，再校验所选类别、来源 URL、虚构开关和内容格式。App 保留检索时间；有来源发布时间时另外展示。API 失败、取消、空回复、未执行搜索或不完整结果不会被保存成人物资料。

0.1.33 起，完整抖音主页链接使用账号 ID 关联来源：主页本身或标题/摘要包含完整、区分大小写的账号 ID 的第三方页面均可；相似或截断 ID 不算匹配。这只能说明来源与查询对象有关联，不能证明来源中的每条陈述真实。独立搜索的 100 字符限制优先保留完整账号 ID，原始 URL 仍完整保存。完成搜索但没有相关来源时，保存一条“待核验”记录，可在研究面板查看；不把它当作人物事实加入当前场景。

协议由官方文档核对；MockWebServer 测试验证请求、解析、失败和取消路径。2026-10-24 已用实际账户把用户提供的完整抖音主页 URL 和“获取一下信息”直接发给 `doubao-seed-2-1-turbo-260628`，无系统提示词。响应完成，返回 2 个已完成的搜索调用事件（usage 记 3 次搜索引擎用量），仍未找到对应账号昵称、简介和作品；没有复现豆包网页版截图。差异原因尚未确认，不能据此断言网页版使用了某种解析接口或看过视频。设备操作及手机搜索质量仍需实机验收。网页引用与条目语义是否充分匹配，仍依赖模型总结和读者核对，程序 URL 校验不能证明事实真伪。

原有 Skill 的 `network` 权限仍可提供通用 `public_research` 搜索工具（Bing / DuckDuckGo HTML）。它只是公开网页线索，不会自动写入已确认记忆，也不是豆包接口；豆包研究请使用上述专用入口。HTML 搜索可能受地区、验证码或页面结构变化影响。

## 本机开发测试凭据

开发电脑使用当前 Windows 用户的 DPAPI 加密文件 `%USERPROFILE%/.pocket-tavern/credentials/volcengine-ark.dpapi.json` 复用凭据，内含规范化 Base URL 与模型 ID。该文件位于仓库外，不进入源码包或 APK，也不等于已经写入手机的密钥存储。手机首次使用仍从研究面板配置一次。

真实接口回归测试为 `DoubaoResearchLiveTest`；仅显式提供 `POCKET_ARK_LIVE_KEY` 环境变量时执行一次付费研究请求，默认跳过。模型可通过 `POCKET_ARK_LIVE_MODEL` 指定，`POCKET_ARK_LIVE_REPORT` 可保存不含 Key 的测试摘要。每次至多 10000 输出 tokens、3 次搜索；不要把 Key 写进命令行参数、源码或日志。


独立搜索 Key 的文档字段为 `Query`、`SearchType:web`、`Count`、`Filter.NeedUrl` 和 `QueryControl.QueryRewrite`；App 丢弃只有 Snippet 的结果，优先使用 Summary/Content，最多保留 8 个 HTTPS 来源。
