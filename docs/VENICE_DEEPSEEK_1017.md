# Venice · DeepSeek V4.1 Flash (1017) 写作设置

适用版本：0.1.48。适用目录 ID：`deepseek-v4-1-flash-1017`，平台协议必须为 Venice。用户界面里的名称可能不同，请以模型 ID 为准。

## 在原会话应用

1. 在模型页刷新 Venice 目录，回到原会话，确认选中上述模型。
2. 打开聊天右上角菜单 → **DeepSeek 写作调优**。
3. 日常续写先选 `low`；复杂剧情可选 `high`。`none` 直接生成，`max` 用于需要更多推敲的任务。选项只取该模型目录实际声明的档位。
4. **自定义生成预算** 默认关闭：不发送生成上限，由平台使用默认值，旧正文值和思考预留保留。需要自己设上限时再开启并编辑两项；发送给 Venice 的总预算是两者之和，且不能超过模型目录上限。关闭预算不关闭思考，也不代表平台无限输出。
5. 平台附加提示默认建议关闭，让应用预设、角色卡和 Skills 控制写作风格；此开关对应 Venice 的附加系统提示，不改变平台安全设置。
6. 点击 **应用到本会话**，下一轮生效。不需要新建聊天。原预设保留，可从聊天顶部选回。

## 文字交互下的场景描写要求

本应用的聊天没有可供读者同步观看的镜头，**文字是唯一的画面来源**。因此“场景写得详细”不是可选的文风偏好，而是理解剧情的基本条件。写作请求启用角色/小说规则时，模型应：

- 先交代门、窗、桌、走廊等空间锚点，以及人物相对位置、朝向、视线和移动路线；
- 把复杂动作按发生顺序写出来，说明动作碰到什么、谁做了什么、产生了什么可观察结果；
- 维护钥匙、武器、文件、手机、伤口等关键物件的持有者、位置、可用状态和变化原因；
- 首次出现人物、物件或新地点时给出当前行动所需的可见信息，再推进对话或冲突；
- 用具体动作和状态承载情绪，并在需要时补充相关的光线、声音、触感、气味或温度。

不能用“他走过去”“双方交手”“气氛紧张”“很快解决”或“不再赘述”代替读者需要知道的空间、过程和结果。细节应服务于复原画面和判断行动因果，不能只堆形容词。清楚不等于把正文写成动作清单：影响理解、行动因果和人物关系的步骤要展开，普通过渡可以自然压缩，不必逐一解释无意义的小动作。

## 多人物的个性与自然对白

每个重要人物应有可追踪的目标、利益、恐惧、经历、关系和知识边界。同一件事不要求所有人轮流发表相同意见；他们应因为在意的后果不同而做出不同判断，并通过措辞、句长、停顿、打断、回避、行动习惯和让步边界表现差异。对白应保留潜台词和关系压力，避免所有人使用同一种礼貌程度、句式和“解释—赞同—追问”节奏；行动和选择优先于“他很冷静”“她很善良”等性格标签。人物差异不能违反已确认的经历、关系和认知，也不能为了显得特别凭空添加设定。

模型仍可能漏写；用户可以在“当前场景与连贯性”中补充人物目标、关系、说话方式和不可逾越的边界，或用“纠错”指出谁的反应与既定性格不符。

应用创建当前预设的副本，保留系统提示、摘要提示、角色和 Skills。重复应用可更新专用副本；如果分支或角色默认设置也引用它，则另建副本，不连带改变其他会话。升级本身不会自动将用户的旧预设改为这些推荐值。

再次打开已调优的会话会回填保存值，包括预算开关、较小的输出预算和已开启的平台提示。切换到其他 Venice 模型时，如果该模型不支持原档位，或已开启的自定义预算超过新上限，会建立兼容副本并提示调整；关闭预算时保留休眠额度不裁剪。离线或缺少思考能力信息的目录项须先刷新；预算关闭时无需目录提供输出上限。

这些是根据协议和预算做出的起始设置，不是经过充分对照证明的“最佳小说参数”。模型写作、指令遵循和事实记忆仍会有波动。

## 这次实际修复

- 默认关闭预算，Venice 请求省略 `max_completion_tokens` 和旧的 `max_tokens`。开启后只发送前者，其数值是正文目标与有效思考预留之和；两部分并非独立硬上限。接收端不按该数值裁剪上游返回内容。
- 普通聊天取消整轮 180 秒及读取空闲 120 秒自动超时，等待平台正常结束、手动停止或真实网络中断。系统结束进程/服务仍会中断生成；已收到的思考与正文继续按原流程保存。摘要仍有独立的预算与超时。
- 显式思考档位取自模型目录，不猜测通用的 `medium` 是否支持。不支持的档位、已开启预算超过目录上限的情况，会在本地报错，不自动重试付费请求。
- 仅在目标 1017 且已确认开启思考时省略温度。关闭思考后调优副本使用温度 1.0。其他平台与其他模型保持自己的协议。
- 不把“隐藏思考”当成“关闭思考”：保留流中的推理数据，并保持工具往返所需的历史 `reasoning_content` 回传。
- 旧的纠错和重写消息只保留历史意图标签和原文，不再每条重复附加“本轮暂停/重写”的主动指令。仅当前用户轮使用相应操作规约；其工具续接保持同一轮含义。
- 自动识别明确的无括号“暂停续写 / 设定修正 / OOC”，避免把作者纠错演成角色对白；普通人物动作、对白不因此改成纠错。
- 简单“继续”用于历史检索的场景线索只来自当前用户消息之前的有效正文，不被当前轮“先查资料”的工具过程说明替换。
- 历史压缩和全部重建单独派生参数：Venice 目录明确支持 `none` 时关闭隐藏思考，否则使用平台默认；不继承聊天模型专用档位。0.1.41 的输出预算供续聊摘要与知识增量共用，按摘要模型上限裁剪；完整性和来源校验保留。

已有记忆中遗漏的事实不会因为升级自动补回；可以在“会话记忆”查看原文，或让支持工具的模型按需查询。确需重新提取全部历史时再使用“从全部原文重建记忆”，这会调用摘要模型并产生用量。日常 compact 只整理新增原文，详见 [压缩与按需记忆](COMPACT_MEMORY.md)。

## 如何核对

“设置 → 请求诊断”显示本次实际使用的输出字段和预算、指定与目录默认思考强度、是否发送温度、工具数量、Venice 平台提示开关。日志不保存 Key、聊天正文或推理正文。`HTTP 200` 或 `usage` 本身仍不能确认最终扣款，结算需账单证据。

离线回归覆盖上下文组装、历史纠错作用范围、工具回放、参数请求、跨平台隔离、共享预设和导入导出。它们不能衡量真实模型的文笔。实际测试结果见 [验证记录](VERIFICATION.md)。

手动对照脚本为 `examples/venice-writing-evaluation.py`，默认只输出中性场景计划。显式运行时最多 6 次请求、每次最多 10000 tokens；无自动重试，输出目录不允许复用。比较的是原始参数组合与建议参数组合，不能把变化单独归因于某一个参数，也不等于手机端全链路验收。

```powershell
# 只查看计划，不读取 Key、不联网
python examples/venice-writing-evaluation.py
# 使用自己保存的单行 Key 文件显式运行（会产生 API 用量）
python examples/venice-writing-evaluation.py --run --key-file C:/private/venice-key.txt
```

也可使用当前进程的 `VENICE_API_KEY`。默认结果在忽略目录 `evidence/venice-writing-evaluation-1017`，源码包不包含该目录。对照输出需人工核对：是否重新演出旧纠错、角色是否无故知道秘密、物品持有与已完成事件是否回滚、不同人物是否有合理且不同的反应。

## 资料与取舍（2026-10-24）

- [Venice 公开模型目录](https://api.venice.ai/api/v1/models?type=text)：此次目标声明 1,000,000 上下文、131072 输出上限，档位为 `none / low / high / max`，默认 `high`。应用读取下载的目录，不将这份快照硬编码成永久能力。
- [Venice 推理模型说明](https://docs.venice.ai/guides/features/reasoning-models)：按目录选择 `reasoning_effort`；不是所有模型都支持同样档位。
- [Venice Chat API](https://docs.venice.ai/api-reference/endpoint/chat/completions)：输出总预算、附加系统提示、关闭思考与剥离思考返回的区别。
- [DeepSeek 思考模式说明](https://api-docs.deepseek.com/guides/thinking_mode/)：思考模式下 temperature 等采样参数不生效；携带工具时须保留协议所需的历史推理，不能套用旧版模型的“删除全部旧推理”建议。
- [官方 1017 模型卡](https://huggingface.co/deepseek-ai/DeepSeek-V4.1-Flash-1017)：本地推理示例的温度与长度建议不是小说专项测试结论，不将本地超长输出配置直接照搬到手机 API。
- [官方 1017 发布说明](https://api-docs.deepseek.com/news/news261017/)：模型性能与输出取向的背景资料，不能据此保证角色戏质量。
- [社区 V4 角色模式说明](https://github.com/victorchen96/deepseek_v4_rolepaly_instruct)：作为旧版本社区参考，不把角色模式触发词视作 1017 的稳定 API。此次没有复制其思维链指令，也没有改动任何上游 Skill 原文。
