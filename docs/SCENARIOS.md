# 内置剧本

## 从手机开始

安装 0.1.5 后，打开底部“角色”，在“剧本”区选择《极寒末世：从继承庄园开始【重开】》，点击“开始游玩”。应用会创建带原始开场的会话并切到聊天页。后续在同一卡片点击“继续游玩”回到最近一局；“开始新局”创建另一份会话，旧消息、摘要和聊天记忆保留。

你扮演谷若尘，直接输入行动、台词或对零号的心中提问。剧本已包含用户控制主角的叙事规则。新局优先沿用当前会话的可用平台与文本模型；没有可用模型时可以先读开场，再通过聊天顶部的模型选择器选择已配置平台的模型。

这份世界书较大，建议选择至少 32K 上下文的聊天模型，长篇游玩优先更大窗口。已核验的一次开局空间提问约占 23.4K 输入预算，具体用量随问题命中的条目变化；可在聊天菜单查看实际上下文。

世界书默认折叠，在角色页展开后可以查看和编辑。剧本卡的更多菜单可以查看设定或删除剧本。专属预设在设置中可编辑；已有聊天也可切换预设。所有写作 Skills 仍由用户自行勾选，这份剧本不会自动授予工具权限或启用 Skills。

来源是用户指定的 Codex 对话“构思末世空间异能小说”（`01a0c3e0-5db3-79d2-89d4-ffa056cf5360`）中已确认的正式故事，而非根据标题重新编写。采用该对话于 2026-10-19 16:25 保存的正式快照，故事 ID 为 `9699074b-bf09-4a38-ae48-abc513b0f8d7`。原始文件仍留在用户工作区，没有修改线上 NovelAI 故事。

资产位于 `app/src/main/assets/scenarios/`。catalog 和角色卡中的来源元数据包含源快照与开场 SHA-256，catalog 还核验角色卡资产本身的哈希。只搬入故事资料，不包含服务密钥、浏览器状态、测试日志或原始脚本代码。

## 运行差异

NovelAI 的“主角控制检查 4.3.11”依赖其专属生成 hooks、后台审校、存储和 UI API，当前 Android 应用没有对应运行时。这一脚本没有移植或执行，不能保证自动拦截越权叙述、库存错误或其他模型偏差。角色控制规则、秘密知情范围和已确认事实仍由原始预设与世界书约束，聊天可编辑、分支和重新生成。

保留原温度 0.45、最大输出 2,048。原平台的其他采样字段、专属上下文插入位置、token 截断规则和空白 prefill 没有模拟。安卓使用本应用的消息上下文和可回退摘要压缩；摘要提示另外要求保留时间、人物知情、资产变化、授权事项与当前决策点，不能把计划写成完成。生成表现取决于所选 Provider/模型，不承诺与 NovelAI 相同。

## 升级和数据

剧本只在首次遇到时安装；已修改的角色、预设和世界书不被覆盖，主动删除的剧本不在重启时重新添加。恢复旧备份也会补齐首次遇到的内置剧本。平台、模型目录、密钥和已有聊天不被重置。

每局独立保存消息、摘要与聊天记忆；世界设定和角色设定共用，用户明确配置的全局/角色记忆仍按原作用域生效。正式开局的数值不是每轮重置指令，后续进展以该局正文和有效摘要为准。
