### “番茄炒蛋（不加青椒）”事实边界

这条不是一个新编的 Skill，而是对上游规则的使用说明。写作时，用户明确给出的事实、物件、人物选择和禁项优先；没有写出的内容不能因为“看起来合理”就自动补进正文。需要补充时先停在已知事实边界内，不能把“番茄炒蛋”擅自写成“番茄炒蛋加青椒”。`dn-deep-novel` 的 Negative Constraints、`at-adult-tension-original` 的“不替玩家做选择/不加一句玩家没说的话”，以及 `dp-review-consistency` 的“删 > 改 > 加”共同覆盖这类约束。应用只负责把上游原文完整发送给模型，不把这段说明伪装成 GitHub 原文。
