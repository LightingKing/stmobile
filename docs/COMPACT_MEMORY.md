# Compact 与按需记忆（0.1.43）

本功能借鉴 compact 的工作记忆方式，使用当前已配置的摘要模型；不是调用 OpenAI 的加密 compaction 接口。

## 正常续聊

每轮固定携带预设、启用的 Skills、当前有效的唯一续聊摘要和尚未归档的近期对话。知识库不自动检索注入，也不发送整库目录。模型需要核对过去的事实、旧人物状态或前后冲突时，可调用 `history_search`，再按需要 `history_read`。读不到的内容保持未知。只有模型目录标记支持工具时才开放调用；无工具模型不会假装已经检索。

过去轮次的记忆查询及读取结果只保留在本地记录中，不在后续每轮重复发送；当前轮工具链保留完整。聊天正文继续保留。研究等其他工具行为沿用原逻辑。

记忆检索每次生成最多 3 轮、6 个实际调用；同参重复查找、连续两次没有新证据或预算不足时提前停止。合法的搜索、读取与继续分页可以正常衔接，助手的工具查询计划不会被搜索当成过去事实。达到这些条件或设置中的工具轮数后，另发一次禁用工具的最终回答请求，依据已有结果回应，不再只留工具结果。最终请求仍计模型费用；平台若无视禁用工具参数，显示明确失败并停止执行。旧版本停在工具步骤的会话会显示重试入口，原文保留。

## 压缩范围与预算

设置 → 上下文压缩新增“日常输入预算”，默认 65,536 tokens，0 表示使用模型安全输入容量。此数包含固定提示、工具定义、摘要及近期原文；模型本身的上下文容量、输出预留和安全余量仍然是上限。默认接近该预算的 80% 时触发压缩，保留近期轮数仍可设置；不会静默裁掉原文。

从 0.1.43 起，这里的五项数字设置可先清空再输入，小数的 `0.` 中间状态不会被改写。修改后点击“保存压缩设置”才应用；空值或超范围会显示具体错误，不替换已保存值。自动压缩开关仍即时保存。

65,536 与默认 80% 对应的触发线为 52,428 个估算 tokens，即使模型本身支持 1M 也仍受此日常上限约束。进度中的“本次原文约 N tokens”仅是待归档部分，未包含其他固定内容、旧摘要及保留对话。0.1.42 的压缩进度、上下文预览与摘要范围同时显示整轮估算和分类占用；来源范围本身不再被用来解释整轮触发原因。固定注入或必须保留的当前轮即使不带摘要也超预算时，拒绝无效自动压缩，说明需要调整什么；不会为压缩而删除这些设定。

摘要请求独立使用摘要模型的实际容量及“上下文覆盖上限”，并扣除提示、旧工作摘要、输出与安全余量，计算包含 ID、偏移和 JSON 转义后的输入。能装下的新增原文一次发送，不固定按 8192 tokens 切段。较小摘要窗口才分批，单条过长消息按安全字符边界切分。

同一请求输出：

- 新工作摘要：当前场景、人物关系、已发生动作、认知边界、更正、未完成事项和下一步衔接线索。
- 知识增量：人物、关系、事件、约定、地点、更正或事实；每项引用本次输入中的来源消息 ID。

输出总上限按窗口最高 10,000 tokens，包含工作摘要与知识增量，并受平台模型输出限制。它不是原文切段大小。截断、过滤、无效 JSON、伪造来源或来源已变都会阻止应用结果。完整来源范围索引只证明原文归档范围，不代表所有事实都被模型无遗漏提取。

## 持久化与恢复

原文保留，知识增量追加，旧条目不被新摘要覆盖。所有新结果完整后一起提交，再持久化到数据库。每个完整请求结果另存手机私有目录的压缩暂存；同会话、同原文、同摘要提示和模型配置的重试可以复用已完成请求。来源或配置变化会使暂存失效。应用不会自动重试失败的付费请求。

压缩使用独立超时：读取空闲 300 秒、整次请求上限 900 秒、写入 60 秒；超时仍不能判断服务端是否扣款。日志保留实际超时参数和请求结果。

升级会保留已有摘要和笔记，不会自动全量重建。下一次普通压缩继承有效旧摘要，仅整理新增范围。只有主动选择“从全部原文重建记忆”才重新读取整场会话；初次读取大型历史的模型费用不能省略。本地存储与搜索不调用模型，检索文本被发送后仍计输入 tokens；工具续答一般需要另一次模型请求。

## 查看与 Obsidian 导出

聊天菜单 → 会话记忆：查看当前/历次摘要，按人物、关系、事件、约定等筛选知识，按名称或别名搜索，打开对应原文。旧版未分类笔记仍然可读。只有明确实体键才把多条记录组织成同一时间线，不根据同名或别名擅自合并人物。

“导出 Obsidian 知识库”生成 Markdown ZIP，包含分类页、对象时间线、知识笔记、摘要版本和来源双链。无需安装 Obsidian 即可在 App 使用记忆；导出是快照，不是外部 Obsidian 双向同步。

## 验证边界

回归验证使用本地模拟响应、保存重载与截图检查；真实模型的提取质量、主动调用时机和长输入稳定性仍取决于平台与模型，不能由来源哈希检查证明。验收结果见 VERIFICATION.md。
