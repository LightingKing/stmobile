# 小世界（计划，待确认）

状态：**已确认**（2026-11-17，用户回复“按默认开做”）：第 6 节四项都用默认值。

## 用户要的是什么

用户原话整理：

- 主动发消息，其实是要**一个小世界**：角色们在里面生活，会在群里聊天，也会私聊我。
- 我**暂停，就是暂停整个世界**。
- 现在的群聊只是把 6 个以内的角色拉进一个群，我说一句它们回一句，**没什么用**。
- 我不用手机的时候，她们也在聊。**世界在电脑的写作服务上跑**，不受手机后台限制，我打开手机时同步就行。
- 世界有**自己独立的角色列表**，不和平时聊天的角色卡混在一起。
- **剧本就是简单版的世界**。

## 现在已有的东西（2026-11-17 查过代码）

| 已有 | 能拿来用的部分 | 缺的部分 |
|---|---|---|

| 剧情状态（`ScenarioStateSync`） | 人物名册里每人有活动、状态，模型每轮更新 | 只在一个聊天里有效，两轮之间什么都不发生 |
| 电脑写作服务（Node） | 已有自己调模型的先例（乱码修复 `repair.mjs`），常驻运行，有管理页 127.0.0.1:8792 | 不知道角色卡和世界书，这些现在都在手机上拼好再发过来 |

结论：**世界 = 剧本 + 时间 + 一个在电脑上替角色们行动的“导演”**。剧本的内容原样搬过来，群聊的分段和气泡也能复用，新增的是电脑上的世界引擎。

## 1. 世界从哪来

- **从剧本做**：剧本页多一个“做成小世界”。剧本里的人物条目变成世界的**居民**，世界观条目变成世界的世界书，设定、叙事规则、“你扮演谁”一起带过去。
- **居民是复制过去的**，属于这个世界自己：在世界里改居民，不影响原剧本，也不影响角色卡。以后也能把一张普通角色卡**复制**进世界当居民。
- 还没有剧本就先用剧本助手做一个。以后再给剧本助手加“世界模式”，多问每个人的作息、目标、彼此关系（见第 5 节）。

## 2. 世界怎么运转（电脑上）

- **世界数据存在电脑上**（`dataDir/worlds/<id>/`），电脑是唯一的准：设定、居民、世界时间、发生过的事、群聊和私信记录、记忆。手机只是一个窗口。
- **世界时间默认和现实同步走**：现实过一小时，世界也过一小时。她们晚上睡觉，早上可能给你发“早安”。暂停时世界时间停住，恢复后从停住的那一刻接着走（所以世界时间可以比现实慢）。
- **每隔一段时间推进一次**（默认 30 分钟，可调 15–120 分钟）。每次推进是**一次模型请求**，“导演”看到：
  - 世界设定、居民卡和每人当前的状态（在哪、在做什么、心情、打算）；
  - 相关的世界书条目；
  - 最近发生的事、群里最近的话、你和每个人私聊的摘要；
  - 世界的记忆（日记和每个人的记忆，见下）。
  
  它返回一份结构化结果：每人状态怎么变、发生了什么事、群里说了哪几句（可以没有）、谁给你发了私信（可以没有）。服务端存下来，世界往前走一步。
- **你说话时立刻回应**：你在群里发言，或回某人的私信，服务端马上发一次请求让相关的人回你，不用等下一次推进。手机上显示“对方正在输入”。
- **谁知道什么**：每条消息都记下谁能看到（群里的话是群里所有人，私信只有那个人，某个地点发生的事只有在场的人）。请求里写明“只有 X 知道”，要求角色不能说出自己不该知道的事。这是靠提示词约束的，不是硬隔离，偶尔可能说漏，第一版先这样，看实际效果再加强。
- **记忆**：
  - 原始记录：最近一天的事件和消息原样保留。
  - 日记：世界里每过一天，额外发一次请求，把这一天写成一章日记。
  - 每个人的记忆：她对你的印象、答应过你的事、和别人的关系变化，随日记一起更新。
  - 思路和手机上的长篇记忆（0.2.1）一样，只是在电脑上做。
- **电脑关机或睡眠时**：不补跑错过的每一次推进（太费钱）。开机后发**一次**“这段时间发生了什么”的补叙请求，最多补一天，然后照常运行。
- **用哪个模型**：默认用写作服务现在的上游模型，每个世界可以单独选。成人向内容沿用现有的两条线（恋爱只限成年人；真实人物不写性内容和隐私）。
- **管理页**新增“小世界”一页：看时间线、居民状态、暂停 / 恢复、今天用了多少次请求和多少 tokens。手机界面做好之前，就能先在电脑上看她们是不是真的在生活。

## 3. 花费控制（真实模型要付费）

世界会一直自己调模型，必须有上限。默认值如下，都能在设置里改：

- **每天推进次数上限**：默认 40 次，加上你说话触发的回应，**每天总请求上限 80 次**。到上限就自动暂停到第二天，手机上提示。
- **安静时段**：默认 1:00–8:00 居民睡觉，不推进；你在这段时间发消息，她们照样可以被吵醒回你。
- **你长时间不看就放慢**：超过 24 小时没打开过这个世界，推进间隔逐步拉长（30 分钟 → 1 小时 → 2 小时），你一打开就恢复。
- **估算**：一次推进大约输入 8–15k tokens、输出约 1k。按默认设置，一天约 50 次请求，输入 50–70 万 tokens。管理页按实际用量统计。

## 4. 手机上怎么看（App）

- **会话列表里有一行“小世界”**，显示世界名、世界时间和未读数。“＋”菜单和剧本页都能新建。
- **世界页分四栏**：
  - **群聊**：居民们的聊天，按世界时间排，带时间戳。你随时可以插话，也可以 @ 某人。
  - **私信**：谁私聊过你，一人一个会话，和普通聊天一样回复。
  - **居民**：每人一张卡：头像、现在在哪、在做什么、心情、和你的关系。点开可以改设定。
  - **世界**：世界时间、暂停 / 恢复按钮、推进间隔、安静时段、每日上限、今天的用量、模型。
- **同步**：打开 App 或进入世界页时拉取新消息，也可以下拉刷新。消息都在电脑上，手机不用常驻后台。
- **通知（第 W3 步）**：照“自己刷视频”的做法，手机每 15–30 分钟问一次电脑“有没有新私信”（只是查询，不调模型），有就弹通知，点开直达那个私信。
- **原来的群聊保留不动**，小世界是新东西。

## 5. 分几步交付

每一步都是能装能用的版本：

| 步骤 | 内容 | 做完能看到什么 |
|---|---|---|
| **W1**：服务端 0.13.0 | 世界引擎：数据存储、世界时间、定时推进、你说话时的即时回应、暂停 / 恢复、花费上限、补叙；接口；管理页“小世界”。拿内置剧本“极寒末世”做第一个测试世界 | 在电脑管理页上看居民自己生活、聊天、给你发私信，暂停能停住 |
| **W2**：App 0.4.0 | 剧本“做成小世界”、会话列表入口、世界页四栏、同步、在群里和私信里说话 | 手机上看群聊、收私信、回复、暂停整个世界 |
| **W3**：App 0.4.1 | 新私信通知；世界记忆页（日记、每人记忆，可改可补）；居民增删改，把角色卡复制进世界 | 不开 App 也知道谁找你；能管她们记住了什么 |
| **W4**：App 0.4.2 | 剧本助手的“世界模式”：多问每人的作息、目标、关系，直接建成世界 | 用聊天的方式从零建一个世界 |

接口（和现有 `/v1/pocket/*` 一样要令牌）：

```
GET    /v1/pocket/worlds                    世界列表
POST   /v1/pocket/worlds                    从手机传来的剧本内容建世界
GET    /v1/pocket/worlds/:id                设定、居民、状态、世界时间
PATCH  /v1/pocket/worlds/:id                改设置（间隔、安静时段、上限、模型）
POST   /v1/pocket/worlds/:id/pause|resume   暂停 / 恢复
GET    /v1/pocket/worlds/:id/messages?since= 拉新消息（群聊 + 私信）
POST   /v1/pocket/worlds/:id/messages       你在群里或私信里说话，返回回应
DELETE /v1/pocket/worlds/:id                删除世界
```

## 不在这次范围内

- 一个世界里多个群（比如宿舍群、班级群）、多个地点各有聊天。
- 居民之间私聊、你“偷看”她们的私聊。
- 世界里发图片和表情包（第一版只有文字）。
- 居民自己上网刷视频再来分享（可以和“自己刷视频”合并，放在以后）。
- 把现有群聊改造成世界。

## 验证

- **服务端**：单测覆盖世界时间与暂停、推进结果解析、谁能看到什么的过滤、每日上限、安静时段、补叙最多一天、重启后接着跑。用假模型跑一整天的加速模拟，确认不会超上限、暂停后不再调模型。
- **App**：单测覆盖“做成小世界”的转换、同步合并、未读数。模拟器连假服务端走一遍：建世界 → 收群聊和私信 → 回复 → 暂停 → 恢复。
- **真实模型**：W1 做完后，开着真实世界跑 2 小时（约 4–8 次请求），开始前再确认。
