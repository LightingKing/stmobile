# 用你的素材建角色、写卡用 Skills、剧本助手（0.2.9–0.3.0）

状态：**方案待用户确认**（2026-11-15）。

用户提的三件事：

1. 能根据我提供的照片、视频和内容创建角色。
2. 创建角色时可以用角色卡相关的 Skills。
3. 能帮我创建剧本：包含世界观和多个角色，创建时也能用 Skills。创建剧本是一个单独的聊天，可以来回沟通调整；剧本建好之后，才开始正式聊天。

分两个版本交付：**0.2.9 做第 1、2 件**（都在“新建角色”表格里），**0.3.0 做第 3 件**（剧本助手）。

---

## 1. 用你自己的照片、视频、文字建角色（0.2.9）

位置：“角色”页 → 新建或编辑角色 → 表格顶部的“让 AI 帮你写”。

- **新增“添加素材”按钮**，一次可以选多个文件：
  - **照片**：最多 6 张。压缩到长边 1600 像素以内，按照片里记录的方向转正。
  - **视频**：1 段，最长 2 分钟、100 MB 以内。每 15 秒抽一帧，最多 8 帧，当作照片用。
  - **文字**：`.txt`、`.md` 文件，或在新增的“补充资料”输入框里直接粘贴，例如设定集、聊天记录、小说片段。最多约 2 万字。
- **素材的展示方式**和“找到的资料”一样：
  - 列在表格上方，标明“你提供的”。
  - 每张照片和视频截图都可以划掉不用，或者设为头像。
  - 文字可以取消勾选。
- **发给模型的方式**：
  - 能看图的模型会收到你的照片和视频截图，最多 6 张，你提供的排在网上找到的前面。
  - 文字直接放进请求，排在所有网上资料前面。
  - 请求里写明：这些是用户本人提供的素材，外貌按照片写，设定以用户的文字为准。
- **不需要电脑写作服务**：只用你自己的素材时，手机直连任何模型都能用。勾选“先联网找资料”时，会和网上找到的资料合在一起。
- **视频里说的话不会转成文字**：这需要语音转文字服务的密钥（Groq 或 OpenAI），目前没有配置，所以只用画面。以后有了密钥可以再加。
- **复用的代码**：
  - App 里已有但没被用上的 `research/ResearchMedia.kt`：压缩照片、从视频抽帧，并做了大小限制。会补上按方向转正，借用 `storeAvatar` 里的 `upright()`。
  - 现有的找图展示、划掉和设为头像（`CardPicture`、`researchPictures`）。

## 2. 写角色卡时用 Skills（0.2.9）

- **“让 AI 帮你写”里新增“使用 Skills”一行**：点开是和会话设置里一样的 Skill 选择器，可以多选。选择会记住，下次新建角色时默认沿用。
- **写卡请求会附上所选 Skill 的正文**：
  - 加一句说明：按这些 Skill 的写法和要求来写角色卡，但仍然只返回角色卡。
  - 成人向 Skill 仍要先在设置里确认过成年才能选，并附带现有的成年人约束。
- **参考文件**：写卡是一次性请求，模型不能边写边去读 Skill 附带的参考文件。所以篇幅不大的参考文件会直接附上，超出预算的不附，并在表格里提示。
- **占用提示**：Skill 和找到的资料共用模型的输入空间，选择器下面会显示所选 Skill 大约占多少 tokens，太大时提醒。
- **内置 Skill 里目前没有专门写角色卡或世界观的**：0.1.65 时下架了。能用的是你自己导入的，以及内置里相关的几个，比如“角色说话风格档案”“说话风格符合角色设定”“网文对话与台词”“中国国内世界观及社会常识”。
- **角色卡助手**（现有的聊天版写卡）：打开时默认带上这里选过的 Skills，在会话设置里也能改。

## 3. 剧本助手（0.3.0）

### 3.1 怎么开始

- **入口**：会话列表“＋”菜单里的“剧本助手”，以及“角色”页“剧本”一栏的“AI 帮我做剧本”。
- **开始前弹出一个小窗**，可以：
  - 选模型。要支持工具调用，不要求电脑写作服务；在电脑写作服务上还能联网找资料。
  - 选要用的 Skills。默认沿用上次选的，可以选世界观、角色、剧情相关的 Skill。
  - 写一两句想法（可以不写）。
- 确定后打开一个**单独的“剧本助手”聊天**，和普通聊天一样可以：
  - 发照片和文字附件；
  - 在会话设置里改 Skills；
  - 中途换模型。

### 3.2 怎么沟通

- **助手的工作方式**：先问清楚题材、基调、你扮演谁，再逐步提出世界观、主要人物、开场。你说哪里要改，它就改。
- **它每定下一部分，就写进这个聊天的“剧本草稿”**。点聊天顶部的“草稿”按钮，可以随时查看当前写到哪一步：
  - **概要**：剧本名、简介、你扮演的身份。
  - **世界观**：地点、规则、势力、历史等，每条是一条世界书条目，标明关键词或“常驻”。
  - **人物**：每人一条，写清身份、外貌、性格、和你的关系。
  - **开场**：第一条消息，以及叙事规则（模型扮演剧中所有人物时要遵守的写法）。
- **草稿分几次写入**：每次只写一部分，所以几十条世界书也写得下。改某一条就只改那一条。

### 3.3 建好之后

- 你说“可以了”时，助手会把草稿交给 App 生成剧本：一张剧本卡，加上世界观和人物的世界书条目。
- 生成后，剧本出现在“角色”页“剧本”一栏，和内置的“极寒末世”一样：
  - 有“开始游玩”按钮；
  - 世界书条目可以在世界书里再改。
- 剧本助手聊天里也会出现一张卡片，写着“剧本已建好”，点“开始正式聊天”就开一局。
  - 正式聊天由剧本卡担任旁白，扮演所有人物，和内置剧本的玩法一样。
  - 剧情状态和人物名册照常可用：人物条目会用 `【角色：名字】` 的格式写，名册能认出来。
- 剧本助手聊天会保留，之后可以回来接着改。改完再生成一次，会**更新**同一个剧本，不会重复建。

### 3.4 要顺手修的旧问题

- 剧本现在靠 id 前缀 `builtin-scenario-` 判断，用户建的剧本会被归到“角色卡”里。改成内置剧本和用户剧本都能认。
- 人物名册在自己的剧本没有匹配条目时，会拿别的剧本的条目来凑。改成只看自己的。
- 删除剧本时，它的世界书条目一并删除（现在会留下）。
- 数据加载时会清掉“角色卡助手”以外的会话类型。要让新的“剧本助手”类型保留下来。

## 不在这次范围内

- 视频语音转文字（需要密钥）。
- 用群聊的方式玩剧本（每个人物一张卡）。这次沿用内置剧本的旁白方式。
- 把剧本导出成 SillyTavern 格式。

## 验证

- 每个版本都写单测：素材处理和大小限制、Skill 正文进入写卡请求、剧本草稿的每次写入和生成、id 判断、删除时清理世界书。
- 模拟器配假模型实测：
  - 选照片和视频建角色，划掉一张后重写；
  - 选 Skill 后，请求里带着 Skill 正文；
  - 剧本助手里沟通三四轮，生成剧本，点“开始正式聊天”，开场消息和世界书条目都正确。
- 用电脑上的真实模型各跑一次，约需几次付费请求，开始前再确认。
