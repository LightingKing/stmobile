# 电脑管理页重做 + 接入更多模型来源

状态：**已在写作服务 0.16.0 实现**（2026-11-18，用户回复“按这个做”）。实现和设计稿的一处不同：总览的时间带改成近 24 小时（标出今天 0 点），见 `docs/VERIFICATION.md`。可点的样稿：本目录的 `index.html`（双击用浏览器打开就行，数据是假的）；截图：`overview.png`、`models.png`、`add.png`、`worlds.png`、`phone.png`。

用户原话：“电脑端怎么接入新的模型，电脑管理端的界面优化一下诶，别做的像个临时工具一样”。

## 现在电脑端怎么接模型

- 电脑只连**一个**模型来源：`config.json` 里的 `upstreamBaseUrl`（现在是 Venice），密钥在私密目录的 `venice-key.txt`（用 `configure-venice.ps1` 保存）。
- 这个来源目录里的文字模型（Venice 现在约 145 个）**自动出现**在手机“电脑”平台的模型列表里，不用一个个接。换默认模型：管理页“电脑设置”或手机“电脑设置”。
- 想接**别的平台**（比如手机上那个中转站的 `k3.1-pro`、DeepSeek 官方、Kimi、OpenRouter、本机 Ollama），现在只能手改 `config.json` 和密钥文件再重启，而且会**替换掉** Venice。这就是下面第 1 部分要解决的。

## 1. 多个模型来源（写作服务）

- **来源列表**存在私密目录 `sources.json`：名字、类型（OpenAI 兼容 / Venice / 本机 Ollama）、接口地址、是否启用。现有的 Venice 自动成为第一个来源，原来的配置照常有效。
- **密钥**只在电脑管理页填，存在私密目录（每个来源一个文件），页面上只显示末四位，**不会发到手机**，手机也改不了（和现在一样）。
- **添加时先试连**：读一次对方的模型列表，显示读到多少个、多少个能调工具，成功了才能保存。
- **手机上的模型名**：Venice 的模型名不变（已有会话不受影响）；其他来源的模型显示为“来源名/模型名”，例如“中转/k3.1-pro”，避免和 Venice 的重名。
- **请求怎么走**：按模型名找到来源，用那个来源的地址和密钥；默认模型（`pocket-direct`）可以设成任何来源的模型；小世界也能选任何来源的模型。运行记录里写明用的是哪个来源。
- **能力和价格**：Venice 的照旧；别的平台常常不写，就按其他来源里的同一个模型推测（和手机 0.3.4 一样的比对办法），页面上用虚线框标出“推测的”。
- **本机 Ollama**：地址只允许 127.0.0.1（可以是 http），不需要密钥；没运行时显示“没有运行”，不影响别的来源。
- **手机不用更新**：在手机模型页把“电脑”平台刷新一次，新来源的模型就出现了。

## 2. 管理页重做

现在是一整页往下堆的方框，顶上一排跳转链接。改成**左侧固定导航 + 七个页面**，原有功能一个不少：

| 页面 | 放什么 |
|---|---|
| 总览 | **今天的账**：一条 24 小时的时间带，每次请求一道竖线，绿色是手机聊天、黄铜色是小世界、灰蓝是整理记忆，越高用的 tokens 越多，旁边是今天的请求次数、tokens、出错次数；**现在的情况**：模型来源、手机上次连接、小世界、备份、社交平台登录，每行一个状态点，有问题的直接给“去看看/去登录”；**最近的请求** |
| 模型 | 模型来源（卡片：名字、地址、密钥末四位、模型数、上次读取；重新读取 / 编辑；默认模型所在的来源标出来）和“添加来源”；全部模型表格（搜索、按来源/能看图/能调工具筛选，上下文、能力、价格，“设为默认”） |
| 小世界 | 每个世界一张卡：名字（楷体）、运行/暂停、世界时间和下次推进、居民头像、最后一句话、今天的请求用量条；点开是现在的世界详情（时间线、居民、设置、日记） |
| 手机 | 在家 / 在外面的地址和网关 Token（各自可复制）、上次连接，以及怎么在手机上填；手机备份；表情包 |
| 联网 | 现在的“联网搜索”“B 站登录”“社交平台”合在一起 |
| 记录 | 请求记录可按用途、模型、成功/失败筛选，点一行在右侧展开详情；服务日志 |
| 设置 | 写作服务自己的设置（和手机“电脑设置”同一份），说明在左、选项在右 |

**样式**（样稿里能看到）：
- 颜色：墨绿 #173C36（导航、标题）、偏绿的纸色 #EEF0EA（页面）、近白 #FBFBF8（内容区）、黄铜 #B8862F（当前页、主要按钮、默认模型）、深红 #A3263A（只用于删除这类危险操作）。
- 字：页面标题、世界名用**楷体**，像酒馆的招牌；正文用微软雅黑；数字等宽对齐。都是这台电脑自带的字体，不用下载。
- 大部分内容用细线分隔的列表，不再每样东西套一个方框；没有全大写标签。窄窗口时导航收到顶上。
